# tsukumo

**キャラクターと一緒に楽しく仕事をするためのターミナル環境。**
tsukumo が Agent SDK（`@anthropic-ai/claude-agent-sdk`）で Claude Code を子プロセスとして
起こし、会話・ツール実行・許可プロンプト・質問を構造化イベントで受け取る。**表示はすべて
HTML** で、ローカルの HTTP サーバから配り、Orca 内のブラウザタブに出す。**入力もそのページで
行う。**

設計判断・要件・用語の正典は `docs/` にある。**このREADMEはセットアップ手順だけを持つ**
（詳細は `CLAUDE.md` と `docs/architecture.md` を参照）。

## セットアップ

- Bun 1.3 以上が必要
- `bun install` で依存関係をインストール

## 使い方

```bash
bun run start
```

これだけで、Claude Code のセッションが起きて、ビューの配信とレイアウトページのタブが Orca 内に
開くところまで進む。**手で並べるものはブラウザタブ1つだけ**で、`claude` を別のペインで動かす
必要は無い。

- **メインビュー・キャラビュー・サイドバー・入力欄は、CSS の grid で1枚の HTML にまとめてある**
  （`docs/architecture.md`「3つのビューは1枚のページにまとめる」）
- ビューは `127.0.0.1` にだけバインドしたサーバから配られ、**ファイルには書き出さない**
  （会話の内容をディスクに残さないため。`docs/coding-standards.md`「会話内容の扱い」）
- ポートは既定 `7327`。`TSUKUMO_VIEW_PORT` で変えられる（`0` を渡すと空きポートを使う）
- `orca` が無い環境では、タブを開けないだけで配信は続く。タブの自動オープンだけ止めたいときは
  `TSUKUMO_OPEN_VIEW=0` を渡す
- プロセスは動かしたままタブだけ閉じてしまったときは、`scripts/open-views.ts` に
  そのビューの URL（例: `http://127.0.0.1:7327`）を渡すと開き直せる

**hook の登録は要らない。** 表情・衣装・作業の進行はすべて SDK のイベントから決まるので、
`~/.claude/settings.json` に足すものは何も無い（2026-09-12 に旧方針の hook を撤去した）。

## 入力欄（右下）から依頼を送る

右下の領域に依頼を書いて Enter を押すと、そのままセッションへ渡る。実行中は同じボタンが
「中断」に変わる。

- **`/` を打つとコマンドの補完**が入力欄の上に重なって出る。前方一致を先に、続けて部分一致を
  並べ、Tab で確定・Enter で実行・クリックでも確定できる
- **許可プロンプトと質問はページの中で答える。** 「このコマンドを実行していいか」も
  `AskUserQuestion` の選択肢も、入力欄の上にボタンとして出て、押した答えが `canUseTool` の
  戻り値として SDK へ返る。許可モード（毎回聞く／編集は自動／全部許す／プラン）も
  サイドバーから切り替えられる
- **セリフは `speak` ツールで届く。** キャラビューの吹き出しに1件ずつ積まれ、ターンの本文は
  レポートとしてメインビューに出る

**会話はこのプロセスの外へ出ない。** 依頼の文面もイベントもメモリ上で扱うだけで、ディスクにも
ログにも書き出さない（`docs/coding-standards.md`「会話内容の扱い」）。

## 画面レイアウト

**4つの領域（メインビュー・サイドバー・キャラビュー・入力欄）の配置と比率はページ側の CSS が
組む。** 仕切りはドラッグで動かせる。`orca terminal split` のようなペイン分割の道具は使わない
（`docs/requirements.md` 4.7 / `docs/architecture.md`「3つのビューは1枚のページにまとめる」）。

**経緯**: 当初はこの3領域も別々のビューとして開き、`orca terminal split` でペインの形に組み立てる
つもりだった。実機で試したところ、Orca の `tab` 系コマンドにはブラウザタブをペインのグリッドへ
配置する手段が無く（`create` / `close` / `list` / `switch` / `show` / `profile` のみ）、
成立しないと分かった。そのため3領域は1枚の HTML にまとめる形へ変えた。

個別のビュー（`/main` `/character` `/sidebar`）の経路も残してあるので、デバッグ目的で
特定の領域だけを見たいときは、Orca 内のブラウザで直接その URL を開けばよい。
