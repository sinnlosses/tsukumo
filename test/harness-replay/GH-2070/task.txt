## 目的・背景

最終レポートの結論の直後に「作業の記録」（したこと／変えたファイル／確かめたこと／かかった時間の4行）を置く（2026-11-03 に利用者と合意。見本は `docs/research/report-work-record-2026-11-03/mock.html`・`mock.png`）。このタスクはその1行目「したこと」の値を、書き手から画面の手前まで運ぶ。並べて描くのは後段のタスク。

いまタスクで実施した中身は、書き手が `Section` の中の段落に書いていて（例: GH-2068 の最終レポートの「`report-head.tsx` の `TaskId` は…」）、置き場が決まっていない。`report` の a2ui の根 `Report` の props は `src/shared/report/a2ui-report-catalog.ts` が定め、欄の説明は `src/server/report/core/prompt/report-tool.ts`、書き方の条は `src/server/report/core/prompt/report-notation.ts` にある。似た欄の `retrospective` は Report の props から `src/shared/session/a2ui-report-view.ts` を通って面の値になる。

## 決まっていること（蒸し返さない）

- 「したこと」は Report の新しい欄（1段落の文字列。インラインの記法 inline code・太字・リンクだけ効く）にする。`phaseSummary` を並べて代わりにはしない（2026-11-03 利用者決定）
- 書くのは `task` を渡すレポートのとき。省いてよく、省いたら記録の行は出さない
