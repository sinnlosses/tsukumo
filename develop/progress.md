### 2026-09-15 質問を1問1答にした（T-117）

**`AskUserQuestion` の質問を1問ずつ出す形にした。** `QuestionAsk` が全問を縦に積んでいたのをやめ、
`index` の state で `questions[index]` を1枚だけ描く。単一選択は選んだ瞬間に次の質問へ進み、
最後の1問を答えた時点で**全問ぶんの `labels` を1回だけ dispatch する**（`labels[i]` は
`questions[i]` への答え1つ、という契約は変えていない）。進捗（`2問中1問目`）を出し、その行に
「戻る」を同居させた（独立した行にすると、その高さのぶん選択肢が見えなくなる）。
**ユーザーが挙げた2件の不具合も直した**: 自由入力に打っても直前に押した選択肢が光ったままだった件
（単一選択では「選択肢」と「自由入力」を排他にした）と、自由入力の「送る」が押しても何も
起きなかった件（`needsSubmitButton` のとき即 return していた。ボタンごと撤去し Enter で進む形に
統一）。**高さの逃げ道は「説明を畳む」＋「箱の中だけスクロール」**（ユーザーの選択）。選択肢を
ラベル＋説明の1行にし（`/` 補完の `.dispatch-suggestion-item` と同じ形）、`.pending-answer` を
`max-height: 64%`、`.question-card` だけ `overflow-y: auto` にした。**`.dispatch-pending-glow` の
`inset: -1px` が領域の外へ 1px はみ出していた**ので内向きの影に変えた（T-118 が見ている
`overflow-x` そのものは触っていない）。
**実機の目視**（`TSUKUMO_DRIVER=fake`・ポート 7403・1400x900・既定の比率。常駐の 7327 は未使用）:
`.layout-dispatch` は scrollH 335 = clientH 335 / scrollW 669 = clientW 669（着手前は 464 > 335）。
