# 計画を書くとき、`## 解くべき論点` への答えをどこに書くかを決める（振り返り: GH-365）

- 観点: 黄 道案内
- 根拠: GH-365 で委譲先が `## やること` の中に `### 論点への答え` の小見出しを置いたら、`tw edit` が終了コード2で拒んだ（許される小見出しは段・名指すファイル・作業先だけ）。太字の行に変えて通した。`next-task` の `rewrite-plan.md` の依頼文には、論点への答えの置き場が書かれていない
- 出し先: claude-skills の `skills/next-task/rewrite-plan.md`「書き直しから委譲する」の依頼文に、論点への答えは `## やること` の段より前に太字の行で書く（または返却の本文に書く）と足す。`task-workflow` の `WORKFLOW.md`「タスクファイル」の段の形と食い違わないようにする
