# `tw edit` に1つの節だけを標準入力の中身で置き換える口を足す（振り返り: GH-230）

- 札: 黄 道具（14回目）
- 根拠: `## やること` を書くために `tw show` の出力から本文を切り出し直す手書きのスクリプトが、同じセッションの2件続けて1回目に失敗した（GH-228 は awk、GH-230 は python で `## やること` の文字列を `## 目的・背景` の文中に当てて枠違いで拒まれた）。どちらも委譲先が自分で切り出しを書き、打ち直して通った
- 出し先: claude-skills の `task-workflow`（`tw edit`）に、`--section 'やること'` のように見出しを1つ指して、その節の中身だけを標準入力で置き換える口を足し、`/next-task` の委譲の依頼文の `## やること` の記入をそれに替える
