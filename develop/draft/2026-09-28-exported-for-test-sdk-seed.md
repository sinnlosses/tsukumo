# SDK を起こす下ごしらえの関数が「テストのためだけに公開しない」とぶつかっている（振り返り: T-741）

- 札: 黄 正典の不備（1回目）
- 根拠: `buildQuerySeedOptions` / `stopHooks`（駆動の adapter の `sdk-driver`）と `toContextUsage` / `toPlanUsage` のコメントが、「本物の `query()` を呼ばずに検査できるよう切り出して公開している」と書いている。`docs/coding-standards.md`「テストのためだけに公開しない」の例外には載っていない。T-741 の委譲先はコメントを消すと非公開へ戻されうるので残した
- 出し先: 人が決める。(a) 正典に「外の SDK を起こさずに組み立てを検査する口」を例外として足す、(b) 公開をやめ、偽の SDK を差し込める口から検査する形に直すタスクにする、のどちらか
