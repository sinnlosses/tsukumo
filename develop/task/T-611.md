## 目的

前段で作った文字の部品を、残る `components/page/` の画面（会話・キャラクター・成果・使用量）にも行き渡らせる。

## 完了条件

- `src/browser/components/page/` で、**字の段・色・太さ（と `margin`・文字の組み）だけを持つ規則が付いた `<p>` / `<span>`**（空の表示 `.speech-log-empty` `.chat-empty` などを含む）が前段の `Text` に置き換わり、規則が消えている。ほかの見た目も持つ規則を残したときは、その理由を結果に1行ずつ書く
- **置き換えないもの**: トークン消費の画面の `--usage-*` の色を持つ規則と、日記帳の `--diary-gold-*` の色・明朝を持つ規則（語彙と同じ property で画面固有の値を持つ。`docs/design.md` 2章「`components/ui/` の部品（variant の作法と一覧）」）。`<summary>` など `Text` の `element` に無い要素に付いた規則は、要素を増やすか残すかを決めて結果に書く
- 部品の API を広げたなら（`element` の値など）、`test/browser/components/ui/text/text.test.tsx` にその行を足してある
- `test/architecture.test.ts`「components/ui/ の部品の className」が通る
- 会話の画面・キャラクターの画面・成果の画面（日記帳の見開きを含む）・使用量の画面を起動して目視し、字の大きさ・色・太さ・間隔が置き換え前と同じであることを確かめている（何を見たかを結果に書く。モーダルの中も測る）
- `bun run check` が通る

## 背景

- 計画時の実測（2026-09-25）で、`page/` の「字の段と色だけ」の単独の class の規則は 52、うち `--usage-*` の色が 17
- 量が多いのは `page/token-usage/token-usage.module.css`（`--usage-*` が多く、置き換えの対象は少ない）、`page/achievement/achievement.module.css`（明朝と `--diary-gold-*` を使う日記帳）、`page/character/character-screen.module.css`
- `main-view/markdown/report-notation.module.css` は Markdown から生まれる HTML に当たる規則で、React の部品では置き換えられない

## 決まっていること（蒸し返さない）

- 画面固有の色（`--usage-*`・`--diary-gold-*`）は `Text` の語彙に入れず、`className` で上書きもしない。その要素は機能の CSS のまま残す
- **見た目を変えない**
