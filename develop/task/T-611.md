## 目的

前段で作った文字の部品を、残る `components/page/` の画面（会話・キャラクター・成果・使用量）にも行き渡らせる。

## 完了条件

- `src/browser/components/page/` で、文字の段・色しか持たない規則（空の表示 `.speech-log-empty` `.chat-empty` などを含む）が前段の部品に置き換わり、規則が消えている。ほかの見た目も持つ規則を残したときは、その理由を結果に1行ずつ書く
- 部品の API を広げたなら、`test/browser/components/ui/` のテストにその振る舞いを足してある
- 会話の画面・キャラクターの画面・成果の画面（日記帳の見開きを含む）・使用量の画面を起動して目視し、崩れが無いことを確かめている（何を見たかを結果に書く。モーダルの中も測る）
- `bun run check` が通る

## 背景

- 量が多いのは `page/token-usage/token-usage.module.css`（`--usage-ink` を使う）、`page/achievement/achievement.module.css`（明朝と `--diary-gold-*` を使う日記帳）、`page/character/character-screen.module.css`
- `main-view/markdown/report-notation.module.css` は Markdown から生まれる HTML に当たる規則で、React の部品では置き換えられない

## 注意

- 画面固有の色（`--usage-ink`・`--diary-gold-*`）を variant に入れるかは T-606 の結論に従う
- 1コミットに収まらない量だと分かったら、画面単位で後続タスクに切り出してよい
