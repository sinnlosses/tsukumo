## 目的

サイドバーのセッションのプルダウン（`src/browser/features/sidebar/session-switch.tsx`）で、どの行がなんのセッションかを見出しだけで見分けられるようにする。中身を知っている Claude 自身に短い題を付けさせ、tsukumo が SDK の `renameSession()` で書き込む。

## 完了条件

- 仕事のモードで、Claude が付けた題が次に一覧を読んだときの見出しに出る（`SDKSessionInfo.summary` は custom title を最優先するので、一覧側の読み口は変えずに済むはず。変える必要があれば変えてよい）
- 利用者が `/rename` で付けた題を tsukumo が上書きしない
- 題の書き込みに失敗してもターンは止まらない（動作中の一時的な失敗として諦める）
- `renameSession` を呼ぶのは `src/server/adapter/sdk-session.ts`（原則3）。題を付けるかどうかの判断は `src/server/core/` に置き、テストで守る
- `bun run check` が通る
- 目視: `bun run start` で依頼を1つ流し、ターンが終わったあとにプルダウンの見出しが付けた題になっていることを確かめて結果に書く

## 背景

- 見出しは `src/server/core/session-restore.ts` の `headingFrom(value.summary)` が SDK の `summary` をそのまま使い、`session-switch.tsx` の `sessionLabel` が24字（`MAX_HEADING_LENGTH`）で切って時刻を足している
- 2026-09-24 に数えたところ、tsukumo の印が付いた直近40件のうち11件の見出しが「/next-task」、2件が「/clear」で、時刻でしか見分けられなかった。`/rename` 由来の `customTitle` を持つものは8件
- `SDKSessionInfo` には `customTitle` / `firstPrompt` / `gitBranch` / `createdAt` もある（`node_modules/@anthropic-ai/claude-agent-sdk/sdk.d.ts` の `SDKSessionInfo`）。`renameSession(sessionId, title, options)` も同ファイルにある
- 題を受け取る口の候補は `report` ツール（`src/server/adapter/sdk-tool.ts`。仕事のときだけ載る。説明文は `src/server/core/report-tool.ts`）に任意の欄を足す形。専用のツールを足す形でもよい。雑談モードは `report` を載せないので対象外でよい

## 決まっていること（蒸し返さない）

- 方針は「Claude に題を付けさせて `renameSession` で書く」（2026-09-24 ユーザー決定。見出しの選び方を賢くする案・`<select>` をやめる案は採らなかった）
- 題は `MAX_HEADING_LENGTH`（24字）に収まる長さで付けさせる

## 解くべき論点

- 付ける契機: 最初の `report` で1回だけか、論点が変わったら付け直してよいか（`/loop /next-task` のように1セッションで複数タスクを進む場合がある）
- `/rename` の題と tsukumo が書いた題は、どちらも `customTitle` に入るので SDK の値だけでは区別できない。tsukumo が最後に書いた題を覚えておいて見比べる、などの見分け方を決める

## 注意

- `sdk-session.ts` の `SESSION_TAG_DELAY_MS` のコメントにあるとおり、本体はターンの終わりにセッションの要約を自分で書き、その直後に付けた印は消えた実測がある。`renameSession` も同じ競合を受けるかを確かめ、受けるなら印と同じく遅らせる／付け直す
- 会話の中身（題そのものを含む）をログに全文で出さない（`docs/coding-standards.md`「会話内容の扱い」）
- 題を付ける指示は人格ではなく tsukumo 側の条（`report-tool.ts` など）に書く
