## 目的

同梱パックの人格が、実在しないパスを正典として指し、`report` がターンを閉じるようになる前の締め方（レポートのあとに `speak`）を書いたままで、tsukumo 側の条と食い違っている。人格の文面を今の仕組みに合わせる。

## 完了条件

- `characters/*/persona.md` が指す `src/server/core/report-notation.ts` がすべて `src/server/report/core/report-notation.ts` になっている（`grep -rn 'src/server/core/' characters/` が空）
- `characters/tsukumo/persona.md` と `characters/tsukumo-spirit/persona.md` の「締めのセリフの言い方」が、締めを `report` の `closing` で言う形になっている（「締めの `speak` はレポートを渡したあとに言う」のような、`report` のあとに `speak` を呼ぶ前提の文が残っていない）。ターンの終わり方の条は tsukumo 側が正典である、という線引きは変えない
- `chou` など他の同梱パックにも同じ前提の文があれば同じく直す
- `bun run check` が通る

## 背景

- 正典のパスの誤り: `characters/tsukumo/persona.md`（5・104・125行目付近）、`characters/tsukumo-spirit/persona.md`（5・72・91行目付近）、`characters/chou/persona.md`（5行目付近）。実物は `src/server/report/core/report-notation.ts`（T-721 の委譲先が指摘）
- 締め方の食い違い: T-749 で `report` が受け付けられるとターンが閉じ、締めのセリフは `report` の `closing` 引数に入るようになった（`src/server/session-driver/adapter/sdk-tool.ts` の `reportTool`、`report-notation.ts` の「`report` が受け付けられると、そこでターンが終わる」）。人格側の「締めのセリフの言い方」は「締めの `speak` はレポートを渡したあとに言うので、レポートはもう画面に出ている」のまま

## 注意

- ホーム側の `~/.tsukumo/characters/` は同梱パックを覆う（同じ名前のパスがあればそちらが使われる）が、そこは人が直す。このタスクでは触らない。結果の節に「ホーム側にも同じ文があれば直してほしい」と書く
- 人格に書くのは言い回しだけで、呼ぶ回数・位置の条を人格側に書き足さない
