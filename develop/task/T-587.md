## 目的

`src/server/` を機能で割る移行（`docs/design.md` 2章「サーバの機能と、機能どうしの辺」）の最初の段。検査を `server/<機能>/{core,adapter}/` の形に載せ、あとの段は機能の一覧・辺の表・許可リストを直すだけで済むようにする。

## 完了条件

- `docs/design.md` 2章「いまの `src/server/` から移す先（移行の対応表）」で段が「1」の6行（`report/core/` の4つ、`system-prompt/core/` の2つ）が移っている。テストも同じ置き換えで移っている
- 同じ節の「段と、`test/architecture.test.ts` の直し方」の表で、直す段に「1」を含む行が入っている
  - `layerOf` が共有の箱と `server/<機能>/{core,adapter}/` を見分け、知らない機能と `core/` `adapter/` の外に置いたファイルでは throw する
  - `SERVER_FEATURES` と `SERVER_FEATURE_IMPORTS` がある（行はこの段の2機能ぶん）
  - 層ごとの循環の検査がある
  - `SDK_BOUNDARY_FILE` が古い位置と新しい位置の両方を許す
  - 冒頭のコメントが新しい形になっている
- 移したパスを指す記述が直っている（`src/` `test/` `scripts/` の import とコメント、`docs/` のうち `history/` と `research/` 以外、`CLAUDE.md`）
- `bun run check` が通る
- 着手時に対応表の前提（ファイルの有無・import の辺）が崩れていたら、表を直してから移す。移す意味が無くなっていたら `dropped` で閉じてよい

## 背景

- 設計と対応表は `docs/design.md` 2章の2つの節。採った・採らなかった案は `docs/history/decision.md`「design.md 2. 全体構成 / ディレクトリ（`src/server/` を機能で割った）」
- まだ移していないファイルは `server/core/` `server/adapter/` の直下（共有の箱と同じ場所）に居るまま動く。「共有の箱は機能を読まない」と「共有の箱に1つの機能だけが読むファイルが無い」の検査は、移し終える最後の段で掛ける

## やること

着手時に調べ直した前提（2026-09-25）: 段1の6ファイル（`src/server/core/` の `report-notation.ts` `report-review.ts` `report-tool.ts` `report-violation.ts` `speech-cadence.ts` `system-prompt.ts`）とそのテスト6本（`test/server/core/`）はすべて在る。import の辺も表どおり（`report-review` → `report-violation` だけが `report` の中の辺、`system-prompt` → `report-notation`（`report`）・`chat-manner` `chat-memory-prompt`（未移動の `chat`）・`session-driver`（未移動の `session-driver`）。`report` を読むのは `session-restore`（`core`）と `fake-driver` `sdk-driver` `sdk-tool`（`adapter`）、`system-prompt` を読むのは配線の `session-start.ts` だけ）。表は直さずに移す。

1. 6ファイルを `src/server/report/core/` と `src/server/system-prompt/core/` へ、テストを `test/server/report/core/` と `test/server/system-prompt/core/` へ `git mv` で移し、相対 import の深さを直す
2. 読み手（`session-start.ts`・`session-restore.ts`・`fake-driver.ts`・`sdk-driver.ts`・`sdk-tool.ts` と各テスト）の import と、移したパスを指すコメント（`{@link}` を含む）を直す

4. `docs/`（`history/` と `research/` 以外）と `CLAUDE.md` の、移したパスを指す記述を直す（`docs/design.md` の対応表そのものは残す）
