## 目的

`git stash list` の一番古い項目（`On main: PTY路線（T-032後の未コミット分。方針転換で不採用）`）を残すか捨てるかを決める。

## 完了条件

- 捨てるなら、その項目だけが `git stash drop` で消えていて、他の stash の項目が残っている
- 残すなら、理由が完了時の結果に書かれている

## 背景

TUI を捨てて SDK で動かす方針へ変えたとき、PTY で本体を包む路線の未コミット分を stash に退避したまま、戻す予定が無い。stash の stack は全作業ツリーで共有なので、残っていると誰かが素の `git stash pop` を打ったときにこれが当たりうる。

## 決まっていること（蒸し返さない）

- 捨てる（2026-09-24 ユーザー決定）。タグなどに移して残すこともしない

## やること

1. `git stash list --format='%gd %H %gs'` で件名の項目の SHA（`0605bd7`）を当て、その `stash@{n}` だけを `git stash drop` する

## 注意

- 人の判断待ち（`hold`）で、stash の消去は破壊的な git 操作なので**利用者の承認が要る**（`loopable: N`）
- 並行するセッションが stash を積んでいることがある。`stash@{n}` の番号は動くので、消す直前に `git stash list --format='%H %gs'` で件名から当てる

## 結果

捨てた（2026-09-24 ユーザー決定）。`git stash list` の SHA `0605bd7`（`On main: PTY路線（T-032後の未コミット分。方針転換で不採用）`）を `stash@{0}` と当てて `git stash drop` した。stash に積まれていたのはこの1件だけで、ほかに消えた項目は無い（drop 後の `git stash list` は空）。
