## 目的

全画面で共有する枠（レイアウト・画面のナビの帯・サイドバー）を、手本の `components/domain/`（AppHeader・AppLayout の置き場）に合わせて移す。

## 完了条件

- `src/browser/features/layout/` `screen-nav/` `sidebar/` の中身が、`docs/design.md` の対応表（T-581）どおり `components/domain/` の下（と、表が `features/` に残すとしたものはそこ）にある。テストも `test/browser/` の同じ相対パスへ移っている
- `test/architecture.test.ts` の `BROWSER_REGIONS` など機能の一覧から、移した機能が表どおりに外れている（または新しい箱の規則に置き換わっている）
- 古いディレクトリにファイルが残っていない。`main.tsx` の import が新しいパスを指す
- `bun run check` と `bun run build` が通る。移したあとに画面を1回開き、帯・サイドバー・領域の境目のつまみが以前と同じに見えることを目視で確かめ、何を見たかを結果に書く

## 背景

- `features/layout/`（`layout.tsx` `presentational-layout.tsx` `layout-resizer.tsx` `split.ts` `hooks/use-layout.ts`）、`features/screen-nav/`（`components/` に7部品と `.module.css`、`domain/` に4ラベル、`hooks/` に3本）、`features/sidebar/`（`task-section.tsx` が置かれる機能 `task-board` を import する、唯一の「領域 → 置かれる機能」の辺）
- 移す先・依存の向きの正典は T-581 が書く `docs/design.md` 2章
