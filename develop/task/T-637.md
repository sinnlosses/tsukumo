## 目的

キャラクターの画面（`src/browser/components/page/character/`）を、`docs/design.md` 2章の
`components/page/` の規約（直下の container / presenter はページに1対だけ、部品は1部品1ディレクトリ）に
合わせる。

## 完了条件

- `page/character/` の直下に残るのは `domain/` `hooks/` `components/`（あるものだけ）と
  `character.tsx` `presentational-character.tsx`（と、使うなら `character.module.css`）だけ
- create / edit / list の画面は `components/` の下の部品になり、各部品は `components/<部品>/` の
  1部品1ディレクトリになっている
- 画面の見た目と振る舞いが変わっていない（一覧・作成・編集・削除の確認を目視で確かめ、何を見たかを
  結果に書く）
- `bun run check` が通る

## 背景

- container 相当が4つ（`character-screen.tsx` `character-create.tsx` `character-edit.tsx`
  `character-list.tsx`）、presenter が2つ（`presentational-character-create.tsx`
  `presentational-character-edit.tsx`）直下にある。CSS は `character-screen.module.css`
- `components/` の下の部品（`portrait-card.tsx` など13個）はファイルを直に置いている
- `hooks/` の `use-character-create.ts` `use-character-edit.ts` は create / edit の部品だけが使う
  （規約では `components/hooks/` か部品の中が候補）
- `main.tsx` が `CharacterScreen` を直に import している

## やること

前提を洗い直した（着手前の実物確認）:

- `src/browser/components/page/character/` の中身は「背景」の記述どおりだった（container 相当4つ
  `character-screen.tsx` `character-create.tsx` `character-edit.tsx` `character-list.tsx`、presenter
  2つ、CSS 1つ、`components/` 直下の部品13個、`hooks/` 3つ）。テストは
  `test/browser/components/page/character/` に `character-screen.test.tsx` `character-create.test.tsx`
  `character-edit.test.tsx` `use-character-create.test.tsx` `use-character-edit.test.tsx` の5本
  （`character-list.tsx` と `components/` 直下13個にはテストが無い）。`main.tsx` は
  `CharacterScreen` を直に import していた——想定崩れは無く、作業をそのまま進める
- 決めた表のとおりに `git mv` で移した。`character-screen.tsx` は「決まっていること」の表どおり
  `character.tsx`（container）+ `presentational-character.tsx`（2段組の JSX）+
  `hooks/use-character.ts`（`createOpen`/`createKey` の state と開閉の呼び先。`CharacterCreateDialogModel`）
  の3つに割った。振る舞いは変えていない（`key` で作り直す下書きの掃除の仕組みもそのまま）
- 相対 import は、旧パス→新パスの対応表を持つ小さな変換スクリプト（node）で機械的に計算して
  書き換えた（手計算の depth 違いを避けるため）。書き換え後は `bun run typecheck` /
  `bun run lint` が無エラーで通ることで正しさを確認した
- テストも同じ形で `git mv` した
  （`character-screen.test.tsx` → `character.test.tsx`、`character-create.test.tsx` →
  `components/character-create/character-create.test.tsx`、`use-character-create.test.tsx` →

  `components/character-edit/character-edit.test.tsx`、`use-character-edit.test.tsx` →
