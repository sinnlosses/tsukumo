## 目的

Bun から Node + Vite + Vitest へ移したあと、bun に残る最後の役目（パッケージ管理・scripts の連鎖・
`tsukumo` コマンドの置き場）を pnpm へ移し、bun を開発環境から外せる状態にする。

## 完了条件

- `bun.lock` と `bunfig.toml` が無く、`pnpm-lock.yaml` がある（`pnpm import` か `pnpm install` で作る）。
  `pnpm install --frozen-lockfile` が通る
- `package.json` の scripts に `bun` の文字が残っていない（`check` などの連鎖は `pnpm run …`）。
  `packageManager` で pnpm の版を固定する
- `mise.toml` から bun が外れ、pnpm が入っている（`package.json` の `packageManager` と版を揃える）
- 型だけ使っている `hast` の宣言（`@types/hast`）が devDependencies にあり、pnpm の厳格な
  `node_modules` で型検査が通る。ほかに未宣言の依存が見つかれば同じく足す
- 依存の install スクリプトが要るもの（esbuild など）は `pnpm.onlyBuiltDependencies` に並べてある
- `README.md` のセットアップと CLAUDE.md の「セットアップ / 環境構築」「よく使うコマンド」が pnpm の手順に
  なっている（`tsukumo` コマンドは本体で `pnpm link --global`）
- 検証コマンド `pnpm run check`（いまの `bun run check` の置き換え）が通る

## 背景

- 2026-09-27 に数えた bun の残り（T-683・T-684 のあとに残る分）: `package.json` scripts の `bun run`
  連鎖（`dev`・`build`・`typecheck`・`test:e2e`・`check` など）、`bun.lock`、`mise.toml` の `bun = "1.4.2"`、
  `tsukumo` コマンド（`bun link` → `~/.bun/bin/tsukumo`。`BUN_INSTALL` 未設定なので常に `~/.bun`）
- 未宣言の依存を bare import と `package.json` で突き合わせた結果は `hast` の1件だけ
  （`src/browser/components/page/conversation/components/main-view/markdown/` の `code-file-name.ts`・
  `task-check.ts`・`markdown.tsx` が `from "hast"` を型で import。いまは推移的な `@types/hast` が
  巻き上げられて解決している）
- `src/server/view-server/adapter/vendor-asset.ts` は `node_modules/{highlight.js,chart.js,mermaid}/…` を
  直に読む。3つとも直接の依存なので pnpm でも直下にシンボリックリンクが張られる（動かしては確かめていない）
- pnpm 10 は依存の install スクリプトを既定で走らせない

## やること

2026-09-27 に前提を数え直した結果、背景の記述はいまも成り立っている（作業は要る）。

- `mise.toml` から `bun = "1.4.2"` を外し、`pnpm = "10.34.5"` を足す。この作業ツリーで
  `mise install` を打って pnpm を入れる
- `package.json`: `scripts` の `bun run` を全て `pnpm run` に置き換える。`packageManager` に
  `pnpm@10.34.5` を足す。`engines.bun` を外す（pnpm の版は `packageManager` が固定するので
  `engines` ブロックごと削ってよい）
- `devDependencies` に `@types/hast` を足す（`hast` を型で import している3ファイルのぶん）
- `bun.lock` を消し、`bun install` の代わりに `pnpm install` を打って `pnpm-lock.yaml` を作る
- `pnpm install` の出力で「ignored build scripts」に挙がるパッケージ（esbuild など）を
  `pnpm.onlyBuiltDependencies` に列挙する
- `README.md` の「開発」節と CLAUDE.md の「セットアップ / 環境構築」「よく使うコマンド」を
  pnpm の手順に直す（`bun install` → `pnpm install`、`bun run build` → `pnpm run build`、
  `bun link` → 本体での `pnpm link --global` など）
- `pnpm run check` と `pnpm install --frozen-lockfile` が通ることを確かめる
- `.claude/settings.json` の hook・`test/`・`scripts/` は実際に `bun` をサブプロセスとして
  起こしていないかを見る（今回数えた限りでは無い。コメント中の `bun run scripts/x.ts` のような
  使用例の文言は完了条件に無いので今回は直さない）
