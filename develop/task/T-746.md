## 目的

文字で書かれがちな「名前: 説明」「A → B」「A → B → C」「12 → 8」を、既存の塊の欄で視覚に描けるようにする（`docs/research/report-block-richness.md` 2章・7章の2）。

## 完了条件

- `table` のセルに `{ from, to }`、`stats` の項目に `before`、`list` の項目に `label`、`list` の並びに `flow` を足す。前の値は `ink-quiet`、後の値は `ink` で、矢印は文字で描く。`label` は名前と説明の2列（760px 以下は1列）、`flow` は小さな札を矢印の文字でつなぎ折り返す
- 塊の形と説明・Markdown の組み立て・CSS・記法の文面（`REPORT_NOTATION_PROMPT` の表）を合わせ、`text` の塊の説明に「数が2つ以上並ぶなら `stats`」を足す
- `docs/display.md` 4.2 と `docs/glossary.md` を合わせる
- 足した4つの欄がそのレポートに出たかを、使われ方の記録（`src/server/report/core/report-usage.ts`）に数え、集計（`scripts/report-block-usage.ts`）に表を足す（外す基準を欄にも当てるため。`docs/research/report-architecture.md` 6章）
- 4つの欄を使ったレポートを目視で確かめ、何が見えたかを結果に書く
- `pnpm run check` が通る
- T-705 のあとの形で成り立たないと分かったら、理由を書いて `dropped` で閉じてよい
