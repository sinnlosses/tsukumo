## 目的

E2E で置き換えられる低シグナルの単体テストを消し、テストの見直し（2026-09-26 合意）を締める。

## 完了条件

- `test-audit` の手順（キャンペーンなら `CAMPAIGN.md`）で `test/` を領域ごとに監査し、T-658・T-659 の E2E が守っている振る舞いだけを確かめている単体テストを消している。消した1件ごとに、どの E2E が守るかをタスクの結果に書いている（テストの跡にコメントは残さない）
- `docs/coding-standards.md`「消すかどうか」表の「残す」行（回帰テスト・書式の固定）に当たるものは消していない
- `docs/design.md` 10章「E2E に任せず単体テストに残すもの」に当たるテスト（`sdk-` の写し・台本に無い並び・未知の `type` / `kind`・スキーマ・時刻に依る計算・再接続とバッチとエラー方針）は残している
- 消したあと、カバレッジ（閾値は置かない）で守られなくなった分岐が無いかを見て、あれば E2E か単体テストで埋めるか、埋めない理由を「埋めないと決めた穴」に書いている
- 消す前後のテスト件数と `bun run check` の所要時間を結果に書く
- `bun run check` が通る
- 領域が広く1コミットに収まらないと分かったら、領域ごとのタスクに分けて登録し、このタスクは最初の領域だけにしてよい

## 背景

- 消す判定は `docs/coding-standards.md`「消すかどうか」表の「E2E の台本が通している振る舞い」の行と、その下の「E2E の台本が通している、とは」の段落に従う
- 2026-09-26 時点で 206 ファイル・2705 件（`test/shared` 33 ファイル、`test/browser/components/page/*` が最も多い）
- `scripts` と直下のテストは T-627 で監査済み（全92件を残した）
- 委譲の縛り（fork を立てない・跡にコメントを残さない）は T-649 がスキルに書く

## やること

調べ直した前提（2026-09-26、`7c3a61e0` の上）:

- 単体テストは 207 ファイル・2718 件、E2E は 14 ファイル・22 件。`bun run check` は 100 秒
  （単体 26 秒・E2E 72 秒）で全部通る
- E2E（T-657・T-658・T-659）が期待値で固定しているのは**場面を流し切った最後の1枚**の DOM の
  構造とメッセージの列だけ。押したのは「許可」と入力欄の ⌘Enter の2つで、札の頭の ‹ › や一覧・
  ログ・質問の選択・画像・補完には触れない。`class`・`style`・`title`・`tabindex`・`placeholder`・
  `document.title` は成果物に残らない
- E2E が画面に出すのは会話の画面（メインビュー・キャラビュー・入力欄・雑談のログ）とサイドバーの
  一部。成果・キャラクター・トークン消費の画面は E2E が無い
- 領域が広く1コミットに収まらないので、**このタスクは最初の領域「会話の画面」
  （`test/browser/components/page/conversation/`、27 ファイル）だけ**にする。残る領域
  （`test/browser/components/domain/sidebar/`・`test/browser/features/task-board/`・`test/shared/`・
  `test/browser/stores/`・`test/server/`）は領域ごとの後続のタスクにする

手順:

1. 会話の画面の 27 ファイルの宣言を1件ずつ台帳に入れ、R/F/C/D を付ける。D にするのは、疑似
   セッションに同じ並びの場面があり、シナリオの期待値（DOM の構造かメッセージの列）がその結果を
   固定しているものだけ。操作（押す・打つ・閉じる）・時刻・`class` / `title` にしか出ない状態・
   回帰テスト・書式の固定・未知の値は R
2. D にした契約ごとに本番のコードへ変異を1つ入れ、keeper の E2E が落ちることを確かめてから
   戻す（退避したコピーから戻す）
3. D を消し、消したあとに要らなくなった準備（関数・import）を片付ける
4. 消す前後のテスト件数と `bun run check` の所要時間を比べる
