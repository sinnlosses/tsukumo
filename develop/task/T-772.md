## 目的

docs の組み替えの仕上げ。どのファイルを開けばよいかを、各ファイルの冒頭と CLAUDE.md の索引だけで決められるようにする。

## 完了条件

- `docs/` の各ファイル（`docs/architecture/` と `docs/architecture/adr/` の入口を含み、`docs/history/`・`docs/research/` は除く）の冒頭に、責務・読む時・直す時が書かれている
- CLAUDE.md の本文と「索引」の表、`README.md` の構成の説明が、組み替え後のファイルを指している
- ADR の置き場（`docs/architecture/adr/`）を CLAUDE.md の索引か `docs/workflow.md` に1行置いている（`domain-modeling`・`maintenance-docs` の既定は `docs/adr/`。スキル側は書き換えない）
- 未完了のタスク本文に旧パス（`docs/design.md`・`docs/chat-mode.md`・`docs/display.md`・`docs/screen-design.md`）が残っていないことを `git grep` で確かめている
- `pnpm run check` が通る

## 背景

- CLAUDE.md は「アーキテクチャ概要」「テスト方針」「索引」で `docs/design.md`・`docs/architecture.md`・`docs/display.md` などを章の句つきで引いている
- `maintenance-docs` スキルの検査（置き場・索引・正典の二重化）がこの形を点検する側にある

## 決まっていること（蒸し返さない）

- 各ファイルの冒頭に責務・読む時・直す時を書く（2026-09-27 のユーザーの指示）

## 注意

- 前の段で張り替え済みの参照は触らなくてよい。ここは冒頭の宣言と索引を揃える段
