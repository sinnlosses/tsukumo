## 目的

委譲先のサブエージェントが、別のエージェントを立てられないようにする。依頼文の1行に頼らず、ツールを持たせないことで防ぐ（2026-09-27 振り返り T-790 のドラフト、ユーザー承認）。

## 完了条件

- claude-skills リポジトリに、`tools` から `Agent` を外したエージェント定義（`agents/<名前>.md`）がある。ほかのツールは今の `general-purpose` と同じものを持つ
- `install.sh` が `~/.claude/agents/` へその定義を張る（スキルと同じく、実ディレクトリや他所を指すリンクは触らず警告する）
- `next-task` スキルの手順5が、委譲の `subagent_type` にその定義の名前を使うと書いている。依頼文から「別のエージェント（fork を含む）を立てない」の1行を外すかどうかも決めて書く
- claude-skills の検証（`check.sh`）が通り、変更が claude-skills の `main` に入っている
- tsukumo 側で docs を触ったなら `pnpm run check` が通る

## 背景

- T-790 の委譲先は、依頼文に「サブエージェントの中では別のエージェント（fork を含む）を立てない」とあったのに、調べもののために `Agent` をフォアグラウンドで1回呼んだ。フォアグラウンドの委譲は、その間 `main` への合図も止める
- 2026-09-27 時点で `~/.claude/agents/` は無い。スキルの実体は `/Users/sinnlos/ghq/github.com/sinnlosses/claude-skills/skills/` にあり、`~/.claude/skills/<名前>` はそこへの symlink（`install.sh` の `ln -sfn` が張る）

## 決まっていること（蒸し返さない）

- 2026-09-27 ユーザー決定: 定義は claude-skills リポジトリに置き、`install.sh` で `~/.claude/agents/` へ張る（tsukumo の `.claude/agents/` には置かない）

## 注意

- `~/.claude/agents/` へ張る（`install.sh` を打つ）のはグローバル設定の変更なので、人がやる。委譲先は打たず、結果に「人がやること」として書く
- claude-skills の本体の作業ツリー（`~/.claude/skills` の symlink 先）では枝を切り替えない。切り替えると全プロジェクトのスキルがその場で変わる。枝が要るなら claude-skills の別の作業ツリーで作業して `main` へ送る
- Agent ツールの `subagent_type` にカスタム定義を指定したとき、`model` の指定で `difficulty` のモデルに変えられるかを確かめる。変えられなければ `dropped` にしてその理由を書いてよい
