## 目的

ほかのキャラクターが「客」として訪ねてこられるように、客になるパックが持つもの（登場と退場の絵・帰りの一言・作り損ねたときの台本）を定義ファイルで表せるようにする。訪問の仕組みは提案 `docs/research/character-visit.md` の論点4・論点7。

## 背景

- 定義の型と検証は `src/shared/character-definition.ts`。`visit` は丸ごと省略できる任意の節にする（無いパックは客にならない）
- 画像の上限は `src/server/adapter/character-edit.ts` の `MAX_IMAGE_FILES_PER_PACK`（`EXPRESSIONS.length + EXTRA_IMAGE_FILES_PER_PACK`）。`peek` の1枚ぶん広げる
- 帳ちゃんのパックは T-516 で作る。設定画 `assets/chou-design-sheet.png` に棚の陰から「ひょこっ」と覗く絵がある
- つくもと帳ちゃんの間柄（つくもが世話を焼く兄貴分）は、ホームのパック（`~/.tsukumo/characters/tsukumo/persona.md`）に1行あるだけで、同梱の `characters/tsukumo/persona.md` には無い

## 決まっていること（蒸し返さない）

- 新しい表情は足さない。台本の表情は9つの enum のうちパックが持つものを使う（提案書 論点7）
- `visit` の中身は `peek`（絵）・`farewell`（帰りの短いセリフ2〜3個）・`scripts`（任意。3〜4行の短い掛け合い）
- **あとで元に戻せる形で入れる**（2026-09-25 ユーザー決定: 「上手くいかず元に戻すかもしれないから revert 可能なようにすることが条件」）
  - このタスクの変更は1コミットにまとめ、訪問と関係の無い変更（ついでの整理・名前の変更・整形だけの差分）を混ぜない。`git revert` 1回でこのタスクの分だけ戻せるようにする
  - 訪問のコードは訪問専用の新しいファイルに置き、既存のファイルへの差し込みは呼び出し・分岐・型の足し込みなど最小にとどめる
  - 完了時の結果の節に「差し込んだ既存のファイル」を列挙する（戻すときに見る場所）
  - 訪問のタスクは後ろから順に revert すれば戻る並びにする（前のタスクが後のタスクの部品に依存しない）

## やること

前提を調べ直した結果、`visit` を足す意味はある（前提は崩れていない）。

- `src/shared/character-definition.ts`: `CharacterDefinition` は `toCharacterDefinition`
  でしか作らない形（`Record` の値を1つずつ検証して詰め直す）で、`mini` / `face` と同じ
  「あれば読む・崩れていれば undefined」の書き方がそのまま流用できる。`visit` は
  `RemovableExpression` の削除口のような編集コマンド（`CharacterEditCommand`）が無いので、
  画面からは触らない読み取り専用の節になる
- `src/server/adapter/character-edit.ts`: `MAX_IMAGE_FILES_PER_PACK` は
  `EXPRESSIONS.length(9) + EXTRA_IMAGE_FILES_PER_PACK(3)`。`EXTRA_IMAGE_FILES_PER_PACK` を
  `4` にして `peek` の1枚ぶん広げる。`referencedImageFileNames` は `mini` / `background.image` /
  `face` を数えて `copyPackOnce`（ホームへ写す）・`removeUnreferencedImage`（消えた参照の掃除）の
  両方が使っているので、`visit.peek` もここに足さないと、画面から他の編集をしてホームへ
  パックが写されたときに `peek.png` が写らず参照が壊れる。1行の追加で足りる
- 帳ちゃんのパック（`characters/chou/`）は T-516 で作られ、9 表情のうち
  `default` / `proud` / `curious` / `sad` / `flustered` / `bored` の6つだけを持つ（`thinking` /
  `serious` / `excited` は無い）。`face.png` あり、`mini` / `background` は無い。ライセンスは
  「このリポジトリのために自作したもの（`assets/chou-design-sheet.png` 由来）」で、
  素材ごと同梱されている（画像も `persona.md` も git 管理下）。**T-516 は素材を同梱する扱い**
  なので、`peek.png` も同じ扱いで同梱する
- `~/.tsukumo/characters/` にはまだ `chou` が無い（`tsukumo` のみ）。ホームのパックは
  `tsukumo` だけなので、このタスクで書き換えるホーム側のファイルは
  `~/.tsukumo/characters/tsukumo/persona.md` の1つだけ（帳ちゃんのホーム版はまだ存在しない
  ので「ホームの帳ちゃん persona.md」は無く、間柄を書く対象から外れる。同梱の
  `characters/chou/persona.md` に書けば、ホームに帳ちゃんのパックができたとき同梱の記述が
  下敷きになる）
- `assets/chou-design-sheet.png`（1536x1024, リポジトリ直下 `assets/`）の右下「ちょっとした
  仕草」の列に「ひょこっ」ラベルの、棚の陰から覗く絵がある。切り出しの道具は ImageMagick
  （`/opt/homebrew/bin/magick`。T-516 が地の除去に既に使っており、新規導入ではない）と
  macOS 標準の `sips` の両方が使える。地はアルファがほぼ0の値に character が乗っている形
  （T-516 の知見）ではなく、この「ひょこっ」パネルはカード状に丸ごと不透明（アルファの
  勾配が character と地を分けていない）なので、地の除去は閾値化ではなく**座標での切り出しと
  トリム**で行う
