## 背景

2026-09-24 に `/simplify` の4観点（再利用・単純化・効率・根本対処）でリポジトリ全体を洗った結果の1件（`docs/history/direction.md` の 2026-09-24「改修コストを下げる直し9件」）。

`src/shared/session-state.ts` の `foldSessionEvent` の `case "character-changed"` は、`CharacterInfo`（`src/shared/character.ts`）の13項目（`pack` `name` `accent` … `editable`）を1つずつ手で写している。イベントの型（`src/shared/session-event.ts`）は `{ kind: "character-changed" } & CharacterInfo & { packs }` で `CharacterInfo` をそのまま持つので、`CharacterInfo` に項目を足しても型エラーにならず、畳み込みから黙って抜け落ちる（`CharacterInfo` はこれまで何度も項目が増えてきた）。

## やること

1. `kind` と `packs` を分割代入で外し、残りを `character` にそのまま入れる形にする（`const { kind, packs, ...character } = event` のような形。型を迂回するキャストは書かない）
2. 残りがちょうど `CharacterInfo` になっていることを型で確かめる（`satisfies CharacterInfo` など）

## 完了条件

- `case "character-changed"` の中に `CharacterInfo` の項目名が1つずつ並んでいない
- `CharacterInfo` に仮の項目を1つ足すと、畳み込みを直さなくても `state.character` に届く（`evidence` に確かめ方を書く。仮の項目は戻す）
