## 目的

テストの走らせ手が Bun から pnpm + Vitest へ移ったあとも、未完了のタスクファイルに残っている `bun run` / `bun test` を直し、着手のたびに本文を読み替えなくて済むようにする。

## 完了条件

- `develop/task/` の未完了（todo・hold）のタスクファイルから `bun run` / `bun test` が消えている（`grep -l 'bun run\|bun test' develop/task/*.md` が、完了済みのファイルを除いて0件）
- `bun run check` などは `pnpm run check` などに、`bun run scripts/x.ts` は `node scripts/x.ts` に置き換えている。Bun にしかない口（`--isolate`・`--parallel` など）に触れている本文は、Vitest での意味に直すか、意味が無くなった理由を1行で添えている
- `task` コマンドで1件ずつではなく、1コミットにまとめて直している
- `pnpm run check` が通る

## 背景

- 登録した 2026-09-27 の時点で、`grep -l 'bun run\|bun test' develop/task/*.md` に当たったのは34件
- T-738・T-725・T-726 の3件で、本文を読み替えるか直してからでないと進められなかった（T-726 の委譲先は friction log に「前提ずれ」と書いた）

## 注意

- 完了済み（done・dropped）のファイルの `## 結果` は当時の記録なので直さない
- 並行する作業ツリーが同じタスクファイルを触っていることがある。送るときに衝突したら、main の上で置き換えを打ち直す
