## 目的

ボタンの見た目（枠だけ・塗り・地なし・リンク風・危険）が十数通り手書きされ、中身が同一の規則まである。ボタンの部品を作って顔と大きさ・押された状態を variant で表し、まず `components/domain/`・`features/`・`components/ui/` から置き換える。

## 完了条件

- `docs/design.md` 2章「`components/ui/` の部品（variant の作法と一覧）」の一覧どおりの `Button`（`type`・`variant`・`size`・`pressed`・`disabled`・`onClick`・`className`。props はすべて必須）が `src/browser/components/ui/button/button.tsx`・`button.module.css` にある。顔（枠・地・字の色と hover・focus-visible・押せないとき・押されたとき）は部品が持ち、箱（高さ・余白・角丸）は持たない（リンク風の `padding: 0` のような既定は `:where()`）。押せないは `aria-disabled` の1通りで、押されても `onClick` を呼ばない
- `test/browser/components/ui/button/button.test.tsx` に、`variant` と `size` のすべての値 → 付く class、`type`、押したときの呼び先、`disabled` のときに呼ばれず `aria-disabled="true"` が付くこと、`pressed` → `aria-pressed`（`"none"` では付かない）、`className` が足されることのテストがある
- `src/browser/components/domain/`・`src/browser/features/`・`src/browser/components/ui/image-zoom/image-zoom.tsx` の `<button>` のうち、**顔が一覧の `variant` のどれかと同じもの**が `Button` に置き換わり、顔の規則が消えている（箱と置き方は `className` に残す）。計画時の実測で対象になるのは、枠だけ（`.task-board-close`・`.image-zoom-close`・`.task-run-cancel`・`.sidebar-persona-memory-confirm-cancel`）、accent の枠（`.task-run-ok`）、warn の枠（`.sidebar-persona-memory-confirm-ok`）、リンク風（`.sidebar-block-action`・`.screen-nav-work-go-to-question`・`.screen-nav-work-toggle-all`・`.screen-nav-settings-reset`）、地も枠も無い（`.screen-nav-chat-mode-button`・`.screen-nav-settings-toggle`・`.sidebar-persona-memory-remove`）
- **置き換えないもの**: 押せる行・押せる文字（`.task-id`・`.task-count-chip-button`・`.sidebar-persona-memory-chip`・`.prompt-image-zoom`）。顔が一覧に無いピル（`.layout-tab`・`.layout-reset-split`・`.screen-nav-toggle`・`.screen-nav-work-toggle`）は、置き換えると見た目が変わるなら残す。hover や `aria-expanded` の見た目が顔と違うもの（`.sidebar-persona-memory-remove` の hover が warn、`.screen-nav-settings-toggle` の開いているときの地）は、顔に合わせて変えるか残すかを決めて結果に書く。残したものは理由を1行ずつ書く
- 押せないの書き方を `aria-disabled` に揃えたことで、もと `disabled` だったボタンがフォーカスできるようになった箇所を結果に書く
- `test/architecture.test.ts`「components/ui/ の部品の className」が `Button` を対象にして通る（検査がまだ無ければこのタスクで足す。足し方は T-607 の完了条件と同じ）
- `docs/design.md` 6.1「部品の置き場」の段落に `<Button>` を足してある
- 置き換えた画面（サイドバー・画面のナビの帯（仕事/雑談の切り替え・設定の歯車・いまの作業）・タスクの一覧と表と実行の確認・覚えたことを忘れる確認・画像の拡大）を起動して目視し、押す前・hover・focus-visible・押せないとき・押されたときの見た目を確かめている（何を見たかを結果に書く。hover・押せないときの見た目が顔に揃って変わったものは、どう変わったかを書く）
- `bun run check` が通る

## 背景

- 計画時の実測（2026-09-25）で `<button>` は 93箇所。顔は「枠だけ（`--rule`）」「accent の枠」「warn の枠」「accent の塗り」「`--state-ng` の塗り」「`--state-warn` の塗り」「地も枠も無い（静かな字）」「リンク風（accent の字・余白0）」に分かれる。リンク風は 9箇所でほぼ同一（字の段が label か action かだけ）
- `.task-board-close` と `.image-zoom-close` は中身が同一（`padding: 0.2rem 0.6rem; border: 1px solid var(--rule); border-radius: 0.4rem; background: none; font-size: var(--font-secondary)`、hover で `border-color: var(--accent)`）
- 押せないときの書き方が `:disabled` と `[aria-disabled="true"]` の2通りある。`screen-nav-chat-mode.tsx` は理由（フォーカスを残して `title` を読ませる）を書いて `aria-disabled` を使っている
- `page/` 側の置き換えは後段（T-613）が受け持つ
- 作法は `docs/design.md` 2章「`components/ui/` の部品（variant の作法と一覧）」が正典

## 決まっていること（蒸し返さない）

- `variant` は顔の束ごとに1つの値（`outline` / `outline-accent` / `outline-warn` / `solid-accent` / `solid-danger` / `solid-warn` / `ghost` / `link`）。軸を掛け合わせない
- **箱（高さ・余白・角丸）は段に丸めず、呼び出し側が `className` で渡す**（揃えるかは別の判断として持ち越し）
- 押せないは `aria-disabled` の1通り
- 押せる行・押せる文字は `Button` にしない

## やること

いまのコードで前提を取り直した結果（2026-09-25）。

- `<button>` は対象範囲（`components/domain/`・`features/`・`components/ui/image-zoom/`）に24箇所ある（`prompt-image.tsx` の3箇所を含む）。うち `Button` に置き換えるのは以下13箇所、残り11箇所（押せる行・押せる文字4つ、ピル4つ、`screen-nav-settings-toggle`、`prompt-image-remove`、`prompt-image-zoom` の重複ぶん）は据え置く
- 置き換える対象と variant・size の対応（既存 CSS の `font-size` から size を、border/background/color から variant を実測して決めた）:
  - `outline`・`size="secondary"`: `task-board-close`（`presentational-task-board.tsx`）、`image-zoom-close`（`image-zoom.tsx`）、`task-run-cancel`（`task-run-confirm.tsx`）、`sidebar-persona-memory-confirm-cancel`（`persona-memory-section.tsx`）
  - `outline-accent`・`size="secondary"`: `task-run-ok`（`task-run-confirm.tsx`）
  - `outline-warn`・`size="secondary"`: `sidebar-persona-memory-confirm-ok`（`persona-memory-section.tsx`）
  - `link`・`size="action"`: `sidebar-block-action`（`section.tsx`。`aria-haspopup="dialog"` を持つので `Button` に `ariaHasPopup` を足す）
  - `link`・`size="label"`: `screen-nav-work-go-to-question`・`screen-nav-work-toggle-all`（`screen-nav-current-work.tsx`）、`screen-nav-settings-reset`（`screen-nav-settings.tsx`。もと `disabled` 属性だったので `aria-disabled` に変える）
  - `ghost`・`size="subheading"`: `screen-nav-chat-mode-button`（`screen-nav-chat-mode.tsx`。`aria-pressed` の on/off と `aria-disabled` + `title` をすでに使っており、`pressed` プロパティにそのまま写せる）
  - `ghost`・`size="action"`: `sidebar-persona-memory-remove`（`persona-memory-section.tsx`。`aria-label` を持つので `Button` に `ariaLabel` を足す）
- `Button` の props は完了条件の一覧（`type`・`variant`・`size`・`pressed`・`disabled`・`onClick`・`className`）に加えて、実際に使う口として `ariaLabel: string | undefined`・`ariaHasPopup: "dialog" | undefined`・`title: string | undefined`（すべて必須キー・`?:` は使わない。`Select` の `title` と同じ形）と `children: ReactNode` を持つ。design.md の一覧表は variant の軸だけを挙げたもので、`Select` も `id`・`ariaLabel`・`title` を独自に持っており前例がある
- `size` の対応表は `ui/text/text.tsx` の `TEXT_SIZE_CLASS` をそのまま import して使う（二重に持たない。`注意` 節のとおり）
- `solid-accent`・`solid-danger`・`solid-warn` は今回の置き換え対象に無い（page/ 側は T-613 の範囲）。型と CSS は完了条件の一覧どおりに用意するが、色の配合は `screen-nav-chat-mode-button` の `[aria-pressed="true"]`（地 accent・字 ground・太さ700）に倣った推測値で、目視の対象には含めない
- 置き換えないもの（理由は報告にまとめて書く）:
  - 押せる行・押せる文字（完了条件のとおり）: `task-id`（`task-run-button.tsx`）、`task-count-chip-button`（`task-count-chip-list.tsx`）、`sidebar-persona-memory-chip`（`persona-memory-section.tsx`）、`prompt-image-zoom`（`prompt-image.tsx`。`prompt-image-remove` も同じ理由で据え置く）
  - ピル（顔が一覧に無い）: `layout-tab`・`layout-reset-split`（`presentational-layout.tsx`）、`screen-nav-toggle`（`screen-nav-menu.tsx`）、`screen-nav-work-toggle`（`screen-nav-current-work.tsx`）
  - `screen-nav-settings-toggle`（`screen-nav-settings.tsx`）: `aria-expanded` の開閉と `aria-controls`、Esc の戻り先を預ける `ref`（`toggleRef`）を持つ。`aria-expanded` は `Button` の語彙に無く、`ref` を渡す口も無いので、顔だけ合わせても振る舞いを落とす。据え置く
- `disabled` → `aria-disabled` で振る舞いが変わるのは `screen-nav-settings-reset` の1箇所だけ（他はもともと `aria-disabled` か、`disabled` を使っていない）

## 注意

- `size` は `Text` の size の名前（`label`〜`body`）を使う。`Text`（T-610）より先に進めるなら、名前だけ揃えて表は `button.tsx` に持つ
