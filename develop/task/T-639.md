## 目的

会話の画面を、`docs/design.md` 2章の `components/page/` の規約どおり1ページ（`conversation.tsx` /
`presentational-conversation.tsx`）にし、4領域をその `components/` の下の部品にする。

## 完了条件

- `page/conversation/` の直下に残るのは `domain/` `hooks/` `components/`（あるものだけ）と
  `conversation.tsx` `presentational-conversation.tsx`（と、使うなら `conversation.module.css`）だけ
- `main-view` / `character-view` / `chat-view` / `dispatch` が**中の形を変えずに**
  `conversation/components/<領域>/` へディレクトリごと移っている（中の組み替えは後段の2件）
- `components/domain/prompt-image.tsx`（+`.module.css`）・`domain/api-error-label.ts`・
  `hooks/use-repository-file-paths.ts` が下の表の移し先へ下りている
- `main.tsx` は `<Activity>` の中に `<Conversation />` を置き、`presentational-conversation.tsx` が
  `<Layout>` と `<Sidebar>` を import して差し込み口を埋めている。`test/architecture.test.ts` の一覧が
  枠 / 画面 / 置かれる機能 の3種類に分かれ、「画面 → 枠」の辺が許されている。2章の表と木・6.1（部品の木）が
  新しいパスに合っている
- 画面の見た目と振る舞いが変わっていない（依頼・レポート・吹き出し・入力欄・雑談モードへの切り替えを
  目視で確かめ、何を見たかを結果に書く）
- `bun run check` が通る

## 背景

- いまは `conversation/` に自分の container が無く、`main.tsx` が `MainView` `CharacterView`
  `ChatView` `Dispatch` を別々に import して `components/domain/layout/layout.tsx` の `<Layout>` の
  差し込み口（`main`（雑談モードなら `<ChatView>`）/ `character` / `dispatch`）に入れている
- 各領域は container / presenter の対・`hooks/`・部品をそれぞれの直下に持つ。`main-view/markdown/` は
  Markdown 一式（部品と道具の `.ts` が混ざる）
- `test/architecture.test.ts` の機能の一覧が `components/page/conversation/<領域>` を持っている
