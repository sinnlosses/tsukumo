## 目的

会話の画面を、`docs/design.md` 2章の `components/page/` の規約どおり1ページ（`conversation.tsx` /
`presentational-conversation.tsx`）にし、4領域をその `components/` の下の部品にする。

## 完了条件

- `page/conversation/` の直下に残るのは `domain/` `hooks/` `components/`（あるものだけ）と
  `conversation.tsx` `presentational-conversation.tsx`（と、使うなら `conversation.module.css`）だけ
- `main-view` / `character-view` / `chat-view` / `dispatch` が**中の形を変えずに**
  `conversation/components/<領域>/` へディレクトリごと移っている（中の組み替えは後段の2件）
- `components/domain/prompt-image.tsx`（+`.module.css`）・`domain/api-error-label.ts`・
  `hooks/use-repository-file-paths.ts` が下の表の移し先へ下りている
- `main.tsx` は `<Activity>` の中に `<Conversation />` を置き、`presentational-conversation.tsx` が
  `<Layout>` と `<Sidebar>` を import して差し込み口を埋めている。`test/architecture.test.ts` の一覧が
  枠 / 画面 / 置かれる機能 の3種類に分かれ、「画面 → 枠」の辺が許されている。2章の表と木・6.1（部品の木）が
  新しいパスに合っている
- 画面の見た目と振る舞いが変わっていない（依頼・レポート・吹き出し・入力欄・雑談モードへの切り替えを
  目視で確かめ、何を見たかを結果に書く）
- `bun run check` が通る

  `ChatView` `Dispatch` を別々に import して `components/domain/layout/layout.tsx` の `<Layout>` の

## やること

調べ直した前提（2026-09-26）: `page/conversation/` の直下はいまも4領域のディレクトリだけで、
container は無い。`main.tsx` が4領域を別々に import して `<Layout>` に差し込んでいる。下ろす3ファイルの
読み手は、`prompt-image.tsx` が `main-view/turn.tsx`・`chat-view/components/chat-log.tsx`・
`dispatch/presentational-composer.tsx`、`api-error-label.ts` が `main-view/turn.tsx`・
`dispatch/hooks/use-turn-status.ts`、`use-repository-file-paths.ts` が `main-view/markdown/repository-link.tsx`・
`dispatch/hooks/use-suggestion.ts` で、どれも会話の画面の中だけ（前提は崩れていない）。

1. 4領域（`main-view` / `character-view` / `chat-view` / `dispatch`）を `git mv` で
   `conversation/components/<領域>/` へディレクトリごと移す（中の形は変えない）。テスト
   （`test/browser/components/page/conversation/<領域>/`）も同じ形で移す
2. 3ファイルを下ろす: `components/domain/prompt-image.tsx`（+`.module.css`、テスト）→
   `conversation/components/prompt-image/`、`domain/api-error-label.ts` → `conversation/domain/`、
   `hooks/use-repository-file-paths.ts` → `conversation/components/hooks/`。`prompt-image.tsx` を下ろすと
   `components/ui/image-zoom/` の読み手が `prompt-image.tsx` だけになり、検査「1つの機能だけが読むファイルは
   無い」が落とすので、これも `conversation/components/prompt-image/components/image-zoom/` へ下ろす
   （作業中に分かった。表には無い）
3. 移したファイルと、それを指すファイルの相対 import を移し先に合わせて直す（一時スクリプトで機械的に）
4. `conversation.tsx`（`Conversation`。`chatMode` をストアから読んで渡す）と
   `presentational-conversation.tsx`（`<Layout>` と `<Sidebar>` を import して差し込み口を埋める）を作り、
   `main.tsx` は `<Activity>` の中に `<Conversation />` を置く。`<ScreenNav>`・`<DiaryNotice>`・
   `usePortraitPreload`・`OVERLAY_SCREEN` は `main.tsx` に残す
5. `test/architecture.test.ts` の領域の一覧を「枠」「画面」「置かれる機能」の3種類に分け、許す辺を
   「枠・画面 → 置かれる機能」と「画面 → 枠」にする（コメントも合わせる）
6. パスを指す記述（`.ts` / `.tsx` / `.module.css` のコメント、`docs/`（`history/` `research/` を除く）、
   `scripts/`、`test/e2e/`）を `grep -rn` で洗い出して直す。`docs/design.md` 2章の表と木・6.1・
   6.3 の見出し（`test/section-reference.test.ts` が拾う参照も）を新しいパスに合わせる
7. `bun run build` のあと、依頼・レポート・吹き出し・入力欄・雑談モードへの切り替えを撮って、
   見た目と振る舞いが変わっていないことを確かめる。`bun run check` を通す

## 注意

- テストは `test/browser/components/page/conversation/` の下にソースと同じ形で並んでいるので一緒に移す。
  `docs/` と `.module.css` のコメントにあるパスの参照も `grep -rn` で拾って直す
- `T-624`（conversation 画面のテストの刈り込み）と同じテストを触る。先に入ったほうに rebase で合わせる
