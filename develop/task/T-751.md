## やること

前提を調べ直した（2026-09-27）。`components/page/conversation/` の `.tsx` に残る `h1`〜`h4`・
`p`・`span` の実物は、コメント中の記述（`markdown.tsx` の説明文に出てくる `<h2>` 等）を除くと
**28件**で、登録時の見積り（34件）とはずれている。

内訳（置換可10・置換不可18）:

- 置換可10件: `balloon.tsx` の `balloon-text`（1）／`presentational-pending-answer.tsx` の
  `pending-summary`（1）／`presentational-turn-status.tsx` の素の `<span>{elapsedLabel}</span>`（1）／
  `command-suggestions.tsx` の `dispatch-suggestion-name`（1）／`file-suggestions.tsx` の
  `dispatch-suggestion-path`（1）／`notation.tsx` の `report-note-label`（1。色・字の段が標準語彙
  `ink-quiet`/`label` で、`letter-spacing` だけ CSS に残せる）／`mermaid-block.tsx` の
  `mermaid-error`（1。同じく標準語彙 `ink-quiet`/`secondary`）／`turn.tsx` の
  `turn-failure-reason`（1。margin だけで色・大きさを持たない）／
  `presentational-turn-header.tsx` の `h2.turn-title`（1。`Heading` に置き換える。margin・
  min-width だけで、見た目は中の `<button>`＋`Text` がそのまま持つ）と `turn-history-text`（1）
- 置換不可18件、理由は8種:
  - 文字を持たない装飾・入れ物の `span`: `chat-typing.tsx` の3点のドット、
    `nudge-portrait.tsx` の `chat-poke-hint`（`Text` を包むだけの入れ物）、
    `presentational-turn-header.tsx` の `turn-title-chevron`（計5）
  - `id` 属性を持つ（`Text` が転送しない）: `nudge-portrait.tsx` の `hintId` を持つ `span`（1）
  - `aria-hidden` を持つ: `presentational-speech-log.tsx` の `speech-log-more`、
    `presentational-turn-header.tsx` の `‹`/`›`・`turn-history-mark`・`turn-history-position`（計5）
  - `title` 属性を持つ: `presentational-speech-log.tsx` の `speech-log-request-text`、
    `markdown.tsx` の `Anchor` が返す `span`（計2）
  - `role`＋`title` を持つ: `presentational-turn-status.tsx` の通知の `span`（1）
  - react-markdown の差し替え表の1エントリ: `markdown.tsx` の `SectionHeading`（`h4`。動的な
    要素マップなので固定の要素を返す部品では代われない）（1）
  - `{...rest}` で動的な属性・`className` をそのまま転送する: `notation.tsx` の
    `NotationInline`（モデルが書いた class 名・属性をそのまま流すので `styles["…"]` の組み合わせに
    閉じない）（1）
  - 地の色を持つバッジ（`background`＋`color`＋`font-size`/`font-weight` を1つの class が一体で
    持つ。T-750/T-723 で見送った「地の色のバッジ」と同じ形）: `question-ask.tsx` の
    `question-ask-chip`、`presentational-turn-header.tsx` の `turn-newest-badge`（計2）

`test/architecture.test.ts` の重なり検査は `tone`/`size` の値に関わらず、渡す `className` が
`color`/`font-size`/`font-weight` を持てば機械的に落とす（T-723 の実測どおり）。置換可の10件は
いずれもこの3プロパティを持たない、または標準語彙の値と一致するクラスなので、CSS 側から
`color`/`font-size` を削って `Text`/`Heading` の `tone`/`size` に委ねる。

## 注意

- **着手の前に、置き換えられる数と置き換えられない数を数える。** `test/architecture.test.ts` は `Heading` / `Text` に渡した `className` の class が `color` / `font-size` / `font-weight` を持つと、`tone` の値に関わらず落とす（`tone="inherit"` では逃げられない）。画面専用の色（`docs/screen-design.md` 13.2）・語彙に無い太さ・状態違いの入れ子セレクタで色を足す class は置き換えられない
- 直接の文字を持たない飾り・入れ物の `span`、`title` / `aria-hidden` / `role` を持つ要素は部品が属性を渡さないので残す
