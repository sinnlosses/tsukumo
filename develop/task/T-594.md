## 目的

## 完了条件

- `docs/design.md` 2章「いまの `src/server/` から移す先（移行の対応表）」で段が「8」の12行が移っている。テストも同じ置き換えで移っている
- `server/core/` と `server/adapter/` の直下には、表で「動かさない（共有の箱）」の6ファイルしか無い
- 同じ節の検査の表で、直す段に「8」を含む行が入っている

- 移したパスを指す記述が直っている（`scripts/` の `server.ts` `bundle.ts` `port-resolution.ts` の import、`docs/design.md` 5章「session-manager.ts（core）」「server.ts と session-socket.ts（adapter）」を含む）

- `bun run check` が通る
- 着手時に対応表の前提が崩れていたら、表を直してから移す
