## 目的

雑談モードの8ファイルを `src/server/chat/{core,adapter}/` へ移す。

## 完了条件

- `docs/design.md` 2章「いまの `src/server/` から移す先（移行の対応表）」で段が「5」の8行が移っている。テストも同じ置き換えで移っている
- `SERVER_FEATURES` と `SERVER_FEATURE_IMPORTS` に `chat` が足されている（→ `session-driver` `character-pack`）
- 移したパスを指す記述が直っている（`docs/chat-mode.md` と `docs/design.md` 7章のパスを含む）
- `bun run check` が通る
- 着手時に対応表の前提が崩れていたら、表を直してから移す。移す意味が無くなっていたら `dropped` で閉じてよい

## 背景

- 雑談の書き口の型は `core/session-driver.ts` に残る（割らない）。`chat` ↔ `session-driver` の機能の単位の輪は、層ごとには輪にならないので許す（`docs/design.md` 2章「サーバの機能と、機能どうしの辺」）

## やること

対応表の段5の8行の前提を調べ直した結果、崩れていなかった（表はそのまま、8ファイル＋対応する
テスト5本を移す）。

- 8ファイルはすべていまの場所にある: `core/chat-archive-entry.ts` `core/chat-compact.ts`
  `core/chat-manner.ts` `core/chat-memory-prompt.ts` `core/chat-nudge.ts`
  `adapter/chat-archive.ts` `adapter/chat-summary.ts` `adapter/persona-memory.ts`。対応するテスト
  （表で「あり」の5本: `chat-compact.test.ts` `chat-memory-prompt.test.ts` `chat-archive.test.ts`
  `chat-summary.test.ts` `persona-memory.test.ts`）も5本ともある
- import の辺は表・edge表どおり: `chat-summary.ts` は `../character-pack/adapter/character-pack.ts`
  を、`persona-memory.ts` は `../character-pack/adapter/character-edit.ts` と
  `../character-pack/adapter/character-pack.ts` を読む（`character-pack` は T-590 で移動済み）。
  `chat-archive-entry.ts` `chat-compact.ts` `chat-memory-prompt.ts` `chat-archive.ts`
  `chat-summary.ts` `persona-memory.ts` はまだ移していない `core/session-driver.ts`
  （雑談の書き口の型 `ChatArchive` / `ChatSummary` などを持つ）を読む。`chat-manner.ts`
  `chat-nudge.ts` は外部 import を持たない
- **まだ移していない側からこの機能への読み手が多数ある**（`src/server/core/session-manager.ts`
  `session-launch.ts` `session-driver.ts`、`src/server/adapter/sdk-driver.ts` `sdk-tool.ts`、
  `src/server/system-prompt/core/system-prompt.ts`、`src/server/character-pack/adapter/character-edit.ts`、
  配線の `src/session-start.ts` `src/current-character.ts`、`shared` の `session-event.ts`
  `command.ts` `persona-memory.ts`）。これらは段7・8まで共有の箱・機能に残るファイルなので、
  設計書の「移行の途中は共有の箱が機能を読む検査を止めておく」に従い、相対 import の深さと
  コメント中のパスだけ直して機能どうしの辺の検査には入れない
- `SERVER_FEATURE_IMPORTS` の `chat` の行は、完了条件どおりだと `session-driver` `character-pack`
  だが、`session-driver` はまだ機能になっていない（`server/core/` の共有の箱のまま。T-593で移す）。
  型は `ServerFeature` に無い名前を許さないので、今回は `character-pack` だけを足す
  （`session-driver` は T-593 で `SERVER_FEATURES` に足したときに一緒に足す）
- 移す意味は失われていない。予定どおり移す

## 注意
