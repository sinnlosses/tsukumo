## 目的

つくもの日記帳を筆で書いたような書体にする（2026-09-25 のフィードバック）。

## 完了条件

- `characters/tsukumo/` に毛筆（筆で書いた字形）の書体ファイルが1つ入り、`character.json` の日記の書体に指定されている
- その書体のライセンスが**再配布を明示的に許している**ことを配布元の文面で確かめ、書体名・配布元の URL・ライセンスを `characters/tsukumo/character.json` の `license` か同じディレクトリのファイルに残す
- 日記の本文に使う字（かな・常用漢字・英数字）が欠けずに出る
- `bun run check` が通り、`bun run build` のあと成果の画面の吹き出しと日記帳の見開きが毛筆で描かれていることを目視で確かめる

## 背景

- 書体を持たせる口は T-598 で作る
- 候補は 衡山毛筆フォント・青柳衡山フォント T など無料の毛筆書体。どれも使う前にライセンスの再配布の条項を読む

## やること

- 口はすでにある（T-598）: `character.json` の `diaryFont` にファイル名を書くと
  `src/server/character-pack/adapter/character-pack.ts` の `characterPackFileNames` が
  allowlist に載せ、`/character/<pack>/<file>` から `font/*` の Content-Type で配る。
  受け付ける拡張子は `.woff2` / `.woff` / `.ttf` / `.otf`（`src/shared/character-diary-font.ts`）。
  ブラウザ側（`FontFace` API・`src/browser/stores/session.tsx`）と CSS 側
  （`src/browser/styles/theme.css` / `achievement.module.css`）も T-598 で対応済みなので、
  このタスクでは**書体ファイルを置いて character.json に1行足すだけ**でよい
- 毛筆書体の候補（衡山毛筆フォント・青柳衡山フォント T など無料配布のもの）を WebSearch /
  WebFetch で調べ、**配布元の文面で再配布が明示的に許されているか**を確認する。割れる・
  見つからない場合はダウンロードせず候補とライセンスの要点を報告して止まる
- 許すものがあれば scratchpad（`/private/tmp/claude-501/.../scratchpad/t599`）に取得して展開し、
  ファイルサイズを確認する。数 MB 程度ならそのまま `characters/tsukumo/` に置く。数十 MB で
  サブセット化が要るなら、新しいツール（fonttools 等）を入れずに止めて報告する
- `characters/tsukumo/character.json` に `diaryFont` を追加し、`license` に書体名・配布元 URL・
  ライセンスの要点を書き足す（ライセンス文の同梱を求める場合は同じディレクトリにライセンス
  ファイルも置く）
- 日記の本文に使う字（かな・常用漢字・英数字）が書体に収録されているか確認する（cmap を
  bun/node の標準機能だけで読めるならそれで、無理なら目視で代表的な字を確認する）
- `bun run format` → `bun run check` → `bun run build` を通す
- `~/.tsukumo/characters/tsukumo/` の有無を確認し、あれば同梱パックを覆うかどうかだけ報告する
  （書き換えない）。一時 `TSUKUMO_HOME` + 疑似セッション（`TSUKUMO_DRIVER=fake` /
  `TSUKUMO_OPEN_VIEW=0` / 空きポート）で起こし、架空の日記データで成果画面の吹き出しと
  日記帳の見開きが毛筆で描かれることを目視・撮影で確認し、`document.fonts` の状態も見る。
  起こしたプロセスは `bun run scripts/stop.ts --port <n>` で必ず止める

## 注意

- 再配布を許す毛筆の書体が見つからなければ、候補と各ライセンスの要点を添えて止まり、ユーザーに選んでもらう
- 大きすぎる書体ファイル（数十 MB）は避けるか、日記の本文で使う字に絞ったサブセットを検討する（サブセット化に外部コマンドが要るならユーザーの承認を得る）
- `~/.tsukumo/characters/tsukumo/` にホームのパックがあると同梱のパックを覆う。目視の前にそちらにも反映されているか確かめる

## 結果

- 毛筆の書体「佑字【肅】(Yuji Syuku)」（SIL OFL 1.1。配布元 https://github.com/Kinutafontfactory/Yuji の OFL.txt で同梱・再配布の許可を確かめた）を `characters/tsukumo/yuji-syuku.ttf`（約8MB）として同梱し、ライセンス全文を `yuji-syuku-OFL.txt`、書体名・配布元・ライセンスを `character.json` の `license` に残した。衡山毛筆フォントは再配布を禁じる文面があり見送った。ASCII・かな・常用漢字2136字の収録は `fc-query` の cmap で欠けが0件なことを確かめた
- 検証コマンド: 2674 pass / 0 fail、`bun run build` 成功。一時ホームの疑似セッションで、成果の画面の吹き出しと日記帳の見開きの本文が毛筆で描かれ、`document.fonts` が `loaded` なことを確かめた。`~/.tsukumo/characters/tsukumo/` のホームのパックは `diaryFont` を持たないので、ふだんの起動では同梱の書体が覆われて出ない（書き換えていない）
- 振り返り: 兆候なし
