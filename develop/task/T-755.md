## 目的

`test/e2e/permission-answer.test.ts` が `bun run check` の中でときどき落ちる。イベントの並びを決まった順にして揺れを無くす。

## 完了条件

- 「許可」を押す前に、並びを競う相手（場面の `speech`）が届くのを待つなどして、押したあとの `pending-changed` と `speech` の順が毎回同じになっている。確かめている内容（押すと answer が流れ、答え待ちの箱が消える）は弱めない
- `bun run test:e2e` を同じテストについて繰り返し（10回以上）走らせて落ちないことを結果に書く
- `bun run check` が通る
- 調べて競う相手が別のものだと分かったら、それに合わせて直してよい。揺れが再現せず正体も確かめられないなら、確かめたことを結果に書いて `dropped` で閉じてよい

## 背景

- 落ち方は `toEqual`（`room.settleAndMatch` の比べ合わせ）。許可を押したときの `pending-changed` と、疑似セッションのシナリオ `permission-answer` の場面 `permission` にある `speech`（`afterMs` 200）が別々のタイマーで競い、並びが入れ替わる（T-672 の委譲先の指摘）
- 疑似セッションの手は `src/server/session-driver/adapter/fake-driver.ts` が場面の始まりからの `afterMs` で流す
- T-672 で E2E の入力欄の場面（`input-dispatch`）に同じ正体の揺れがあり、開幕の一言を待ってから送る形で直した（コミット dbe904b0）
