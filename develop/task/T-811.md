## 目的

書式を読むスクリプトの自己テストが、正典（SKILL.md）の雛形とずれた手書きの入力だけで通り、実際に流れてくる行を読めないまま検証を通過した。次に書式を変える人・読むスクリプトを書く人が同じ取りこぼしをしないよう、条として残す（振り返り: T-782）。

## 完了条件

- claude-skills の `retrospect/SKILL.md`（か、スキル全体の規約の置き場のうち適切な1か所）に、「書式を読むスクリプトの自己テストは、SKILL.md の雛形の行をそのまま写した入力を最低1件含める」旨を1〜2行で書く。置き場を選んだ理由を `## 結果` に書く
- 同じ条に当たる既存の自己テストがあれば、雛形を写した入力が入っているかを見て、欠けていたら足すか、欠けている場所を `## 結果` に書く
- claude-skills の `./check.sh` が通り、claude-skills の `main` に入っている。結果の節に claude-skills のコミットハッシュを書く
- このリポジトリの `pnpm run check` が通る（このリポジトリで変えるのはタスクファイルだけ）
- 調べて同じ条がすでにあれば、場所を添えて `dropped` で閉じてよい

## 背景

- T-782 の委譲先は、ドラフトの雛形を `- 札: <色> <札>（<N>回目）` に変えたのと同じコミットで、札を数える `tally.py` を書いた。自己テストの入力は `### 見出し` と `（N回目）` の無い `- 札: 黄 揺れ` だけで、実際に移ってくる `# 見出し` と `（N回目）` 付きの行を数えられないまま `./check.sh` を通った。受け入れでメインが直した（claude-skills の c09b13d）
- `task-workflow` の `WORKFLOW.md` は「手順は `task` コマンドが持ち、自己テスト（`scripts/selftest_task.py`）で守る」としている

## 注意

- 作業するのは claude-skills のリポジトリ（`~/ghq/github.com/sinnlosses/claude-skills`。`~/.claude/skills/` の各スキルはそこへの symlink）。本体の作業ツリーで枝を checkout しない（動いている全プロジェクトのスキルが入れ替わる）。枝が要るなら `git -C ~/ghq/github.com/sinnlosses/claude-skills worktree add` で別の作業ツリーを作る
- 着手時に `git -C ~/ghq/github.com/sinnlosses/claude-skills status --short` が空でなければ止めて預ける（他人の未コミットの変更は触らない）
- claude-skills の運用（検証コマンド・ブランチ）はそのリポジトリの `CLAUDE.md` に従う。枝の名前を付けるなら `feature/tsukumo-<このタスクのID>`
