## やること

前提を調べ直した結果、`components/page/achievement/` の `.tsx` に残る `h1`〜`h4`・`p`・`span` は
`surprise-section.tsx`・`diary-book.tsx`・`lantern-calendar.tsx`・`bookmark-section.tsx` の
4ファイルに計40件（登録時の数と一致）。`achievement.tsx`・`presentational-achievement.tsx`・
`diary-section.tsx`・`diary-notice.tsx`・`day-switch.tsx` は対象0。

- 置換可 17件・不可 23件と数えた。不可の理由は3種:
  - 画面専用の色 `--diary-gold-*`（`docs/screen-design.md` 13.2）を直接持つ: `bookmark-section.tsx`
    の4件、`surprise-section.tsx` の10件、`diary-book.tsx` のしおり区画6件
  - 語彙に無い可変の大きさ・色: `diary-book-kanji-date`（`calc(…* --diary-scale)`）・
    `diary-book-paragraph`（`--diary-text`）の font-size、`diary-book-lamp` の
    `color-mix(...)`（単一トークンに写せない）
  - `aria-hidden` を持つ装飾 span（`diary-book-ribbon`）
- 置換可の17件には、`Text` の `tone="inherit"` で親（`.diary-book-badge` や `<p>` の diary-gold
  クラス）の色を保ったまま構造だけ `Text` に変える形を含む（`token-usage` の `BarredValue` と
  同じ既存パターン）。CSS 側は対応する class から `color`/`font-size`/`font-weight` を外し、
  `font-family`・`letter-spacing`・`margin` などレイアウトだけを残した

## 注意

- **着手の前に、置き換えられる数と置き換えられない数を数える。** `test/architecture.test.ts` は `Heading` / `Text` に渡した `className` の class が `color` / `font-size` / `font-weight` を持つと、`tone` の値に関わらず落とす（`tone="inherit"` では逃げられない）。画面専用の色（`docs/screen-design.md` 13.2）・語彙に無い太さ・状態違いの入れ子セレクタで色を足す class は置き換えられない
- 直接の文字を持たない飾り・入れ物の `span`、`title` / `aria-hidden` / `role` を持つ要素は部品が属性を渡さないので残す
