## 目的

全幅の入れ物（`.mermaid` / `.chart-block`）に入った図・グラフがある塊では、書き上げる演出の帯が全幅のままになる。中身の `svg` / `canvas` の実際の幅を右端に使って帯を縮めるかを決め、縮めるなら直す。

## 完了条件

- 縮めない結論なら、理由が完了時の結果に書かれている
- 縮めるなら、図・グラフを含む塊で帯の右端が描かれた図の右端になっていることを疑似セッション（`notation` の場面）と `scripts/capture-view.ts --measure` で確かめ、`bun run check` が通る

## 背景

`src/browser/features/main-view/reveal/measure.ts` の `lineBoxesOf` は図・グラフの要素の box をまるごと1行として扱う。要素は `plan.ts` の `FIGURE_SELECTOR` で拾った入れ物なので、mermaid や Chart.js のように全幅の入れ物に入っていると、筆がなぞる幅が 950px 前後のまま残る（筆は実際にその上を通るので誤りではない）。帯の幅を塊の枠ではなく行の右端にそろえた直しのときに、範囲外として残した。

## 注意

- 人の判断待ち（`hold`）。見え方の好みなので、縮めるかどうかは利用者が決める
- 演出はマウント時の DOM しか見ないので、目視には新しい依頼（か疑似セッションの読み直し）が要る
