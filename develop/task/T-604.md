## 目的

`(sum, x) => sum + x.y, 0` の合計と、`a < b ? -1 : a > b ? 1 : 0` の比較関数を remeda に寄せ、何を足しているか・何で並べているかを1語で読めるようにする。

## 完了条件

- 次の合計が `sumBy`（数の配列なら `sum`）になっている: `src/server/session-driver/core/prompt-image-shelf.ts`（53行付近）・`src/shared/main-view.ts`（509行付近）・`src/shared/chat-log.ts`（167行付近）・`src/browser/components/page/conversation/character-view/hooks/use-speech-log.ts`（116・123行付近）・`src/browser/domain/context-usage.ts`（126行付近）・`src/browser/domain/reveal/plan.ts`（119行付近）・`src/browser/domain/reveal/band.ts`（206行付近）
- 次の並べ替えが `sortBy` になり、手書きの比較関数が消えている: `src/server/achievement/core/achievement.ts`（294行付近）・`src/browser/components/page/conversation/dispatch/command-suggestions.tsx` の `byName`・`src/browser/components/page/conversation/dispatch/file-suggestions.tsx`（71行付近）・`src/server/diary/adapter/diary.ts`（140行付近。降順）
- 並びの結果（昇順・降順、同じ値の扱い）は変えない
- `bun run check` が通る

## 背景

- 2026-09-25 の調査で洗い出した箇所。行番号は調査時点のもので、着手時の `main` で取り直す
- `chat-log.ts:167` は `boundary` を0として数える条件つきの合計で、`sumBy` のコールバックの中に条件を置けば同じ意味になる
- `use-speech-log.ts:123` は `turns.slice(0, turnIndex)` の合計を `flatMap` の中で毎回取っている。`sumBy` に替えるだけにし、走査の形は変えない
- remeda の `sortBy` は `<`/`>` で比べる安定ソートで、新しい配列を返す

## 決まっていること（蒸し返さない）

- `clamp`（6箇所）・`times`/`range`（4箇所）・`unique`（4箇所）には置き換えない（標準の慣用句や名前付きの関数に包まれていて、差が無い）
- 戻り値が `ReadonlyMap` の集計（`achievement.ts` の `achievementCommitCountsByDate`・`chat-archive.ts` の `readDayIndexHeadings`）は `countBy`/`groupBy` にしない（`Record` になり、呼び出し側まで変わる）
- 状態を持つ `reduce`（`report-violation.ts`・`report-tidy.ts`・`split-blocks.ts`・`stores/session.tsx`）と、複数の項目を足す `sumTotals`・`totalUsage` は対象外

## やること

`main` で行番号を取り直した結果（2026-09-25 時点）。

合計 → `sumBy` / `sum`:

- `src/server/session-driver/core/prompt-image-shelf.ts:53`
  `let total = [...shelved.values()].reduce((sum, full) => sum + full.length, 0)`
  → `let total = sumBy([...shelved.values()], (full) => full.length)`
- `src/shared/main-view.ts:509`
  `const total = counts.reduce((sum, count) => sum + count, 0)`
  → `counts` は `number[]` なので `sum(counts)`
- `src/shared/chat-log.ts:167`（`chatLogByteSize`）
  条件つき合計をそのまま `sumBy` のコールバックへ移す:
  `sumBy(entries, (entry) => (entry.speaker === "boundary" ? 0 : byteLength(entry.text)))`
- `src/browser/components/page/conversation/character-view/hooks/use-speech-log.ts:116`
  `const speechCount = turns.reduce((count, turn) => count + turn.speeches.length, 0)`
  → `sumBy(turns, (turn) => turn.speeches.length)`
- 同ファイル:123（`turns.slice(0, turnIndex).reduce(...)`）
  → `sumBy(turns.slice(0, turnIndex), (earlier) => earlier.speeches.length)`（走査の形は変えない）
- `src/browser/domain/context-usage.ts:126`
  `untilCompactTokens: freeRows.reduce((total, row) => total + row.tokens, 0),`
  → `untilCompactTokens: sumBy(freeRows, (row) => row.tokens),`
- `src/browser/domain/reveal/plan.ts:119`
  `const weight = members.reduce((sum, member) => sum + memberWeight(member), 0)`
  → 既存の `memberWeight` をそのまま渡せる: `sumBy(members, memberWeight)`
- `src/browser/domain/reveal/band.ts:206`
  `const total = bands.reduce((sum, band) => sum + widthOf(band), 0)`
  → 既存の `widthOf` をそのまま渡せる: `sumBy(bands, widthOf)`

並べ替え → `sortBy`:

- `src/server/achievement/core/achievement.ts:293`〜295（`graduationsOf` 末尾の
  `.sort((a, b) => a.registeredOn < b.registeredOn ? -1 : ... )`）
  → `flatMap` の結果を変数に受け、`sortBy(graduations, prop("registeredOn"))` を返す
  （昇順＝登録の古い順で、元の比較と同じ）
- `src/browser/components/page/conversation/dispatch/command-suggestions.tsx` の `byName`
  （`commands.filter(...).toSorted(byName)` が2箇所）
  → `byName` を削除し、`sortBy(commands.filter(...), prop("name"))` に置き換え
- `src/browser/components/page/conversation/dispatch/file-suggestions.tsx:71`
  （`byPath`。`paths.toSorted(byPath)` の1箇所）
  → `byPath` を削除し、`sortBy(paths, identity())` に置き換え
- `src/server/diary/adapter/diary.ts:140`（`listDiaryDates` 末尾、降順）
  `[...dates].sort((left, right) => (left < right ? 1 : left > right ? -1 : 0))`
  → `sortBy(dates, [identity(), "desc"])`（新しい順のまま）

`byName`・`byPath` はどちらもファイル内でしか使われておらず（`toSorted` 以外からの参照なし）、
削除してよい。

## 注意

- 箇所ごとに置き換えて読みにくくなると判断したら、その箇所は残して理由を結果の節に書く
