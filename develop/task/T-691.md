## 目的

仕事モードの会話を、雑談と同じ1つの記憶のアーカイブへ書く（T-690 で正典に書いた形で）。
読み戻し・定着・`recall` は後段（T-692）。

## 完了条件

- 仕事モードのとき、依頼の冒頭・そのターンの `report` の `conclusion`・セリフ（表情つき）が、
  T-690 で決めた形でアーカイブに書かれる。レポートの `body`・ツールの入出力・許可プロンプト・
  質問・画像そのものは書かれない
- 復元で流し直された仕事のイベントは書かれない
- 雑談のときの書き方は変わらない
- 上をテストで守っている（フィクスチャに実際の会話を使わない）
- `bun run check` が通る

## 背景

- 書くかどうかの分岐: `src/server/session/core/session-manager.ts` の `receive`（`origin === "driver" && state.chatMode`）
- 何を書くか: `src/server/chat/core/chat-archive-entry.ts` の `appendChatArchiveEntry`
  （いまは `request` と `speech` の2種類だけ）
- 書き先: `src/server/chat/adapter/chat-archive.ts`
- 決定と形は T-690 が正典に書く（`docs/chat-mode.md` 4.9・`docs/design.md` 7章）

## 注意

- T-690 の結論で行の形・改名・プロセスをまたぐ排他が決まる。本文が T-690 のあとで直されていれば
  そちらに従う
- 会話の文面をログ・`evidence` に写さない（`docs/coding-standards.md`「会話内容の扱い」）
