## 目的

部品の中で部品を定義すると、レンダーのたびに部品の型が変わり、その下の DOM と state が作り直される（入力欄のフォーカスが飛ぶ・演出がやり直しになる類いの不具合）。これを `bun run check` で必ず落とし、`docs/coding-standards.md`「React」節にも規約として書く。出どころは vercel-labs/agent-skills の react-best-practices の `rerender-no-inline-components`。

## 完了条件

- `.oxlintrc.json` の `rules` で `react/no-unstable-nested-components` が `"error"` になっている
- `docs/coding-standards.md`「React」節に、部品の中で部品を定義しない条が1つある（理由と、lint が落とすことを書く。例外を設けるならその範囲も）
- 部品の中で部品を定義した一時ファイルに対して `oxlint` がエラーを出すことを確かめ、一時ファイルは消してある（`src/` の中に壊しを入れない）
- `bun run check` が通る

## 背景

- `.oxlintrc.json` は `plugins: ["typescript", "react"]`、`categories` は `correctness: "error"` と `suspicious: "warn"`。`package.json` の `lint` は `oxlint src test scripts` で、警告では落ちない
- oxlint 1.85.0 で試した結果（計画時に一時ファイルで確認）:
  - `react(static-components)`（「Cannot create components during render」）は既定でエラー。ただし当たるのは、内側で定義した部品を**その場で JSX に使った**形だけ
  - `react(no-unstable-nested-components)` は既定では**警告**止まり。`const Row = (...) => <li/>` を `map` の中で `<Row />` として使う形は、こちらにしか当たらない（つまりいまは check を通ってしまう）
- この規則を `"error"` にした一時設定で `src/browser` を lint した結果、違反は0件だった
- `docs/coding-standards.md`「React」節には、`useEffect` の4類型・代替の表・依存配列・ref・「部品は `function` で書く」の小節がある。部品の定義位置についての条は無い

## やること

- 前提の再確認: oxlint は 1.85.0 のまま（バージョン変わらず）。`.oxlintrc.json` は
  計画時の内容のまま変わっていない。`bunx oxlint --rules` はこの環境では出力が空になる
  （原因不明、実害なし）ので、ルールの有無は一時ファイルに実際に当てて確かめる
- 一時ファイルで検証: 部品の中で部品を定義し `map` の中で使うコードを scratchpad に置き、
  ルールを足す前は `warning`（exit 0）、`"error"` にすると `error`（exit 1）になることを
  確認してから消す
- `.oxlintrc.json` の `rules` に `"react/no-unstable-nested-components": "error"` を追加する
- `bun run lint`（`src test scripts`）で違反が無いことを確認する（0件だった）
- `docs/coding-standards.md`「React」節に `### 部品の中で部品を定義しない` を追記し、
  「節の索引」の `## React` の行にも一言足す（見出し数は編集前後で35→36、`###` が1つ増えた分と
  一致することを確認する）
- `bun run format` → `bun run check` を通す

## 注意

- 文書を直すときは「ドキュメントを編集するときの罠」（CLAUDE.md）に従い、`docs/coding-standards.md` 冒頭の「節の索引」の表に小節を足す必要があるかを見る。見出しの数を編集の前後で数える
- 着手時点で `src/` `test/` `scripts/` に違反が見つかったら、規則を緩めずに部品を外へ出して直す。直す量が1コミットに収まらないほど多ければ、そこで止めて報告する
