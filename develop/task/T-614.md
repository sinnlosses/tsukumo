## 完了条件

- T-606 が `docs/design.md` 2章に書いた作法どおりのバッジの部品が `src/browser/components/ui/<部品>/`（T-616 の形）にあり、`test/browser/components/ui/` に variant → class のテストがある

- `bun run check` が通る
