## 目的

`report` の引数を文字列の `body` から節と塊の並び（`sections`）に切り替え、モデルが型付きの塊でレポートを書くようにする。表の見出しや `#` の見出しのように、今は検査で守っている条を型で守らせる（`docs/research/report-block.md` 11章の2段目）。

## 完了条件

- ツールの schema と各塊の説明（`describe`）を入れ、引数を `sections` にする
- 検査を入れ替える（提案書8章）: 型で守られるようになる `untitled-table` / `top-heading` / `favor-in-body` を外し、表の行の長さ・節の見出し・逃げ道の中に塊の種類がある記法を書いたときの差し戻しを足す
- 整形（`src/shared/report-tidy.ts`）を塊ごとに掛け直す
- `REPORT_NOTATION_PROMPT` の表から、塊になった行を落とす
- MCP に渡る `inputSchema` の字数と、縮んだ文面の字数を実物で測り、`docs/display.md` 4.2 に書く
- 切り替えの前後で、差し戻しの回数と逃げ道の割合を数える（集計値だけ）
- `docs/display.md` 4.2 と `docs/glossary.md` を合わせる
- `bun run check` が通る

## 背景

- 提案書の4章（schema の案）・6章（逃げ道）・8章（要らなくなるものと残るもの）・9章（ツールの定義の重さ）
- `report` の結果に `claude/endTurn` を付けてターンを閉じる案（13章）は T-703 で試している。結果によっては、締めのセリフの欄 `closing` をこのタスクの schema に含めるかを決める

## やること

前提の確かめ（2026-09-27）: T-704 で `src/shared/report-block.ts`（節と塊の形・`reportSectionsMarkdown`）が入り、記録と `SessionEvent` の `report` はすでに `sections` を持つ。ツールの引数だけがまだ文字列の `body` で、`reportEvents` と `ReportReview` の送り直しの判定が `reportSectionsOfBody` で逃げ道の塊1つに畳んでいる。T-749 で `closing` が必須の引数として入り、通った `report` はターンを閉じている（背景の「`closing` を含めるか」は決着済みで、そのまま残す）。前提は崩れていない。

- `sdk-tool.ts` の `report` の引数を `body` から `sections`（`reportSectionSchema` の並び。省ける）に替え、handler は節の並びのまま検査へ渡す
- `ReportDraft` を `sections` で持ち、検査（`report-violation.ts`）を入れ替える: `untitled-table` / `top-heading` / `favor-in-body` を外し、表の行の長さ・節が2つ以上のときの見出しの欠け・逃げ道（`markdown` の塊）の中の塊の種類がある記法（`#`/`##` の見出し・表・箇条書き・`note`・`stats`・フェンス）を足す。`long-paragraph` は `text` の塊と逃げ道の段落、`too-many-notes` は `note` の塊、`unknown-mermaid` は `mermaid` の塊で数える
- `reportEvents` は `sections` を塊ごとに検証し（崩れた塊・知らない種類は落とす）、無ければ `body` を今までどおり逃げ道の塊1つに畳む（過去の transcript）。送り直しの判定は節の並びをそのまま比べる
- 整形を `report-tidy.ts` の節の並びの関数に移し、逃げ道の塊には今の整形を、`text` の塊には定型だけの塊と冒頭の結論の繰り返しを落とす判定を掛ける。空になった節は落とす
- `REPORT_NOTATION_PROMPT` から塊になった行（`note`・バッジ・表・`<details>`・mermaid・`stats`・番号付き・チェックリスト・箇条書き・フェンス）と、それに付いた注意書きを落とし、使い方は各塊の `describe` へ移す。ツールの説明文と `checks` の説明から `body` を消す
- 実物の `tools/list` で `inputSchema` の字数、文面の字数を切り替えの前後で測り、`docs/display.md` 4.2 と `docs/glossary.md`（report ツール・節・塊）を合わせる
- 切り替えの前の差し戻しの回数と逃げ道の割合を transcript から集計値だけで数える（切り替えの後は、まだ呼び出しが無い）

## 注意

- 過去のレポートを数えるときは集計値だけを出し、本文を写さない（`docs/coding-standards.md`「会話内容の扱い」）
