119 から T-697 までで減っている）、`grep -c '^#\{2,3\} '` は 42。T-686 は `todo` なので 11章の

（`package.json` の `dev` は既に `node src/cli.ts` で、11章の写しとずれているが、直すのは T-686）。

論点の決定:

- **3章と4章の線**: 残すのは、両側（サーバとブラウザ）にまたがる順序と不変条件——起動で即時終了
  する前提と順序、起動と起こし直しが同じ一続きを通ること、ブラウザはローカルで echo しない、
  再接続は `hello` の snapshot で置き換える、zod を使う範囲、時刻はイベントの発生側が打つ、版を
  上げる条件、`SessionState` に入れないもの（`connection`・成果）、API の不調の持ち方、記録の時刻の
  形。消すのは実装の写し——3章の mermaid の図（`createSessionLaunch` の呼び出し列そのもの）と、
  型や関数から読めるフィールドの列挙。SDK の版の実測（`local_command_run` の 0.3.274、
  `getSessionMessages` の 0.3.280）と「当初は〜」の経緯は `docs/history/decision.md` へ移し、
  版の下限を下げると黙って効かなくなる、という見直しの条件だけを正典に1行残す
- **10章「E2E の成果物と再現」は design.md に締めて残す**。中身は目視の手順ではなく、機械が
  判定に使う成果物の契約（残す・落とす・置き換え・時計の固定・期待値の更新）で、
  `docs/architecture.md`「手で確かめること」（自動で捉えられない見た目の確認）とは種類が違う。
  句を引く参照も5箇所ある。古くなった記述（`src/session-start.ts` にも `Temporal.Now` がある）は
  いまの形に直す
