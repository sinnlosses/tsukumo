## 背景

2026-09-24 の振り返り（T-448, T-475）から、利用者の承認を得て登録した。

`docs/display.md` 4.2 は「一度出した本文は二度と消えない」と言うが、それをイベント列で守るテストが無い。`mainViewTurns` のテストは `turnUnsettled` に真偽値を直に渡すだけで、イベント列から畳むテストは無かった。2026-09-24 の修正（7b06eec3・1cdf60fd）で `test/shared/session-state.test.ts` の期待値は「続きのターンは吹き出しと表情を持ち越す」に直り、`test/browser/stores/main-view-turn.test.ts` にも3件足されたが、どれも畳み終えた最後の姿しか見ていない。

## やること

1. 続きのターンを2回以上含む現実の並び（依頼 → 中間 `report` → 合図（`turn-resumed` → `speech` → ターンの終わり）→ 合図 → 完了の返事 → 最終 `report`）を、`foldSessionEvent` で1件ずつ畳むテストを足す
2. 1件畳むごとに、「それまでに出ていた `report` の本文がメインビューから消えていない」「吹き出しが空に戻っていない」を確かめる。メインビューの側は `mainViewTurns` など画面が実際に使う関数を通して見る

### 調べ直した前提（着手前）

- `src/shared/session-state.ts` の `foldSessionEvent`（非公開）は `applySessionEvent` を通してしか呼べない。`turn-resumed` は `resumeTurn`（吹き出し・表情・`speechCalledInTurn` を持ち越し、`bodiesInTurn` だけ空に戻す）、`turn-started` は `beginTurn`（吹き出し・表情・`speechCalledInTurn` も空に戻す）に分かれている（1cdf60fd）
- `SessionState.bodiesInTurn`（`TurnBodies`）は「いま走っている SDK ターンで `report`/`utterance` が届いたか」を持ち、`utterance`/`report` イベントと `beginTurn`/`resumeTurn`/`conversation-cleared` で更新される（7b06eec3）
- `src/browser/stores/main-view-turn.ts` の `unsettledBodies` は `state.turn.kind === "running"` と `state.bodiesInTurn.report` の組で `report` を伏せるかどうかを決める（`utterance` 側は a1d8706e でさらに `backgroundTasks` も見るよう広がっているが、これは対象の2コミットの外）。`mainViewTurnsOf(state)` は React に依存しない純粋関数で、`SessionState` を直接渡してテストできる（既存の `test/browser/stores/main-view-turn.test.ts` がその形で使っている）
- `test/shared/session-state.test.ts` の `applySessionEvent（背景のタスク）` に、1cdf60fd で足された2件（`turn-resumed` で吹き出し・表情を持ち越す／続きのセリフが前のセリフに続けて積まれる）はあるが、**どちらも `turn-resumed` を1回しか含まず、畳み終えた最後の姿だけ**を見ている
- `test/browser/stores/main-view-turn.test.ts` の `mainViewTurnsOf（claude が自分で始めた続きのターン）` に、7b06eec3 で足された4件（`fold`（`reduce` で `applySessionEvent` を1件ずつ適用）はあるが、こちらも `turn-resumed` は1回だけで、**`fold` が返す最終形だけ**を見ている（1件畳むごとの確認は無い）
- 前提は崩れておらず、T-541 が指す穴（続きのターンを2回以上含む並びを1件ずつ畳んで、出た本文が消えないことを見るテストが無い）はそのまま存在した
- 足したテスト: `test/browser/stores/main-view-turn.test.ts` に `describe("mainViewTurnsOf（続きのターンを2回以上含む並びを1件ずつ畳む）")` を新設。依頼 → 中間 `report` → `turn-resumed` → `speech` → `turn-finished`（合図1）→ `turn-resumed` → `speech`（完了の返事）→ 最終 `report` → `turn-finished`（合図2）の作り物イベント列を `applySessionEvent` で1件ずつ畳み、ループの中で「中間レポートが一度 `mainViewTurnsOf` の `shownBodies` に出たら、以降のどの1件でも消えない」「最初の続きのセリフが `state.speeches` に一度出たら、以降のどの1件でも空配列に戻らない」をイベントごとに確認する。畳み終えた最終形（中間・最終レポートの両方が出る、吹き出しに2件残る）も確認する
