## 目的

入力欄を、素の `<textarea>` と「書きながら装飾が見える」マークダウンエディタの間で切り替えられるようにする。
形は T-700 の提案書に従う。

## 完了条件

- 入力欄の切り替えの口で、`<textarea>` とマークダウンエディタを行き来できる
- 片方のモードで書いた内容が、切り替えた先にそのまま出る（下書きは1つ）
- エディタのモードでも `/` と `@` の補完・画像の貼り付けとドロップ・Enter で改行・Command+Enter で送信が効く
- 切り替え・下書きの引き継ぎ・エディタでの送信を E2E で守る（`docs/design.md` 10章「E2E の走らせ方」）
- 見た目（装飾・候補窓の位置・切り替えの口）を目視で確かめ、何が見えたかを結果に書く
- `bun run check` が通る

## 背景

- 入力欄は `src/browser/components/page/conversation/components/dispatch/components/composer/`
  （`presentational-composer.tsx` / `hooks/use-composer.ts` / `hooks/use-suggestion.ts` / `hooks/use-prompt-image.ts`）。
  `use-composer.ts` は `HTMLTextAreaElement` と `selectionStart` を直接読んでいる
- 設計は `docs/research/markdown-composer.md`、仕様は `docs/display.md` 4.2「入力欄」（切り替えの段落）。要点:
  - 部品は **CodeMirror 6 の最小構成**。足す依存は `@codemirror/state`・`@codemirror/view`・
    `@codemirror/commands`・`@codemirror/language`・`@codemirror/lang-markdown`・`@lezer/highlight`。
    `markdownLanguage` を拡張として直接渡し、**`markdown()` は呼ばない**（呼ぶと HTML などの文法が
    束に入り +268KB）。見込みは素の束で +578KB（いまの `main.js` 3.10MB の約19%）
  - 下書きの持ち主は `use-composer.ts` の `Draft` のまま。`textAreaRef` を `ComposerSurface`
    （`focus`・`caret`・`placeCaret`）の ref に替え、`ComposerChange` は `Draft`、`ComposerKey` は
    DOM の型を借りない平らな形、`onKeyDown` は「処理したか」の `boolean` を返す
  - エディタの面は `Prec.highest` の `domEventHandlers` で `keydown` / `paste` / `dragover` / `drop` を
    受けて既存の呼び先へ渡し、処理した（画像は `defaultPrevented`）ら CodeMirror へ流さない。
    `defaultKeymap` から `Mod-Enter`（`insertBlankLine`）を外す
  - 補完の候補窓は位置を変えない（包みの下端に底を合わせる配置で、キャレットの座標を使わない）
  - 切り替えの口は道具の行のボタン1つ（キーなし）。モードは `browser/domain/` の1ファイルで
    `localStorage` に覚え、既定は `<textarea>`（E2E の DOM の写し17件はそのまま）
  - 装飾は字の大きさ・太さ・色・等幅だけで、記号は隠さず色を落とす（`Decoration.replace` を使わない）

## 決まっていること（蒸し返さない）

2026-09-26 にユーザーが決めた:

- エディタの形は書きながら装飾が見えるもの。素の `<textarea>` にいつでも戻せて、書いた内容は両方のモードに反映される
- 補完と画像はエディタのモードでもそのまま使う。Enter は改行、送信は別のキー

## 注意

- 差分は2段に割る: まず `ComposerSurface` を切り出して `<textarea>` だけで今のテストを通し
  （振る舞いは変えない）、そのあとにエディタの面と切り替えを足す
- エディタの面の `useEffect` は4類型に収める（`EditorView` を作って壊す＝外部システムの購読、外で変わった
  下書きとプレースホルダを書き写す＝React の外への書き込み）。作った1回のリスナから最新の呼び先を
  読むのは `useEffectEvent`。書き写しは文面が違うときだけ `dispatch` して往復させない
- エディタのモードの DOM を E2E の写しに残すなら、`test/e2e/scenario-run.ts` で `.cm-editor` の子を
  辿らない（CodeMirror が付ける `ͼ` の class を写しに入れない）
- IME は CDP の合成入力でしか確かめていない。目視で、実機の日本語入力で見出し・太字の行に変換確定
  できることと、変換確定の Command+Enter で送られないことを見る。Orca のタブでの動作も見る
- 装飾の色は `src/browser/styles/theme.css` の変数から取り、`HighlightStyle` は class だけ付けて中身は
  CSS Modules に書く
