## 目的

入力欄を、素の `<textarea>` と「書きながら装飾が見える」マークダウンエディタの間で切り替えられるようにする。
形は T-700 の提案書に従う。

## 完了条件

- 入力欄の切り替えの口で、`<textarea>` とマークダウンエディタを行き来できる
- 片方のモードで書いた内容が、切り替えた先にそのまま出る（下書きは1つ）
- エディタのモードでも `/` と `@` の補完・画像の貼り付けとドロップ・Enter で改行・Command+Enter で送信が効く
- 切り替え・下書きの引き継ぎ・エディタでの送信を E2E で守る（`docs/design.md` 10章「E2E の走らせ方」）
- 見た目（装飾・候補窓の位置・切り替えの口）を目視で確かめ、何が見えたかを結果に書く
- `bun run check` が通る

## 背景

- 入力欄は `src/browser/components/page/conversation/components/dispatch/components/composer/`
  （`presentational-composer.tsx` / `hooks/use-composer.ts` / `hooks/use-suggestion.ts` / `hooks/use-prompt-image.ts`）。
  `use-composer.ts` は `HTMLTextAreaElement` と `selectionStart` を直接読んでいる
- 部品・状態の持ち方・補完と画像のつなぎ方・切り替えの口は T-700 が決め、この節を直す

## 決まっていること（蒸し返さない）

2026-09-26 にユーザーが決めた:

- エディタの形は書きながら装飾が見えるもの。素の `<textarea>` にいつでも戻せて、書いた内容は両方のモードに反映される
- 補完と画像はエディタのモードでもそのまま使う。Enter は改行、送信は別のキー
