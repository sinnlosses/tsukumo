## やること

テスト7本を移す）。

- 7ファイルはすべていまの場所にある: `core/achievement.ts` `adapter/main-history.ts`
  `adapter/character-edit.ts` `adapter/character-pack.ts` `core/character-selection.ts`
  `adapter/diary.ts` `core/diary-tool.ts`。対応するテスト
  （`test/server/core/achievement.test.ts` など）も7本ともある
- import の辺は表・edge表どおり: `diary/adapter/diary.ts` は
  `repository/adapter/git.ts`（repository、T-589で移動済み）と `./character-pack.ts`（同時に
  character-pack へ移る）を読む。`achievement/adapter/main-history.ts` は
  `repository/adapter/git.ts` を読む。`character-edit.ts` は同じ機能内の `character-pack.ts` を
  読む。`achievement.ts` `character-selection.ts` `diary-tool.ts` は `shared/` しか読まない葉
- **まだ移していない側からこの3機能への読み手が多数ある**（`src/server/core/session-driver.ts`
  `session-launch.ts` `session-manager.ts` `sdk-message.ts`、`src/server/adapter/sdk-driver.ts`
  `sdk-tool.ts` `server.ts` `chat-summary.ts` `persona-memory.ts`、配線の
  `src/view-delivery.ts` `src/current-character.ts` `src/session-start.ts`）。これらは段7・8まで
  共有の箱に残るファイルなので、設計書の「移行の途中は共有の箱が機能を読む検査を止めておく」に
  従い、相対 import の深さだけ直して機能どうしの辺の検査には入れない
- 移す意味は失われていない。予定どおり移す
