## 目的

`develop/task/` から `done` / `dropped` のタスクファイルを消しても（後続のタスクで入れる）、`/retrospect` がそのタスクの本文・結果の節・登録から完了までの差分を読めるようにする。

## 完了条件

- `skills/retrospect/scripts/material.py` の `print_task` が、`HEAD` に `develop/task/T-xxx.md` が無いとき、そのファイルが最後に存在したコミットの版を出す（出典の行にそのコミットが分かる）
- `print_task_file_diff` も同じで、`HEAD` に無いときは最後に存在した版との差を出す
- `HEAD` にあるときの出力は変わらない。旧形式（`develop/tasks.json`・`docs/history/tasks.md`）への戻り先も残る
- ファイルを消したタスクで `material.py` を走らせた結果を、テストか実行ログで示す
- claude-skills の `./check.sh` が通り、変更が claude-skills の `main` に入っている。tsukumo 側は `bun run check` が通る

## 背景

2026-09-24 に利用者が「振り返りが済んだ `done` / `dropped` のタスクファイルを消す」と決めた（`docs/history/direction.md` の 2026-09-24 の項）。消す仕組みは別のタスクで入れ、これはその前提になる読む側の直し。

- `print_task`（`material.py` の 66行目あたり）は `git show HEAD:develop/task/T-xxx.md` だけを見て、無ければ `develop/tasks.json` → `docs/history/tasks.md` に戻り、どこにも無ければ「develop/task/ にも tasks.json にもアーカイブにも無い」を出す
- `print_task_file_diff`（105行目あたり）は `git log --diff-filter=A` で登録のコミットを取り、`HEAD:` の版と `git diff <登録> HEAD` で比べる。ファイルが `HEAD` に無いと、いまの節が空で、差分は削除として出る
- 最後に存在した版は `git log -1 --diff-filter=D --format=%H -- <path>` の親（`<hash>^`）で取れる見込み（確かめていない）
