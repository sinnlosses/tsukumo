## 目的

`develop/task/` から `done` / `dropped` のタスクファイルを消しても（後続のタスクで入れる）、`/retrospect` がそのタスクの本文・結果の節・登録から完了までの差分を読めるようにする。

## 完了条件

- `skills/retrospect/scripts/material.py` の `print_task` が、`HEAD` に `develop/task/T-xxx.md` が無いとき、そのファイルが最後に存在したコミットの版を出す（出典の行にそのコミットが分かる）
- `print_task_file_diff` も同じで、`HEAD` に無いときは最後に存在した版との差を出す
- `HEAD` にあるときの出力は変わらない。旧形式（`develop/tasks.json`・`docs/history/tasks.md`）への戻り先も残る
- ファイルを消したタスクで `material.py` を走らせた結果を、テストか実行ログで示す
- claude-skills の `./check.sh` が通り、変更が claude-skills の `main` に入っている。tsukumo 側は `bun run check` が通る

## 背景

2026-09-24 に利用者が「振り返りが済んだ `done` / `dropped` のタスクファイルを消す」と決めた（`docs/history/direction.md` の 2026-09-24 の項）。消す仕組みは別のタスクで入れ、これはその前提になる読む側の直し。

- `print_task`（`material.py` の 66行目あたり）は `git show HEAD:develop/task/T-xxx.md` だけを見て、無ければ `develop/tasks.json` → `docs/history/tasks.md` に戻り、どこにも無ければ「develop/task/ にも tasks.json にもアーカイブにも無い」を出す
- `print_task_file_diff`（105行目あたり）は `git log --diff-filter=A` で登録のコミットを取り、`HEAD:` の版と `git diff <登録> HEAD` で比べる。ファイルが `HEAD` に無いと、いまの節が空で、差分は削除として出る
- 最後に存在した版は `git log -1 --diff-filter=D --format=%H -- <path>` の親（`<hash>^`）で取れる見込み（確かめていない）

## やること

前提を読み直した（claude-skills HEAD `bab0449`。`git -C ~/ghq/github.com/sinnlosses/claude-skills status --short` は空）。

- `print_task`（`skills/retrospect/scripts/material.py` 66行目）は `git show HEAD:develop/task/T-xxx.md` だけを見て、無いと即 `tasks.json` → アーカイブへ落ちる。`print_task_file_diff`（105行目）も `HEAD:{rel}` を「いまの節」として読み、無いと空扱いのまま差分が丸ごと削除として出る。背景に書かれた通りで、前提は崩れていない
- T-558 はまだ着手されていない（該当コミットなし、`~/.claude/skills/` にも反映無し）ので、先行実装に合わせる必要は無い
- `git log -1 --diff-filter=D --format=%H -- <path>` で「そのパスを最後に消したコミット」を取り、その親（`<hash>^`）が「最後に存在した版」になることを一時リポジトリで確認した
- 実装方針: 両関数に共通の `last_existing_ref(root, rel) -> str | None` を足す。`HEAD:{rel}` が読めないとき、この関数で `<削除コミット>^` を求めて代わりに読む
  - `print_task`: 出典の行を `develop/task/T-xxx.md（<ref>）` にして、`HEAD` でないときにどのコミットを見ているか分かるようにする
  - `print_task_file_diff`: 「いまの節」の取得先を `HEAD` からその ref に差し替え、`git diff <base> <end_ref>` の `<end_ref>` も同じ ref にする。`HEAD` に無いときは削除コミットも分かるように1行添える
  - どちらも `HEAD` にあるときの経路・出力はそのまま変えない。`tasks.json` → `docs/history/tasks.md` への旧経路もそのまま残す
- 完了条件の「ファイルを消したタスクで material.py を走らせた結果」は、`skills/retrospect/` にテストの仕組みが無いため、`/tmp` に一時 git リポジトリを作って `develop/task/T-900.md` を足す→消すコミットを積み、`material.py` を走らせた実行ログで示す（tsukumo・claude-skills 本体には触れない）
