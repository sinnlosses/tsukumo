## 目的

`src/browser/` の中で class 名を手で連結している箇所を、`docs/coding-standards.md`「class 名は clsx で組む」の形に揃える。

## 完了条件

- `src/browser/` の（テストを除く）`className` を組む箇所に、配列の `.filter(...).join(" ")` と、2つ以上の class 名をつなぐテンプレート文字列（``className={`${...} ${...}`}`` など）が残っていない。`grep -rn '\.join(" ")' src/browser` と ``grep -rn 'className={`' src/browser`` の残りは、class 名を組むものでないことを結果に1行ずつ書く
- 置き換えた箇所から、clsx が捨てるので要らなくなった `?? ""` と `value !== undefined` の型ガードが消えている
- 画面の見た目が変わっていない（`bun run test:e2e` の DOM の期待値が class の並び以外で変わっていないこと。並びが変わったなら `git diff` で class の集合が同じことを確かめて期待値を書き直す）
- `bun run check` が通る

## 背景

- 2026-09-26 に clsx を依存に足し、`docs/coding-standards.md` に「class 名は clsx で組む」を書いた（このタスクの登録と同じコミット）
- 登録時点の数え: 配列の `join(" ")` が10か所（`ui/button` `ui/text` `ui/stack` `ui/heading` `ui/dialog`、`page/token-usage/usage-review-card.tsx`、`main-view/mini-portrait.tsx`、`markdown/markdown.tsx`、`markdown/notation.tsx`、`screen-nav/components/screen-nav-current-work.tsx`）、`` className={` `` のテンプレート文字列が71か所

## 決まっていること（蒸し返さない）

- 条件付きの class は `cond && styles["x"]` で渡す（オブジェクト記法は使わない）
- class 名が1つだけのものは包まない

## 注意

- テンプレート文字列の中には、区切りの空白を片側の変数が持っている形がある（`diary-section.tsx` の `` `${styles["achievement-diary"] ?? ""}${dimmed}` `` の `dimmed` など）。置き換えるときはその変数の中身の先頭の空白も落とす
- `markdown/notation.tsx` の `join(" ")` は hast の `className` の組み立てかもしれない。class 名の文字列を JSX に渡すのでないものは対象外
