## 目的

窓から溢れた雑談の逐語と前のあらすじを受け取り、エピソードの配列と新しいあらすじと話題の見出しを返す使い捨ての `query()` を用意する。組み立てと検査は core、SDK に触るのは adapter の1ファイル（訪問の台本と同じ割り方）。いつ呼ぶか・結果をどこに書くかは後段が決める。

## 完了条件

- `src/server/chat/adapter/sdk-chat-consolidation.ts` に定着の `query()` がある。起こし方は `docs/design.md` 7章「定着はどこで走るか」のとおり（`CHAT_CONSOLIDATION_MODEL`・`tools: []`・`mcpServers: {}`・`settingSources: []`・`maxTurns: 1`・`persistSession: false`・`thinking: disabled`・`outputFormat` の JSON スキーマ）で、`structured_output` を返すだけ
- `src/server/chat/core/chat-consolidation.ts` に、指示文・依頼の文面の組み立て（行番号・話者の別・文面・日付の見出し、前のあらすじ、直前の見出し）・出力の JSON スキーマ・検査（同じ節の表の決め。`end` が入力の全行を切れ目なく覆う）・モデルと時間切れ（120 秒）がある。検査は丸ごとで、1か所でも崩れていたら「作れなかった」に畳む（例外で常駐プロセスを落とさない）
- 行番号の区切りを、各エピソードの `from` / `to`（アーカイブの行の時刻）に直す純関数がある
- 指示に、見出し・要旨・手がかり語・あらすじに書いてよいものの線（自分の言葉で書く・発言を引用しない・利用者について知ったことは書かない）と、`weight` の目安（`docs/chat-mode.md` 4.9「窓から溢れた会話は定着で畳む」）が入っている
- 本物の claude を起こさずに、組み立てる `query()` の引数と出力の検証をテストで確かめている
- `bun run check` が通る

## 背景

- 前例: 日記の `src/server/diary/adapter/sdk-diary.ts`（`persistSession: false`・`settingSources: []`・`maxTurns`）と、訪問の台本の `src/server/visit/adapter/sdk-visit-script.ts`（`outputFormat`）
- 原則3: Agent SDK の境界は機能の `adapter/` 直下の `sdk-` で始まるファイルに閉じ込める（CLAUDE.md「アーキテクチャ概要」）
- 出力の形と検査の正典は `docs/design.md` 7章「定着はどこで走るか」

T-642 は完了しているので前提は崩れていない。**このタスクの範囲は `docs/design.md` 7章の表の

  - 定数: `CHAT_CONSOLIDATION_MODEL = "haiku"`、`CHAT_CONSOLIDATION_TIMEOUT_MS = 120_000`
    （2026-09-26 のユーザー決定どおり）、見出し・要旨・手がかり語・話題の文字数上限の表
  - 指示文（`systemPrompt` をそのまま置き換える）: エピソードの区切り方（`end` は前のエピソードより

    線（自分の言葉で書く・発言を引用しない・利用者について知ったことは書かない）、`weight` の目安
    （3=約束・頼まれた覚えごと・キャラクター自身に関わる決め事、2=中身のある話題、1=挨拶と相槌。
    `docs/chat-mode.md` 4.9）、`topics` は0〜3件・新しい順・`<topics>` のような印は書かない
  - 依頼の文面の組み立て: `ChatUnconsolidatedEntry[]`（`chat-archive.ts` が返す、行番号なし）を
    受け取り、1始まりの行番号を振りながら「n. 話者: 文面」の行にし、日付が変わるところに見出しを
    挟む（`chat-memory-prompt.ts` の `verbatimPart` と同じ考え方）。前のあらすじ（無ければ空文字）・
    直前のエピソードの見出し（無ければ空文字）も渡す
  - 出力の JSON Schema と、受け取った `structured_output` を検査して型に畳む関数（丸ごと検査。
    `episodes` は1件以上・`end` が渡した行数と切れ目なく一致・`title`/`gist`/`cues`/`weight` の形。
    `synopsis` は文字列。`topics` は0〜3件・各40字まで）。1か所でも崩れていたら `undefined`
    （`parseVisitScript` と同じ形）

    `ChatEpisodeDraft.from` / `.to` に直す純関数

- `src/server/chat/adapter/sdk-chat-consolidation.ts` を新規作成する。`sdk-visit-script.ts` と
  同じ形（`tools: []`・`mcpServers: {}`・`strictMcpConfig: true`・`settingSources: []`・
  `maxTurns: 1`・`persistSession: false`・`thinking: { type: "disabled" }`・

- テスト: `test/server/chat/core/chat-consolidation.test.ts` に、文面の組み立て（行番号・話者の別・
  日付の見出し・前のあらすじ・直前の見出しが `prompt` に載ること、`model` が
