## 目的

窓から溢れた雑談の逐語と前のあらすじを受け取り、エピソードの配列と新しいあらすじを返す使い捨ての `query()` を、SDK の境界として1ファイルに用意する。いつ呼ぶか・結果をどこに書くかは後段が決める。

## 完了条件

- `src/server/chat/adapter/` 直下の `sdk-` で始まるファイル（名前は T-641 の正典に従う）に、定着の `query()` がある。`persistSession: false`・`settingSources: []` で、`outputFormat` の JSON スキーマで形の決まった出力を受け取る
- 受け取った出力は境界で検証し、形が合わなければその回を失敗として返す（例外で常駐プロセスを落とさない）
- 要約の指示に、見出し・要旨・手がかり語に書いてよいものの線（自分の言葉で書く・発言を引用しない・利用者について知ったことは書かない）が入っている
- 本物の claude を起こさずに、組み立てる `query()` の引数と出力の検証をテストで確かめている
- `bun run check` が通る

## 背景

- 前例: 日記の `src/server/diary/adapter/sdk-diary.ts`（`persistSession: false`・`settingSources: []`・`maxTurns`）と、訪問の台本の `src/server/visit/adapter/sdk-visit-script.ts`（`outputFormat`）
