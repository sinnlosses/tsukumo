## 目的

T-749 で `report` がターンを閉じ、締めのセリフを `closing` で出すようにしたが、実物での目視をしないまま閉じた。実物で1ターン見て、ずれがあれば直す。

## 完了条件

- 新しく起こした tsukumo のプロセス（`bun run build` 済みの `main`）で仕事のターンを1回流し、次を見て結果に書く: レポートが描かれたあとに `closing` のセリフが吹き出しに出ること、`report` のあとに assistant の本文や `speak` が続かずターンが終わること、入力欄が次の依頼を受け付ける状態に戻ること
- ずれがあれば直し、直したものを守るテストがある。ずれが無ければ見たことを結果に書いて閉じる
- `bun run check` が通る

## 背景

- T-749 の完了条件のうち実物での目視は、サブエージェントからは tsukumo を起こせず未実施。`closing` の吹き出しと「`report` のあとに assistant が来ない」ことは疑似セッションと T-703 の実測でしか確かめていない
- 通したときに `_meta["claude/endTurn"]` を付けてターンを閉じるのは `src/server/session-driver/adapter/sdk-tool.ts` の `reportTool`。`closing` を取り出すのは `assistant` メッセージの変換（`toSessionEvents`）
- 同梱パックの人格の締め方を `closing` に合わせる T-754 のあとに見る（人格が古いままだと、`report` のあとに `speak` を呼ぼうとする形が混ざる）

## 決まっていること（蒸し返さない）

- 目視はサブエージェントに委譲せず、`/next-task` のメインが行う（2026-09-27 ユーザーの判断）。起こし方は `docs/workflow.md` の tsukumo を起こす手順、生きたタブの DOM の測り方は orca のタブ一覧から URL を取って構造だけ拾う形
- 見るのは DOM の構造と流れで、会話の中身をログや結果に全文で残さない（CLAUDE.md「会話内容の扱い」）

## 注意

- ホーム側の `~/.tsukumo/characters/` が同梱パックを覆っていると人格の直しが反映されない。見る前にどちらの `persona.md` が読まれているかを確かめる
