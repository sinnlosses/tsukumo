## 背景

2026-09-24 に `/simplify` の4観点（再利用・単純化・効率・根本対処）でリポジトリ全体を洗った結果の1件（`docs/history/direction.md` の 2026-09-24「改修コストを下げる直し9件」）。

`typeof value === "string" ? value : undefined` だけの小さな関数が、層をまたいで別名で6つある（2026-09-24 時点: `src/server/core/sdk-message.ts`、`src/server/adapter/claude-account.ts`、`src/shared/task-summary.ts`（`optionalStringOf`）、`src/shared/character-definition.ts`、`src/browser/features/main-view/markdown/markdown.tsx`、`src/browser/lib/tool-summary.ts`）。着手時に次で取り直す:

```bash
grep -rn 'typeof value === "string" ? value : undefined' src scripts
```

## 解くべき論点

- 置き場所とファイル名。`src/shared/lib/byte-length.ts` の前例（複数箇所の物差しを1つに揃える）にならい、`src/shared/` の下で概念を名乗る単数形のファイルにする（`helpers.ts` / `utils.ts` のような置き場所の名前にしない。`CLAUDE.md` 原則5）。数値や真偽値の同じ形の関数が近くにあれば一緒に置くかも決める

## やること

1. `src/shared/` に関数を1つ置き、見つかった写しをすべてそれに置き換える
2. 置き換えた先の関数名がファイルごとに違っていたら揃える

### 着手時に調べ直した前提

grep で現状を取り直したところ、背景に書かれた6箇所がそのまま残っていた（`src/server/core/sdk-message.ts:706`、`src/server/adapter/claude-account.ts:52`、`src/shared/task-summary.ts:249`（`optionalStringOf`）、`src/shared/character-definition.ts:254`（`stringField` 内）、`src/browser/features/main-view/markdown/markdown.tsx:197`（`codeFileName` 内）、`src/browser/lib/tool-summary.ts:66`（`stringField` 内））。数値・真偽値の同形（`typeof value === "number" ? value : 0` 相当の単純な1行コピー）は無く、`number | undefined` を返す関数は他にもあるがどれも計算を伴い同形ではないため、今回は文字列の1関数だけを寄せる。

置き場所: `src/shared/utils/optional-string.ts`。「optional string」は tsukumo の語彙（`docs/glossary.md`）ではなく、実装は `typeof` の判定だけで外部パッケージにも実行環境の API にも依存しない（`docs/design.md` 2章「`lib/` と `utils/` に置く基準」手順2の表で「ライブラリに依存しない汎用の道具」に当たる）ため `utils/`（`lib/` ではない）。`src/shared/` に `utils/` はまだ無いので新設する。

関数名: `optionalString`（6箇所中2箇所が既にこの名前で、他は `optionalStringOf` / `stringField`（内部で使うだけ）/ ローカルの無名処理なので、これに揃える）。シグネチャは `(value: unknown): string | undefined`。

置き換え方:

- `src/server/core/sdk-message.ts` / `src/server/adapter/claude-account.ts`: ローカル定義を削除し、`optionalString` を import してそのまま使う
- `src/shared/task-summary.ts`: ローカルの `optionalStringOf` を削除し、呼び出し側3箇所を `optionalString` に差し替える
- `src/shared/character-definition.ts` / `src/browser/lib/tool-summary.ts`: `stringField(record, key)` はレコードからのフィールド取り出しという別の関心事なので関数自体は残し、内部の1行だけを `optionalString(value)` の呼び出しに差し替える
- `src/browser/features/main-view/markdown/markdown.tsx`: `codeFileName` 内の1行を `optionalString(value)` に差し替える
