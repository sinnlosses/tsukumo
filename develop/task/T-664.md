## やること

前提を調べ直した結果、T-639 のあとの実際の置き場所は表の「いま」列どおり
（`components/page/conversation/components/<character-view|chat-view|dispatch>/` の下）で、
崩れは無かった。`character-view` の直下（`character-view.tsx` / `presentational-character-view.tsx` /
`character-view.module.css` / `hooks/use-character-view.ts`）、`chat-view` の直下、`dispatch` の
`dispatch.tsx` / `dispatch.module.css` は表のとおり「同じ相対パス」のままで動かす必要が無い。
動かすのは次だけ:

- `character-view`: `balloon-track.tsx` → `components/balloon-track/`、`balloon.tsx` →
  `components/balloon/`、`speech-log.tsx` `presentational-speech-log.tsx`
  `hooks/use-speech-log.ts` → `components/speech-log/`（フックは `hooks/` の下）
- `chat-view`: `components/chat-log.tsx` `chat-day.tsx` `chat-time.tsx` `chat-typing.tsx`
  `nudge-portrait.tsx` を `components/<名前>/<名前>.tsx` へ1部品1ディレクトリ化、
  `components/chat-speech.tsx` + `hooks/use-chat-speech.ts` → `components/chat-speech/`
  （フックは `hooks/` の下）
- `dispatch`: `composer.tsx` `presentational-composer.tsx` `hooks/use-composer.ts`
  `use-suggestion.ts` `use-prompt-image.ts` `prompt-image.ts` → `components/composer/`
  （フックは `hooks/`、`prompt-image.ts` は `domain/`）、`command-suggestions.tsx`
  `file-suggestions.tsx` → `components/<名前>/<名前>.tsx`、`pending-answer.tsx`
  `presentational-pending-answer.tsx` `hooks/use-pending-answer.ts` → `components/pending-answer/`、
  `turn-status.tsx` `presentational-turn-status.tsx` `hooks/use-turn-status.ts` →
  `components/turn-status/`

いずれも `git mv` で移し、移した部品の内部で `character-view.module.css` /
`chat-view.module.css` / `dispatch.module.css` を読んでいる箇所は相対パスを直す（CSS 自体は
2つ以上の部品が読むので、親の階層に置いたまま動かさない）。テストは同じ形で
`test/browser/components/page/conversation/components/<領域>/` の下へ移す。

## 注意
