## 目的

前段で作った並べる部品を、残る `components/page/` の画面（会話・キャラクター・成果・使用量）にも行き渡らせ、並べるだけの手書きの flex 規則を無くす。

## 完了条件

- `src/browser/components/page/` の `*.module.css` から、並べるだけの規則（flex の向き・間隔・揃えしか持たないもの）が消え、前段の部品に置き換わっている。並べる以外の見た目も持つ規則を残したときは、その理由を結果に1行ずつ書く
- 部品の API を広げたなら、`test/browser/components/ui/` のテストにその振る舞いを足してある
- 会話の画面（メインビュー・キャラビュー・入力欄・振り分け）、キャラクターの画面、成果の画面（日記帳の見開きを含む）、使用量の画面を起動して目視し、崩れが無いことを確かめている（何を見たかを結果に書く。モーダルの中も測る）
- `bun run check` が通る

## 背景

- 量が多いのは `page/token-usage/token-usage.module.css`（1,042行）、`page/achievement/achievement.module.css`（936行）、`page/character/character-screen.module.css`（934行）、`page/conversation/character-view/character-view.module.css`（589行）、`chat-view.module.css`（341行）、`dispatch/dispatch.module.css`（336行）、`main-view/` の各ファイル
- `main-view/markdown/report-notation.module.css` は Markdown から生まれる HTML に当たる規則で、React の部品では置き換えられない

## 注意

- 画面が多く1コミットに収まらない量だと分かったら、画面単位で後続タスクに切り出してよい
