## 目的

成果の画面の「<キャラクターの名前>と振り返る」で、日記を会話のセッションの外で書かせる。依頼文もレポートも会話のメインビューに残らないようにする（形は T-595 で決める）。

## 完了条件

- 振り返りのボタンを押しても、会話のメインビューに依頼文・レポート・ターンが増えない
- 日記は今までどおり `diary` で受け取られ、成果の画面と日記帳に出る。書けなかったときは「書けなかった」が出てボタンが戻る
- T-595 で決めた形（`docs/requirements.md` 4.11・`docs/design.md`「日記の受け取りと保存」）に沿うテストがある
- `bun run check` が通り、`bun run build` のあと実際に振り返りを1回押して、会話の画面に何も増えず成果の画面に日記が出たことを目視で確かめる

## 背景

- いまの送り口は `src/server/core/session-manager.ts` の `reflectAchievement`（会話の駆動へ `beginDiaryDay` → `prompt`）。`diary` ツールは `src/server/core/diary-tool.ts`
- 本文の詳細は T-595 の着地後に揃える
