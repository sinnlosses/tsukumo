## 目的

委譲の決まり文句「`develop/task/T-xxx.md` 以外の `develop/` を触らない」と、完了条件「後段のタスクの本文を直す・大きすぎれば分ける」がぶつかり、サブエージェントが申し送りだけ書いて止まる。誰がやるかを手順に書いて迷わせない。

## 完了条件

- claude-skills の `skills/next-task/SKILL.md` 手順5に、「委譲の前に完了条件を読み、後段のタスクの本文を直す・分ける分はメインが受け入れで（本文の編集と `task new` で）行う。サブエージェントには申し送りを書かせる」旨を1行足す
- claude-skills の `./check.sh` が通り、claude-skills の `main` に入っている。結果の節に claude-skills のコミットハッシュを書く
- tsukumo の `bun run check` が通る（tsukumo 側は変えない）

## 背景

- T-635 の完了条件「後段の本文に表を書き込み、大きすぎれば分ける」に対し、サブエージェントは委譲の決まり文句に従って後段を触らず、メインが受け入れで T-636〜T-640 を直し、T-639 を分けて T-663・T-664 を登録した
- 手順5の委譲で渡す項目は `~/.claude/skills/next-task/SKILL.md` の「5. **委譲する**」の箇条書き（結果の節を書かない・背景のコマンドを止める、などが並ぶ）

## 注意

- 作業するのは claude-skills のリポジトリ（`~/ghq/github.com/sinnlosses/claude-skills`。`~/.claude/skills/` の各スキルはそこへの symlink）。**本体の作業ツリーで枝を checkout しない**（動いている全プロジェクトのスキルが入れ替わる）。枝が要るなら `git -C ~/ghq/github.com/sinnlosses/claude-skills worktree add` で別の作業ツリーを作る
- **着手時に `git -C ~/ghq/github.com/sinnlosses/claude-skills status --short` が空でなければ止めて預ける**（他人の未コミットの変更は触らない）
