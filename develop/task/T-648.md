## 目的

日記を書く段（`DiaryStage`）は前へ戻らない、とコメントと `docs/design.md` が言っている約束を、畳み込みそのもので守る。いまは戻す向きのイベントが来ないので害は無いが、約束がコードに無い。

## 完了条件

- `src/shared/session-state.ts` の `withDiaryStage` が、`writing` 中に今より前の段への移動を受け付けない（段の順は `src/shared/diary.ts` の `DIARY_STAGES` の並び）
- 前の段の `diary-stage` イベントを畳んでも段が変わらないことを、テスト1件で確かめている
- `bun run check` が通る

## 背景

- `withDiaryStage`（`src/shared/session-state.ts` の 920 行あたり）は `writing.kind === "writing"` ならどの段にも上書きする。呼び手は `diary-stage` イベント（851 行あたり）と、書き始めの `"write"`（849 行あたり）
- 出典: T-622 の振り返り（`develop/direction.md` のエージェントのドラフト、2026-09-25 にユーザー承認）

## やること

現状のコードを調べ直した。`withDiaryStage`（`src/shared/session-state.ts` 919-922 行）は
`writing.kind === "writing"` なら段をどの向きにも無条件で上書きしていて、「段は戻らない」という
約束（コメント・`docs/design.md`）がコードには無い。呼び手は2つ（`src/server/diary/adapter/sdk-diary.ts`
の `diary` ツールの塊の合図から作る `session-event.ts` のイベント）:

- `diary-drafting`（849 行、`withDiaryStage(state.diaryWriting, "write")`）— `diary` ツールの塊が
  開いたときに送られる（`sdk-diary.ts` 149 行あたり）
- `diary-stage`（851 行、`withDiaryStage(state.diaryWriting, event.stage)`）— 同じ塊の中で
  `bookmark` の鍵を見つけたときに `{ stage: "pick" }` だけを送る（`sdk-diary.ts` 172 行あたり）

`diary-stage` が送る段は `"pick"` 固定で、`diary-drafting` は必ず `diary-requested`（段 `"read"`）の
あとに来る。つまり**いまの呼び手はどちらも前へ戻す向きのイベントを送らない**ので、注意に書かれた
「戻す向きが意図された呼び手」は無い。約束はそのままでよく、`withDiaryStage` に守らせる実装だけが
抜けていた。

- `src/shared/session-state.ts` の `withDiaryStage` を、`DIARY_STAGES` の並びでいまの段より前の
  `stage` を受け取っても変えないようにする
- 前の段（`"pick"` → `"read"`）への `diary-stage` を畳んでも段が変わらないことを、
  `test/shared/session-state.test.ts` にテスト1件足す（先に落ちることを確認してから直す）

## 注意

- 調べて、849 行あたりの `"write"` のように前の段へ戻すことが意図された呼び手があれば、その呼び手だけ例外にするのではなく、約束のほうが違っていないかをタスクの結果の節に書いて止める
