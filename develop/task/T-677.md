## 目的

まだ作業が続いている（背景の仕事を待っている・通知で続きのターンが走っている）あいだに、末尾のレポートが「最終レポート」と名乗って画面に出ないようにする。札は「このやり取りでもうレポートは増えない」と機械的に言えるときだけ立てる。

## 完了条件

- 「最終レポート」の札（`MainViewStep.final` と、それに基づく地の段・ラベル）は、いちばん新しいやり取りでは**ターンが `running` でなく、背景のタスク（`SessionState.backgroundTasks`）も残っていない**ときだけ立つ。それ以前のやり取りは今までどおり
- 背景のタスクを待って SDK ターンが一度閉じた場面・通知で続きのターンが走っている場面で、末尾のレポートに札が出ないことを E2E で守る（既存の `background-task-running` / `background-task-resumed` のシナリオと期待値に寄せられるなら寄せる）
- やり取りが閉じたら札が立つ（閉じたあとの表示は今と同じ）
- `docs/display.md`・`docs/screen-design.md` 13.2・`docs/glossary.md`「最終レポート」の定義を合わせる
- 手で確かめる: 背景の仕事を待っているあいだ札が出ず、閉じたら出ること。何が見えたかを結果の節に書く
- `bun run check` が通る

## 背景

- 札を立てるのは `src/shared/main-view.ts` の `markFinalReport`（「最後の、中間でない本文」に `final`、中間レポートがあれば `hasInterimReport`）。描くのは `src/browser/components/page/conversation/components/main-view/components/turn/turn.tsx`（`finalLabel`）
- 伏せる判定は `src/browser/stores/main-view-turn.ts` の `unsettledBodies`。`report` は「いま走っている SDK ターンで届いたもの（`bodiesInTurn.report`）」だけを伏せる。背景の仕事を待って黙ると SDK が `result` を出して `turn-finished` が届き、前の SDK ターンの最後の `report` が確定扱いになる。その結果、続きのターンが走っているあいだも・背景のタスクが残っているあいだも、`markFinalReport` がそれに札を立てる（これが利用者の見た症状）
- 伏せる判定（`report` を出すかどうか）は変えない。前の SDK ターンの `report` を伏せると、合図が届くたびに出ていた中間レポートが消えて出直す問題が戻る（`unsettledBodies` のコメント）。変えるのは札だけ

## 決まっていること（蒸し返さない）

- 閉じていないあいだの末尾のレポートは、札も地の段上げも付けない（中間レポートの破線の枠にもしない。追い越されたら今までどおり中間レポートとして畳まれる）

## 注意

- `mainViewTurns` の2つめの引数（`TurnBodies`）に「やり取りが閉じたか」を足すか別の引数にするかは、読む人が追いやすいほうを選ぶ
