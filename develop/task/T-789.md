## 目的

Node の型消去で型だけの import が値の import として残り、import の輪を作って `node` で起こしたときに初期化前参照で落ちる不具合を、書き方の段階で機械的に防ぐ。

## 完了条件

- `.oxlintrc.json` で `typescript/no-import-type-side-effects` が `error` になっている
- `src`・`test`・`scripts` の型だけの `import { type X }` がすべて `import type { X }` に直っている（値と型が混ざる `import { type A, B }` はそのまま）
- `typescript/consistent-type-imports`（`fixStyle: inline-type-imports`）の自動修正が新しい規則と食い違う形を出さないことを確かめ、食い違うなら設定を直す
- `docs/coding-standards.md` の該当する節に、型だけの import は文全体の `import type` で書く理由を1行足す（節の索引の見出しの数を前後で合わせる）
- `pnpm run check` が通る

## 背景

- `src/shared/command.ts` の `import { type FRAME_ERROR_REASON } from "./frame.ts"` は、`tsconfig.json` の `verbatimModuleSyntax: true` と Node の型消去のもとで `import {} from "./frame.ts"` として残り、`frame.ts` → `session-event.ts` → `command.ts` → `frame.ts` の輪を作っていた（bun は消すので見えなかった）。`command.ts` の1行だけは文全体の `import type` に直してある
- 型だけのインライン形は `src`・`test`・`scripts` に約314ファイルある。輪ができるかは import を足すたびに変わる
- `.oxlintrc.json` の `typescript/consistent-type-imports` は `fixStyle: inline-type-imports`。oxlint 1.85.0 は `typescript/no-import-type-side-effects` を持ち、型だけのインライン形（`import { type A }`）だけを指し、混在（`import { type C, D }`）は指さないことを一時ファイルで確かめた

## やること

- `.oxlintrc.json` の `rules` に `"typescript/no-import-type-side-effects": "error"` を足す
- `oxlint src test scripts vite.config.ts --fix` を実行し、型だけのインライン `import { type X }` を `import type { X }` に揃える。値と型が混ざる `import { type A, B }` は対象外（oxlint 側で無視される）ので手を入れない
- `typescript/consistent-type-imports`（fixStyle: inline-type-imports）は、値だけの import が編集の結果すべて型だけになる場合に一時的に `import { type A, type B }` を出し、それを `no-import-type-side-effects` が指摘し直す1回分の食い違いが起こることを一時ファイルで確認した。既存の314ファイルはすでに型だけのインライン形なのでこの食い違いには当たらず、`--fix` 1回で `import type { X }` に揃うことを実行結果で確かめる
- `src/shared/command.ts` の「文全体を import type にする」理由のコメントを、規則が守るようになったので消す
- `docs/coding-standards.md` の該当節に、型だけの import は文全体の `import type` で書く理由を1行足す（節の索引の見出し数を前後で確認）

## 注意

- 置き換えは `oxlint --fix` で出せるならそれを使い、手で1ファイルずつ直さない。直したあと、`src/shared/command.ts` に付いている「文全体を import type にする」理由のコメントは、規則が守るので消す
- 規則の自動修正が無い・食い違いが解けないと分かったら、押し切らずに理由を書いて止める
