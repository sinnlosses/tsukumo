## 背景

- パックの形は `characters/tsukumo/`（`character.json` + `persona.md` + 素材）。定義の型と読み取りは `src/shared/character-definition.ts`（`portraits` は「あるものだけでよい」。`docs/requirements.md` 4.4）、パックの置き方は `characters/README.md`
- 表情の enum は `src/shared/expression.ts` の9つ（default / thinking / proud / flustered / serious / curious / sad / excited / bored）。パックごとの呼び名は `character.json` の `expressions`
- 1つのパックが持てる画像は `MAX_IMAGE_FILES_PER_PACK`（表情の数 + 2。`src/server/adapter/character-edit.ts`）
- 設定画は `assets/chou-design-sheet.png`（ユーザーが用意した1枚）。右上の格子に表情6つ（通常・ねむい・びっくり・にっこり・きょとん・しょんぼり）が、**灰色のまだらな地の上に**描かれている。ほかに三面図・人のシルエットとの背丈の比較・仕草3つ・棚の陰から「ひょこっ」と覗く絵がある
- 画像の加工には `magick`（ImageMagick。`/opt/homebrew/bin/magick`）が使える。素材を作る道具として使うだけで、tsukumo の実行時の依存にはしない。python の PIL はこのマシンでは架構違いで読み込めない（2026-09-24 確認）
- 帳ちゃんの設定: 古い帳面の付喪神で、膝くらいの背丈の記録係。つくもは世話を焼く兄貴分の側に回る（`characters/tsukumo/persona.md`「覚えたこと」）

## 決まっていること（蒸し返さない）

- 素材は設定画から切り出す。地の除去を試み、仕上がりが粗ければ仮の素材として置いて、あとで差し替える（2026-09-24 ユーザー決定）
- 自作のキャラクターなので、`characters/tsukumo/` と同じくパックごとコミットする（`characters/README.md`「既定のキャラクター」）
- 設定画はパックのディレクトリに置かない（画像の数の上限に数えられる）

## 解くべき論点

- 6つの表情を9つの enum のどれに当てるか（例: 通常→default、ねむい→bored、びっくり→flustered、にっこり→proud か excited、きょとん→curious、しょんぼり→sad）。当たる絵の無い enum は置かない
- `mini` / `face` を用意するか（`face` は帯に出る顔）
- 地の除去のやり方と、仮の素材で置くかどうかの見切り
- パックのディレクトリ名（`characters/chou/` など）・`accent`・`persona.md` の口調と一人称（上の設定と設定画から起こす叩き台。利用者があとで直す前提）

## やること

1. 表情を切り出し、地を除去してパックのディレクトリに置く
2. `character.json` と `persona.md` を書く
3. `characters/README.md` の既定のキャラクターの記述に帳ちゃんを足す

### 前提の調べ直しと「解くべき論点」への判断（2026-09-25）

- `assets/chou-design-sheet.png` は 1536x1024。右上の格子（表情6つ）は見た目こそ
  「灰色のまだらな地」だが、**実測するとアルファがほぼ0（0.01〜0.1）の地に、キャラ本体だけ
  アルファ0.97〜0.99が乗っている**（`magick -format "%[pixel:p{x,y}]"` で確認）。つまり
  地の除去は「新しく透過させる」のではなく、**既にほぼ透過している値を閾値でON/OFFに振り切る
  だけ**で済む（`-channel A -level 30%,55% +channel` → `-trim`）。「地の除去」は当初の想定より
  軽い作業だった
- **表情の当て方**: 通常→`default`、ねむい→`bored`、びっくり→`flustered`
  （見開いた目＝驚きは「あわわ」に近い）、にっこり→`proud`
  （closed-eye の穏やかな微笑みで、`excited`＝わくわく の元気さより落ち着いた記録係の性分に
  合う。`excited` は据えない）、きょとん→`curious`、しょんぼり→`sad`。**`thinking` /
  `serious` は当たる絵が無いので置かない**（`portraits` は「あるものだけでよい」ので未指定 →
  `default` に落ちる。実機のキャラクター画面で確認済み、空きは「＋」の追加カードになるだけで
  壊れない）
- **`mini` / `face` は今回は作らない。** 設定画は全身の小さいトークン絵しか無く、顔だけの
  クローズアップ素材が無い。両方とも `character.json` の任意項目で、無ければ
  `mini` は `portraits.default` の縮小、`face` は帯に何も出ないだけで壊れない
  （`characters/README.md`「定義ファイルの形」）ので、無理に作らず見送った
- **地の除去の見切り**: 6枚とも閾値化だけで背景の地は実用上消えるが、**輪郭のアルファが
  段階的に変化する境で、拡大すると点線状のかすかな縁が残る**（`magick -resize 200%` で確認）。
  UI 上の暗い背景では実用上ほぼ見えないが、**厳密には仮素材**として扱う
  （`characters/README.md` に明記済み）
- **ディレクトリ名・accent・persona.md**: `characters/chou/`。`accent` は表紙のネイビー
  （`#6a7180`、design sheet 左上のスウォッチから実測）、`chatAccent` は栞紐のクリーム寄り
  （`#cbb896`、目算）。`persona.md` は「背景」節の設定（古い帳面の付喪神・膝くらいの背丈の
  記録係・つくもが兄貴分）から、丁寧語・一人称「わたし」・びっくりしたときだけ語尾が崩れる、
  という叩き台を書いた。**利用者があとで直す前提の下書き**
