## 目的

会話画面の複雑な機能を、T-657 の土台に乗った E2E で確かめる。後段の監査で、ここが守る振る舞いの単体テストを消せるようにする。

## 完了条件

- 次の機能ごとに E2E が1本ずつある: speak → キャラビューの吹き出し、report → メインビュー（記法の描画を含む）、許可のモーダル、質問（単数・複数・プレビュー）
- 各 E2E が、どの振る舞いを守っているかをテストの名前で言っている（後段の監査が「どのシナリオが守るか」を書くときに引く）
- 台本に場面が足りなければ `test/fixture/fake-session.json` に足している（手書きの架空の会話だけ）
- `bun run check` が通る

## 背景

- 使える場面: `fake-session.json` の `report`・`long-report`・`permission`・`question-multi`・`question-pair`・`question-long`・`question-preview`・`notation`・`narration` など
- シナリオと場面の対応は T-656 が正典に書く一覧に従う（食い違ったらそちらを直す）
