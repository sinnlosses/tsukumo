## 目的

コード・ドキュメントにタスク番号を書かない規約を、`docs/` についても機械的に検査する。

## 完了条件

- タスク番号の検査が `docs/` も見る。ただし `docs/history/` 以下と、`docs/requirements.md`「7. 未決事項」の対応タスク列は許す
- いまの `docs/` にある違反は、消すか言い換えて0件にする（許す場所のものは残す）
- 許す場所の例外が効いていること、`docs/` の違反が落ちることを、`test/scripts/task-mention.test.ts` か `test/task-id.test.ts` の既存の表に行を足して確かめる
- `bun run check` が通る
- 調べて前提が成り立たなければ、理由を書いて `dropped` で閉じてよい

## 背景

- `scripts/task-mention.ts` は `src/` / `test/` / `scripts/` のコメント・テスト名のタスク番号だけを集める（冒頭のコメント）。入口は `scripts/lib/task-mention-repository.ts`、0件を保つのは `test/task-id.test.ts`
- T-555 で、委譲文で「docs にタスク番号を書かない」と明示したのに、サブエージェントが `docs/workflow.md` に番号を書き、`bun run check` は通った（受け入れでメインが消した）
- 規約の正典は CLAUDE.md「コーディング規約・レビュー方針」（唯一の例外は `docs/requirements.md`「7. 未決事項」の対応タスク列）

## やること

前提を調べ直した（2026-09-26）。現状:

- `scripts/lib/task-mention-repository.ts` の `SCANNED_DIRECTORIES` は `["src", "test", "scripts"]` で、
  `docs/` は対象外。`collectStrayTaskMentions` は `docs/` を一切読んでいない
- いまの `docs/`（`docs/history/` を除く）には `T-\d{3,}` の出現が0件（`grep -rnoE 'T-[0-9]{3,}' docs | grep -v '^docs/history/'` で確認）。`docs/requirements.md`「7. 未決事項」の表の行も、現状の1行（「箱が変わった時点で起こす」）にはタスク番号が無い。**よって「消すか言い換えて0件にする」作業は不要**（すでに0件）
- `docs/history/` は `docs/history/` のみに存在する唯一の `history` ディレクトリ。`docs/` 以下に `.md` 以外の非バイナリ検査対象になりうるファイル（`.ts`/`.tsx`/`.css`）は無い
- `docs/requirements.md`「7. 未決事項」の表は2列（`未決事項` / `対応タスク`）で、同ファイル内に他にも2列の表（例: 4.10 節「何 / 上限」）がある。CLAUDE.md が許すのは「対応タスク」列だけなので、ファイル単位ではなく**節（`## 7. 未決事項`）＋列（表の2列目）**まで絞る必要がある

やる作業:

1. `scripts/lib/task-mention-repository.ts` の `SCANNED_DIRECTORIES` に `"docs"` を足し、`SCANNED_EXTENSIONS` に `.md` を足す。`docs/history/` は名前ではなくパス（`root` からの相対パスが `docs/history`）で除く新しい `SKIPPED_PATHS` を導入する（`SKIPPED_DIRECTORIES` は名前ベースのままなので、たまたま他所にできる `history` という名のディレクトリまで巻き込まないようにする）
2. `scripts/task-mention.ts` に、`docs/requirements.md`「7. 未決事項」の対応タスク列だけを拾う前に伏せる純粋関数 `maskAllowedRequirementsPendingTaskColumn(sourcePath, text)` を足す。`## 7. 未決事項`（レベル2見出し）に入っている間だけ、表の行（区切り行を除く）の**最後の列**にあるタスク番号を伏せる。1列目（未決事項そのもの）や、節の外の表は伏せない
3. `scripts/lib/task-mention-repository.ts` の `collectStrayTaskMentions` で、`findTaskMentions` に渡す前にこの関数を通す
4. `test/scripts/task-mention.test.ts` に、(a) `maskAllowedRequirementsPendingTaskColumn` の純粋関数テスト（対応タスク列は伏せる・未決事項列は伏せない・節の外は伏せない・対象ファイル以外は伏せない）と、(b) `collectStrayTaskMentions` を `mkdtemp` の一時ディレクトリで実行して `docs/` が拾われ `docs/history/` が除かれることを確かめる統合テストを足す（この2ファイルのどちらかに足す指定があるため、このファイルにまとめる）
5. `scripts/task-mention.ts` と `scripts/lib/task-mention-repository.ts` 冒頭のコメント、`test/task-id.test.ts` の該当コメントを、`docs/` を検査対象に含める内容に更新する
