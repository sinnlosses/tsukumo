## 目的

雑談モードと同じく、仕事モードでも**セリフを押すと、そのセリフを言ったときの表情へ立ち絵が遡る**
ようにする。押せる場所は**キャラビューの吹き出し**と、右上「ログ」で開く**セリフのログ（モーダル）の
行**の両方。

## 完了条件

- キャラビューの吹き出しを押すと、立ち絵がそのセリフの `speak` に添えた表情になる
- セリフのログのセリフの行を押すと、ログの床に立つ立ち絵がそのセリフの表情になる
- 押した挙動（印・解き方・新しいセリフが来たときに解ける・ドラッグで文字を選んだときは押したことに
  しない・キーボードで押せる）が、雑談モードの `docs/screen-design.md` 13.7「会話を遡る」と揃っている。
  揃えなかった点があれば、その理由を正典に書いてある
- 正典（`docs/display.md` 4.2 と、必要なら `docs/screen-design.md`）に仕事モードでの挙動を書いてある
- 上の挙動を E2E で守っている（`TSUKUMO_DRIVER=fake` の疑似セッションで、表情の違うセリフを2件以上
  並べ、押す前後で立ち絵の表情が変わることを確かめる）
- 実画面で、吹き出しとログの行をそれぞれ押して立ち絵の絵柄が入れ替わることを撮った画像で確かめた
- `bun run check` が通る

## 背景

- **雑談モードの実装**: `src/browser/components/page/conversation/components/chat-view/hooks/use-chat-view.ts`
  の `ViewedSpeech`（`latest` / `pinned`。`pinned` は押した時点のセリフの件数を持ち、件数が変われば
  失効する）。押すと選ぶの見分け（押し始めからの距離）と `role="button"` の `<div>` は
  `chat-view/components/chat-speech/`（`chat-speech.tsx` と `hooks/use-chat-speech.ts`）
- **仕事モードの表情の源**: `character-view/hooks/use-character-view.ts` の `useCharacterView`。
  今のターンは `SessionState.speechExpression`、過去のターンのタブを選んでいるときは
  `shared/turn-speech.ts` の `turnSpeeches` が返す**そのターンの最後のセリフの表情**を当てている
- **セリフごとの表情は記録に残っている**（`SessionRecord` の speech に `expression`。雑談の
  `shared/chat-log.ts` はこれを読んでいる）。`TurnSpeech` は今は `speeches: readonly string[]` と
  最後の表情しか持たないので、セリフごとの表情を渡す形に広げる必要がありうる
- 吹き出し: `character-view/components/balloon/balloon.tsx`・`balloon-track/balloon-track.tsx`。
  今のターンの吹き出しは `SessionState.speeches`（前のターンの最後の1件を残す規則が乗っている）から出る
- セリフのログ: `character-view/components/speech-log/`（`hooks/use-speech-log.ts` の `SpeechLogEntry`、
  `presentational-speech-log.tsx` の `SpeechLogRow`）。ログの床の立ち絵はキャラビューから `portrait`
  として渡される（`presentational-character-view.tsx`）

## 決まっていること（蒸し返さない）

- 押せる場所は吹き出しとログの行の**両方**（2026-09-26 ユーザーの選択）
- 立ち絵の「動き」は遡らない（雑談・過去のターンのタブと同じ扱い）
- 押せるのはキャラクターのセリフだけ（ログの依頼の区切りは押せない）

## 解くべき論点

- **留めた状態を吹き出しとログで1つにするか**: ログの床の立ち絵はキャラビューのものと同じなので、
  1つの状態にしてログで押した行がキャラビューにも残るのが素直。分けるなら理由を正典に書く
- **過去のターンのタブとの関係**: タブを切り替えたときに留めた選択を解くか。そのターンの
  「最新」（最後のセリフ）に印が付く既定をどう出すか
- 吹き出しの印の出し方（雑談の「地と縁を強める」を吹き出しの見た目にどう写すか。枠も操作子も
  増やさない、は 13.1 原則2 のまま）
