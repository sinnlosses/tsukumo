## 目的

成果の画面の「小さな驚き」に出す、その日の卒業（登録から日が経って done になったタスク）と節目（通算 N 件目のタスク、N コミット目）を tsukumo が数える。

## 完了条件

- その日に done になったタスクのうち、**新形式（`develop/task/`）で登録したもの**について、ファイルが `main` に入ったコミットの日付から「登録から N 日」を出せる。旧形式（`tasks.json` 時代）のタスクは卒業に出さない
- 卒業とみなす日数の下限と、節目の刻み（タスクの件数・コミット数）は T-561 の仮決めに従う
- 結果が `DailyAchievement`（または T-561 が決めた型）に載り、ブラウザが受け取れる
- 振り返りの依頼文（`achievementReviewRequestText`）に卒業と節目が載る
- `bun run check` が通る

## 背景

- 1日ぶんの集計は `src/server/adapter/main-history.ts` の `readAchievement`、型と依頼文は `src/shared/achievement.ts`
- タスクファイルの置き場は `develop/task/T-xxx.md`（done のあと `docs/history/tasks.md` へアーカイブされることがある。アーカイブ後も登録日が取れるかは調べる）

## 注意

- 通算の件数の数え方（アーカイブ済みを含めるか）で迷ったら、T-561 の `docs/requirements.md` 4.11 に従い、書かれていなければ仮に決めて `docs/requirements.md` に書き足す
