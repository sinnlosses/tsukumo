## 目的

`color: var(--ink-quiet)`・`font-size: var(--font-secondary)` / `var(--font-label)` のような「文字の段と色だけ」の規則が各機能の CSS に散っている。文字の部品を作って大きさ・色（静か・強調・状態）を variant で表し、まず `components/domain/` と `features/` から置き換える。空の表示（「まだ何もない」の一文）もここに寄せる。

## 完了条件

- T-606 が `docs/design.md` 2章に書いた作法どおりの文字の部品が `src/browser/components/ui/<部品>/`（T-616 の形）にあり、`test/browser/components/ui/` に variant → 描かれる class のテストがある
- `src/browser/components/domain/` と `src/browser/features/` で、文字の段・色しか持たない規則（空の表示 `.task-empty` `.sidebar-empty` `.screen-nav-work-empty` を含む）が部品に置き換わり、規則が消えている。ほかの見た目も持つ規則を残したときは、その理由を結果に1行ずつ書く
- 置き換えた画面（サイドバー・画面のナビの帯・タスクの一覧と表）を起動して目視し、崩れが無いことを確かめている（何を見たかを結果に書く）
- `bun run check` が通る

## 背景

- 計画時の実測で、`color: var(--ink-quiet)` は 21ファイル119規則、`--font-secondary` は 22ファイル94規則、`--font-label` は 13ファイル86規則。数字の桁揃え（`font-variant-numeric: tabular-nums`）が 3ファイル9規則、`text-overflow: ellipsis` が 8ファイル10規則
- 色のトークンは `src/browser/styles/theme.css` の `--ink` / `--ink-quiet` / `--accent` / `--state-ok` / `--state-warn` / `--state-ng` / `--state-ask`
- `components/page/` の置き換えは後段のタスクが受け持つ

## 注意

- 見出しは別のタスク（見出しの部品）が受け持つので、ここでは `<h*>` を置き換えない
