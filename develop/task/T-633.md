## 目的

`Stack` / `HStack` / `VStack` の口が足りずに置き換えを見送った並べの規則を、口を足したうえで置き換える。

## 完了条件

- `docs/design.md` 2章の `Stack` の行に、足す口（`element` の値の追加、`aria-label` / `aria-labelledby`、`ref`）と、足さないと決めたものの理由を書く
- 足した口ごとに、部品のテストに行を足す（設計の「要るものが出たらテストの行と一緒に足す」）
- T-608 で「`Stack` の口に無い」を理由に残した並べの規則を置き換える。置き換えないと決めたものは理由をタスクの結果に書く
- 描画に関わるので、置き換えた画面を目視し、何をどう確かめたかをタスクの結果に書く
- `bun run check` が通る
- 調べて前提が成り立たなければ、理由を書いて `dropped` で閉じてよい

## 背景

- `src/browser/components/ui/stack/stack.tsx` の `StackElement` は `"div" | "section" | "span"` だけで、`aria-*` と `ref` の口は無い
- T-608 では、要素が `<ul>` / `<li>` / `<p>` / `<header>` / `<footer>` / `<label>` / `<form>` のもの（約13件）、`aria-label` の要る `<section>`（6件）、`scrollIntoView` の `ref` が要る2件を残した。ツール呼び出しが397回と重く、口が無いことで判断が箇所ごとに割れた

## 解くべき論点

- `element` を文字列の合併型で広げるか、別の書き方（`as` など）にするか。`docs/design.md` 2章の variant の作法に合う形を選ぶ
- `ref` は React 19 の `ref` を props で受ける形でよいか

## やること

着手前にコードで前提を取り直した（2026-09-26）。T-615（ダイアログ）と T-626（`components/ui/` のテストの刈り込み）はどちらも `develop/task/` から消えていて（done）、`Stack` の口はいまも `element: "div" | "section" | "span"` だけで `aria-*` と `ref` は無い。前提は成り立っている。

`src/browser/components/page/` の `*.module.css` に残る `display: flex` の規則を全部並べ直し、gap が段（0 / 0.25 / 0.5 / 0.75 / 1 / 1.25rem）に乗り、箱の見た目（余白・枠・地・影）を持たず、`inline-flex` でもメディアクエリで並べが変わるものでもない規則を、要素・属性で振り分けた。

- **置き換える**（口を足せば置き換えられるもの）:
  - `aria-label` の `<section>`: `achievement/surprise-section.tsx` の `.achievement-surprise`（column・md）
  - `aria-labelledby` の `<section>`: `character/presentational-character-edit.tsx` の `.character-section` ×5（column・md）
  - `<header>` / `<footer>` / `<label>`: `conversation/main-view/question-ask.tsx` の `.question-ask-head`（row・center・wrap・sm）・`.question-ask-foot`（row・center・between・wrap・sm）・`.question-ask-option-choose`（row・baseline・sm）
  - `<p>`: `token-usage/period-usage-card.tsx` の `.usage-card-scale`（row・between・sm）。字の色・書体は `className` に残す（`Stack` は色の軸を持たないので、画面の語彙と部品の語彙が競らない）
  - `ref`: `conversation/character-view/presentational-speech-log.tsx` の `.speech-log-scroller`（column・gap なし。`use-speech-log.ts` の転がし位置の読み書きに使う ref）
- **口を足す**（使う箇所のあるものだけ）: `element` に `"header" | "footer" | "label" | "p"`、名前は `Dialog` と同じ判別可能な合併型で `name: { kind: "none" } | { kind: "label"; label } | { kind: "labelledby"; id }`（2つを並べた `| undefined` は1つの状態なので合併型にする）、`ref: Ref<HTMLElement> | undefined`（React 19 の props で受ける ref）。props はすべて必須なので、既存の `Stack` / `VStack` / `HStack` の呼び出しにも `name={{ kind: "none" }}` と `ref={undefined}` を足す
- **置き換えない**（理由）:
  - `.main-turns`（`main-view.tsx`）: `ref` に加えて `data-brush-origin` が要る。`data-*` の口は足さない
  - `.speech-log-speech`（`<li>`）: `data-age` を選択子が読む。同上
  - `.speech-log-entries`（`<ol>`）: gap が 12px で rem の段に写らない（丸めない）
  - `.dispatch-form`（`<form>`）: `onSubmit` が要る。イベントの口は足さない（`Stack` は並べることだけを持つ）
  - `.character-screen-note`: すでに `Text`（`<p>`）で、1つの要素に部品は1つ
  - `.usage-review-running-head` / `.usage-review-result-head`: 狭い画面で `flex-wrap` が変わる（T-608 と同じ理由）
- `docs/design.md` 2章の一覧の `Stack` の行と「描く要素を変える口」に、足した口と足さないもの（`ol`/`ul`/`li`/`form`・`data-*`・イベント）の理由を書く。テストは `stack.test.tsx` に要素4つの行・名前の3通り・`ref` の行を足す
