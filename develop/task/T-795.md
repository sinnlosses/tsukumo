## 目的

文書だけを変えた差分の受け入れで、E2E `test/e2e/speak-bubble.test.ts` が2件中1件落ちた。差分と無関係に `pnpm run check` が落ちないよう、原因を当てて直す（振り返り: T-674）。

## 完了条件

- `pnpm run test:e2e` か `speak-bubble.test.ts` 単独を続けて回し（回数を決めて書く）、落ちた回の成果物（前段で残るようにしたもの）から、食い違ったのが DOM かメッセージの列か・どの要素かを `## 結果` に書く
- 原因を直し、同じ回数を回して1度も落ちないことを `## 結果` に書く
- 原因が他のシナリオにも当たる型（場面のタイマーとの競り合い・取得中を撮る・時計）なら、`docs/design.md` 10章「E2E の揺れを生まない書き方」に当たる条があるかを見て、無ければ足す
- `pnpm run check` が通る
- 決めた回数で再現せず原因も立たなければ、回数と結果を添えて `dropped` で閉じてよい

## 背景

- 2026-09-27 の T-674 の受け入れで1回目の `pnpm run check` の E2E が 23 pass / 1 fail（`speak-bubble.test.ts`、約7秒）。直後の `pnpm run test:e2e` 3回はいずれも 24 pass。落ちた it の名前と中身は控えていない
- `speak-bubble.test.ts` は `closing-narration` と `question-multi` の2場面で、どちらも `waitForEvent("turn-finished")` のあと `settleAndMatch(60_000)` を呼ぶだけ（操作はしない）
- ブラウザの時計を最初から凍らせる直し（立ち絵の反応が固まる不具合）のあとも出ている
- ほかの揺れのタスク: T-790（`background-task` の取得中）・T-794（開幕の場面との競り合い）・T-776（単体テストの時間切れ）

## 注意

- 期待値を落ちた回の形に書き換えて揺れを隠さない
- 待ち時間を延ばすだけの直し方はしない（何を待つかを直す）
