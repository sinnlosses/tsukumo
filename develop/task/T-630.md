## 目的

`scripts/capture-catalog.ts` の `notation-figure` / `notation-chart` の件で、mermaid の図と chart が確実に撮れるようにする。

## 完了条件

- `bun run scripts/capture-catalog.ts --only notation-figure` と `--only notation-chart` で、図と chart が描かれた状態の画像が撮れる（撮った画像を見て確かめ、何が見えたかをタスクの結果に書く）
- ほかの件の待ち時間は変えない
- `bun run check` が通る
- 調べて前提が成り立たなければ、理由を書いて `dropped` で閉じてよい

## 背景

- `notation` 場面はレポートの演出が着地するまで約15秒かかる。`capture-catalog.ts` の送りの操作は `PREPARE_TIMEOUT_MS`（2000ms）で切れるので、図に届く前に取りこぼす（`notation-figure` は139行目、`notation-chart` は145行目あたり）
- T-584 のサブエージェントは手製の Playwright スクリプトで着地を待って撮り直した
- `docs/architecture.md`「手で確かめること」は、この2件を「記法の見本の下側」を出す件として案内している

## やること

**`bun run scripts/capture-catalog.ts --only notation-figure --out /tmp/xxx` を実際に撮って原因を確かめ直した**（着手直後、いまの `main` に対して）。撮れた画像は、送った先ではなく画面の途中（チェックリストの項目のあたり）を写していた——`scrollIntoViewIfNeeded` 自体は失敗しておらず（`当てられなかった` のログは出ない）、**演出中の自動送り（`src/browser/domain/reveal/brush-scroll.ts`）がフレームごとに送り先を引き戻していた**のが原因。図・グラフはレポートの末尾に近い塊で、演出（約15秒）がそこへ届く前に `PREPARE_SETTLE_MS`（800ms）が明け、撮ってしまっていた。

演出は `use-report-reveal.ts` の `SKIP_EVENT_NAMES`（`pointerdown` / `keydown`）でいつでも打ち切れる（打ち切ると即座に全部を出し切り、自動送りも止まる）。**15秒待つのではなく、`prepare` を当てる前にキーを1つ打って演出を着地させてから送る**方式にした:

- `CatalogEntry` に `readonly skipReveal: boolean` を足した（**`prepare` と同じく全件で必須の値にし、`?:` は使わない**——コーディング規約の「`| undefined` は5箇所だけ」に当たらないため）。`true` は `notation-figure` / `notation-chart` の2件だけで、ほかの14件は `false`（**ほかの件の待ち時間・挙動は変わらない**）
- `SKIP_REVEAL_KEY`（`"Escape"`）を定数で足した。`window` に立てた listener はキーの種類を見ずに `keydown` なら何でも拾うので、押すキーの意味は問わない。フォーカスがどこにあっても `capture: true` の listener が拾うので、打つ前に何かへフォーカスを当てる必要は無い
- `captureShot` で、`SCENE_TAIL_MS` を待ったあと・`prepare` を当てる前に、`entry.skipReveal` が立っていれば `page.keyboard.press(SKIP_REVEAL_KEY)` を1回打つ処理を足した

`--only notation-figure` / `--only notation-chart` を広い窓・狭い窓それぞれで撮り直し、`Read` ツールで画像を見て、mermaid の図（開始→確認→完了のフローチャート）と chart（A/B/C の棒グラフ）が写っていることを確かめた（詳細は報告に書く）。`--only notation-note` と `--only command-suggestions`（`skipReveal: false` のまま）も撮り直し、**前と同じ絵**（`notation-note` は同じく演出の途中を写す絵のまま、変えていない）であることを確かめ、回帰が無いことを見た。

## 結果
