## 目的

Vitest で単体テストのファイルが並んで走るようになり、`test/server/view-server/adapter/bundle.test.ts` が実物の `dist/browser/` を出し直している間に `test/cli.test.ts` の起動が成果物の対を読めずに落ちる。`pnpm run check` の揺れを1つ消す（振り返り: T-760）。

## 完了条件

- `bundle.test.ts` が実物の `dist/browser/` を書き換えない（出し先を引数で渡して一時ディレクトリに書く）か、2つのファイルが同時に走らない
- `pnpm run test` を10回続けて回し、1度も落ちない（回数と結果を `## 結果` に書く）
- `pnpm run check` が通る

## 背景

- `test/server/view-server/adapter/bundle.test.ts` 18〜19行目のコメント: 「`buildUiBundle` は `dist/browser/` を出し直す（`.gitignore` してある成果物の置き場）。つまり check を通すと成果物も新しくなる — 頼ってよい副作用ではないが…」
- `buildUiBundle` は `src/server/view-server/adapter/bundle.ts`。`vite build` で作った1組を `dist/browser/` に置く
- T-760 の委譲先が `pnpm run check` を数回回すうちに、`cli.test.ts` の1件がこの組み合わせで落ちた（単独では通る）。Vitest に移ってから当たりやすくなった見込み（確かめていない）
- E2E の段は `dist/browser/` を自分で組み立てる（`docs/design.md` 10章）。出し先を変えるなら E2E の組み立てとの関係も見る

## やること

- `buildUiBundle` と `readUiBundle` を「出し先（`builtDir`/`outDir`）を必須の引数で受け取る」形に変える。
  いまは両方とも引数無しで `builtUiDir()`（実物の `dist/browser/`）を内側で決めていて、
  `bundle.test.ts` がそのまま呼ぶと実物を書き換える
  - `buildUiBundle(outDir: string)`: `bundleWithVite(bundledFilePath(...UI_SOURCE_DIR_RELATIVE_PATH), outDir)` を呼ぶだけにする
  - `readUiBundle(builtDir: string)`: 内側の `builtUiDir()` 呼び出しを削り、渡された `builtDir` を使う
- 本番の呼び出し側にも同じ引数を明示で渡す（テストのためだけの口にしない）
  - `src/main.ts`: `readUiBundle(builtUiDir())`
  - `scripts/build-ui.ts`: `buildUiBundle(builtUiDir())`
- `test/server/view-server/adapter/bundle.test.ts` の `buildUiBundle`/`readUiBundle` の呼び出しを
  `temporaryDir()`（既にある一時ディレクトリのヘルパー）に向け、実物の `dist/browser/` を触らないようにする
- 冒頭のコメントと各関数の doc コメントを、出し先が引数になった前提に直す

## 注意

- 出し先を引数にするとき、テストのためだけに公開する口にしない（`docs/coding-standards.md`「テスト」節）。本番の呼び出しも同じ引数を渡す形にする

## 結果

- 検証コマンド: 2729 pass / 0 fail（単体）・24 pass / 0 fail（E2E）
- `buildUiBundle` / `readUiBundle` が出し先を引数で受け取り、`bundle.test.ts` は一時ディレクトリへ組み立てる。実物の `dist/browser/` を書き換えないので `cli.test.ts` と取り合わない。受け入れで、引数にした理由を書いた doc コメントの段落を2つ削った
- `pnpm run test` を10回続けて回すと、3回目が1回落ちた（落ちたテストのログは残っていない）。15回追加で回したのと、2ファイルだけを5回回したのは全部通った。残った揺れは T-776 の範囲
- 振り返り: 受け入れのときにメインが直したもの（ドラフト 1件）
