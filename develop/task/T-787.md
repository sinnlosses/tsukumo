## 目的

docs の組み替え（T-769〜T-771）は数百件の参照を張り替える。行をまたいだ参照が検査から漏れると、迷子の参照が残っても `pnpm run check` が通ってしまう。組み替えの前に、検査が行をまたぐ形も拾うようにする。

## 完了条件

- `scripts/section-reference.ts` の `findSectionReferences` が、パス（と「章」「の」など）で行が終わり、次の行の頭（コメント記号・引用記号・字下げを除いたあと）が「で始まる参照を拾う
- 拾えるようになった参照のうち、いまの main で迷子になっているものは張り替えるか、張り替え先が分からなければ `## 結果` に一覧で残す
- `test/scripts/section-reference.test.ts` に、行をまたぐ形を拾う場合と、拾わない場合（次の行が「で始まらない）を足す
- `pnpm run check` が通る

## 背景

- `REFERENCE_HEAD`（`scripts/section-reference.ts`）は1行の中で「パス → 章・番号 → の → 「」を照らし、`findSectionReferences` は `lineText.matchAll(REFERENCE_HEAD)` で行ごとに拾う。句が閉じずに行が終わる場合は `MAX_CONTINUATION_LINES`（3行）まで次の行を追うが、「 の開きそのものが次の行にある形は拾えない
- 2026-09-27 の振り返り（T-768）: 旧 `docs/architecture.md` の句を引く参照のうち5件がこの形で、検査もスクリプトの洗い出しも拾えず、`git grep` で手で見つけた
- 継続行の頭の記号は `CONTINUATION_PREFIX` で落としている
