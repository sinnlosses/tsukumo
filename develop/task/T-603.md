## 目的

規約「型を迂回するキャストを使わない」に当たっている2箇所を、remeda の型付きの関数に替えてキャストを消す。

## 完了条件

- `src/browser/components/page/achievement/lantern-calendar.tsx` の `(Object.keys(LAMP_LABEL) as readonly LampLevel[])` が remeda の `keys(LAMP_LABEL)` になり、`as` が無い
- `src/shared/task-summary.ts` の `isOneOf` が消え、呼び出しの3箇所（`status`・`difficulty`・`loopable` の検証）が remeda の `isIncludedIn` になっている
- 絞り込み後の型（`LampLevel`・`NEW_TASK_STATUS_VALUES[number]` など）が、書き直す前と同じに推論されている
- `bun run check` が通る

## 背景

- `lantern-calendar.tsx:69`: `LAMP_LABEL` は `Readonly<Record<LampLevel, string>>`（16行）。`Object.keys` が `string[]` を返すため、キャストで `LampLevel[]` にしている
- `task-summary.ts:212`: `function isOneOf<const T extends readonly string[]>(value: string, values: T): value is T[number]` が `(values as readonly string[]).includes(value)` をしている。呼び出しは 132・137・142 行
- remeda 2.50.0 は `keys`・`isIncludedIn` を持つ（`node_modules/remeda/dist/` で確認済み）

## 注意

- `isIncludedIn` の型の絞り込みがこの呼び出しで効かないと分かったら、そのファイルは替えずに理由を結果の節に書く。2箇所とも効かなければ `dropped` で閉じてよい
