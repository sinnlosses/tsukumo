## 目的

タスクを1件やり終えるたびに、その1件を振り返る。まとめて振り返ると間が空いて薄くなり、別の作業ツリーで動いたタスクのトランスクリプトも拾えない。同じ作業ツリー・同じセッションのうちに振り返れば、サブエージェントのトランスクリプトから手数まで取れる。

## 完了条件

- `/next-task` の最後（`task ship` のあと）に、その1件だけを対象にした振り返りの手順がある。`/loop` から回っているときも走る
- 振り返りは**兆候に当たったときだけ** `develop/direction.md` の `## エージェントのドラフト` に積み、当たらなければ `develop/retrospective.md` の記録だけ進める。兆候の一覧（下の「決まっていること」）が `retrospect` の SKILL.md にある
- `retrospect` の SKILL.md と `WORKFLOW.md` から「`/loop` に載せない」の決まりが、今回の決定に合わせて書き換わっている（手で呼ぶまとめての振り返りも残すかは論点で決める）
- 下の「解くべき論点」の1つ1つに結論があり、完了時の結果に論点 → 結論を1行ずつ書く
- claude-skills の `./check.sh` が通り、変更が claude-skills の `main` に入っている
- tsukumo の `CLAUDE.md`「導入済みスキル」の `retrospect` の説明（「手で呼ぶ。`/loop` には載せない」）が新しい形に直っていて、`bun run check` が通る

## 背景

2026-09-24 に利用者が決めた（`docs/history/direction.md` の 2026-09-24 の項）。同日の振り返り（`f1adaf96`..`7ef5a7ba`、175コミット・71タスク）では、範囲内のタスクに割り付くトランスクリプトが1件も無く、手数を見られなかった。原因は `skills/retrospect/scripts/transcript.py` の `project_dir` が、起こした作業ツリーの slug（`~/.claude/projects/-Users-...-tsukumo-4/`）の下しか探さないこと。同じ作業ツリーで動いた T-533 は `material.py` で手数（ツール呼び出し60件・`character-edit.ts` を8回直した）まで取れた。

いまの `retrospect` は `scan.py` が `develop/retrospective.md` の「最後に振り返ったコミット」から `HEAD` までを範囲にし、コミット件名のタスクIDでタスクに割り付ける。

## 決まっていること（蒸し返さない）

- `/loop` から回っているときも走らせる（「無人だと根拠の薄い気づきが溜まる」への答えは、兆候の縛りで積む量を絞ること）
- 兆候の例: 検証コマンドの打ち直し・`task ship` の失敗（`VERIFY_FAILED` など）・同じファイルを3回以上直した・ツールのエラー・完了条件に無い差分・受け入れのときにメインが直したもの
- 当たらなければドラフトには何も積まない（「うまくいった」は書かない）

## 解くべき論点

1. **基準点の共有**: `develop/retrospective.md` の「最後に振り返ったコミット」は1行で、複数の作業ツリーが並行してタスクごとに振り返ると、互いのタスクを飛ばす・同じ行で衝突する。範囲を「そのタスクのコミット」に絞る形（例: `scan.py` / `material.py` にタスクIDを渡す）にするか、基準点の持ち方を変えるか
2. **記録の置き場**: タスクごとに振り返った事実を `develop/retrospective.md` に積むのか、タスクファイルの結果の節に1行で書くのか（コミットを増やさないなら後者。`task ship` のあとに振り返るとタスクファイルはもう送り済み）
3. **手順の位置**: `task ship` のあとに振り返ると、ドラフトを積んだ `direction.md` を別のコミットで送ることになる。`task done` の前（受け入れの直後）に振り返って同じコミットに入れるほうがよいか
4. **まとめての振り返り**: 手で呼ぶ `/retrospect`（範囲まとめて）を残すか。残すなら、タスクごとの振り返りと範囲が重ならない形にする
5. **費用**: 1件ごとに `material.py` を走らせるトークンの量。兆候の判定を `material.py` の出力（数だけ）で済ませ、兆候に当たったときだけ diff を読む形にできるか
