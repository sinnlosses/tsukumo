## 目的

画像を原寸で拡大して見る面 `ImageZoom` を、汎用の部品の置き場 `components/ui/` へ戻す。
この部品は tsukumo の語彙を持たないので、置き場の基準（`docs/design.md` 2章「`components/ui/` の部品」の「読み手の数は問わない」）に合わせる。

## 完了条件

- `src/browser/components/ui/image-zoom/image-zoom.tsx` と `image-zoom.module.css` があり、`prompt-image/components/image-zoom/` は無い
- 読み手（`prompt-image.tsx` ほか）の import が新しい場所を指している
- `components/ui/` は `stores/` を読めない（`test/architecture.test.ts` の箱の辺）ので、`ImageZoom` が props だけで動くままであることを確かめる
- パスを指す記述（`.ts` / `.tsx` / `.module.css` のコメント・`docs/`）が新しい場所を指している（`bun run scripts/find-stray-reference.ts` が通る）
- `docs/design.md` 2章の `components/ui/` の部品の一覧に `ImageZoom` の行がある
- `bun run check` が通る

## 背景

- 2026-09-26 に、`components/ui/` に掛けていた「1つの領域だけが読むファイルは置かない」という検査をユーザーの指示で外した（`ui/` は汎用の部品の置き場で、読み手の数を問わない）
- `ImageZoom` は元は `components/ui/image-zoom/` にあったが、読み手が `prompt-image.tsx` だけになったときにこの検査に落とされ、`prompt-image/components/image-zoom/` へ下ろされていた（`docs/design.md` の「読み手が会話の画面の1つに戻ったものは、上げる引き金の逆で下ろした」の段）
- 同じ検査で `ui/` から出された部品は、git の履歴で見るかぎり `image-zoom` だけ

## やること

- `git mv` で `src/browser/components/page/conversation/components/prompt-image/components/image-zoom/` を `src/browser/components/ui/image-zoom/` へ移す（`.tsx` と `.module.css` の2ファイル）
- `image-zoom.tsx` の import 相対パス（`Button`・`Dialog`）を新しい階層に合わせて短くする
- `image-zoom.tsx` 冒頭のコメントを、`prompt-image.tsx` を名指しした tsukumo の語彙（開く場所・呼び出し元の内訳）を落とし、`components/ui/` の他部品と同じ「値と呼び先を props で受け取る部品」の説明に書き換える
- `image-zoom.module.css` 冒頭のコメントの自己参照パスを、`components/ui/` の他部品（`select.module.css` など）と同じ形（バックティックのファイル名だけ）に直す
- `prompt-image.tsx` の import と冒頭コメントの参照先を `./components/image-zoom/image-zoom.tsx` → `../../../../../../components/ui/image-zoom/image-zoom.tsx` に直す
- `test/comment-reference-backlog.ts` の `image-zoom.tsx`・`image-zoom.module.css` の2行のパスを新しい場所に直す
- `docs/design.md` 2章の「形だけの部品（`Select`）」の段に `ImageZoom` を、「`Select`・`Button` は持たないので `ui`」の段に `ImageZoom` を、それぞれ以前あった書き方（`git show bb92b55b` / `7b963f3d`）に合わせて足す
- `docs/design.md` 2章の「読み手が会話の画面の1つに戻ったものは、上げる引き金の逆で下ろす」の段にある `image-zoom` の例（いまは事実と逆になる）を外す
- `bun run format` → `bun run check` → `bun run scripts/find-stray-reference.ts` を通す
