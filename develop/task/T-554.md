## 目的

ターンが `speak` のツール呼び出しで終わったときに Claude Code 本体が差し込む催促を、仕組み（環境変数）と条（「完了」の1行）の両方で塞ぎ、1往復増えるのを止める。

## 完了条件

- `buildQuerySeedOptions` のテストが、環境変数 `CLAUDE_CODE_TERMINAL_MCP_TOOLS=mcp__tsukumo__speak` が子プロセスへ渡る形を確かめる
- 見張りのテストが、催促の文面の利用者メッセージで1行出し、その他では出さないことを確かめる
- `chat-manner.ts` に「完了」の1行の条があり、雑談の画面にその1行が出ない
- 実物の tsukumo を起こし、雑談で数往復して催促が挟まらないこと（見張りのログが出ないこと）を確かめ、結果の節に書く（対話的な検証なので loopable は N）
- `bun run check` が通る

## 背景

T-546 で決めた（`docs/chat-mode.md` 4.9「雑談モードで変わるもの」の催促の段）。本体は `[Your previous response had no visible output. Please continue and produce a user-visible response.]` を利用者の発言として差し込む。仕事のターンは `src/server/core/report-notation.ts` の「完了」の1行の条だけで防いでいて、`Stop` の関所（`src/server/core/report-tool.ts`）は1行が無くても差し戻さない。雑談（`src/server/core/chat-manner.ts`）には防ぐものが無い。

本体の判定（同梱の `claude` 2.1.280 を読んだ結果）: `stop_reason` が `end_turn`/`stop_sequence` で、最後の応答に空でないテキストが無く、かつ直前のツールの往復に環境変数 `CLAUDE_CODE_TERMINAL_MCP_TOOLS`（カンマ区切りのツール名）に載ったツールの成功した呼び出しが無いときに、1回だけ催促する。この変数は公式の文書に無い。

## 決まっていること（蒸し返さない）

- 環境変数と条の両方で塞ぐ（2026-09-24 ユーザー決定）。片方だけにしない
- 環境変数: `query()` の子プロセスに `CLAUDE_CODE_TERMINAL_MCP_TOOLS=mcp__tsukumo__speak` を渡す。仕事・雑談の両方のモードで渡す。`process.env` を引き継いだうえで足す（SDK の `env` が丸ごと置き換えかどうかは SDK の型定義で確かめる）
- 条: 雑談の `chat-manner.ts` にも「最後の `speak` のあとに「完了」の1行だけ書いて終える」を足す。仕事の `report-notation.ts` の条はそのまま残す（保険）
- 見張り: 催促の文面で始まる利用者側のメッセージを SDK のイベントで見かけたら、それが届いたという事実だけをログに1行出す（中身は写さない。`docs/coding-standards.md`「会話内容の扱い」）。変数が効かなくなったことに気づくためのもの

## やること

- 環境変数: `Config` に `inheritedEnv`（読んだ環境そのもの）を足し、`session-start.ts` →
  `SessionDriverOptions.inheritedEnv` → `buildQuerySeedOptions` の `env` へ運ぶ。足す値と変数名は
  `src/server/core/visible-output-nudge.ts`（`childProcessEnv`）が持つ。SDK の `env` は
  `process.env` と混ざらず丸ごと置き換わる（`sdk.d.ts` の `env` の注釈）ので、引き継ぎを先に広げる
- 見張り: 同じファイルの `isVisibleOutputNudge`（`type: "user"` で `content` が固定文で始まる）を
  `relayMessages` で見て、`VISIBLE_OUTPUT_NUDGE_NOTICE` を stderr に1行出す
- 条: `chat-manner.ts` に「最後の `speak` のあとに「完了」とだけ書いて終える」を足す
- docs: `docs/chat-mode.md` 4.9 の段に実装の場所を、`docs/architecture.md`「レポートはテキストでは
  なく `report` ツールで受け取る」と `docs/display.md` 4.2 に環境変数で塞ぐ旨を足す
