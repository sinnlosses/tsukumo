## 目的

たまたま被害が出なかった箇所を、将来の失敗の芽として振り返りで拾う（Blameless postmortem の「Where we got lucky」）。いまは「検証コマンドの打ち直し」が3回以上でないと兆候に当たらず、1回の打ち直しで通った揺れが見逃される。

## 完了条件

- `retrospect` の「1件だけ振り返る」と手順3の兆候の表に「運良く助かった」の行があり、打ち直して通った・単独なら通る・受け入れで偶然気づいた、のどれか1回で当たる
- 当たったときの札と行き先が `retrospect` の SKILL.md の節「札と1行の書式」に沿っている（表の「札の候補」の列は、打ち直して通った・単独なら通る → `揺れ`、受け入れで偶然気づいた → 気づいたものに合わせる。色は実際に響いた重さで付け、「運良く」は兆候の行が表す）
- `next-task` の受け入れ（手順6）で、打ち直して通ったことを報告に残す口がある（無ければ足す）
- claude-skills 側の検査（`./check.sh`）が通り、claude-skills の `main` に入っている
- このリポジトリの `pnpm run check` が通る
