## 目的

前段で作ったボタンの部品を、残る `components/page/` の画面にも行き渡らせ、画面ごとに手書きされたボタンの顔を無くす。

## 完了条件

- `src/browser/components/page/` の `<button>` のうち、**顔が前段の `Button` の `variant` のどれかと同じもの**が `Button` に置き換わり、顔の規則が消えている（箱——高さ・余白・角丸——と置き方は `className` に残す）。計画時の実測で候補になるのは、枠だけ（`.character-button`・`.diary-book-topbar-button`・`.achievement-day-switch-button` / `-today`・`.turn-nav-button`・`.pending-action`）、accent の枠（`.achievement-review-button`）、accent の塗り（`.character-create-submit`・`.diary-book-review-button`・`.diary-notice-open`・`.usage-review-start`・`.dispatch-send`）、`--state-ng` の塗り（`.character-delete-ok`・`.character-clear-confirm-ok`）、`--state-warn` の塗り（`.question-ask-answer`）、リンク風（`.character-link-button`・`.achievement-diary-open-book`・`.usage-review-previous`・`.usage-review-result-close`・`.usage-table-more`）、地も枠も無い（`.dispatch-tool`・`.diary-notice-dismiss`）
- **置き換えないもの**: 押せる行・押せる文字（`.achievement-calendar-day`・`.diary-book-toc-day`・`.chat-poke`・`.turn-title-toggle`・`.turn-history-jump`・`.character-list-new`・`.character-card-action`・吹き出し）、トークン消費の画面の `--usage-*` の顔（`.usage-review-stop`・`.usage-review-retry`・`.usage-review-proposal-*`・`.token-usage-choice`）、顔が一覧に無いもの（`.speech-log-open` / `-close`）。地の色が少し違うもの（`.pending-action` の `--surface` の地など）は、置いた場所で見た目が変わらないなら置き換え、変わるなら残す。残したものは理由を結果に1行ずつ書く
- 部品の API を広げたなら、`test/browser/components/ui/button/button.test.tsx` にその行を足してある（顔を足すなら `docs/design.md` 2章の一覧も直す）
- 押せないの書き方を `aria-disabled` に揃えたことで、もと `disabled` だったボタンがフォーカスできるようになった箇所を結果に書く
- `test/architecture.test.ts`「components/ui/ の部品の className」が通る
- 会話の画面（入力欄の送信・道具のボタン・許可・質問の札・札の頭の ‹ ›）・キャラクターの画面（作成・名前の編集・削除の確認・立ち絵を外す確認を含む）・成果の画面（日記帳の見開きと書き終わりの知らせを含む）・使用量の画面を起動して目視し、押す前・hover・focus-visible・押せないときの見た目を確かめている（何を見たかを結果に書く。hover・押せないときの見た目が顔に揃って変わったものは、どう変わったかを書く）
- `bun run check` が通る

## 背景

- 画面ごとに高さ（`30px` / `34px` / `2.25rem` / `2.5rem` / `2.75rem`）と角丸（`0.4rem` / `0.5rem` / `0.5625rem` / `8px` / `9px` / `0.875rem`）が違う。これは箱なので `className` に残る
- 作法は `docs/design.md` 2章「`components/ui/` の部品（variant の作法と一覧）」が正典

## 決まっていること（蒸し返さない）

- **箱（高さ・余白・角丸）は段に丸めない**（揃えるかは別の判断として持ち越し）
- トークン消費の画面の `--usage-*` の顔は `Button` の語彙に入れない
- 押せる行・押せる文字は `Button` にしない
