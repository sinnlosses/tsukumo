## 目的

前段で作ったボタンの部品を、残る `components/page/` の画面にも行き渡らせ、画面ごとに手書きされたボタンの顔を無くす。

## 完了条件

- `src/browser/components/page/` の `<button>` のうち、ボタンの見た目だけを持つもの（`.character-button` / `-danger`、`.character-link-button`、`.achievement-review-button`、`.diary-book-review-button`、`.diary-book-topbar-button`、`.achievement-day-switch-button`、`.turn-nav-button`、`.speech-log-close`、`.usage-review-result-close` など）が部品に置き換わり、規則が消えている。残したものは理由を結果に1行ずつ書く
- 部品の API を広げたなら、`test/browser/components/ui/` のテストにその振る舞いを足してある
- 会話の画面・キャラクターの画面（作成・削除の確認を含む）・成果の画面（日記帳の見開きを含む）・使用量の画面を起動して目視し、押す前・hover・押せないときの見た目を確かめている（何を見たかを結果に書く）
- `bun run check` が通る

## 背景

- 画面の高さの違い（`30px` / `34px` / `2.25rem` / `2.5rem` / `2.75rem`）と角丸の違い（`0.4rem` / `0.5rem` / `0.5625rem` / `8px` / `0.875rem`）がある。size の段に寄せるかは T-606 の結論に従う
