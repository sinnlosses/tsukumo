## 目的

画面の部品を置き換えるタスクで、目視で確かめたい状態を疑似セッションで出せるようにする。

## 完了条件

- `test/fixture/fake-session.json` と `scripts/capture-catalog.ts` の件で、次の状態を出して撮れる: 帯の「いまの作業」の実行中・失敗・背景のタスク、表情やキャラクターを消す確認のモーダル、日記帳の見開き
- すでに出せる状態があれば、足さずに、どの場面・件で出せるかを `docs/architecture.md`「手で確かめること」から辿れるようにする
- 撮った画像を見て確かめ、何が見えたかをタスクの結果に書く
- `bun run check` が通る
- 調べて前提が成り立たなければ、理由を書いて `dropped` で閉じてよい

## 背景

- 部品の置き換え（T-607・T-608・T-610）の目視で、この3つの状態と確認のモーダルを疑似セッションで出せず、毎回「組み立てた CSS の計算値を元の宣言と突き合わせる」で代えた。T-610 はツールのエラー5件、`screen-nav-current-work.tsx` の編集7回だった
- `fake-session.json` にはすでに `background-task` の場面がある（帯に出るかは確かめていない）
