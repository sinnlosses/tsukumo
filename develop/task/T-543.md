## 目的

サイドバー「セッション情報」のコンテキストの行を、ユーザーが用意した見本
（`/Users/sinnlos/Downloads/サイドバーのコンテキスト表示-html/SB-Context.dc.html` の「案1」）の形に
作り直す。いまは「コンテキスト」の文字ごとリンクを張った1行で、割合と自動圧縮までの残りが読めない。

## 完了条件

- リンクは右端の `›`（ホバー中は「詳しく ›」）だけ。「コンテキスト」のラベル・割合・量・棒はリンクにしない（ホバーで下線を出さない）
- 1段目に「コンテキスト」のラベル・大きめの割合（例 `28%`）・`使っている量 / 窓の大きさ`・右端の `›`、
  2段目に棒、3段目に「自動圧縮まで あと N」が出る
- ホバー（とキーボードのフォーカス）で札の背景と枠が浮き、右端が「詳しく ›」になる
- 割合が 70% 以上のときは割合の数字と棒を警告の色にし、3段目を「そろそろ区切りどき。自動圧縮まで あと N」にする
- リンク（`›`）の `aria-label` で「コンテキスト N% 使用。トークン消費の画面で詳しく見る」と読める
- 取得中・取れないときも札の高さが変わらない（いまの約束を保つ）
- `docs/screen-design.md` の「#### 使用量の行」を新しい形に書き直す
- `bun run check` が通る。加えて `bun run build` のあと実画面で、通常・ホバー・70% 以上（値を差し替えて）の3つを目視し、何が見えたかをタスクの結果に書く

## 背景

- いまの実装は `src/browser/features/sidebar/context-usage-row.tsx` の `ContextUsageRow`。
  `<a href="#token-usage">` の中にラベル・`使用 81K / 1M`・4px の棒を横1列に並べ、
  `sidebar.module.css` の `.context-usage-row:hover` で `text-decoration: underline` を出している
- 数は `src/browser/domain/context-usage.ts` の `useContextUsage` が返す `UseContextUsageResult`
  （`ready` のとき `totalTokens` / `maxTokens` / `percentage` / `untilCompactTokens`）。
  **自動圧縮までの残り（`untilCompactTokens`）は既に畳んであり、トークン消費の画面の札が使っている**ので、
  取得側に手を足す必要は無いはず
- 仕様の正典は `docs/screen-design.md` の「#### 使用量の行」（行の数は札の「使っている量」と同じ、
  取り直しはターンが終わるたび、取れないときも高さが変わらない、など）
- 見本の寸法: 札は `padding 8px 10px`・`margin 0 -10px`・角丸 10px・段の間 6px。割合は 15px / 500 の等幅、
  量と3段目は 11px。棒は高さ 8px・角丸 4px。ホバー時の背景 `#22212b`・枠 `#3a3946`、
  警告時の背景 `#2a2619`・枠 `#6b5a2c`・数字 `#f3dfae`・棒 `#e3b95c`、通常の棒 `#66d1be`
