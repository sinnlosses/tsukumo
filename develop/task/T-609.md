## 目的

`<h1>`〜`<h4>` に付いた見出しの規則（`margin: 0` + `font-size: var(--font-*)` + `font-weight`）が画面ごとに手書きされ、太さが `normal` / `600` / `700` / `bold` とばらついている。見出しの部品を1つ作り、段と色を variant で表して揃える。

## 完了条件

- T-606 が `docs/design.md` 2章に書いた作法どおりの見出しの部品が `src/browser/components/ui/` にあり、`test/browser/components/ui/` に level・variant → 描かれる要素・class のテストがある
- `src/browser/` の `<h1>`〜`<h6>` のうち、見出しの見た目だけを持つものが部品に置き換わり、対応する `*.module.css` の規則が消えている。画面固有の見た目（書体が明朝・色が日記の金など）を残したものは、その理由を結果に1行ずつ書く
- 置き換えた画面を起動して目視し、見出しの大きさ・太さの変化が意図どおりであることを確かめている（何を見たかを結果に書く）
- `bun run check` が通る

## 背景

- 計画時の実測で `<h1>`〜`<h6>` は 21ファイル33箇所。見出しの規則の例: `.task-board-heading`（heading・600）、`.achievement-title` / `.token-usage-title`（heading・normal）、`.character-create-heading`（heading・bold）、`.usage-table-title` / `.context-title` / `.achievement-calendar-title`（subheading）、`.character-section-heading` / `.usage-review-proposal-title`（body・700）、`.step-heading` / `.screen-nav-settings-heading`（label・ink-quiet）、`.turn-history-heading` / `.screen-nav-work-*-heading`（ink-quiet）
- 字の大きさのトークンは `src/browser/styles/theme.css` の `--font-label` / `--font-action` / `--font-secondary` / `--font-subheading` / `--font-body` / `--font-heading`
- 日記帳（`.diary-book-*-heading`）は `--font-serif` と `--diary-gold-*` を使う画面固有の見た目

## 注意

- 見出しの太さを揃えることで見た目が変わる箇所は、T-606 の結論に従う
