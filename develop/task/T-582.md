## 目的

## 完了条件

- `test/architecture.test.ts` の箱の一覧と箱をまたぐ辺の表が、`docs/design.md` に T-581 が書いた表と一致している（まだ移していない `features/` の機能もそのまま通る形）
- いまの `src/browser/components/` の6部品（と `.module.css`）と、T-581 の対応表が `components/` 側へ移すとしたもの（`browser/hooks/` など）が、表どおりの場所にある。対応するテストも `test/browser/` の同じ相対パスへ移っている
- 移したファイルを読む import がすべて新しいパスを指し、古い `src/browser/components/` 直下にファイルが残っていない
- `bun run check` が通る。`bun run build` が通る
