## 目的

ブラウザ側で使うライブラリを検討する。t3code の `apps/web/package.json` の依存と、Base UI・react-split・AutoAnimate を中心に、tsukumo に入れる値打ちがあるものを選ぶ（2026-09-27 ユーザーの指示）。

## 完了条件

- `docs/research/` に提案書を書く。候補ごとに「置き換える自作のもの・足す依存の重さ・入れたときに消せるコード・入れない理由」を表で並べ、入れる・入れないの推奨を付ける
- 入れると推奨したものは、実装のタスクの案を `develop/direction.md` のエージェントのドラフトに書く（登録はユーザーの承認のあと）
- `bun run check` が通る

## 解くべき論点

- Base UI を `components/ui/` の土台にするか（CSS Modules と色の正典 `docs/screen-design.md` との相性）
- react-split と今の分割の実装のどちらが読みやすいか
- AutoAnimate の演出が `docs/requirements.md`「2.2 対象外とすること」と画面の目的に沿うか

## やること

いまのコードで確かめた前提（2026-09-27）:

- `components/ui/` は `src/browser/components/ui/` の10部品。浮かぶもの・選ぶものは素の要素で持つ（`Dialog` は `<dialog>` の `showModal()`、`Select` は `<select>`）
- 分割は `components/page/conversation/components/conversation-layout/` の CSS grid の `fr` と3本の `LayoutResizer`（`role="separator"`）。比率は `domain/split.ts` が `localStorage` に持つ
- zustand は T-680・T-681 で入り済み、組み立ては T-684 で Vite、入力欄のエディタは T-700 が CodeMirror 6 に決めて実装は T-701
- `docs/design.md` 6.5 は「アニメーションのライブラリも要らない」、6.6 は「Tailwind には移らない」と決めている。E2E は `reducedMotion: "reduce"` で走る

手順:

1. t3code の `apps/web/package.json` の依存を1つずつ、tsukumo の同じ役目のもの（自作・既存の依存・無し）と突き合わせる
2. Base UI・react-split・AutoAnimate（と分割の比較相手に react-resizable-panels）を一次情報と `/tmp` での試し組み立て（gzip の増分）で測る
3. `docs/research/browser-library.md` に候補ごとの表と推奨を書く
4. 重なる既存のタスク（T-728・T-688）の背景に足すことを `develop/draft/` に1件ずつ積む

## 注意

- 依存を足すのはこのタスクの外（提案だけ）
- 既存のタスクと重なる候補は、そのタスクの背景に足すべきことをドラフトに書く
