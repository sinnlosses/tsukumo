## 目的

`report` の本文を型付きの塊で受ける案（`docs/research/report-block.md`）の最初の段として、記録と表示の側を節と塊の形（`sections`）に切り替える。ツールの引数はまだ文字列の `body` のままにし、利用者から見た変化を出さずに、塊の形と「塊 → Markdown」の組み立てを入れる。

## 完了条件

- `src/shared/report-block.ts` に節と塊の zod の形（提案書4章）と、塊から Markdown を組む関数（5章の逃がし方）を置く
- 記録（`src/shared/session-state.ts` の `report`）と `SessionEvent` の `report` を `body: string` から `sections` に替える
- `src/server/session-driver/core/sdk-message.ts` の `reportEvents` が、文字列の `body` を逃げ道の塊（`markdown`）1つに畳む（7章）。描く側に「文字列か塊か」の分かれ道を持ち込まない
- 過去のレポートの見た目が変わらないことを E2E と目視で確かめ、何が見えたかを結果の節に書く
- `docs/glossary.md` に「節」「塊」を足す
- `bun run check` が通る

## 背景

- 提案書の4章（塊の一式と schema の案）・5章（インラインの Markdown）・7章（過去の記録との互換）・11章の1段目
- 型で受けて描く前例は `checks`（`src/shared/report-check.ts`）
