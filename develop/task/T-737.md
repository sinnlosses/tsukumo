## 目的

CSS Modules の型の生成を `happy-css-modules` から css-modules-kit（https://github.com/mizdra/css-modules-kit）へ移すべきかを検討する（2026-09-27 ユーザーの指示）。

## 完了条件

- 推奨（移す・移さない）と理由を `docs/research/` に書く。少なくとも、型の生成の仕組み（生成ファイルか言語サービスか）・`bun run check` の型検査との組み合わせ・エディタの補完と定義へのジャンプ・保守の状況を比べる
- 移すと推奨したなら、実装のタスクの案を `develop/direction.md` のエージェントのドラフトに書く
- `bun run check` が通る

## 背景

- 今は `package.json` の `happy-css-modules`（^5.0.2）。仕組みの説明は `docs/design.md` の `styles["..."]` の型を述べた箇所
- 組み立てを Vite へ移すタスク（T-684）があり、移行の時期はそれと合わせて考える
