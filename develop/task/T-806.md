## 目的

逃げ道（`markdown` の塊）から新しい塊へ昇格させるきっかけを、使われ方の記録の数で機械的に出せるようにする。

## 完了条件

- `src/server/report/core/report-usage.ts` の1行に「塊の無い記法の種類」（`cols` / `card`・`chart`・`svg`・`dl`・引用・区切り線・`<details>`）と「塊のある記法が HTML の容れ物の中に出たか外に出たか」を足している。中身は持たず、形式の版を上げる
- `scripts/report-block-usage.ts` に上の2つの表を足している
- `docs/display.md` の `#### 塊を足す・外す基準` を、足す基準は塊の無い記法の数に、容れ物（複数の塊を畳む・並べる）の判断は塊のある記法の容れ物の中の数に当てる形に書き換えている
- `pnpm run check` が通る
- 調べて成り立たなければ、理由を書いて `dropped` で閉じてよい

## 背景

- 足す基準は「逃げ道の中の同じ記法が3%以上」だが、記録する記法（`src/server/report/core/report-violation.ts` の `MARKDOWN_NOTATIONS`）は塊のある8種だけで、塊の無い記法を数えていないので基準が空振りする
- 塊のある記法が逃げ道に入ったレポートは記録112件のうち8件（7.1%）。それが HTML の容れ物の中なのか、差し戻しの枠を使い切った2回目なのかを記録が区別しない
- 提案書 `docs/research/report-architecture.md` 1章・6章・7章の段1。T-746 より前に済ませる（欄と塊を足す前後で逃げ道の使われ方を見比べるため）

## 注意

- 記録に会話の中身（本文の文字列）を入れない（`docs/coding-standards.md`「会話内容の扱い」）
