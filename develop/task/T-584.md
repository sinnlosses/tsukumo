## 目的

会話の画面を構成する4つの領域を、手本の `components/page/<画面>/` に合わせて `components/page/conversation/` へ移す。

## 完了条件

- `src/browser/features/main-view/` `character-view/` `chat-view/` `dispatch/` が、`docs/design.md` の対応表の段3の行どおり中身ごと（`markdown/` `hooks/` `components/` `domain/` と `.module.css` を含む。ファイル名は変えない）`components/page/conversation/<同じ名前>/` にある。テストも `test/browser/` の同じ相対パスへ移っている
- `test/architecture.test.ts` の領域の一覧の4つのパスが `components/page/conversation/<領域>/` になっている（4つどうしの import は禁止のまま）
- 古いディレクトリにファイルが残っていない。`main.tsx` の import が新しいパスを指す（`<Root>` は `main.tsx` に残す）。移したパスを指す記述（`docs/` の `history/` 以外・`CLAUDE.md`・`src/` と `test/` のコメント。`src/server/core/report-notation.ts` を含む）が新しいパスになっている
- `bun run check` と `bun run build` が通る。画面を開いてメインビューのレポート（mermaid と chart を含むもの）・キャラビューの吹き出し・入力欄・雑談モードの切り替えが以前と同じに見えることを目視で確かめ、何を見たかを結果に書く

## 背景

- `features/main-view/` はいちばん大きい（`markdown/` の下に11ファイル、`domain/turn-title.ts`、`hooks/` に4本、`.module.css` が5枚）。`markdown/vendor-script.ts` と `chart.ts` は `src/server/adapter/vendor-asset.ts` が配る経路を読む（`shared/vendor-asset.ts` 経由なのでパスには依存しない）
- 雑談モードでは `main.tsx` の `<Root>` がメインビューを `chat-view` に差し替え、キャラビューを畳む（`docs/chat-mode.md` 4.9）。組み立ては `main.tsx` に残す決定（`docs/design.md` 2章）
- 移す先・依存の向きの正典は `docs/design.md` 2章（T-581 が書いた対応表・箱の表）

## やること

`docs/design.md` 2章「いまの `src/browser/` から移す先（移行の対応表）」（段3の行）で前提を
確かめ直した。表は本文と食い違っていない（`features/main-view/` `character-view/` `chat-view/`
`dispatch/` を中身ごと `components/page/conversation/<同じ名前>/` へ、テストも
`test/browser/` の同じ相対パスへ）。作業は要る。

- `git mv` で4領域を `src/browser/features/<領域>/` → `src/browser/components/page/conversation/<領域>/`
  へ、対応する `test/browser/features/<領域>/` → `test/browser/components/page/conversation/<領域>/`
  へ移す（ディレクトリごと。ファイル名は変えない）
- `test/architecture.test.ts` の `BROWSER_REGIONS` の4つのパスを
  `components/page/conversation/<領域>` に直す
- 相対 import の深さ調整（`components/page/conversation/<領域>/` は `features/<領域>/` より
  2段深いので、`../../` が増える）。4領域から `features/task-board` など置かれる機能への
  import、共有部品（`components/domain/` `components/ui/` `domain/` `hooks/` `lib/` `stores/`）への
  import、`main.tsx` からの import を洗い出して直す
- 移したパスを指す記述（`.ts`/`.tsx` のコメント・`.module.css` のコメント・`docs/`・`CLAUDE.md`）を
  `grep -rn` で洗って直す。`src/server/core/report-notation.ts` のコメントを含む
- `bun run format` → `bun run check` → `bun run build` を通す
- 疑似セッションで起こして目視確認する
