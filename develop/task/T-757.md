## 目的

並行する作業ツリーが `develop/direction.md` の `## エージェントのドラフト` の末尾に積んだ行どうしが、送り出しのたびにぶつかる。ぶつかっても両方を残す形にし、衝突の印が main に入ったら検証で落ちるようにする。

## 完了条件

- リポジトリ直下の `.gitattributes` で `develop/direction.md` に `merge=union` が付いている（git 組み込みのドライバなので外部コマンドは増えない）
- `develop/` の下のファイルに衝突の印（行頭の `<<<<<<< ` / `||||||| ` / `=======` / `>>>>>>> `）が残っていたら落ちるテストがあり、印を1行書き足すと落ちることを確かめて結果に書く
- 一時的な枝2本で `## エージェントのドラフト` の末尾に別々の行を足して merge し、衝突せずに両方の行が残ることを確かめて結果に書く（確かめたあと、枝は消す）
- `bun run check` が通る

## 背景

- 2026-09-27 の1日で、`## エージェントのドラフト` の末尾への追記どうしが3回ぶつかった。T-721・T-697 は `task ship` のあとに「衝突の印を消す」コミットを1つずつ足し、T-697 の分は `|||||||` の行が main に入った（コミット b75193f7 で消した）。T-672 は `CONFLICT` で止まり、手で付け替えた
- 今は `.gitattributes` が無い
- 迷子の参照の検査は `test/section-reference.test.ts`（入口は `scripts/find-stray-reference.ts`）が `bun run test` の中で走っている。衝突の印の検査も同じようにテストとして並べる

## やること

- いまのコードで前提を確かめ直した: リポジトリ直下に `.gitattributes` は無い（新規作成）。
  `develop/direction.md` は存在する。`develop/` の下は現状すべて `.md`（`develop/task/*.md` と
  `develop/direction.md` のみ）。`git config` は `merge.conflictstyle diff3`（背景の記述どおり）
- `test/section-reference.test.ts` は `scripts/section-reference.ts`（純粋関数）＋
  `scripts/lib/repository-reference.ts`（ファイルを読む入口）に分かれている。衝突の印の検査も
  同じ形にする: `scripts/conflict-marker.ts`（`<<<<<<< ` / `||||||| ` / `>>>>>>> ` の行頭を拾う
  純粋関数。`=======` は見出しの下線と区別できないので見ない）＋
  `scripts/lib/repository-conflict-marker.ts`（`develop/` 以下を読んで集める）＋
  `test/conflict-marker.test.ts`（0件を保つテスト）
- リポジトリ直下に `.gitattributes` を作り、`develop/direction.md merge=union` の1行だけを書く
- 印を1行足すと `test/conflict-marker.test.ts` が落ちることを確かめてから戻す
- 一時的な枝2本での merge の確認は、このワークツリーの外（`/tmp` に `git worktree add` するなど）
  で行い、確かめたら消す
- `bun run format` → `bun run check` を通す

## 注意

- `union` は `develop/direction.md` にだけ付ける。`develop/task/*.md` や `docs/history/*.md` に付けると、front matter のような本当にぶつかるべき所まで黙って両方残る
- このリポジトリの git は `merge.conflictstyle diff3` なので、衝突すると `|||||||` の行も入る。印の検査はこれも拾う
- `=======` は Markdown の見出しの下線にもなる。印の検査は、`<<<<<<< ` と `>>>>>>> ` の組で見るなど、誤検知しない形にする

## 結果

- 検証コマンド: 2706 pass / 0 fail、E2E 24 pass / 0 fail。`<<<<<<< ` と `||||||| ` をそれぞれ `develop/direction.md` に1行足すとテストが落ち、戻すと通ることを確かめた
- 一時リポジトリで2本の枝が `## エージェントのドラフト` の末尾に別々の行を足して merge し、衝突せず両方が残った（枝ごと削除済み）
- 振り返り: 受け入れのときにメインが直したもの（`|||||||` を検査に足した）（ドラフト 0件）
