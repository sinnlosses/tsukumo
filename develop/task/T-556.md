## 目的

## 完了条件

- 次のどちらかが入っている（どちらにするかは着手時に決め、理由を完了時の結果に1行）: (a) `task.py` の `done` と `new` が、書き込んだファイルに「タスク運用」節の整形コマンドをかける（`なし` なら何もしない）/ (b) `next-task` 手順7・`plan-tasks` 手順7・`retrospect` 手順5 に、コミットの直前に整形コマンドを打つ手順がある
- claude-skills の `./check.sh` が通り、変更が claude-skills の `main` に入っている
- tsukumo の `bun run check` が通る

2026-09-24 の振り返り（`develop/retrospective.md` の `f1adaf96`..`7ef5a7ba`）で見つけたもの。T-527 の `task ship` が付け替え後の `format:check` で落ちた。原因は2つで、`task done --result-file` が書き込んだ結果の表（`oxfmt` が列を揃え直す）と、先に `main` へ入っていた登録のコミット（`115a3843`）が `develop/direction.md` に残した空行2行。どちらも `next-task`・`plan-tasks` の手順に整形が無いために起きる。
