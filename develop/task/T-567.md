## 目的

見本 SEIKA-4 の (d) 暦の日を押す と (e) まだ振り返っていない日を押す の場面を作り、過去の日記を読み返せるようにする。

## 完了条件

- 暦の日（と吹き出しの「日記帳で読む」）から見開きのモーダルが開く。左ページにしおり・この日に終えたこと・卒業や節目、右ページに縦書きの本文・漢数字の日付・曜日・灯り・署名と顔
- 前後の日へ送れ、目次から日記のある日へ飛べる（送り方と目次の中身は T-561 の仮決めに従う）。閉じられる（Esc と枠の外も）
- 書き足された日は段落の区切りが見える
- まだ振り返っていない日は白紙のページと「この日を振り返る」が出て、押すとその日付で振り返りの依頼が送られる
- 漢数字の日付への変換は純粋関数でテストしてある。部品の振る舞いのテストがあり、`bun run check` が通る
- 目視確認（(d)(e) の場面と縦書きの見え方）を結果に書く

## 背景

- 見本は `docs/history/mockup/achievement-diary-2026-09-25/SEIKA-4d-OpenDay.dc.html` と `SEIKA-4e-OpenBlank.dc.html`
- モーダルの先例はセリフのログ（`src/browser/features/character-view/speech-log.tsx`、`src/browser/hooks/use-modal-dialog.ts`）
- 目視はモーダルの中まで測る（横スクロールの有無など）
