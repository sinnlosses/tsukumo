## 目的

手書きの `<button>` を `components/ui/` の `Button` に寄せる置き換えを、T-724 が閉じたところから続ける。残りは `Button` の props を広げるかどうかの判断が要るものなので、その判断を先に決めてから置き換える。

## 完了条件

- `components/ui/` の外の `<button>` を種類（`ref` が要る・`aria-expanded`/`aria-controls` が要る・`disabled` の専用の見た目・`data-*`・`role`・`docs/design.md` 2章が除く中身そのものを押すもの）ごとに分け、種類ごとに「`Button` に受け口を足して置き換える」か「`<button>` のまま残す」かを決め、`## 決まっていること（蒸し返さない）` に書く
- 置き換えると決めた箇所を置き換える。**元の見た目を変えない**（置き換えの前後で、枠・地・字の色・下線・太さ・opacity・cursor の computed style を通常と hover で比べて一致させる）
- 2章の除外に当たるものは `<button>` のまま残す
- 置き換えた数と残した数・残した理由を `## 結果` に書く
- `pnpm run check` が通る
- 調べて置き換える価値のあるものが無ければ `dropped` で閉じてよい

## 背景

- T-724 は `<button>` 15箇所のうち9箇所を `Button` にし（variant を5つ足した）、6箇所は `docs/design.md` 2章「`Button` にしない」（押せる文字・チップ・暦の日・吹き出しのように中身そのものを押すもの）に当たるとして残した
- 2026-09-27 時点で `src/browser` の `components/ui/` の外に `<button>` が36箇所（25ファイル）ある（T-724 が残した6箇所を含む）。多いのは `turn-header/presentational-turn-header.tsx`（5）・`usage-review-card/usage-review-card.tsx`（4）・`main-view/markdown/markdown.tsx`（3）
- 2026-09-27 の振り返り（T-724）: 最初の委譲先は2章の除外に当たるものまで既存の variant に寄せ、見た目を変えていた。受け入れで見た目の差が見つかり、ユーザー決定で opus でやり直した

## 解くべき論点

- `Button` に `ref`・`aria-expanded`/`aria-controls`・`data-*`・`role` の受け口を足すか（足すなら型でどこまで許すか）
- `disabled` のときの専用の見た目を持つものを variant で表すか、`<button>` のまま残すか
- 1コミットに収まらないなら、決めた種類ごとに後段のタスクへ分ける

## 注意

- 見た目の比べ方は T-724 の `## 結果`（fake driver の実ブラウザで computed style を並べ比べる）に倣う
