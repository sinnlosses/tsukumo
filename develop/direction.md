### ミニ立ち絵の仕様を練り直す（現状と選択肢。2026-09-21）

**決めていない。** 現状を1枚にまとめ、軸ごとの選択肢と推奨を並べただけ。承認をもらってから実装する。

#### 1. 現状の経路（イベント → 筆先の座標 → 立ち絵の位置）

1. **出る引き金は「確定したレポートが、やり取りを描き始めたあとに現れたとき」だけ。**
   `turn.tsx` が `final` の立っている最後のステップを選び、**マウント時点で既にあった本文なら選ばない**
   （過去のタブ・再読み込みでは出ない）。`prefers-reduced-motion: reduce` では演出ごと走らない
2. `report-reveal.ts` がレポートの根を受け取り、`reveal-plan.ts` が**トピック**（見出し・水平線が境目）に
   割って、塊ごとに「出し始め／出し終わりの時刻」を決める（文字1つ 40ms、塊ごとに下限 2400ms・
   上限 8000ms）。DOM は完成品のまま置き、**見せる範囲だけ**を進める
3. 毎フレーム `advanceBlock()` が走る。塊の中の行を上下2つの**帯**に割り、帯を左から右へなぞって
   斜めに戻る（Z字）。横の振れ幅は**塊を囲む枠の幅**（`frameOf`＝いちばん広い要素の幅）で、
   縦は帯の上端・下端。**文字の要素は `clip-path`、図・グラフは `opacity`** で見せる
4. そのフレームの筆先を `{ x, top, bottom }`（**ビューポート座標**）で `publishBrushTip()` に渡す。
   同時に `brush-scroll.ts` が、筆先が器の上下 96px に入ったら器を送る
5. `mini-portrait.tsx` が `useBrushTip()` で受け、**筆先があることだけ**を条件に描く
   （`character.mini` が無いパックは `portraits.default` の縮小に落ちる）。位置は
   `transform: translate3d(x, bottom) translateY(-100%)` ＝ **筆先の右・いまの帯の下端に立つ**。
   `position: fixed` + `left: 0.4rem` なので、姿の左端は筆先の 6.4px 右
6. 出し切る／利用者がホイール・指・ポインタ・キーで打ち切ると `publishBrushTip(undefined)` で**消える**

**いまの調整箇所は6つだけ**（`mini-portrait.module.css`）: 高さ（本文の行の3倍）・不透明度（1）・
筆先との余白（0.4rem）・追従の時定数（0.05s）・縁の drop-shadow（地の色×2）・暈の drop-shadow（差し色×2）。
**`<Portrait>` の4つの動き（呼吸・移動・完了の反応・失敗でびくっ）は渡していない**ので、
ミニ立ち絵が持つ動きは筆先への追従だけ。

#### 3. 軸と選択肢

##### 軸A: そもそも出すか（3案）

- **A-1 出す（いまのまま）。** 壊れるもの: 無し。ただし上の「3.0秒しか居ない」「地の上を滑る」は残る
- **A-2 出さない（撤去）。** 壊れるもの: 2026-09-14 の指示「キャラが書いているように動くと楽しい」が消える。
  演出（筆）自体は残せる
- **A-3 出す場所を変える**（本文の上ではなく、レポートの左の余白・行番号の位置に縦に並ぶ）。
  壊れるもの: 広い窓には余白があるが、**狭い窓には無い**ので2つの置き方を持つことになる

##### 軸B: 出す条件（4案）

- **B-1 筆先があるあいだだけ（いまのまま）。** 出ている時間は塊の数で決まる
- **B-2 ターンが動いているあいだずっと出す**（筆先が無いときは「待っている」位置に控える）。
  壊れるもの: 「書いている様子」という意味付けが薄れ、キャラビューの立ち絵との役割の差が消える
- **B-3 塊が2つ以上あるときだけ出す**（短いレポートでは筆だけ走らせる）。
  壊れるもの: 出たり出なかったりする理由が利用者から見えない
- **B-4 出す時間の下限を入れる**（現れたら最低1.5秒は消えない）。
  壊れるもの: 筆先が無くなったあとの居場所を別に決める必要がある

##### 軸C: 大きさと濃さ（4案 x 2）

大きさ:

- **C-1 いまのまま**（本文の行の3倍＝79px 固定）。**狭い窓ではキャラビューの61%**になり「明確に小さく」が崩れる
- **C-2 キャラビューの立ち絵に対する比で決める**（例: 常に35%）。壊れるもの: 窓を狭めると 46px まで縮み、
  2026-09-21 の目視で「判別できない」とされた 53px を下回る
- **C-3 本文の行の倍数のまま、下限と上限を px で挟む**（例: 64〜96px）。壊れるもの: ほぼ無い（いまの値がその中に入る）
- **C-4 狭い窓では出さない**（760px 以下は演出だけ）。壊れるもの: 狭い窓で「書いている様子」が消える

濃さ・縁取り（2026-09-21 に不透明へ変えた直後なので、**不透明そのものは蒸し返さない**）:

- **C-5 いまのまま**（暈x2・縁取りx2）
- **C-6 地の上では暈を弱め、文字の上でだけ強める。** 壊れるもの: 文字の上かどうかを描画中に判定する仕組みが要る
  （筆先の座標だけでは分からない）。**割に合わない**

##### 軸D: 筆先との関係（4案。**いちばん効く軸**）

- **D-1 いまのまま**（筆先の右・帯の下端。横画は枠の幅ぜんぶ）
- **D-2 横画の幅を「その帯に実際にある行の右端」までにする。** 実測の 24〜49% が 100% に近づき、
  **姿が本文の上を歩く時間が倍以上**になる。壊れるもの: 帯ごとに右端が変わるので**横画の速さが帯ごとに変わる**
  （時間は文字数で決まるため。速さを揃えるなら時間の配り方を幅で按分し直す必要がある）
- **D-3 筆先の左に立たせる**（書いたばかりの文字の上に立つ）。壊れるもの: **読みかけの文字を隠す**
- **D-4 帯の下端ではなく、帯の下（次の行の側）に立たせる。** 壊れるもの: 塊の最後の帯では本文の外にはみ出す

##### 軸E: 追従の仕方（3案）

- **E-1 いまのまま**（毎フレーム引き直す 0.05s の線形。遅れ＝速さx0.05s）。
  横画では 35px（姿の幅に収まる）だが、**斜めの戻りでは 155px** で姿が大きく置いていかれる
- **E-2 横画と戻りで時定数を変える**（戻りは 0 にして即座に付いていく）。壊れるもの: 戻りが瞬間移動に見える
- **E-3 戻りのあいだは姿を消す**（筆を上げている、という見立て）。壊れるもの: 塊ごとに1回ちらつく

#### 4. 推奨

**D-2（横画の幅を実際の行の右端までにする）を最優先。** 数字の上でいちばん効く（地を滑る時間が
半分以下に減る）うえ、変えるのは `report-reveal.ts` の `frameOf()` を**帯ごとの右端**にする1箇所で済み、
ミニ立ち絵の側は1行も変わらない。あわせて:

- **C-3**（高さに px の下限・上限を入れる）。狭い窓で「明確に小さく」が崩れているのを塞ぐ
- **E-2**（戻りだけ時定数を 0 にする）。155px の置き去りは D-2 を入れても残る
- 軸A は **A-1（出す）**、軸B は **B-1（いまのまま）** を推す。**出ている時間の短さは、確定した本文にだけ
  演出を掛ける変更（案B。別タスク）で自然に解ける**ので、ここで条件を足して二重に効かせない

**採らないほうがよいと考えるもの**: C-6（文字の上かどうかの判定）と D-3（筆先の左）。前者は仕組みが増えるわりに
見た目の差が小さく、後者は読みかけの文字を隠す。

#### 5. 確定した本文にだけ演出を掛ける変更（案B）の前後で変わること

|                            | いま（書きかけに掛かる）   | 案Bのあと（確定した本文に掛かる）             |
| -------------------------- | -------------------------- | --------------------------------------------- |
| 出ている時間               | 3.0秒（台本の `report`）   | 塊の数ぶん伸びる（14要素で 30.5秒の実測あり） |
| 通る範囲                   | 最終的な本文の 6%          | 本文の全体                                    |
| 器を送る（`brush-scroll`） | ほぼ効かない（本文が短い） | **効く**（1画面に収まらない）                 |
| 軸B（出す条件）            | 「短すぎる」が問題         | 「長すぎる」が問題になり得る                  |
| 軸D（被り）                | 被る時間が短く目立たない   | **被る時間が伸びるので効いてくる**            |

**軸Dと軸Eは案Bの前に入れてよい**（筆の形の話で、相手が誰でも同じ）。**軸Bを触るのは案Bのあと**にしたい。
