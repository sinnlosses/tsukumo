# 未対応の指示メモ（ここに書くと次のセッションが `/plan-tasks` でタスク化する。エージェントのドラフトは `develop/draft/` に1件1ファイル。正典: `task-workflow` の `WORKFLOW.md`）

## ユーザーから

- lint を充実させたい。受け入れのレビューで人の目が差し戻している種類（コメントに呼ぶ側の名前を括弧で並べる・正典の言い直し、など）を集め、機械で拾える形のものは lint の規則（か `test/architecture.test.ts`）に落とす。差し戻しの往復を1回ずつ減らすのが狙い
- `report` の差し戻しを減らしたい。数で決まる記法の規則（`conclusion` の1文目は全角50字以内・見出しは30字以内・日本語で書く、など）を、システムプロンプトの条だけでなく `report` ツールの欄の説明（`sdk-tool.ts` の `describe`）にも書き、書くその場で目に入るようにする
- `report` の差し戻しの種類を `report-usage` の記録に残したい（中身は入れず、違反の種類の名前だけ）。どの規則が何回当たったかを振り返れるようにし、よく当たる規則は欄の形で防ぐ・当たらない規則は削る判断を数でできるようにする
