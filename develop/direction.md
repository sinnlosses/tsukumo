### 補足（メインセッションの読み。タスク化のときに確かめること）

上の2点は引っ張る方向が逆に見えるが、biim の構成は「ゲーム画面が主役、テロップは短い」なので
噛み合う可能性がある。対応づけの案:

| biim       | tsukumo                                |
| ---------- | -------------------------------------- |
| ゲーム画面 | claude の TUI ペイン（読んで打つ場所） |
| 立ち絵     | tsukumo ペイン                         |
| テロップ   | 短い一言だけ（発話全文ではない）       |
| 情報パネル | モデル・経過時間・context 残量など     |

**確かめるべき論点**: 二重表示の何が厳しいのか。「全文が出るのは良いが2箇所にあるのが問題」なのか
「そもそも全文はいらない」なのか。ここで `docs/requirements.md` 4.2「吹き出し」の要件自体が変わる。

また、二重表示の根本的な解として、案B（statusline にマスコットを出す＝入力ペインの中に居させる、
`docs/requirements.md` 4.5 / T-006）が効く可能性がある。画面構成の検討と合わせて評価する。
