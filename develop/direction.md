### メインセッションが調べた事実

`orca terminal send --text "..." --enter` で live terminal に入力を送れる。`--interrupt` で
中断も送れる。`orca terminal read --screen` で**claude の現在の画面を読める**ので、許可
プロンプトの検知も原理的には可能。**Orca 側の機能は揃っている。**

### 訂正した誤解

ユーザーは「入力ペインには自分の入力だけ」と考えていたが、**Claude Code の TUI は入力欄の上に
会話が流れる**（応答も表示される）。設定では変えられない。できるのはペインを数行の高さにして
実質入力欄だけを見せることで、**二重表示は減らせるが無くせない**。入力の送り込み（Q6）が
実現すれば完全に消える。
