# コメントとタスク番号

規則の正典はこのファイル。理由と例外は `docs/coding-standards.md` の括弧の節（子のファイルは `docs/coding-standards.md` の目次で引く）。

- コメントは**無いと明らかに不都合を招くことだけ**（ファイルの責務・書き直すと壊れる制約・外部との対応）。「〜の方針でこうした」・正典の要約・規約への参照は書かない。経緯・採らなかった案は正典へ（「コメント」）
- コメントから別の場所は**シンボルの名前と正典の「句」で指し**、呼ぶ側・使う側を並べない（「別の場所を指すとき」）
- コメントに Markdown の記法を使わず、意味の切れ目で行を改める（決まった幅で文を割らない）
- コード・ドキュメントにタスク番号を書かない（「タスク番号を書かない」）
