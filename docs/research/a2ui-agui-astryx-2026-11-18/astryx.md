- MIT、Meta Open Source、リポジトリ `github.com/meta/astryx`（`packages/core`）、StyleX（`nm/@astryxdesign/core/package.json`）。

### 4.4 `src/browser/components/ui/` が包む部品と、未使用の有望部品

- Astryx の import は `src/browser/components/ui/` 配下のみ（`grep -rn "@astryxdesign/core" src` で他に該当なし）。
- 包んでいる部品（import の指定子）: `Text`（Text・Heading）、`VStack`、`HStack`、`Stack`、`VisuallyHidden`、`Button`、`ToggleButton`、`TextInput`、`TextArea`、`Field`、`Selector`、`MoreMenu`、`Table`、`Spinner`、`Skeleton`、`Resizable`、`Lightbox`、`Icon`、`Divider`、`Dialog`、`BottomSheet`、`Chat`（`ChatComposer` のみ）、`Card`、`Blockquote`、`Banner`、`Badge`、`theme`、`i18n`、`locales/ja-JP`。
- `Skeleton` の包みは `className`・`style` のみを通し、高さは `"1lh"` か未指定（`src/browser/components/ui/skeleton/skeleton.tsx`）。`width`・`radius`・`index` は未使用。利用箇所はタスク一覧・使用量カード・UI ギャラリーで、レポートでは未使用（`grep` の結果）。
- 未使用で有望な部品

| 課題 | 部品                                                                                                                                                                 | 理由                                                                |
| ---- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------- |
| 1    | `ProgressBar`、`Skeleton` の `index`、`Markdown` の `isStreaming`、`Timer`、`useAnimatedLayout`                                                                      | 確定的な進捗・波の遅延・逐次の本文・経過時間・寸法変化の平滑化      |
