## 判定

決めてあった規則どおりなら不採用になる。利用者は2026-09-23に、次の方針で進めると決めた:

- 推測ではなく仕組み化・ルール化につながるなら採用する
- 仕組み化につながっていて穴があるなら、それを塞ぐ手段を考える
- レポートの出力をパイプラインにして、フィルターや整形で良いレポートにする

6件はどれも「最後の `report` のあとに1行を超える本文」で、ターンの終わりに数えれば推測なしで
見分けられる。そこで次の3つを入れてから、同じ3条件で試し直す（タスクは `develop/tasks.json`）:

1. **`Stop` の関所**: SDK のターンの終わりに、最後の `report` のあとの本文が1行を超えていたら
   `block` にして、`report` で渡し直すよう返す（`@anthropic-ai/claude-agent-sdk` 0.3.280 の
   `StopHookInput` / `decision: "block"`）
2. **パイプラインの検査**: `report` の引数を規約のうち機械で判定できる条で検査し、違反をツールの
   戻り値で返して書き直させる（「戻り値は `"ok"` だけ」の決定は利用者が変えてよいと決めた）
3. **パイプラインの整形**: 意味を変えずに落とせるもの（定型の前置き・締めの行、余分な空行など）を
   落として描く
