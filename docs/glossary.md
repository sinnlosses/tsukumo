# 用語集

tsukumo で使う固有の用語を、**日本語表記・コード上で使う英語識別子・定義**の3点でまとめたもの。
表記ゆれを防ぐことが目的なので、迷ったらここに合わせる。

**方針**:

- ここに載せるのは**このプロジェクト固有の概念だけ**。タイムアウト・リトライ・エラー型のような
  一般的なプログラミング概念は載せない
- **英語識別子はまだコードが無いため「予定」**。実装時にこの表を正典として命名し、
  変えたくなったら**先にここを直してからコードを直す**
- 同じものを指す言い方が複数あるときは1つに決め、他は「避ける言い方」に書く

## このファイルの読み方

現時点では小さいので通読してよい。**25KBを超えたら**、下の索引で用語を1つ特定して
その見出しだけを読む運用に切り替える:

```bash
sed -n '/^### 立ち絵/,/^#\{2,4\} /p' docs/glossary.md
```

## 実行構成

### 箱

- **英語識別子（予定）**: 使わない（コード上はホストのポートとして現れる。下記）
- **定義**: tsukumo のページを表示する入れ物。いまは Orca のブラウザタブ。ページ自体は
  「どの箱でも動く Web アプリ」として作る
- **注記**: 箱に頼む仕事は**ページを開くこと（`showView`）1つだけ**
  （`docs/architecture.md`「箱（Orca のタブ）と中身（Web アプリ）を分ける」）
- **避ける言い方**: コンテナ（別の意味に取られる）、シェル、ラッパー

### サイドカー

- **英語識別子（予定）**: 使わない
- **定義**: **2026-09-11 の方針転換で役目を終えた語。** 本体とは別のペインで常駐し、
  transcript と状態ファイルを読んでビューを配るプロセスを指していた
- **注記**: いまの tsukumo は Claude Code を**動かす側**であって、横で覗くプロセスではない。
  **プロセスそのものを指したいときは「tsukumo」と書く**
- **避ける言い方**: **「サイドカー」を現在の説明に使わない**（経緯を語るときだけ使ってよい）

### ペイン

- **英語識別子（予定）**: `pane`
- **定義**: ターミナルの分割された1区画
- **注記**: **tsukumo はもうペインを分割しない**（2026-09-11）。画面は1枚のページに収まり、
  ターミナルのペインは tsukumo を起動する1つで足りる。tmux は未導入で、前提にもしない
  （`docs/architecture.md`「ペイン分割は Orca を前提にした」に経緯がある）

### サイドバー

- **英語識別子（予定）**: `sidebar`
- **定義**: 画面レイアウトの右上に置く、幅の狭いビュー。会話ではなく「その他情報」を出す
  （`docs/requirements.md` 4.7）
- **注記**: 中身は上から **(1) タスク一覧 (2) セッション情報** の2区画
  （`docs/display.md` 4.2）。コンテキスト使用量は出さない。**「いま何をしているか」の区画は
  2026-09-23 に帯の「いまの作業」へ移した**（`docs/screen-design.md` 13.9）
- **注記**: **雑談中は中身が差し替わる**（2026-09-23）: 上から **プロフィールの札・最近の話題・
  覚えていること・セッション** の4段で、タスク一覧は出さない（`docs/screen-design.md` 13.7「雑談のときの
  サイドバー」）
- **注記**: **レポートやセリフはここに出さない**（同じものを2箇所に出さないため）
- **避ける言い方**: 情報パネル、ステータスペイン、HUD

### ホスト

- **英語識別子（予定）**: `host`
- **定義**: tsukumo のページを出す相手。実測環境では Orca。**頼む仕事はビューを見せること
  （`showView`）だけ**で、それ以外の依存は持たない
- **注記**: ホストに依存する操作は1つのポート（`src/server/core/host.ts`）の裏に置き、実装は
  アダプタ（`src/server/adapter/orca-host.ts`）に閉じ込める（`docs/architecture.md`
  「ホスト依存の操作は1つのポートにまとめる」。「アダプタ」の項は「通信（移行後）」にある）
- **注記**: **「本体」とは別のもの**。本体は Claude Code の CLI を指す
- **避ける言い方**: 端末環境、プラットフォーム、シェル

### 本体

- **英語識別子（予定）**: 使わない（コード上に本体を指す識別子は現れない）
- **定義**: Claude Code の CLI そのもの。**tsukumo から見て、SDK が子プロセスとして起こす側**
  （2026-09-11 まではこちらが親で、transcript を書き出す側だった）
- **避ける言い方**: 親、ホスト、メイン

### 部屋

- **英語識別子（予定）**: `room`（名前は `roomName(viewPort)`。`src/shared/room.ts`）
- **定義**: 起こした tsukumo 1つの居場所。**ビューのポート1つが部屋1つ**で、同じディレクトリで
  2つめを起こすとポートがずれて別の部屋になる
- **注記**: 名前は和の色名12個をポートの並び順に割り当てたもの（7327 が「空色の間」。
  `docs/screen-design.md` 13.9）で、**語彙の外のポートはポート番号をそのまま名乗る**。
  **名前は画面（帯の左端）のためだけのもので、セッションの目印はポート番号のまま**。
  キャラクターの持ち物ではないので、語彙はパックの定義ファイルではなくコード側にある。
  **サイドバーのセッションの行には出さない**（一覧はいまの部屋のものだけなので、部屋の名前は
  全行で同じになり見分けの役に立たない。行を見分けるのは SDK の見出しと最終更新時刻。
  `docs/screen-design.md` 13.9「セッションの行の見出し」）
- **避ける言い方**: ルーム、ワークスペース、インスタンス

## 会話の駆動

### セッション

- **英語識別子（予定）**: `session`
- **定義**: SDK の `query` 1つ。**tsukumo 1プロセスにつき1つ**
- **注記**: **起こし直したときは前の続きから始まる**（`docs/requirements.md` 4.8。鍵は起動した
  作業ディレクトリと、tsukumo が `tagSession` で付けた印。**印はキャラクターパックごと・
  雑談かどうか・ビューのポートごとに違う**（`tsukumo:<パック名>@7327` と
  `tsukumo:<パック名>:chat@7327`。**末尾の `@` から先が目印で、中身はポート番号**。コード上は
  `SessionMark.viewPort` / `SessionChoice.viewPort`。**画面には部屋の名前として出る**）ので、
  セッションはキャラクターとモードと目印で分かれる）。新規で起こす逃げ道は
  `TSUKUMO_NEW_SESSION=1`
- **避ける言い方**: 会話、スレッド、コンテキスト

### セッション駆動

- **英語識別子（予定）**: `sessionDriver`
- **定義**: SDK を起動し、届いたイベントを tsukumo 内部の型に変換するモジュール。
  原則2の「受け取る」層にあたる
- **注記**: ここに表示の都合を持ち込まない。何をどう出すかは「決める」層の仕事
- **避ける言い方**: ランナー、ブリッジ、クライアント

### プラン

- **英語識別子（予定）**: `plan`
- **定義**: 契約の段と枠（`Max 20x` / `Pro` など）。出どころは2つあり、**Claude Code 自身の控え
  （`~/.claude.json` の `oauthAccount`）を先に見る**
- **注記**: **SDK の `accountInfo()` が返す `subscriptionType` は契約の段と合わないことがある**
  （Max の契約でも `"Claude Pro"` を返す実測がある）。控えは段（`claude_max`）と枠
  （`default_claude_max_20x`）を別々に持つので、そちらから組み立てられるならそれを使い、
  **組み立てられないときだけ SDK の値へ落ちる**（決めるのは `src/server/core/plan.ts`）。
  **知らない綴りは訳さない**（勝手な名前を付けると、画面の値が実態と違っていても気づけない）。
  どちらからも決まらなければ画面に何も出さない。`email` / `organization` はここに含めない
  （駆動の外へ出さない。会話内容の扱いと同じ考え方）
- **避ける言い方**: サブスクリプション、契約種別、ティア

### コンテキストの内訳

- **英語識別子（予定）**: `contextUsage`
- **定義**: いまのセッションが**文脈の窓**をどう使っているかを分類ごとに割った数。Agent SDK の
  `getContextUsage()` が返すもので、中身は Claude Code の `/context` と同じ
- **注記**: **ここでの「コンテキスト」は文脈の窓のこと**で、セッションの言い換えではない
  （セッションの「避ける言い方」としての「コンテキスト」とは別の語）。**分類は `kind`
  （`used` / `free` / `buffer` / `deferred`）で判定し、`name`（英語の表示名）では判定しない**
  — 知らない `name` は訳さずそのまま出す。**入るのはメモリファイルのパス・スキル名・MCP
  ツール名だけ**で、会話の文面は入らない（メッセージは数だけ）
- **避ける言い方**: コンテキスト使用量、コンテキストウィンドウ、トークン残量

### ターン

- **英語識別子（予定）**: `turn`
- **定義**: **利用者の依頼1つに対する応答**のまとまり。メインビューは1ターン＝1枚のレポートで
  区切る（`docs/display.md` 4.2）
- **注記**: 1つのターンの中に、複数の `speak` の呼び出しと、複数のツール実行が入りうる。
  **依頼なしで claude が自分で始めるターンもある**（背景のタスクが終わった知らせを受けて
  続きを報告する。記録を持たないターンの始まり `turn-started` として扱い、メインビューでは
  元の依頼のやり取りに積む。`docs/screen-design.md` 13.9「背景のタスク」）
- **避ける言い方**: やり取り、ラウンド、メッセージ

### 背景のタスク

- **英語識別子（予定）**: `backgroundTask`（型は `src/shared/background-task.ts` の
  `BackgroundTask`、状態は `SessionState.backgroundTasks`、イベントは `background-tasks-changed`）
- **定義**: ターンが終わったあとも claude が動かし続けているもの（`run_in_background` の Bash・
  背景のサブエージェントなど）。SDK の `system` / `background_tasks_changed` が顔ぶれ全体を
  運び、`ambient`（活動でないもの）は数えない
- **注記**: 帯の「いまの作業」が、ターンの外でも「背景で作業中」として出す
  （`docs/screen-design.md` 13.9「背景のタスク」）。**develop/tasks.json のタスク（サイドバーの
  タスク一覧）とは別のもの**
- **避ける言い方**: バックグラウンドジョブ、背景タスク（「タスク」単独はタスク一覧と紛れるので、
  「背景の」を付けて言う）

### speak ツール

- **英語識別子（予定）**: `speak`（ツール名そのもの）
- **定義**: tsukumo がプロセス内の MCP サーバとして提供するツール。引数は `text`（セリフ）と
  `expression`（表情）で、**戻り値は `"ok"` だけ**
- **注記**: **セリフの唯一の主経路**（`docs/architecture.md`「セリフはテキストの規約ではなく、
  ツール呼び出しで受け取る」）。**セリフが届く経路はこれだけ**（行頭マーカーの補助は
  2026-09-21 に撤去した）
- **避ける言い方**: 発話ツール、say、talk

### report ツール

- **英語識別子（予定）**: `report`（ツール名そのもの）
- **定義**: tsukumo が `speak` と同じプロセス内の MCP サーバで提供するツール。引数は
  `conclusion`（結論。必須）・`body`（本文。任意）・`favor`（お願い。任意）で、**戻り値は
  `"ok"` か、差し戻すときの規約違反だけ**。メインビューには `conclusion` → `body` → `favor`
  （お願いの塊）の順に描く
- **注記**: **試行中**（`TSUKUMO_REPORT_TOOL=1` のときだけ、仕事のセッションに載る。採否が
  決まったら消すか、レポートの唯一の経路にする）。レポートにするのはメインの呼び出しだけで、
  サブエージェントの呼び出しは捨てる。1つでも呼ばれたターンではツールの外に書いた本文を出さず、
  最後の呼び出しが最終レポート、それより前が中間レポートになる。規約の差し替えは
  `src/server/core/report-tool.ts`。`Stop` フックの関所も同じファイルにあり、SDK のターンの最後の
  `report` のあと（無ければターンの頭から）に1行を超える本文を書いて止まろうとしたら差し戻す。
  **呼び出しそのものも検査する**: 機械で判定できる記法の条に違反した呼び出しは描かずに、違反と
  直し方を戻り値で返して呼び直させる（1ターンに1回まで。`src/server/core/report-review.ts`）。
  通った `body` は描く前に整形し、意味の変わらない行（`conclusion` の繰り返し・定型だけの行・
  中身の無い見出し）を落とす（`src/shared/report-tidy.ts`）
- **避ける言い方**: レポートツール、reply

### remember ツール

- **英語識別子（予定）**: `remember`（ツール名そのもの）
- **定義**: tsukumo が `speak` と同じプロセス内の MCP サーバで提供するツール。引数は
  **1行の文字列1つ**で、**戻り値は `"ok"` だけ**。受け取った1行を「覚えたこと」へ書き足す
- **注記**: **雑談モードのときだけ載る**（`docs/design.md` 7.1）。何を書いてよいかの判断は
  モデル側の条（`src/server/core/chat-manner.ts`）が持ち、tsukumo 側は書く場所と上限だけを持つ
- **避ける言い方**: 記憶ツール、memorize、save

### forget ツール

- **英語識別子（予定）**: `forget`（ツール名そのもの）
- **定義**: `remember` と同じプロセス内の MCP サーバで提供するツール。引数は**消したい1行の
  文字列1つ**で、**戻り値は `"ok"` だけ**。「覚えたこと」の中の**完全一致する1行**を消す
- **注記**: **雑談モードのときだけ載る**（`remember` と同じ）。**消せるのは「覚えたこと」の節の
  行だけ**で、もともと `persona.md` にあった文面は消せない。一致する行が無くても何も返さない
  （`docs/design.md` 7.1）
- **避ける言い方**: 忘却ツール、delete、remove、unremember

### keep ツール

- **英語識別子（予定）**: `keep`（ツール名そのもの）
- **定義**: `remember` と同じプロセス内の MCP サーバで提供するツール。**引数は無く**、
  **戻り値は `"ok"` だけ**。いま話している1往復に「残す」旗を立て、**直近を読み戻す窓
  （64 KiB）から溢れても落ちない**ようにする
- **注記**: **雑談モードのときだけ載る**（`remember` と同じ）。**指せるのはそのターンだけ**で、
  過去のやり取りも文面も指せない。旗を書くのは**ターンの終わり**なので、ターンの途中のどこで
  呼んでも同じ1往復に付く。**消すツールは無い**（消す手は索引のファイルを消すこと）。
  いつ立てるかの判断はモデル側の条（`src/server/core/chat-manner.ts`）が持つ
- **避ける言い方**: ピン留め、pin、star、favorite、保存ツール

### index ツール

- **英語識別子（予定）**: `index`（ツール名そのもの）
- **定義**: `remember` と同じプロセス内の MCP サーバで提供するツール。引数は**その日の見出し
  1行**で、**戻り値は `"ok"` だけ**。下の「雑談の索引」に1行足す
- **注記**: **雑談モードのときだけ載る**（`remember` と同じ）。**書けるのは1ターンに1行、
  120文字まで**で、**見出しが付くのは書いた日**（前の日には付け直せない）。何を書いてよいかの
  判断はモデル側の条（`src/server/core/chat-manner.ts`）が持つ
- **避ける言い方**: 目次ツール、tag、label、要約ツール

### recall ツール

- **英語識別子（予定）**: `recall`（ツール名そのもの）
- **定義**: `remember` と同じプロセス内の MCP サーバで提供するツール。引数は**引く言葉1つ**で、
  **戻り値は当たった日の雑談そのもの**（当たらなければ短い一言だけ）。下の「雑談の索引」を引き、
  **当たった日のアーカイブだけ**を逐語で読む
- **注記**: **雑談モードのときだけ載る**（`remember` と同じ）。**戻り値が `"ok"` だけではない
  唯一のツール**で、返すのは**その会話自身の過去**だけ（`docs/chat-mode.md` 4.9「古い雑談は
  索引を引いて思い出す」）。**引けるのは1ターンに1回、1回 8 KiB まで**
- **避ける言い方**: 検索ツール、search、grep、思い出しツール

### 覚えたこと

- **英語識別子（予定）**: `personaMemory`（節の見出しは `## 覚えたこと`）
- **定義**: `remember` ツールで書き足した、**キャラクター自身についての1行**を並べた
  `persona.md` 末尾の節。書き先は `~/.tsukumo/characters/<パック名>/persona.md` の1箇所だけ
- **注記**: **利用者について知ったことは入らない**（`docs/chat-mode.md` 4.9 が正典）。
  節より前は書き換えず、節を消せば書き足す前の人格に戻る。**1行ずつ消せるのは `forget`
  ツールだけ**で、節の外の文面はどちらのツールからも触れない
- **避ける言い方**: メモリ、記憶、学習した内容

### 雑談の要約

- **英語識別子（予定）**: `chatSummary`
- **定義**: 雑談の記憶を畳むために claude 自身の圧縮（`/compact`）が作る要約と、その**最新の1つ**を
  tsukumo が持つ写し（`~/.tsukumo/chat-summary/<パック名>.md`）。**受け持つのは直近より前だけ**で、
  直近は要約せず逐語のまま渡る（下の「雑談のアーカイブ」。`docs/chat-mode.md` 4.9）
- **注記**: 写しを持つのは**新しいセッションへ記憶を渡すため**で、載せ直すのは雑談のセッションの
  `systemPrompt`。載せるのは**新規に起こしたとき**と**`/clear` を見たあと**の2つで、それ以外の
  `resume` には載せない（claude 側の要約が既にある）。どちらかは**写しの1行目の印**が持つ。
  **「別の場所に複製しない」に対して認められた例外の1つ**（残る2つは下の「雑談のアーカイブ」と
  「雑談の索引」。`docs/chat-mode.md` 4.9、形と上限は `docs/design.md` 7章）
- **避ける言い方**: コンパクト、圧縮ログ、会話の履歴

### 最近の話題

- **英語識別子（予定）**: `chatTopics`（状態の欄。イベントは `chat-topics-changed`、部品は
  `RecentTopicSection`）
- **定義**: 雑談中のサイドバーの2段目に並べる、話題の見出し（新しい順に3件まで）。**雑談の要約の
  写しの最後に claude 自身が書いた見出しの節**（`<topics>` の組）から取り出す
  （`docs/chat-mode.md` 4.9、形は `docs/design.md` 7章）
- **注記**: 更新されるのは圧縮のときだけ。**画面へ運ぶのは見出しだけ**で、要約の本文は運ばない
- **避ける言い方**: 話題の一覧、トピック、履歴

### 雑談のアーカイブ

- **英語識別子（予定）**: `chatArchive`
- **定義**: 雑談モードの会話（利用者の依頼とキャラクターのセリフ、セリフの表情つき）を、届いた
  その場で1行ずつ書き足していくファイル（`~/.tsukumo/chat-archive/<パック名>/<日付>.jsonl`）
- **注記**: **画面のログとは別物。** 画面の 100 ターンは**画面の上限**で、アーカイブは
  その上限にも圧縮にも影響されない（`docs/chat-mode.md` 4.9）。**残すのは雑談だけ**で、
  仕事の会話・本文（レポート）・ツールの入出力・画像そのものは入らない
- **注記**: **「別の場所に複製しない」に認められた例外の2つ目**（3つ目は下の「雑談の索引」。範囲は
  `docs/chat-mode.md` 4.9、形と上限は `docs/design.md` 7章）。**画面の復元の材料ではない**
  （画面を組み直すのは transcript から。4.8）が、**キャラクターの記憶の材料ではある** —
  新しい雑談のセッションを起こすとき、**新しいほうから 64 KiB** だけを逐語のまま読み戻して
  `systemPrompt` に載せる（2026-09-21。同じ日にあった「claude へ戻さない」を覆した）
- **注記**: **「残す」旗の付いた1往復は、この 64 KiB から溢れても落ちない**（上の「keep ツール」）。
  旗は同じディレクトリの `kept.jsonl` に**行を指す時刻だけ**として積み、**文面は複製しない**。
  読み戻すのは窓の**外側に 8 KiB** まで（`docs/chat-mode.md` 4.9、形は `docs/design.md` 7章）
- **避ける言い方**: バックアップ、会話ログの保存、履歴ファイル

### 雑談の索引

- **英語識別子（予定）**: `chatIndex`（ファイルは `index.jsonl`）
- **定義**: 雑談の**その日の見出し**（1ターンに1行、**1日に何行でもある**）を並べたファイル
  （`~/.tsukumo/chat-archive/<パック名>/index.jsonl`）。書くのは `index` ツール、引くのは
  `recall` ツールで、**当たった日のアーカイブだけ**が逐語で読まれる
- **注記**: **会話の写しではなく、その日の目次**（claude が自分の言葉で書いた1行）。
  **「別の場所に複製しない」に認められた例外の3つ目**（`docs/chat-mode.md` 4.9、形と上限は
  `docs/design.md` 7章）。`docs/` の「節の索引」と同じ作りで、**全文検索の仕組みは持たない**
- **注記**: **当たらない日のファイルは開かない**。消す手は `index.jsonl` を消すことで、
  **会話そのものは残る**（旗の索引と同じ）
- **避ける言い方**: 全文検索、インデックス（カタカナ）、検索インデックス、目録

### 圧縮の区切り

- **英語識別子（予定）**: `compactBoundary`
- **定義**: claude 自身の圧縮（`/compact`）が起きた位置に、雑談のログへ出す**細い線1本**
  （SDK では `system` / `compact_boundary` のメッセージにあたる）
- **注記**: **文言は添えない**（2026-09-21 決定。ユーザーの言葉「これは頭の中で行われるもの、
  という想定だから文言は出さないよ」）。「ここから前は要約になっている」に当たる説明文は
  画面に出さない。**セリフでも知らせない** — セリフの文面を決めるのは claude だけで、
  tsukumo がキャラクターの言葉を作らない（`docs/chat-mode.md` 4.9）
- **注記**: **押せない・畳めない**（利用者の操作の対象にしない）。**圧縮の数値**
  （`compact_metadata` の `pre_tokens` / `post_tokens` / `duration_ms`）は運ばない・画面に
  出さない
- **注記**: **仕事のメインビューには出さない。** 出るのは雑談のログ（`shared/chat-log.ts` の
  `chatLogEntries`）だけ
- **避ける言い方**: 忘却の印、要約の境界、コンパクション境界

### 許可プロンプト

- **英語識別子（予定）**: `permissionPrompt`
- **定義**: ツールを実行してよいかをモデルが利用者に尋ねるもの。SDK では `canUseTool` に届く
- **注記**: **キャラが聞く**。吹き出しに出して、その下のボタンで答える。`AskUserQuestion`
  （キャラクターからの質問）も同じ経路・同じ見た目で扱う（`docs/display.md` 4.2）
- **避ける言い方**: 確認ダイアログ、承認フロー、パーミッション

### transcript

  `docs/coding-standards.md`「会話内容の扱い」が正典。**SDK のイベントも同じ扱い**
- **注記**: SDK で動かしても transcript は書かれる。**セッションの復元では、ここを正典として

### セッションスラッグ

### 発話

- **英語識別子（予定）**: `utterance`
- **定義**: **ターンの本文**。SDK の `assistant` イベントのテキストにあたる
- **注記**: **セリフは含まない**（セリフは `speak` ツールで別に届く）。本文はすべて詳細

- **避ける言い方**: メッセージ、レスポンス

## 表示

- **注記**: **表示はすべてビューである**（2026-09-09 に全 HTML 化した。

### 画面

### キャラクター画面

### メインビュー

- **注記**: **作業の進行はサイドバーへ移した**（2026-09-11 決定）。1ターン＝1枚で、書きかけの

- **注記**: 素材はリポジトリに同梱せず、キャラクター定義からパスで参照する

### 吹き出し

- **英語識別子（予定）**: `balloon`（並びは `balloon-track`）
- **定義**: **セリフ**1件を囲って見せる表示。キャラビューの中で立ち絵と同居する。
  1件につき1つ出し、今のターンの分を並び（`balloon-track`）に縦へ積んで**最新を一番上**に見せる
  （並びは自前でスクロールする）。**立ち絵は領域の左下、並びは右上**に置き、領域の高さは全部使う。
  **最新の1件だけを濃く大きくし**（左下の角から立ち絵へ向けて尻尾を伸ばす）、過去は小さく薄くする

- **注記**: **ターンの本文は入れない**（本文はメインビューのレポートに回る）。

### セリフのログ

- **英語識別子（予定）**: `speech-log`
- **定義**: キャラビューの右上の「ログ」から開くモーダル。**キャラビューの舞台（立ち絵と吹き出し）を

  上→下で、ターンの境目に依頼の区切り（`きみ「<依頼の1行目>」 <時刻>`）を挟み、開いた直後は
  最新（下端）が見えている。過去の吹き出しは古いほど薄い（2026-09-23）
- **注記**: 材料は記録（`records`）で、別に溜めない。**雑談のログ・会話のアーカイブとは別物**
  （あちらは雑談モードの会話で、利用者の発言も並ぶ）
- **避ける言い方**: 履歴、発言履歴

### セリフ

- **英語識別子（予定）**: `speech`
- **定義**: **`speak` ツールの `text` 引数**。吹き出しに出す、会話のための言葉
- **注記**: 分離は**ツール呼び出しで届く**（2026-09-11）。行頭マーカー（`アスナ: `）で本文から
  切り出す補助の経路は**2026-09-21 に撤去した**（どの `persona.md` もマーカーを使えと書いて
  おらず、発火していなかった。`docs/display.md` 4.2）
- **注記**: 以前この語は「キャラクター定義側の固定文言」を指すために空けてあったが、
  出力の分離が決まったことで**キャラクターが話す言葉**を指す語に確定した。固定文言を

- **避ける言い方**: 台詞（表記は「セリフ」に統一）、メッセージ、一言

### 詳細

- **英語識別子（予定）**: `detail`
- **定義**: **ターンの本文**そのもの（手順・コード・表・判断とその理由）。メインビューに

- **注記**: **中身は変えない。** 読みづらさの主因は見た目なので、整形は見た目の範囲に留める

- **注記**: 表示単位としては「レポート」と呼ぶ。「詳細」はセリフと対になる役割の名前

### 中間レポート

- **注記**: 同じ位置に出る**実況**（「まず読むね」「次はテスト」）は落とす。落とす／残すの規則は

- **注記**: あとに別のレポートが出た中間レポートは `<details>` で畳む（`MainViewStep.superseded` /

  4.2 が正典
- **避ける言い方**: 途中経過、進捗レポート、速報

### お願い

- **英語識別子（予定）**: `favor`（レポートの中では `<div class="note note-favor">`）
- **定義**: **キャラクターから利用者への1件**。利用者にしか決められない・できないこと
  （判断・作業・情報）を、レポートの**いちばん最後**に1つだけ置く。印を付けた塊で描かれ、

- **注記**: **向きが「依頼」と逆。** 依頼は利用者からキャラクターへ（`turn-request`）、お願いは
  キャラクターから利用者へ。画面でも、依頼の見出しの縦罫とお願いの縦罫が同じ `accent` で対になる
- **注記**: **本文が正典**で、`speak` の側では「お願いがある」ことだけを言う（中身を二重に
  書かない）。**無いターンでは置かない**。規約は `src/server/core/report-notation.ts` と
  各パックの `persona.md`
- **避ける言い方**: 依頼（逆向き。`turn-request` が使っている）、質問（選択肢を出して答えを待つ

### 選択肢の比較

- **英語識別子（予定）**: `questionPreview`（`QuestionOption.preview`。札は `<QuestionAsk>`）
- **定義**: 質問（`AskUserQuestion`）の**選択肢ごとに付く Markdown の本文**と、それをメインビューに

- **注記**: **選択肢そのものは入力欄の箱に出たまま**（押す場所と読む場所を分ける。2026-09-21 決定。

- **注記**: `preview` は `AskUserQuestion` が元から持つ項目名なので**そのまま使う**。描くのは

- **避ける言い方**: プレビュー（カタカナだけだと「下書きの見え方」と読める）、選択肢の詳細

### 表情

- **英語識別子（予定）**: `expression`
- **定義**: 立ち絵の差分（思案 / どや顔 / あわあわ など）。**切り替わるのは `speak` の

### 書いている

- **注記**: 表情や素材は増やさず、CSS の動き1つ（筆を運ぶような小さな横の揺れ）で表す。優先順位

- **避ける言い方**: 執筆中、タイピング中

### 覆い

- **英語識別子（予定）**: `veil`（`character.json` の `background.veil`）
- **定義**: キャラビュー（と雑談中のメインビュー）に敷いた**背景画像の上に1枚かぶせる、
  `ground` 一色の膜**。値はその膜の不透明度で、`0.75` なら画像が見えるのは 25%。DOM の要素では
  なく、`.layout-ground` の `background` に積む2枚目のレイヤ（`linear-gradient()` に `ground` を
  同じ値で2回並べた平らな面）を指す
- **注記**: 画像の明暗によらず地の明るさを `ground` の側へ引き戻すために置く。これがあるので
  画像を `#ffffff` / `#000000` の2点と仮定するだけでコントラストの最悪値を押さえられる。
  **下限は 0.7**（`docs/screen-design.md` 13.8）。立ち絵より奥にあるので立ち絵は薄くならない
- **避ける言い方**: オーバーレイ、マスク、フィルタ、暗幕

### いまの作業

- **英語識別子（予定）**: `current-work`（帯の部品。`src/browser/features/screen-nav/` の中）
- **定義**: 帯のまん中に出す、tsukumo がいま何をしているかの札。状態の語（作業中 / 答え待ち /
  背景で作業中 / 依頼待ち / 止まっている）と、実行中の手順の1行の要約を並べる。押すと**依頼の手順**の一覧が
  帯の下に開く（`docs/screen-design.md` 13.9）
- **注記**: 2026-09-23 に、サイドバーの「いま何をしているか」の区画と帯の答え待ちの印を
  これ1つに置き換えた。**失敗したツールの引数と出力を読める場所は、開いた一覧の中の失敗した行**
- **避ける言い方**: ピル、ステータスバッジ、インジケーター（形の名前で、何を出すかを言わないため）

### 依頼の手順

- **英語識別子（予定）**: `turnStep`（一覧を導く関数は `src/shared/turn-step.ts` の
  `currentTurnSteps`）
- **定義**: いちばん新しい依頼（ターン）の中で claude が呼んだツール1回ぶん。済み / 実行中 /

## Claude Code 側の仕組み

### hook

- **英語識別子（予定）**: `hook`
- **定義**: Claude Code が特定のイベント（`SessionStart` / `PreToolUse` / `Stop` など）で
  実行する外部コマンド
- **注記**: **tsukumo は hook を使わない**（2026-09-11）。状態はすべて SDK のイベントで届く。
  以前は状態ファイルを書くために使っていた
- **注記**: hook の stdout はエスケープされてテキスト扱いになるため、そこから描画はできない
  （`docs/requirements.md`「3. 技術制約」）。登録先の `~/.claude/settings.json` は
  **orca が専有しているので上書きしない**

### 状態ファイル

- **英語識別子（予定）**: `stateFile`
- **定義**: **2026-09-11 の方針転換で役目を終えた語。** hook が書き、tsukumo が読む小さな
  ファイルで、表情の元になるイベント種別と実行中のモデルを持っていた
- **注記**: 表情は `speak` の引数とツールの実行状況から、モデルは SDK のオプションから分かる

### statusline

- **英語識別子（予定）**: `statusline`

### output style

## 通信（移行後）

2026-09-13 に決めた移行（`docs/design.md`）で加わった語。

### プロトコル

- **英語識別子**: `shared`（ディレクトリ `src/shared/`）
- **定義**: サーバ（core）とブラウザ（browser）の**両方が import する契約**。イベント・状態・reducer・
  コマンドとフレームの zod スキーマ・`PROTOCOL_VERSION`
- **注記**: `node:` にも `document` にも触らない。zod のスキーマが正典で、型は `z.infer`。
  **ディレクトリ名は 2026-09-20 に `protocol` から `shared` へ改めた**（層の名前を「どの実行環境で
  動くか」に合わせたため。`docs/research/architecture-placement.md`）
- **避ける言い方**: 共通、API、コントラクト

### アダプタ

- **英語識別子**: `adapter`（ディレクトリ `src/server/adapter/`）
- **定義**: 外の世界（Agent SDK・HTTP/WebSocket・ホスト・ファイル・子プロセス）に触るコードの
  置き場所。**1ファイル = 1つの境界**。判断は持たず、`core` から呼ばれるか `cli.ts` が結ぶ
- **注記**: インターフェースは**実装が2つあるもの（駆動・ホスト）にだけ** `core` に置く
  （`core/session-driver.ts` / `core/host.ts`）。`core → adapter` の import は
  `test/architecture.test.ts` が落とす
- **避ける言い方**: インフラ層、外界、helpers

### フレーム

- **英語識別子**: `ServerFrame`（`hello` / `events` / `error`）
- **定義**: サーバがブラウザへ WebSocket で送る1件。`hello` は接続直後の snapshot、`events` は
  まとめたイベント、`error` はコマンドの失敗
- **注記**: 経路名 `/ws` とトークンのクエリ名は `src/shared/session-socket.ts` が正典で、
  `adapter` と `browser` は値を再掲しない
- **避ける言い方**: メッセージ（SDK の `SDKMessage` と紛れる）、パケット

### コマンド

- **英語識別子**: `ClientCommand`（`prompt` / `interrupt` / `answer` / `set-model` /
  `set-permission-mode` / `switch-character` / `new-session`）
- **定義**: ブラウザがサーバへ WebSocket で送る1件。`commandId` を持ち、失敗は `error` フレームで返る
- **注記**: **スラッシュコマンド（`/model` など）とは別物。** あちらは `prompt` の `text` に書く
- **避ける言い方**: リクエスト、アクション

### セッションの姿

- **英語識別子**: `SessionState`（移行前は `SessionView`）
- **定義**: イベントを畳んで得た「いま画面に出すべき中身」。サーバとブラウザが**同じ reducer**
  （`applySessionEvent`）で同じ姿を持つ
- **注記**: 時刻はイベントの `at`（サーバの時計）から入る。ブラウザの時計を reducer に渡さない
- **避ける言い方**: ビューモデル、ストア、状態（単に「状態」と言うと接続中かどうかなどと紛れる）

### fake driver

- **英語識別子**: `fakeDriver`（`TSUKUMO_DRIVER=fake`）
- **定義**: `SessionDriver`（`src/server/core/session-driver.ts` の契約）と同じ形で、手で書いた
  疑似セッションどおりにイベントを流す実装（`src/server/adapter/fake-driver.ts`）。claude を起こさずに
  画面全体を動かすための道具
- **注記**: 疑似セッションは**架空の会話だけ**（`docs/coding-standards.md`「会話内容の扱い」）
- **避ける言い方**: モック（テストの中の置き換え一般と紛れる）、スタブ

### 疑似セッション

- **英語識別子**: `fakeSession`
- **定義**: fake driver（`src/server/adapter/fake-driver.ts`）が流すために手で書いた架空のイベント列
  （`test/fixture/fake-session.json`）。claude を起こさずに画面全体を動かすための材料
- **注記**: 疑似セッションは**架空の会話だけ**（`docs/coding-standards.md`「会話内容の扱い」）
