# 用語集

tsukumo で使う固有の用語を、**日本語表記・コード上で使う英語識別子・定義**の3点でまとめたもの。
表記ゆれを防ぐことが目的なので、迷ったらここに合わせる。

**方針**:

- ここに載せるのは**このプロジェクト固有の概念だけ**。タイムアウト・リトライ・エラー型のような
  一般的なプログラミング概念は載せない
- **英語識別子はまだコードが無いため「予定」**。実装時にこの表を正典として命名し、
  変えたくなったら**先にここを直してからコードを直す**
- 同じものを指す言い方が複数あるときは1つに決め、他は「避ける言い方」に書く

## このファイルの読み方

現時点では小さいので通読してよい。**25KBを超えたら**、下の索引で用語を1つ特定して
その見出しだけを読む運用に切り替える:

```bash
sed -n '/^### 立ち絵/,/^#\{2,4\} /p' docs/glossary.md
```

## 実行構成

### 箱

- **英語識別子（予定）**: 使わない（コード上はホストのポートとして現れる。下記）
- **定義**: tsukumo のページを表示する入れ物。いまは Orca のブラウザタブ。ページ自体は
  「どの箱でも動く Web アプリ」として作る
- **注記**: 箱に頼む仕事は**ページを開くこと（`showView`）1つだけ**
  （`docs/architecture.md`「箱（Orca のタブ）と中身（Web アプリ）を分ける」）
- **避ける言い方**: コンテナ（別の意味に取られる）、シェル、ラッパー

### サイドカー

- **英語識別子（予定）**: 使わない
- **定義**: **2026-09-11 の方針転換で役目を終えた語。** 本体とは別のペインで常駐し、
  transcript と状態ファイルを読んでビューを配るプロセスを指していた
- **注記**: いまの tsukumo は Claude Code を**動かす側**であって、横で覗くプロセスではない。
  **プロセスそのものを指したいときは「tsukumo」と書く**
- **避ける言い方**: **「サイドカー」を現在の説明に使わない**（経緯を語るときだけ使ってよい）

### ペイン

- **英語識別子（予定）**: `pane`
- **定義**: ターミナルの分割された1区画
- **注記**: **tsukumo はもうペインを分割しない**（2026-09-11）。画面は1枚のページに収まり、
  ターミナルのペインは tsukumo を起動する1つで足りる。tmux は未導入で、前提にもしない
  （`docs/architecture.md`「ペイン分割は Orca を前提にした」に経緯がある）

### サイドバー

- **英語識別子（予定）**: `sidebar`
- **定義**: 画面レイアウトの右上に置く、幅の狭いビュー。会話ではなく「その他情報」を出す
  （`docs/requirements.md` 4.7）
- **注記**: 中身は上から **(1) いま何をしているか (2) タスク一覧 (3) セッション情報** の3区画
  （2026-09-11 決定。`docs/requirements.md` 4.2）。コンテキスト使用量は出さない
- **注記**: **レポートやセリフはここに出さない**（同じものを2箇所に出さないため）
- **避ける言い方**: 情報パネル、ステータスペイン、HUD

### ホスト

- **英語識別子（予定）**: `host`
- **定義**: tsukumo のページを出す相手。実測環境では Orca。**頼む仕事はビューを見せること
  （`showView`）だけ**で、それ以外の依存は持たない
- **注記**: ホストに依存する操作は1つのポート（`src/infrastructure/host.ts`）の裏に置き、実装は
  アダプタ（`src/infrastructure/orca-host.ts`）に閉じ込める（`docs/architecture.md`
  「ホスト依存の操作は1つのポートにまとめる」）
- **注記**: **「本体」とは別のもの**。本体は Claude Code の CLI を指す
- **避ける言い方**: 端末環境、プラットフォーム、シェル

### 本体

- **英語識別子（予定）**: 使わない（コード上に本体を指す識別子は現れない）
- **定義**: Claude Code の CLI そのもの。**tsukumo から見て、SDK が子プロセスとして起こす側**
  （2026-09-11 まではこちらが親で、transcript を書き出す側だった）
- **避ける言い方**: 親、ホスト、メイン

## 会話の駆動

### セッション

- **英語識別子（予定）**: `session`
- **定義**: SDK の `query` 1つ。**tsukumo 1プロセスにつき1つで、毎回新規**に始まる
- **注記**: **再開はしない**（`docs/requirements.md` 2.2）。プロセスを落とすと会話は終わる
- **避ける言い方**: 会話、スレッド、コンテキスト

### セッション駆動

- **英語識別子（予定）**: `sessionDriver`
- **定義**: SDK を起動し、届いたイベントを tsukumo 内部の型に変換するモジュール。
  原則2の「受け取る」層にあたる
- **注記**: ここに表示の都合を持ち込まない。何をどう出すかは「決める」層の仕事
- **避ける言い方**: ランナー、ブリッジ、クライアント

### ターン

- **英語識別子（予定）**: `turn`
- **定義**: **利用者の依頼1つに対する応答**のまとまり。メインビューは1ターン＝1枚のレポートで
  区切る（`docs/requirements.md` 4.2）
- **注記**: 1つのターンの中に、複数の `speak` の呼び出しと、複数のツール実行が入りうる
- **避ける言い方**: やり取り、ラウンド、メッセージ

### speak ツール

- **英語識別子（予定）**: `speak`（ツール名そのもの）
- **定義**: tsukumo がプロセス内の MCP サーバとして提供するツール。引数は `text`（セリフ）と
  `expression`（表情）で、**戻り値は `"ok"` だけ**
- **注記**: **セリフの唯一の主経路**（`docs/architecture.md`「セリフはテキストの規約ではなく、
  ツール呼び出しで受け取る」）。行頭マーカーは補助
- **避ける言い方**: 発話ツール、say、talk

### 許可プロンプト

- **英語識別子（予定）**: `permissionPrompt`
- **定義**: ツールを実行してよいかをモデルが利用者に尋ねるもの。SDK では `canUseTool` に届く
- **注記**: **キャラが聞く**。吹き出しに出して、その下のボタンで答える。`AskUserQuestion`
  （キャラクターからの質問）も同じ経路・同じ見た目で扱う（`docs/requirements.md` 4.2）
- **避ける言い方**: 確認ダイアログ、承認フロー、パーミッション

### transcript

- **英語識別子（予定）**: `transcript`
- **定義**: Claude Code がセッションごとに書き出す JSONL ファイル。1行1イベントで、
  `~/.claude/projects/<セッションスラッグ>/<session-id>.jsonl` にある
- **注記**: **ユーザーの生の会話ログである**。扱いの制約は
  `docs/coding-standards.md`「会話内容の扱い」が正典。**SDK のイベントも同じ扱い**
- **注記**: SDK で動かしても transcript は書かれるが、**tsukumo はもう読まない**（2026-09-11）
- **避ける言い方**: ログ、履歴、JSONL（ファイル形式を指したいときだけ「JSONL」と言う）

### セッションスラッグ

- **英語識別子（予定）**: `projectSlug`
- **定義**: transcript の置き場所を決めるために、cwd をスラッグ化したディレクトリ名
- **注記**: **2026-09-11 の方針転換で役目を終えた語。** transcript を読まなくなり、追従先を
  探す必要も無くなった（`docs/architecture.md`「追従先は自前でスラッグ化せず、hookが書いた
  パスを読む」に経緯がある）

### 発話

- **英語識別子（予定）**: `utterance`
- **定義**: **ターンの本文**。SDK の `assistant` イベントのテキストにあたる
- **注記**: **セリフは含まない**（セリフは `speak` ツールで別に届く）。本文はすべて詳細
  （レポート）として扱う（`docs/requirements.md` 4.2）。2026-09-11 までは「セリフと詳細を
  両方含んだ全体」を指していた
- **注記**: 本文をそのまま吹き出しに出すことはしない
- **避ける言い方**: メッセージ、レスポンス

## 表示

### ビュー

- **英語識別子（予定）**: `view`（識別子は `ViewName` = `main` / `character` / `sidebar`）
- **定義**: tsukumo が HTML で組み立て、箱の中のブラウザタブに出す表示単位。
  メインビュー・キャラビュー・サイドバーの3つがあり、**入力欄と合わせて1枚のページ**に入る
- **注記**: **表示はすべてビューである**（2026-09-09 に全 HTML 化した。
  `docs/architecture.md`「表示はターミナル描画をやめて、すべて HTML にした」）
- **避ける言い方**: 画面、ウィンドウ、パネル

### メインビュー

- **英語識別子（予定）**: `main`
- **定義**: レイアウトの左上に置く、いちばん広いビュー。**レポートだけ**を出す
- **注記**: **作業の進行はサイドバーへ移した**（2026-09-11 決定）。1ターン＝1枚で、書きかけの
  本文がリアルタイムに流れる（`docs/requirements.md` 4.2）
- **注記**: 以前は「詳細ビュー」と呼んでいた（`docs/history/direction.md` 2026-09-09）
- **避ける言い方**: 詳細ビュー、詳細ペイン、プレビュー

### キャラビュー

- **英語識別子（予定）**: `character`
- **定義**: レイアウトの左下に置くビュー。**立ち絵と吹き出しが同じ領域に同居する**
- **注記**: 許可プロンプトと質問のボタンは**ここには出さない**。右下の入力欄の上に出る（2026-09-11。
  吹き出しの下に出したときは気づきにくく、入力欄と離れていた）
- **注記**: ターミナルのペインではなく HTML のビュー。**これが決まったことで、端末の画像
  プロトコルが通らない問題は関係なくなった**
- **避ける言い方**: キャラペイン、立ち絵ペイン

### ビューサーバ

- **英語識別子（予定）**: `viewServer`
- **定義**: ビューをブラウザに配るローカルの HTTP サーバ。`127.0.0.1` にだけバインドし、
  本文をメモリに持ち、更新を Server-Sent Events で push する。**依頼・回答・中断は同じサーバへの
  POST で受ける**（2026-09-11）
- **注記**: **移行後（2026-09-13 決定）は本文を持たず、ページ・束ねた JS と CSS・同梱物・立ち絵を配り、
  イベントとコマンドを WebSocket 1本でやり取りする**（`docs/design.md` 5章）。識別子は `server`
- **注記**: **本文をファイルに書き出さない。** 会話の一部を含むため
  （`docs/coding-standards.md`「会話内容の扱い」）
- **避ける言い方**: プレビューサーバ、開発サーバ

### 立ち絵

- **英語識別子（予定）**: `portrait`
- **定義**: キャラビューに表示するキャラクターの画像。HTML の `<img>` で出す
- **注記**: 素材はリポジトリに同梱せず、キャラクター定義からパスで参照する
- **避ける言い方**: スプライト、アバター、アイコン、マスコット（「マスコット」は
  statusline 側の小さい絵を指す語として空けておく）

### 吹き出し

- **英語識別子（予定）**: `balloon`（並びは `balloon-track`）
- **定義**: **セリフ**1件を囲って見せる表示。キャラビューの中で立ち絵と同居する。
  1件につき1つ出し、今のターンの分を並び（`balloon-track`）に縦へ積んで**最新を一番上**に見せる
  （並びは自前でスクロールする）。**立ち絵は領域の左下、並びは右上**に置き、領域の高さは全部使う。
  **最新の1件だけを濃く大きくし**（左下の角から立ち絵へ向けて尻尾を伸ばす）、過去は小さく薄くする
  （2026-09-12 決定）。折り返し・全角文字の幅・禁則処理はブラウザに任せる
- **注記**: **ターンの本文は入れない**（本文はメインビューのレポートに回る）。
  答え待ちの許可・質問のボタンは吹き出しの下ではなく、右下の入力欄の上に出る（`docs/requirements.md` 4.7）
- **避ける言い方**: バブル、コメント欄、メッセージボックス

### セリフ

- **英語識別子（予定）**: `speech`
- **定義**: **`speak` ツールの `text` 引数**。吹き出しに出す、会話のための言葉
- **注記**: 分離は**ツール呼び出しで届く**（2026-09-11）。行頭マーカー（既定は `アスナ: `）で
  本文から切り出す経路は**補助**として残る（`docs/requirements.md` 4.2）
- **注記**: 以前この語は「キャラクター定義側の固定文言」を指すために空けてあったが、
  出力の分離が決まったことで**キャラクターが話す言葉**を指す語に確定した。固定文言を
  指したくなったら別の語を立てる
- **避ける言い方**: 台詞（表記は「セリフ」に統一）、メッセージ、一言

### 詳細

- **英語識別子（予定）**: `detail`
- **定義**: **ターンの本文**そのもの（手順・コード・表・判断とその理由）。メインビューに
  レポートとして出す
- **注記**: **中身は変えない。** 読みづらさの主因は見た目なので、整形は見た目の範囲に留める
  （`docs/requirements.md` 2.2）。**口調も落とさない**
- **注記**: 表示単位としては「レポート」と呼ぶ。「詳細」はセリフと対になる役割の名前
- **避ける言い方**: ログ、詳細情報

### 表情

- **英語識別子（予定）**: `expression`
- **定義**: 立ち絵の差分（作業中 / どや顔 / あわあわ など）。**`speak` の `expression` 引数で
  切り替わり**、ツールの実行中は自動で「作業中」になる（`docs/requirements.md` 4.3）
- **避ける言い方**: 感情、ステート、ムード

### 衣装

- **英語識別子（予定）**: `outfit`
- **定義**: 実行中のモデルに対応する立ち絵の見た目。`haiku` = 軽装 / `sonnet` = 通常装備 /
  `opus` = 戦闘配置。モデルは SDK に渡した値から分かる
- **注記**: 「装備の重さ＝モデルの重さ」というメタファーで、Asuna output style の
  「出撃時の掛け声」のモデル分岐と対応する
- **避ける言い方**: コスチューム、スキン、テーマ

### キャラクター定義

- **英語識別子（予定）**: `characterPack`
- **定義**: 立ち絵の素材パスと、表情・衣装の対応を宣言的に書いた差し替え可能な定義ファイル
- **注記**: **移行後（2026-09-13 決定）は「キャラクターパック」**: `character.json`（表情のラベル・
  行頭マーカーを含む）と `persona.md`（tsukumo 向けの人格）と素材を1つのディレクトリで束ねたもの
  （`docs/design.md` 7章）。人格と素材を別々に選ぶ形はやめる
- **注記**: **コードにキャラクターの中身を書かない**ための置き場所
  （`docs/architecture.md` 原則4）
- **避ける言い方**: 設定ファイル（`config` は別の意味に使いたくなるため）、テーマ

### フォールバック

- **英語識別子（予定）**: 使わない（動作の呼び名であって、対応する識別子は置かない）
- **定義**: 表示物が1つ欠けても、残りを表示して動作を続けること。立ち絵の素材が無ければ
  セリフだけを出し、`orca` が無ければタブを開かずに配信だけ続ける
- **注記**: **表示物が1つ欠けたことを起動失敗にしない**（`docs/requirements.md` 4.2）
- **注記**: 端末の画像プロトコルが使えるかどうかは、立ち絵が `<img>` になったことで
  関係なくなった（2026-09-09）

## Claude Code 側の仕組み

### hook

- **英語識別子（予定）**: `hook`
- **定義**: Claude Code が特定のイベント（`SessionStart` / `PreToolUse` / `Stop` など）で
  実行する外部コマンド
- **注記**: **tsukumo は hook を使わない**（2026-09-11）。状態はすべて SDK のイベントで届く。
  以前は状態ファイルを書くために使っていた
- **注記**: hook の stdout はエスケープされてテキスト扱いになるため、そこから描画はできない
  （`docs/requirements.md`「3. 技術制約」）。登録先の `~/.claude/settings.json` は
  **orca が専有しているので上書きしない**

### 状態ファイル

- **英語識別子（予定）**: `stateFile`
- **定義**: **2026-09-11 の方針転換で役目を終えた語。** hook が書き、tsukumo が読む小さな
  ファイルで、表情の元になるイベント種別と実行中のモデルを持っていた
- **注記**: 表情は `speak` の引数とツールの実行状況から、モデルは SDK のオプションから分かる
  ようになったので、ファイルを介する必要が無くなった

### statusline

- **英語識別子（予定）**: `statusline`
- **定義**: Claude Code の入力欄下に出る1行の表示。ここに小さいマスコットを出すのが案B
- **注記**: 現状 orca が専有している。優先度は低く、MVPには含めない

### output style

- **英語識別子（予定）**: 使わない
- **定義**: Claude Code の応答の人格・口調を定義する設定。実測環境では `Asuna` が有効
- **注記**: 衣装のモデル分岐は、この output style の「出撃時の掛け声」と対応させる。
  **`speak` を呼ぶタイミングの規約もここに書く**（`docs/requirements.md` 4.2）
- **注記**: **SDK で効くかは未確認**（`docs/requirements.md`「7. 未決事項」）。効かないときは
  `systemPrompt` の preset に中身を足す形に倒す

## 通信（移行後）

2026-09-13 に決めた移行（`docs/design.md`）で加わった語。**コードが移行前のあいだは「予定」**。

### プロトコル

- **英語識別子（予定）**: `protocol`（ディレクトリ `src/protocol/`）
- **定義**: サーバ（core）とブラウザ（ui）の**両方が import する契約**。イベント・状態・reducer・
  コマンドとフレームの zod スキーマ・`PROTOCOL_VERSION`
- **注記**: `node:` にも `document` にも触らない。zod のスキーマが正典で、型は `z.infer`
- **避ける言い方**: 共通、shared、API

### フレーム

- **英語識別子（予定）**: `ServerFrame`（`hello` / `events` / `error`）
- **定義**: サーバがブラウザへ WebSocket で送る1件。`hello` は接続直後の snapshot、`events` は
  まとめたイベント、`error` はコマンドの失敗
- **避ける言い方**: メッセージ（SDK の `SDKMessage` と紛れる）、パケット

### コマンド

- **英語識別子（予定）**: `ClientCommand`（`prompt` / `interrupt` / `answer` / `set-model` /
  `set-permission-mode` / `switch-character` / `new-session`）
- **定義**: ブラウザがサーバへ WebSocket で送る1件。`commandId` を持ち、失敗は `error` フレームで返る
- **注記**: **スラッシュコマンド（`/model` など）とは別物。** あちらは `prompt` の `text` に書く
- **避ける言い方**: リクエスト、アクション

### セッションの姿

- **英語識別子（予定）**: `SessionState`（移行前は `SessionView`）
- **定義**: イベントを畳んで得た「いま画面に出すべき中身」。サーバとブラウザが**同じ reducer**
  （`applySessionEvent`）で同じ姿を持つ
- **注記**: 時刻はイベントの `at`（サーバの時計）から入る。ブラウザの時計を reducer に渡さない
- **避ける言い方**: ビューモデル、ストア、状態（単に「状態」と言うと接続中かどうかなどと紛れる）

### 偽の駆動

- **英語識別子（予定）**: `fakeDriver`（`TSUKUMO_DRIVER=fake`）
- **定義**: `SessionDriver` と同じ契約で、手で書いた架空の台本どおりにイベントを流す実装。
  claude を起こさずに画面全体を動かすための道具
- **注記**: 台本は**架空の会話だけ**（`docs/coding-standards.md`「会話内容の扱い」）
- **避ける言い方**: モック（テストの中の置き換え一般と紛れる）、スタブ
