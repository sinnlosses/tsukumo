# 完了タスクのアーカイブ

`develop/tasks.json` の `status: "done"` になったタスクを、トリガーに達した時点でここへ移す
（基準と手順は `docs/workflow.md`「肥大化したときのアーカイブ」が正典）。

タスクごとに `## T-XXX <タスク名>` の節を作り、**当時の記述をそのまま**移す。後から書き換えない。
`develop/tasks.json` 側の `evidence` は「コミットハッシュ・テスト件数・このファイルへの参照」に
置き換える。

セッション開始時に読む必要はない。過去の判断の経緯をたどりたいときだけ、`grep` で該当する
`## T-XXX` を見つけてその節だけを読む。**通読しない。**

（まだアーカイブされたタスクは無い）
