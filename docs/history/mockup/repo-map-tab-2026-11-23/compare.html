地図のタブの中身 — 候補を3案に組んで見比べる

ADR 0082 論点 7 の「タスク｜地図」のタブで、ミニマップの下に何を出すかの3案。物差しは「会話しながら横目で見て、そこから話し始める・タスクを起こす役に立つか」。箱の名前は今の src/ の機能、会話と数は架空。1400×900 の実寸。

案 A 箱の行だけ（推す）

論点 1〜4 の答え

  • 1: ミニマップの下は「会話で指された箱」→「このセッションで変えた箱」の順に箱のバッジの行。どちらも無いときは空の1行。ずれの件数は出さない（着手時の見立てから外した）
  • 2: 箱の詳細（役割・置き場・決定の記録・用語・つながり）は広げた地図の側。タブは行ごとに名前と役割の1行だけ
  • 3: タスクのタブを開いていたら切り替えず、「地図」のタブ名に青緑の点と件数を付ける
  • 4: 選んだ行の右端に1つのボタン「この箱について話す」。押すと入力欄に箱のバッジと「server/report（中）について、」を入れ、送らない

同じ情報が2か所に出ないか

  • ずれは pnpm run check の段がレポートの「確かめたこと」の1行に出すので、タブには出さない
  • 「変えた箱」は箱の粒度で、このセッションを通して積む。レポートの「変えたファイル」はそのターンのファイルの粒度なので重ならない

案 B 箱の詳細をタブに

論点 1〜4 の答え

  • 1: ミニマップの下は選んだ箱の詳細と、ずれの件数（1以上のとき）。指された箱が選びになる。変えた箱は1行のバッジの並び
  • 2: 箱の詳細の5項目をタブに積む
  • 3: タスクのタブを開いていても、箱が指されたら地図のタブへ切り替える
  • 4: 詳細の下に1つのボタン「この箱について話す」。下書きは A と同じ

同じ情報が2か所に出ないか

  • ずれの件数がレポートの「確かめたこと」の行と重なる
  • 勝手に切り替わると、見ていたタスクの区画を見失う。296px に5項目を積むと、指されるたびに選びが替わって読み切れない

案 C 1つの列と口2つ

論点 1〜4 の答え

  • 1: 指された箱と変えた箱を1つの列に新しい順で混ぜ、行に「指された」「変えた」の札を付ける
  • 2: 箱の詳細は広げた地図の側（A と同じ）
  • 3: タスクのタブを開いていたら切り替えず、タスクのタブの頭に「箱が指された · 地図で見る」の1行を出す
  • 4: 選んだ行の下に2つのボタン「話す」「タスクにする」。「タスクにする」は「server/report（中）の直しをタスクにして: 」を入れる

同じ情報が2か所に出ないか

  • 知らせの1行がタスクのタブの中に入り、タスクの一覧の区画に地図の情報が混ざる
  • 「タスクにする」の下書きは、利用者が文を続けて頼む形と同じ所へ行き着く。口が2つでも入力欄に入れるまでは同じ
