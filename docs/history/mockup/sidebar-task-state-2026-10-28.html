サイドバーのタスク行: ループ可・待ちを一覧で読む 4案

同じ6件を4通りで描いた。「ループ可」= loopable: Y の着手できる行、「待ち」= 依存で止まった行（blocked）と hold の行、「手で」= loopable: N の着手できる行。値は実画面の theme.css と task-item の寸法に合わせてある。

案A 印の形 + 右端の ↻

印の形で待ち（破線の角丸＝依存待ち、二本線＝hold）を言い、右端の ↻ でループ可を言う。列は1つ増えるだけ。

  • GH-1709report に row と panel を足す↻›
  • GH-1733操作の状態を自作する·›
  • GH-1738surface を結線する↻›
  • GH-1725決定待ちの移行方針·›
  • GH-1734ADR と振り返り↻›

案B 右端の文字チップ

「ループ」「待ち」「手で」を語で出す。読むのに慣れが要らない。代わりに題の幅が約40px削れる。

  • GH-1731描画の共有層をつなぐループ›
  • GH-1709report に row と panel を足すループ›
  • GH-1733操作の状態を自作する手で›

  • GH-1725決定待ちの移行方針待ち›
  • GH-1734ADR と振り返り待ち›
