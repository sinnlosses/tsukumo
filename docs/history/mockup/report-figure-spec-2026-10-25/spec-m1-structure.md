目的: report の呼び出しは判定の7つの関門を通ったときだけ描かれ、違反は欄を直す戻り道でモデルへ返る
形: connection
向き: LR
群:
- モデル側: モデル, 直して渡し直す
- サーバ: 形の検査, 判定, 通す, 記録
- ブラウザ: 整形, 欄ごとに描く, 吹き出し
節点:
- モデル | report を呼ぶ
- 形の検査 | 省いた欄は引き継ぐ
- 判定 | 7つの関門を上から順に
- 通す | endTurn を付ける
- 記録 | 引数のまま持つ
- 整形 | 落としても同じ行だけ
- 欄ごとに描く
- 吹き出し | closing を出す
- 直して渡し直す | 直す欄だけ
- Stop の関所 | report 無しで止まろうとしたとき
関係:
- モデル -> 形の検査: 引数を渡す
- 形の検査 -> 判定: 揃った引数
- 判定 -> 通す: 違反なし
- 通す -> 記録
- 記録 -> 整形
- 整形 -> 欄ごとに描く
- 欄ごとに描く -> 吹き出し
- 判定 -> 直して渡し直す: 違反あり [戻り]
- 直して渡し直す -> 形の検査: 呼び直す [戻り]
- Stop の関所 -> モデル: report で渡し直させる [戻り]
強調:
- 戻り道（違反あり・呼び直す・渡し直させる）
データ: なし
