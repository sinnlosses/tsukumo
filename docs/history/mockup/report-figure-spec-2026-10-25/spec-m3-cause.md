目的: 段の所要が「不明」になる原因は、最初の work_plan の渡し方の2通りの誤りに行き着く
形: cause
向き: TD
群:
- 原因: current を 1 以上で渡す, first に 0 を渡す
- 直し方: 着手時に current 0 で渡す, first を計画の次にする
節点:
- current を 1 以上で渡す | 作業を終えてから最初の work_plan
- first に 0 を渡す | 計画の段を委譲の範囲に入れる
- 最初の記録が途中から | 段の開始の時刻が無い
- 計画の段に「…」 | 範囲の先頭が番号を持たない
- 所要が「不明」 | 帯とレポートに出る
- 着手時に current 0 で渡す
- first を計画の次にする
関係:
- current を 1 以上で渡す -> 最初の記録が途中から: 招く
- 最初の記録が途中から -> 所要が「不明」: その段と前の段が測れない
- first に 0 を渡す -> 計画の段に「…」: 招く
- 計画の段に「…」 -> 所要が「不明」: 計画の段が測れない
- 着手時に current 0 で渡す -.> current を 1 以上で渡す: 防ぐ
- first を計画の次にする -.> first に 0 を渡す: 防ぐ
強調:
- 所要が「不明」
データ: なし
