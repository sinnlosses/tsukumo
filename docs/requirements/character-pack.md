# tsukumo 要件定義: キャラクターパック

ステータス: **ドラフト**。入口は `docs/requirements.md`（要件定義の全体）。

責務: 4.4 キャラクターパック（素材と表情の対応の差し替え、画面から変える・作る・消す）。
読む時: パックの置き場所・定義ファイル・画面から作る・変える・消す要件に触るとき。
直す時: キャラクターパックの要件を変えたとき。

## 4. 機能要件

### 4.4 キャラクターパック

素材（立ち絵の画像）と、表情の対応は**宣言的な定義ファイル**で差し替え可能にする。
ハードコードしない（`docs/architecture.md` 原則4）。

**置き場所**（`characters/README.md` が使い方の正典）:

| 場所                            | 中身                                                       |
| ------------------------------- | ---------------------------------------------------------- |
| `characters/tsukumo/`           | 既定のキャラクター。**このリポジトリのために自作**したもの |
| `characters/tsukumo-spirit/`    | もう1体。同じく**このリポジトリのために自作**したもの      |
| `characters/local/`             | 利用者が自分で用意した素材。**`.gitignore` 済み**          |
| `~/.tsukumo/characters/<name>/` | **画面から作ったパック**                                   |

**画面から作ったパックはリポジトリの外（`~/.tsukumo/`）に書く**。
探索先の優先順位・画像の受け取り方（data URL を WebSocket のコマンドに載せる）・大きさの上限は
`docs/architecture/character-pack.md`（「画面から作るときの置き場と受け取り方」を含む）が正典。**cwd には依存させない**ので、どのプロジェクトから起こしても同じ
パックが選べる。**作る口も、立ち絵・差し色を変える口も、会話の画面とは別のキャラクター画面にある**
（4.7、`docs/architecture/screen-design.md` 13.6）。

**このリポジトリは公開されている。** 権利のある画像（公式絵・ファンアート等）を
コミットしないため、利用者の素材は `characters/local/` に置く
（`docs/architecture/adr/0014-no-bundled-character-asset.md`）。

**定義ファイル**（`character.json`）は次を持つ:

- `portraits`: 表情（4.3 の一覧）→ 画像ファイル。
  **「あるものだけ」でよく、見つからない表情は `default` に落ちる。** 1枚から始められる

**移行後は「パック」になる**: `character.json` に `expressions`（表情名 → ラベル）と
`speechMarker` が加わり、同じディレクトリの `persona.md`（tsukumo 向けの人格）と素材を1単位として
読む。切り替えは別のパックでセッションを起こし直し、**新規のセッションから始まる**
（`docs/architecture/character-pack.md`・4.8）。

**同梱するパックは自作のものだけ**（理由は 2.2 の「キャラクター素材そのものの
同梱・配布」で、**`persona.md` に書く人格の記述も「素材」に数える**）。既存の作品のキャラクターを
演じさせたいときは、`characters/local/` に自分で置く（`.gitignore` 済み）。

**人格の二重適用は `applyFlagSettings({ outputStyle: "default" })` で避ける**。
`~/.claude/settings.json` の `outputStyle` は全プロジェクトに効くので、そのまま `persona.md` を
足すと人格が2つ重なる。**セッションを起こしたあとに呼ぶと `init` の `output_style` が `default`
になり、グローバルの人格が消えて `persona.md` だけが残る**。**これはセッション限りの層にしか
触らず、設定ファイルを書き換えない**（実測は `docs/history/decision.md`）。
`settingSources` からユーザー設定を外す案は、**orca の hooks まで外れる**ので採らない。

**日記の書体（`diaryFont`）はパックが持つ**。効くのは成果の画面の吹き出しと
日記帳の見開きの本文だけ（`docs/architecture/screen-design/principle-and-type.md` 13.3「例外は日記の本文だけ」）。パックに同梱した
書体ファイルだけを指せ、外部フォントは足さない。無いパックは端末の明朝体のまま。**キャラクター
編集の画面から差し替える口は無い**（手で `character.json` と書体ファイルをパックに置く）。

**切り替えたときに画面から消すのは吹き出し・立ち絵・メインビューの3つ。** 素材が1体しか無くても
サイドバーの `<select>` は出す（選択肢1つ。無いように見えるほうが分かりにくい）。

**画面から変える**（口の並びは `docs/architecture/screen-design.md` 13.6）:

- **使用中以外のパックも変えられる**（キャラクター画面の一覧で選んだパック）。起動先の
  `characters/local` と同じ名前のパックだけは変えられない（ホームに書いても探索の順で負け、次の
  起動で消えたように見えるため）
- **反映はセッションを起こし直さない**（会話も履歴も消えない）。使用中のパックを変えたときだけ、
  使用中の姿と素材がホームの版に替わる。**立ち絵を足した表情を `speak` で選べるのは次の起動から**
  （`speak` の enum は起こしたときの定義から作る）
- **受け付ける素材**: 立ち絵と顔は `.svg` / `.png` / `.gif`、背景は `.png` / `.jpg` / `.webp`
  （写真が主な素材で、透過も要らない。`.gif` は入れない — 動く背景は
  読む面の隣で気が散る）。大きさと枚数の上限は `docs/architecture/character-pack.md`「画面から作るときの置き場と受け取り方」
- **名前と自己紹介文は1つのボタンから2つの欄をまとめて変える**（`characterPack.setProfile`）。
  どちらも空文字を通し、名前が空なら id へ折り返し、ひとことは空白だけなら「無い」に畳む

**新しく作る**:

- **id と表示名を分けて受け取る。** 保存するフォルダの名前になるのは id だけ（半角の英数字と
  `.` `_` `-`。`.` では始められない）。表示名は空文字を許し、文字種も縛らない（長さの上限だけ）。
  空なら id と同じ名前で出る（同じ文字列を2回打たせない）
- **既にある id は弾く**（作れてしまうと既存のパックが黙って隠れる）。変えたいなら選んで編集の口で変える
- **最低限そろえさせるのは `default` の立ち絵1枚と画面の差し色2つ**（仕事・雑談）。
  ほかの表情は作ったあとに足す（**作る口は最低限にする**）
- **人格（`persona.md` の本文）も作るときに書ける。** 空なら人格なしで作る（`persona.md` を書かない）
- **立ち絵から欄を生成できる。** 立ち絵を置いて「立ち絵から生成」を押すと、Opus が立ち絵1枚から
  id・名前・差し色2つ・人格を書いて欄を埋め、利用者が直してから作る。**置いただけでは生成しない**。
  生成を使わず手で入れて作ることもできる
- **作った直後に自動では切り替えない**（切り替えは会話の画面の初期化なので、作る操作の副作用に
  しない）。作れたら一覧で作ったパックを選んだ状態にするだけ

**消す**（id を打って確かめるのは画面の側）:

- **消すのはいつもホームの版だけ。** 使用中のパックは断る（切り替えてから消す）
- **消すと何が起きるかはパックごとに決まり、一覧の1件が持つ**（`removal`。使用中かどうかは混ぜない）:

  | `removal`             | どのパック                                      | 消したあと                                                       |
  | --------------------- | ----------------------------------------------- | ---------------------------------------------------------------- |
  | `"delete"`            | ホームにしか無い（画面から作ったもの）          | 一覧から消える。あらすじと会話のアーカイブ（雑談と仕事）も消える |
  | `"revert-to-bundled"` | 同梱のパックを画面で直したホームの版            | **同梱の版が一覧に戻る**。会話の記録は残る                       |
  | `"none"`              | 同梱だけ・起動先の `characters/local`・一覧の外 | 画面から消す口を出さない（届いてもサーバが断る）                 |

- **同梱を直したものは「同梱に戻す」と見せる**（「消す」と見せると押したあとも同じ名前が一覧に
  残り、消えなかったように見える）。戻すと、画面で直した見た目とキャラクター自身が書き足した
  「覚えたこと」も消える（どちらもホームの版の中にある）ので、画面はそれを文言で伝える
- **会話の記録（あらすじ・会話のアーカイブ）は、一覧から名前ごと消えるとき（`"delete"`）だけ
  一緒に消す。** 記録の鍵がパックの名前だけなので、残すと同じ id で作り直したパックが消したパックの
  会話を思い出す。同梱に戻すときは同じキャラクターが続くので残す
- **消せないもの（既知の制約）**: claude 側の transcript（`~/.claude/`）は触らない。同じ id で作り直し、
  同じ起動先・同じポートで起こすと、印が同じなので消したパックのセッションが切り替え先の一覧に出うる。
  別の tsukumo のプロセスがそのパックを使用中でも止めない（そのプロセスでは素材が 404 になり、次に
  起こすと既定のパックへ落ちる）
