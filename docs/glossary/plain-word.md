# 用語集: わかりにくい語の言い換え

ステータス: **正典**。入口は `docs/glossary.md`（用語集の方針と、子のファイルの一覧）。

責務: レポートの本文と `speak` のセリフに出さない「わかりにくい語」と、その言い換え先を持つ。
読む時: レポートや文書の語を、概念を知らない人にも意味が取れる語に言い換えるとき。
直す時: 利用者が「この語は意味が取れない」と指摘したとき（`PLAIN_WORDS` に1行足す）。

## 言い換えの方針

短さより、語だけで意味が分かることを優先する。少し長くてもよい。
新しい言い換えは、語が表す概念の説明と推奨をセットで利用者に示して決める。

**新しい語を作る・言い換えるときは、次のどれかに当てはまる語を選ぶ**。初見の人が辞書どおりに読んで、意味を当てられるかを問う。

- 辞書どおりに読めば意味が当たる語
- 素直なカタカナ語（ステップ・セクション・カード・プログレスバー）
- 説明的な複合語（描画領域・内容部品・欄外注）

1〜2文字の漢字名詞（帯・面・葉・札・塊・段）を、辞書の意味から離れた用語にしない。

**正典はコードの `PLAIN_WORDS`（`src/server/report/core/plain-word.ts`）で、下の表は `pnpm run format` がそこから書き直す**ので、表は手で直さない。
コードを正典にしたのは、`report` の本文の検査（`src/server/report/core/plain-word-find.ts`）が実行時に表を読むため（文書を実行時に読む経路を作らない）。文書の表を作るときに読むのは `scripts/document/` で、`test/` も対応を見る。
語を足すときは `PLAIN_WORDS` に1行足して `pnpm run format` を打つ。長い綴りを先に置く（「再演集」は「再演」より前）。
「塊」は表に足さない。綴りの部分一致で検査するため、氷の塊のような普通の語まで差し戻してしまう。規約と `describe` の文面だけを「部品」に言い換えてある。
「札」も単独では足さず（お札・名札・改札・入札・表札・札幌を巻き込むため）、画面の表示物を指す複合語の綴りで足す。言い換え先は、四角い面に複数の部品を載せる表示物なら「カード」、地も枠も無い字だけの表示なら「ラベル」、地か枠の付いた小さな印なら「バッジ」、形を指す「形の札」は「形の名前」。「親の札」は「母親の札」のように普通の語の後半に当たるので足していない。足した「数の札」は「複数の札束」に当たる。本文での実例が無いので残し、テストの「既知の巻き込み」で当たることを固定してある。
1文字の語（帯・面・葉）は単独では足さず、複合語の綴りで足す（「画面」「携帯」「言葉」を巻き込まないため）。「面の名前」のように「画面の名前」にも当たる綴りは足さない。普通の語の前半に当たりやすい綴り（葉ごと・葉を直接・葉の機能・葉の実装・葉専用・設定の面・エディタの面・読む面）は、「言葉ごと」「設定の面倒」「読む面白さ」まで巻き込むので足していない。足した綴りにも例外が残る。「葉の部品」は「言葉の部品」に、「ワークフローの面」「入力欄の面」「詳細の面」「並べた面」は「〜の面倒」「〜の面積」のような面で始まる語に当たる。どちらも本文での実例が無いので残し、テスト（`plain-word-find.test.ts`「既知の巻き込み」）で当たることを固定してある。
ワークプランの旧称「段」も、単独では足さない。「段」で終わる綴り（最後の段・前の段・今の段・済んだ段・飛ばした段）は「最後の段落」「今の段階」「飛ばした段落」に、「段」で始まる綴り（段のまとめ・段の並び・段の数）は「後段のまとめ」「手段の数」に当たるので足していない。足したのは、続きに段落・段階が自然に来ない6語（まとめ待ちの段・並列の段・委譲先の段・段ごとの時間・段の群・段の閉じ方）で、「並列の段」は「並列の段階」に当たる（テストの「既知の巻き込み」で固定）。
「棚」「台本」も単独では足さない。「棚」は棚卸し・本棚、「台本」は再現の手順を書いた台本（`- 確かめ方:` の「再現の台本」・疑似セッションの台本・再生の台本）に当たる。足したのは、画像を置いておく場所を指す5語（画像の棚・原寸の棚・棚の原寸・棚に置・棚から）と、Claude Code のワークフローのスクリプトを指す2語（台本の完了・台本の中の委譲先）。言い換え先は「置き場」「ワークフロースクリプト」。「棚に置」「棚から」は「本棚に置く」「本棚から」にも当たるが、本文での実例が無いので残し、テスト（`plain-word-find.test.ts`「既知の巻き込み」）で当たることを固定してある。
表の綴りは、レポートの本文と `speak` のセリフの地の文に使わない（引用・コード・パスの中は除く）。別の意味で使う綴り（例: テストで同じ操作をなぞる意味の「再演」）が要るときは、別の言い方にする。
