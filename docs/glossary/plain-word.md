# 用語集: わかりにくい語の言い換え

ステータス: **正典**。入口は `docs/glossary.md`（用語集の方針と、子のファイルの一覧）。

責務: レポートの本文に出さない「わかりにくい語」と、その言い換え先を持つ。
読む時: レポートや文書の語を、概念を知らない人にも意味が取れる語に言い換えるとき。
直す時: 利用者が「この語は意味が取れない」と指摘したとき（`PLAIN_WORDS` に1行足す）。

## 言い換えの方針

短さより、語だけで意味が分かることを優先する。少し長くてもよい。
新しい言い換えは、語が表す概念の説明と推奨をセットで利用者に示して決める。

**正典はコードの `PLAIN_WORDS`（`src/shared/report/plain-word.ts`）で、下の表は `pnpm run format` がそこから書き直す**ので、表は手で直さない。
コードを正典にしたのは、`report` ツールが実行時に読むため（文書を実行時に読む経路を作らない）。
語を足すときは `PLAIN_WORDS` に1行足して `pnpm run format` を打つ。長い綴りを先に置く（「再演集」は「再演」より前）。
表の綴りは、レポートの本文の地の文に使わない（引用・コード・パスの中は除く）。別の意味で使う綴り（例: テストで同じ操作をなぞる意味の「再演」）が要るときは、別の言い方にする。
