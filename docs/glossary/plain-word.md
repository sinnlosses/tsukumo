# 用語集: わかりにくい語の言い換え

ステータス: **正典**。入口は `docs/glossary.md`（用語集の方針と、子のファイルの一覧）。

責務: レポートの本文と `speak` のセリフに出さない「わかりにくい語」と、その言い換え先を持つ。
読む時: レポートや文書の語を、概念を知らない人にも意味が取れる語に言い換えるとき。
直す時: 利用者が「この語は意味が取れない」と指摘したとき（`PLAIN_WORDS` に1行足す）。

## 言い換えの方針

短さより、語だけで意味が分かることを優先する。少し長くてもよい。
新しい言い換えは、語が表す概念の説明と推奨をセットで利用者に示して決める。

**新しい語を作る・言い換えるときは、次のどれかに当てはまる語を選ぶ**。初見の人が辞書どおりに読んで、意味を当てられるかを問う。

- 辞書どおりに読めば意味が当たる語
- 素直なカタカナ語（ステップ・セクション・カード・プログレスバー）
- 説明的な複合語（描画領域・内容部品・欄外注）

1〜2文字の漢字名詞（帯・面・葉・札・塊・段）を、辞書の意味から離れた用語にしない。

**正典はコードの `PLAIN_WORDS`（`src/server/report/core/plain-word.ts`）で、下の表は `pnpm run format` がそこから書き直す**ので、表は手で直さない。
コードを正典にしたのは、`report` の本文の検査（`src/server/report/core/plain-word-find.ts`）が実行時に表を読むため（文書を実行時に読む経路を作らない）。文書の表を作るときに読むのは `scripts/document/` で、`test/` も対応を見る。
語を足すときは `PLAIN_WORDS` に1行足して `pnpm run format` を打つ。長い綴りを先に置く（「再演集」は「再演」より前）。
「札」「塊」は表に足さない。綴りの部分一致で検査するため、始め方の札（画面の語）やお札・氷の塊のような普通の語まで差し戻してしまう。規約と `describe` の文面だけを言い換えてある。「札」は形を指すときは「形の名前」(条の表の列名は「形」)、画像の notes と badge では「ラベル」、keyFigures では「カード」、「塊」は「部品」にした。
1文字の語（帯・面・葉）は単独では足さず、複合語の綴りで足す（「画面」「携帯」「言葉」を巻き込まないため）。「面の名前」のように「画面の名前」にも当たる綴りは足さない。普通の語の前半に当たりやすい綴り（葉ごと・葉を直接・葉の機能・葉の実装・葉専用・設定の面・エディタの面・読む面）は、「言葉ごと」「設定の面倒」「読む面白さ」まで巻き込むので足していない。足した綴りにも例外が残る。「葉の部品」は「言葉の部品」に、「ワークフローの面」「入力欄の面」「詳細の面」「並べた面」は「〜の面倒」「〜の面積」のような面で始まる語に当たる。どちらも本文での実例が無いので残し、テスト（`plain-word-find.test.ts`「既知の巻き込み」）で当たることを固定してある。
ワークプランの旧称「段」も、単独では足さない。「段」で終わる綴り（最後の段・前の段・今の段・済んだ段・飛ばした段）は「最後の段落」「今の段階」「飛ばした段落」に、「段」で始まる綴り（段のまとめ・段の並び・段の数）は「後段のまとめ」「手段の数」に当たるので足していない。足したのは、続きに段落・段階が自然に来ない6語（まとめ待ちの段・並列の段・委譲先の段・段ごとの時間・段の群・段の閉じ方）で、「並列の段」は「並列の段階」に当たる（テストの「既知の巻き込み」で固定）。
表の綴りは、レポートの本文と `speak` のセリフの地の文に使わない（引用・コード・パスの中は除く）。別の意味で使う綴り（例: テストで同じ操作をなぞる意味の「再演」）が要るときは、別の言い方にする。

## 言い換え

### わかりにくい語の言い換え表

<!-- plain-word-table:start -->

| わかりにくい語   | 言い換え先                   | 意味                                                                                                      |
| ---------------- | ---------------------------- | --------------------------------------------------------------------------------------------------------- |
| 再演集           | タスクの再試集               | 送り出し済みのタスクを、前後で解かせ直すために凍結して保存したもの                                        |
| 再演             | タスクの再試                 | 設定や文書を変える前後で、送り出し済みのタスクを本物の claude に解かせ直して結果を比べること              |
| 有界な自律       | 承認なし実行の上限           | 新しい /loop の流れの最後の段階。人の承認なしで自動で動くが、回数と触れる範囲に上限があり、その中に収まる |
| 辺               | 矢印                         | 図の中で、点（ファイルや部品の名前）と点をつなぐ線。「A が B に値を渡す」というつながりを表す             |
| 節点             | 箱                           | 図の中で、ファイルや部品の名前を1つ置く点。矢印の両端になる                                               |
| 転がして         | スクロールして               | 枠に収まらない中身を、枠の中で上下に送って続きを見ること                                                  |
| 窓               | ブラウザの表示サイズ         | tsukumo の画面を開いたブラウザの、中身を描ける領域の幅と高さ（1440x900 など）                             |
| 進み具合の帯     | 進み具合のプログレスバー     | 画面の端に出す、いま計画のどこまで進んだかをフェーズの並びで見せる表示                                    |
| ワークプランの帯 | ワークプランのプログレスバー | 画面の端に出す、ワークプランのどこまで進んだかをフェーズの並びで見せる表示                                |
| 委譲中の帯       | 委譲中のプログレスバー       | 委譲先に任せている作業のどこまで進んだかを見せる表示                                                      |
| 傍注             | 欄外注                       | 本文の横の余白の欄に添える、出典やどこを見るかを書いた短い注                                              |
| ワークフローの面 | ワークフローの描画領域       | ワークフローの設定を描く、画面の中の領域                                                                  |
| 入力欄の面       | 入力欄の描画領域             | 入力欄を描く、画面の中の領域                                                                              |
| 詳細の面         | 詳細の描画領域               | 詳細を描く、画面の中の領域                                                                                |
| 並べた面         | 並べた描画領域               | 比べるために並べて描いた、画面の中の領域                                                                  |
| 振り返りの葉     | 振り返りの内容部品           | レポートのセクションを組む内容部品（文・表・図など中身を持つ部品）のうち、振り返りを書くもの              |
| 葉の部品         | 内容部品                     | レポートのセクションを組む、文・表・図など中身を持つ部品（配置のための部品は含めない）                    |
| 図の葉           | 図の内容部品                 | 内容部品（文・表・図など中身を持つ部品）のうち、図を描くもの                                              |
| まとめ待ちの段   | まとめ待ちのフェーズ         | 済んだが、まとめ（中間レポートの要約）がまだ届いていないフェーズ                                          |
| 並列の段         | 並列のフェーズ               | 同時に走らせる、複数のフェーズのまとまり                                                                  |
| 委譲先の段       | 委譲先のフェーズ             | 委譲先に任せているフェーズ                                                                                |
| 段ごとの時間     | フェーズごとの時間           | 最終レポートに出す、フェーズごとの所要時間                                                                |
| 段の群           | フェーズのグループ           | 並列に走らせる複数のフェーズをまとめたもの                                                                |
| 段の閉じ方       | フェーズの閉じ方             | report でそのターンのフェーズを済ませる・飛ばすことの申告                                                 |
| レポートの節     | レポートのセクション         | レポートの本文を区切る、見出しと塊の並びを持つ単位                                                        |
| 見出しの無い節   | 見出しの無いセクション       | 見出しを付けていない、レポートの本文の区切り                                                              |
| 節の塊           | セクションの塊               | レポートの本文の区切りの中に並ぶ、種類の決まった本文の1単位                                               |
| 節が2つ以上      | セクションが2つ以上          | レポートの本文の区切りが複数あること                                                                      |
