# 用語集: 吹き出しとセリフ

ステータス: **正典**。入口は `docs/glossary.md`（用語集の方針と、子のファイルの一覧）。

責務: 吹き出しとセリフ（反応・セリフのログ・迎えの挨拶・待ちの一言・声の定位置・従っているセリフ・いまの様子）の用語を持つ。
読む時: 吹き出しやセリフ、そこに出す言葉を指す語の表記に迷ったとき。
直す時: この範囲の用語を足す・識別子を変えるとき（用語はこの子に足し、親には足さない）。

## 表示

### 吹き出し

- **英語識別子**: `balloon`
- **定義**: **セリフ**1件を囲って見せる表示。広い画面ではメインビューの会話の流れに、狭い画面では入力欄の上の顔のそばとセリフのログに出す
  （広い画面のキャラビューには出さない）。
  1件につき1つ出し、セリフのログでは**最新の1件だけを濃く大きくし**（立ち絵へ向けて尻尾を伸ばす）、過去は小さく薄くする。
  折り返し・全角文字の幅・禁則処理はブラウザに任せる
- **注記**: **ターンの本文は入れない**（本文はメインビューのレポートに回る）。
  答え待ちの許可・質問のボタンは吹き出しの下ではなく、メインビューの**お伺い**に出る（`docs/requirements.md` 4.7）
- **注記**: **狭い画面（760px 以下）では、入力欄の上に顔と並べて最新の1件だけを出す**（作業中も常に出し、
  3行で切る。押すとセリフのログ。`docs/architecture/screen-design.md` 13.9「狭い画面（760px 以下）」）
- **注記**: 進み具合のプログレスバーの下線の区間を押すと、吹き出しは出さず、押した区間の下にそのフェーズの詳細が重なって出る
  （`docs/architecture/screen-design.md` 13.13「進み具合のプログレスバー」）
- **避ける言い方**: バブル、コメント欄、メッセージボックス

### 反応

- **英語識別子**: 出来事は `ReactionKind` で、値は迎える `welcome` / 再試行 `retrying` / 失敗 `failed` /
  利用上限 `limited` / 待ち `idle`。1行は `ReactionLine`、反応の行の問い合わせが書く4つの行は
  `WrittenReactions`（状態の欄は `writtenReactions` で型は `WrittenReactionsState`、イベントは
  `reactions-written`）・`ShownReaction`（いま出す反応。導く関数は
  `src/shared/session/shown-reaction.ts` の `shownReaction`）・記録の種類 `reaction`（出し始めた出来事で積む。
  積む関数は `src/shared/session/session-fold.ts` の `applySessionEvent`）・待ちの一言を出す時刻が来た合図の
  イベント `waiting-line-due`
- **定義**: 機械の出来事に応えて、吹き出しに出す1行のセリフと表情。迎えるは下の
  「迎えの挨拶」、ほかは挨拶とは別の問い合わせが代（起こした1回）につき1回書いた行（パックには書かない。
  `/clear` では書き直さない）
- **注記**: **`speak` ではない**。吹き出しに出すものはセッションの状態から導き、出し始めた時刻で記録（`reaction`）に
  1件積んでセリフのログに残す。
  どの出来事で何を出すか・無ければどうするか・いつ消えるかは
  `docs/architecture/display.md` 4.2「出力の分離（セリフと詳細）」
- **避ける言い方**: プレースホルダ、定型文（キャラクターの言葉として出すもの）、自動セリフ

### セリフのログ

- **英語識別子**: `speech-log`
- **定義**: 狭い画面の吹き出しから開くモーダル。**キャラビューの舞台（立ち絵と吹き出し）を
  そのまま上へ伸ばし**、このセッションのセリフを吹き出しのまま遡って読む。並びは古い→新しいを
  上→下で、ターンの境目に依頼の区切り（`<利用者の呼び名>「<依頼の1行目>」 <時刻>`）を挟み、開いた直後は
  最新（下端）が見えている。過去の吹き出しは古いほど薄い
- **注記**: 材料は記録（`records`）で、別に溜めない。**雑談のログ・会話のアーカイブとは別物**
  （あちらは雑談モードの会話で、利用者の発言も並ぶ）
- **注記**: 狭い画面（760px 以下）では入力欄の上の吹き出しを押して全面で開く（キャラビューが無いため）
- **避ける言い方**: 履歴、発言履歴

### セリフ

- **英語識別子**: `speech`
- **定義**: **`speak` ツールの `text` 引数**。吹き出しに出す、会話のための言葉
- **注記**: 分離は**ツール呼び出しで届く**。行頭マーカー（`アスナ: `）で本文から
  切り出す補助の経路は**撤去した**（どの `persona.md` もマーカーを使えと書いて
  おらず、発火していなかった。`docs/architecture/display.md` 4.2）
- **注記**: 以前この語は「キャラクター定義側の固定文言」を指すために空けてあったが、
  出力の分離が決まったことで**キャラクターが話す言葉**を指す語に確定した。固定文言を
  指したくなったら別の語を立てる
- **避ける言い方**: 台詞（表記は「セリフ」に統一）、メッセージ、一言

### 迎えの挨拶

- **英語識別子**: `welcomeGreeting`（状態の欄。イベントは `welcome-greeting-changed`）。挨拶1つは
  `WelcomeGreeting`、カードの名前の差し込みの印は `WELCOME_GREETING_CARD_MARK`、書く関数は
  `src/server/welcome-greeting/core/welcome-greeting-writer.ts` の `greetWelcome`。書けた挨拶と反応の行をセッションごとに
  覚えて同じセッションへ戻る代で出し直す関数は `src/server/welcome-greeting/core/kept-welcome.ts` の `createWelcomeKeeper`
- **定義**: 迎える局面の吹き出しに出す、セッションを新しく起こすたびと `/clear` のたびに背景の使い捨ての `query()`
  （`sonnet`）がパックの人格の口調で書く1〜2文の挨拶。カードがあるときは始め方の一覧の先頭のカードを名指す
- **注記**: カードの名前は書かせず、差し込みの印を書かせて画面が出すときに先頭のカードの名前を差し込む（カードの並びが
  後から変わっても名指しが古くならない）。反応の行は持たない（別の問い合わせが書く）。反応と同じく記録に積んでセリフのログに
  残し、記録の文は画面が表示した1行（カードの名前込み。コマンド `recordWelcomeGreeting`・イベント `welcome-greeting-shown`）。いつ書き直すか・書けなかったときはどうするか・続きから起こしたときのおかえりは
  `docs/architecture/display.md` 4.2「出力の分離（セリフと詳細）」
- **避ける言い方**: 自動セリフ、定型の挨拶（毎回書き直すもの）

### 待ちの一言

- **英語識別子**: `waitingLine`（`report` の引数と、イベント・記録の欄。値は `ReportWaitingLine`）・
  `waitingLineDelayMs`（ターンが閉じてから出すまでの間。選べる値は `話しかける間合い`）。導く関数は `src/shared/session/shown-reaction.ts` の
  `shownReaction` と `waitingLineDueAt`
- **定義**: 依頼を待つ間に吹き出しへ出す一言。Claude Code がターンの終わりに `report` の引数で前もって書く
  （`closing` と同じ文と表情の組）
- **注記**: 反応と同じく、出すたびに記録に積んでセリフのログに残す。出す時刻はサーバの時計が決め、
  `waiting-line-due` を流す。いつ出るか・書いていないときはどうするか・
  続きから起こした直後のおかえりは `docs/architecture/display.md` 4.2「出力の分離（セリフと詳細）」
- **避ける言い方**: 放置セリフ、アイドルのセリフ（長いアイドルのふるまいは作らない）

### 声の定位置

- **英語識別子**: `VoiceBand`
- **定義**: 広い画面の仕事の画面で、メインビューのスクロール容器の外、入力欄のすぐ上に吹き出し1件ぶんの高さを取る区画（声の帯）。
  迎える反応（迎えの挨拶・おかえり）が出ていればその1件、無ければいちばん新しいやり取りの直近のセリフ1件を出す
  （`docs/architecture/adr/0063-character-voice-place-and-bearing.md` 論点 1・2、`docs/architecture/adr/0074-latest-speech-in-voice-band.md`）
- **注記**: 記録の順は変えず、描く位置だけを変える。流れは、帯にいま出ている1件だけを描かない。帯は何も出していないあいだも高さを取る
- **避ける言い方**: 立ち絵の吹き出し（立ち絵は吹き出しを持たない）

### 従っているセリフ

- **英語識別子（予定）**: `followedSpeech`
- **定義**: 立ち絵がいま表情で従っている声1件。押して留めたセリフがあればそれ、無ければ声の定位置の声、
  無ければ選んでいるやり取りのいちばん新しいセリフ（反応の行を含む）。尾はこの1件にだけ付け、先を立ち絵の顔へ向ける
  （`docs/architecture/adr/0063-character-voice-place-and-bearing.md` 論点 3）
- **注記**: 明るさを出す「いまの一言」とは別の語。完了したあと待ちの一言が出るまでは、いまの一言は無いが、
  従っているセリフ（締めのセリフ）はあって尾が付く
- **避ける言い方**: 最新の吹き出し、選んだセリフ（押していないときも決まる）

### いまの様子

- **英語識別子**: `PresentScene`
- **定義**: tsukumo がメインの入力に `UserPromptSubmit` フックの `additionalContext` で添えて、キャラクター（Claude Code の
  セッションのモデル）へ渡す材料。時間帯・続けて働いた時間・今日終えたタスクの数・前の依頼からの経過・使用量の集計期間・
  次に着手できるタスクの札の6つで、前に渡したときから変わったものだけを渡す
  （`docs/architecture/adr/0063-character-voice-place-and-bearing.md` 論点 10）
- **注記**: 数と決まった語と札の ID だけで、会話の文面は入れない。言うかどうか・どう言うかはキャラクターが決め、
  渡す時機は tsukumo が決める。雑談では渡さない
- **避ける言い方**: コンテキスト（Claude Code のコンテキストと紛れる）、状況報告、ステータス
