# 用語集: アーキテクチャの地図

ステータス: **正典**。入口は `docs/glossary.md`（用語集の方針と、子のファイルの一覧）。

責務: リポジトリを箱の木で表すアーキテクチャの地図の用語（地図・地図のファイル・地図の定義・作り手・箱・縮尺・意図したエッジ・実際のエッジ・ずれ・箱の印・箱のバッジ・`map_box` ツール・ミニマップ）を持つ。
読む時: 地図とその契約・画面を指す語の表記に迷ったとき。
直す時: この範囲の用語を足す・識別子を変えるとき（用語はこの子に足し、親には足さない）。

## 地図とその契約

### 地図

- **英語識別子（予定）**: `architecture-map`（機能・検証の段の名前）、`ArchitectureMap`（地図のファイルを読んだ型）
- **定義**: リポジトリを大・中・小の3段の**箱**の木と、箱どうしのエッジで表したもの。**作り手**が**地図のファイル**に書き、tsukumo が読んで描く。
  紛れるときは「アーキテクチャの地図」と言う
- **注記**: 契約の正典は `docs/architecture/architecture-map.md`、判断の経緯は `docs/architecture/adr/0082-architecture-map-contract.md`。
  `pnpm run repo-map` が委譲先のために書く export の一覧（`repo-map`）とは別物
- **避ける言い方**: リポジトリの地図・リポマップ（`repo-map` の export の一覧と紛れる）、作業の地図（会話の画面の進行を見せる、置き換えた前の案の名前）、アーキテクチャ図（mermaid などで描いた1枚の図と紛れる）

### 地図のファイル

- **英語識別子（予定）**: `.architecture-map.json`（ファイル名）
- **定義**: 作業ディレクトリの根に**作り手**が書く JSON の値1つ。tsukumo が地図について読むのはこのファイルだけで、これが契約の形
- **注記**: 欄・版・読めないときの振る舞いは `docs/architecture/architecture-map.md`。tsukumo の開発では `pnpm run check` が毎回書き直し、git の外に置く
- **避ける言い方**: 地図のデータ（**地図の定義**と紛れる）

### 地図の定義

- **英語識別子（予定）**: `architecture-map.toml`（tsukumo での置き場は `docs/architecture/` の下）
- **定義**: 人が直す大・中の**箱**と**意図したエッジ**を書いた、**作り手**の入力の TOML。作り手はこれと抽出の結果を合わせて**地図のファイル**を書く。tsukumo は読まない
- **注記**: 書式は契約の外で、作り手が決める。TOML にした理由は `docs/architecture/adr/0082-architecture-map-contract.md` の論点 1
- **避ける言い方**: 地図の正典（tsukumo が読む契約は**地図のファイル**のほう）

### 作り手

- **英語識別子（予定）**: `producer`（地図のファイルの `source.producer` の欄）、`tsukumo-architecture-map`（tsukumo-plugins に同梱する作り手のプラグイン）
- **定義**: リポジトリを読んで**地図のファイル**を書き、地図と実装の**ずれ**を照合するもの。tsukumo の外にあり、tsukumo は起こさない
- **注記**: 同梱の作り手は契約に型の合う1つの例で、利用者独自の作り手も同じ立場で当てられる。作り手の義務は `docs/architecture/architecture-map.md` の「作り手の義務」
- **避ける言い方**: 抽出器（抽出は作り手の役の1つにすぎない）、ジェネレータ（どの生成物を作るかが語から読めない）

## 箱と縮尺

### 箱

- **英語識別子（予定）**: `MapBox`（型）、`boxes`（欄）
- **定義**: 地図の木の1要素。大・中・小のどれかの**縮尺**の段にあり、ID・役割の1行・属するファイルの glob を持つ。外の世界の箱はリポジトリの外の相手（大の段だけ）
- **注記**: 大・中の箱の ID は人が付ける名前、小の箱の ID はディレクトリのパス。改名した大・中の箱は古い ID を別名に残す。レポートの図（`Graph`）のノードとは別の概念
- **避ける言い方**: ノード（レポートの図のノードと紛れる）、コンポーネント（React の部品と紛れる）、要素（用語集が退けた語）

### 縮尺

- **英語識別子（予定）**: `MapLevel`（`1` が大・`2` が中・`3` が小）
- **定義**: 地図の木の段。大は層と外の世界、中は機能など人が切った単位、小はディレクトリ。大・中は人が**地図の定義**で直し、小は**作り手**が抽出で作る
- **注記**: 全体の図は大の段を描き、**箱**を押すとその箱にフォーカスした図（その箱の子と、子とつながる外の箱）に潜る
- **避ける言い方**: 階層（ディレクトリの深さと紛れる）、レベル1・2・3（画面では大・中・小と言う）

## エッジとずれ

### 意図したエッジ

- **英語識別子（予定）**: `IntendedEdge`（型）、`edges.intended`（欄）
- **定義**: 「この向きに依存してよい」と宣言した**箱**どうしのエッジ。どの段の箱のあいだにも書け、両端の子孫どうしの import を覆う
- **注記**: **地図の定義**に人が書いたものと、依存の規則（tsukumo では `.dependency-cruiser.cjs` の `server-feature-edge:` の規則）から**作り手**が読んだものがある
- **避ける言い方**: 許可エッジ（依存の規則の allow と紛れる）、宣言の矢印（エッジと言い方を揃える。図の上の線の形を言うときだけ矢印）

### 実際のエッジ

- **英語識別子（予定）**: `ActualEdge`（型）、`edges.actual`（欄）
- **定義**: **作り手**が抽出した、小の**箱**どうしの import の本数（`count`）つきのエッジ。粗い段では tsukumo が両端を祖先の箱に置き換えて本数を足し合わせる（束ねる）
- **注記**: 同じ小の箱の中で閉じる import は持たない。束ねた本数と箱の中で閉じた本数の和は、いつも実際のエッジの本数の和に等しい
- **避ける言い方**: 依存グラフ（dependency-cruiser のモジュールどうしの全件と紛れる）

### ずれ

- **英語識別子（予定）**: `MapFinding`（型）、`findings`（欄）
- **定義**: 地図と実装の食い違い。種類（`kind`）と重さ（`error`・`warn`）を持つ
- **注記**: 種類の一覧は `docs/architecture/architecture-map.md`「ずれ」。`error` が1件でもあると検証の段 `architecture-map` が落ちる
- **避ける言い方**: 違反（依存の規則の違反と紛れる）、ドリフト（言い方を揃える）

## 箱を指す

### 箱の印

- **英語識別子（予定）**: `{{map: …}}`（書き方。`…` は箱の ID を1つ）、`map`（行内の印の種類）
- **定義**: レポートの本文・`speak` のセリフ・入力欄から送った依頼の文で**箱**を指す字の並び。tsukumo は**箱のバッジ**で描き、知らない ID は字のまま残す
- **注記**: レポートの本文の行内の印（`{{…}}`）の仲間で、インラインコードの中は読まない
- **避ける言い方**: 地図のリンク（Markdown のリンクではない）

### 箱のバッジ

- **英語識別子（予定）**: `MapBoxBadge`
- **定義**: **箱の印**を描いた、箱の表示名と**縮尺**の小さなバッジ。入力欄の頭・本文・セリフで同じ部品を使い、触れると地図の同じ箱が光る
- **注記**: 色は地図で箱を指す色（狐火の青緑）に固定し、変更・追加・**ずれ**の色と混ぜない
- **避ける言い方**: 箱の札（札はバッジ・ラベルへ言い換える語。`docs/glossary/standard-word.md`）

### map_box ツール

- **英語識別子（予定）**: `map_box`（ツール名そのもの）
- **定義**: エージェントが**箱**の定義を引く MCP の道具。ID を渡すとその箱の欄とつながる箱を、渡さなければ大・中の箱の ID・表示名・役割の一覧を返す。**地図のファイル**だけを読む
- **避ける言い方**: 地図の検索（全文を探す道具と紛れる）

### ミニマップ

- **英語識別子（予定）**: `ArchitectureMapPanel`（サイドバーの「地図」のタブの中身。ミニマップと、その下の中身）
- **定義**: サイドバーの「地図」のタブに出す、今の図の縮小。押すと中央の列に地図を広げ、会話の流れの上に重ねる
- **注記**: ミニマップの下には、選んだ箱の役割・目的・概要を出す（`docs/architecture/adr/0082-architecture-map-contract.md` の論点 7）
- **避ける言い方**: 縮図（言い方を揃える）
