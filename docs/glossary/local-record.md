# 用語集: 手元に残す記録

ステータス: **正典**。入口は `docs/glossary.md`（用語集の方針と、子のファイルの一覧）。

責務: 改善や不具合の追跡のために手元に残す記録（進行の計測値・診断ログ・使い捨ての問い合わせの記録）の用語を持つ。
読む時: 手元に残す計測や診断の記録を指す語の表記に迷ったとき。
直す時: この範囲の用語を足す・識別子を変えるとき（用語はこの子に足し、親には足さない）。

## 表示

### 進行の計測値

- **英語識別子**: `experienceMetric`（機能は `usage`、記録の1行は `ExperienceMetricRecord`）
- **定義**: 会話の画面の使い心地を、改善の前後で比べるために手元に残す数。依頼を送ってから結論が見えるまでの時間・
  答え待ちで止まっていた時間・つまずいてから立ち直るまでの手数の3つと、仕切りを離した回数と比率
  （`docs/architecture/screen-design.md` 13.13）
- **注記**: 入るのは数・時刻・セッションID・局面の名前（`ConversationMoment` の値）・仕切りの名前（固定の3語）と比率（%）だけで、会話の中身は入らない。
  外へは送らない
- **避ける言い方**: 体験の数（何を数えたものか伝わりにくいため改めた旧称）、テレメトリ（外へ送るように読める）、UX 指標、メトリクス

### 診断ログ

- **英語識別子**: `diagnostic`（機能は `diagnostic`、記録の1行は `DiagnosticRecord`、書き口は `DiagnosticLog`）
- **定義**: 不具合の経緯をあとから追うために手元に残す足跡。`~/.tsukumo/diagnostic/<日付>.jsonl` の1本に、
  流れ（`flow`）ごとの行を積む。流れは、畳んだ `SessionEvent` の足跡（種類・時刻・駆動の代）、
  ブラウザの例外の足跡（拾った経路・`error.name`・スタックの先頭数フレームの出どころと行・列）、
  握りつぶした失敗の足跡（`swallowed-failure`）、依頼の遅れの足跡（`prompt-delay`。渡す手順に入ってから `push` を終えるまで・`push` から SDK が書き終えるまで・書き終えてから最初のメッセージまでの3区間のうち、どれかが 3 秒を超えたときだけ、区間のミリ秒を書く）、
  迎えの挨拶と反応の行の書き込みの足跡（`welcome-writing`。1回終えるたびに、書いたもの・結果・全体の所要・各回の結果と所要・検査落ちの理由の語）、
  あらすじの古い行を上限のために落とした足跡（`synopsis-trim`。時刻と落とした行数）、
  `report` の関所が `Stop` を止めた足跡（`report-gate-block`。時刻だけ）、
  始め方の札が押された足跡（`recommendation-pressed`。時刻と札の種類）、
  ツール1回の前に掛かった時間の足跡（`tool-hook-duration`。tsukumo の PreToolUse のフックが当たるツールの結果を受けるたびに、ツールの語・委譲先の中か・結果のフックの名前・フックからツールが走り始めるまでとツール本体のミリ秒）の9つ
- **注記**: 入るのは数・真偽・決まった語だけで、会話の中身もエラーのメッセージも入らない。外へは送らない。
  14日を過ぎた日付のファイルは消える
- **避ける言い方**: ログ（stderr や会話のアーカイブと紛れる）、テレメトリ、トレース

### 使い捨ての問い合わせの記録

- **英語識別子**: `throwawayQuery`（記録の1行は `ThrowawayQueryRecord`、1回ぶんは `ThrowawayQueryFootprint`、書き口は `ThrowawayQueryRecorder`）
- **定義**: 会話とは別に起こす1回限りの `query()`（日記・定着・おすすめの札・迎えの挨拶・反応・キャラ生成・見直し・提案の実行）の
  回数と費用を追うために手元に残す数。`~/.tsukumo/throwaway-query/<日付>.jsonl` に、`query()` 1回につき1行を積む
- **注記**: 入るのは種類・開始の時刻・所要・入出力トークン・結果の種類だけで、依頼の文面・指示文・応答は入らない。
  トークン消費の記録（会話の `query()` の累計）とは混ぜない。外へは送らない。90日を過ぎた日付のファイルは消える
- **避ける言い方**: 使用量（トークン消費の記録と紛れる）、テレメトリ
