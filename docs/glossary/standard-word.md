# 用語集: 標準語への言い換え

ステータス: **正典**。入口は `docs/glossary.md`（用語集の方針と、子のファイルの一覧）。

責務: 文書・コメント・画面の文言・書き手向けの文面に残る「わかりにくい語」を、エンジニアが使う標準語へ置き換える対応（群ごとの置き換え先・検索の仕方・置き換えない語）を持つ。
読む時: 「箱」「窓」「辺」のような語を標準語に直す作業をするとき、どの語に直すか・どこまで直すかを確かめたいとき。
直す時: 置き換えの対象や置き換え先を変えるとき（言い換えの表の正典は `PLAIN_WORDS`。語の足し引きは `docs/glossary/plain-word.md` に従う）。

## 方針

文書とプロンプトが使う語をモデルのレポートと課題本文が写していることが分かったので、`docs/` を直して言い換えの表（`PLAIN_WORDS`）に頼らずに済む状態を目指すと決めた。置き換え先は**エンジニアが使う標準語**に寄せる。

- 識別子（型名・関数名・ファイル名・CSS クラス・`kind` の文字列）は変えない。例外は内容部品の識別子で、`ReportBlock*` を `LeafComponent*` に揃えた（利用者決定。ファイル名 `report-block*.ts` は据え置き）
- `docs/history/`・`docs/architecture/adr/`・`docs/research/` は過去の記録なので書き換えない
- 用語集が過去に「避ける言い方」として退けた語は、紛れる理由が残る限り採らない（ブロック・サイドノート・ラッパー・要素）
- 語の意味が文脈で変わるものは機械で置き換えず、文脈を読んで語を選ぶ

## 標準語に直す語

出現数は置き換えを始める前の `docs`・`src`・`test`・`scripts`・`vendor`・`.claude`・`characters` の合計（`docs/history/`・ADR・`docs/research/` を除く。この文書と、名前に `plain-word` を含むファイル（言い換えの表・その生成と自己テスト）は数えない。`PLAIN_WORDS` の綴り（共有の箱だけは表に無いので、その語そのもの）で数えた）。

| 旧語（綴り）                                     | 標準語                 |                出現数 | 検索の仕方と注記                                                                                                                                                           |
| ------------------------------------------------ | ---------------------- | --------------------: | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 節点（と、図の中の点を指す「箱」）               | ノード                 |                   155 | `rg -n '節点'`。「箱」は一般語（CSS の箱・余白の箱）にも使うので、図の説明（`Graph` の `source` の記法など）の文脈だけ直す                                                 |
| 辺                                               | エッジ                 | 233（巻き込みを含む） | `rg -n '辺' \| rg -v '周辺\|窓辺\|左辺\|右辺\|上辺\|下辺\|底辺\|一辺\|辺り\|身辺\|海辺'`。「機能どうしの辺」「辺の表」「辺の規則」は直す。矢印は図形の矢印を指すときは残す |
| 窓                                               | 文脈で分ける（下の表） | 642（巻き込みを含む） | 窓口・窓辺は直さない（窓口は別の意味の語）                                                                                                                                 |
| ワークフローの面・入力欄の面・詳細の面・並べた面 | サーフェス             |                    28 | 画面の中の描く領域を指す A2UI の surface。`rg -n '(ワークフロー\|入力欄\|詳細)の面\|並べた面'`                                                                             |
| 共有の箱                                         | 共有モジュール         |                    23 | `docs/architecture/server-feature.md` の「どの機能にも属さない共有のもの」。`server/core/`・`server/adapter/` 直下を指す                                                   |

**窓の分け方**:

| 窓の意味                                     | 標準語                 | 例                                                                               |
| -------------------------------------------- | ---------------------- | -------------------------------------------------------------------------------- |
| ブラウザの描ける領域の幅・高さ               | ビューポート           | 窓幅 → ビューポート幅、広い窓 → 広いビューポート                                 |
| ブラウザを開いたもう1つの画面                | ウィンドウ             | 別の窓で使う → 別のウィンドウで使う                                              |
| 記録を数える期間                             | 集計期間               | 記録の窓 → 集計期間                                                              |
| サイドバーから開く、タスクの詳細の小さな表示 | プレビュー             | のぞき窓 → プレビュー                                                            |
| モデルが一度に読める量の範囲                 | コンテキストウィンドウ | 窓の外 → コンテキストウィンドウの外、窓に入って → コンテキストウィンドウに入って |

## 現行の言い換え先を正式な語にするもの

`PLAIN_WORDS` の言い換え先が、すでに標準語か、過去の用語集の決定で選んだ語であるものは、言い換え先をそのまま文書の語にする（追加の決定は要らない）。

| 群     | 旧語 → 正式な語                                                                                                                  |
| ------ | -------------------------------------------------------------------------------------------------------------------------------- |
| 部品   | 塊 → 部品、葉 → 内容部品、節 → セクション、傍注 → 欄外注、余白の柱・傍注の柱 → 欄外注の列、包み → 外枠（関数・hook は ラッパー） |
| 札・帯 | 札 → カード（形の札は形の名前、変更の札・セッションの札などはラベル、絞り込みの札・等幅の札などはバッジ）、帯 → プログレスバー   |
| 手順   | 段 → フェーズ、台本 → ワークフロースクリプト、目録 → タスク見出し行、再演 → タスクの再試、有界な自律 → 承認なし実行の上限        |
| 口・棚 | 押す口・開く口 → ボタン、選び口 → 選択メニュー、受け取り口ほか → 〜する関数、棚 → 置き場                                         |
| その他 | 転がして → スクロールして、脇の話 → 補足メッセージ、合図 → 通知                                                                  |

## 置き換えない語

- 過去の用語集が退けた理由が残る語: ブロック（Markdown の block・止める意味のブロックと紛れる）、サイドノート（補足メッセージの aside と紛れる）、ラッパー（`host` の呼び名として退けた語。関数・hook を包むものを指す「ラッパー関数」「ラッパー hook」は別）、要素（HTML の要素と紛れる）
- 内容部品の対の配置部品（`Row`・`Card`・`Section` など）は、内容部品と同じ部品の群として現行のまま
- 窓口・周辺・窓辺・左辺のような、別の意味で普通に使う語
