# `report` の `figure` は省ける欄にし、図を置くかの既定は利用者の設定に持つ（2026-10-27）

ステータス: 採用

**`figure` を省ける欄にし、図を置かない理由の enum を書き手に言わせるのをやめる。図を置くかの既定（図派 `chart`／文派 `text`）は、新しいセッションの既定の4つ目として利用者の設定に持ち、`figure` の欄の説明の文だけを変える。** ADR 0028 の追記「図を欄で必須にした（2026-10-13）」を改める（0028 は凍結なので書き換えない）。

## 何が困っていたか

`figure` が必須で、図を置かないなら理由（`short-answer`・`no-shape`・`single-value`・`no-material`）を毎回言わせていた。30 日の記録は図ありが 471 件・なしが 2,111 件で、なしの大半は理由を言うだけの手間になっていた。
図を欲しがるかは個人差が最大の要因で（文だけを選ぶ人が 41%、個人内の一貫性 82〜89%）、推奨は「文脈つきの図を既定にし、個人設定で切れる」。根拠は `docs/research/report-rethink-2026-10-26/index.html` 5・8節と `theory.md` 2節。

## 決めたこと

- `figure` を省いた呼び出しは通り、図なしとして描く（読み戻しでは理由 `unrecorded` の `none` に畳む。`omitted` のような新しい理由は足さない）。理由つきの `none` は旧い記録と呼び出しの互換のため読める
- 図を置く条件は欄の説明が持ち、置かない理由の enum は説明から外す
- 設定は `figurePreference: "chart" | "text"`（既定 `chart`）。`SessionDefault` の4つ目で、保存・配信は model・effort・permissionMode と同じ道（`~/.tsukumo/state.json` の `sessionDefault`、`setSessionDefault`、`session-default-changed`）。起こすときの値が `report` の `figure` の説明の文を決める
- `text` でも構造・前後・3つ以上の数がある節は図を置いてよい。設定は書き手への既定の指示で、図の塊を拒む検査は足さない
- 理由と本文が食い違う回の数え方（`figure-contradiction`）は変えない。理由を書いた旧い形の呼び出しにだけ働く

## 採らなかった案

| 案                                      | 採らなかった理由                                                                                                                                                                      |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 設定を `SessionDefault` と別に持つ      | 画面へ流す道（イベントと手続き）を新設することになる。既存の道に載せれば足りる                                                                                                        |
| 省いた呼び出しに `omitted` の理由を足す | 使用記録・集計の約8ファイルに波及する。欄が無い呼び出しはすでに `unrecorded` に畳まれている。代わりに、省いた回と旧い記録・形の崩れを記録から区別できない（図なしの回の数え方に効く） |
| 文派のとき図の塊を差し戻す              | 構造・前後・数がある節の図まで拒むことになる                                                                                                                                          |

## 見直す条件

- 図なしの回の割合が文派でも図派でも変わらず、設定が使われていない
- 省いた回で、構造のある節の図が抜ける不具合が数で見えた

## 結果

- 欄の説明は `reportFigureDescription(preference)`、設定の面は「セッションの既定」の「図の既定」
