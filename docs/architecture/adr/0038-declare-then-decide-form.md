# `report` は問いと数を申告させて形は決定表が決め、本文は `body` で受け、差し戻しは文法と数の整合に絞る（2026-10-28）

ステータス: 採用

**書き手に塊の種類と節の札を選ばせるのをやめる方向に決める。書き手は問いと数（型・基数・関係）を申告し、形は決定表が決める。本文は Markdown の `body`（型つきフェンス入り）で受ける。差し戻しの重心は、体裁の条から文法と数の整合の条へ移す。** ADR 0028 の「梯子」と「条8を形の札の表に替えた」を改める（0028 は凍結なので書き換えない）。ただし `body` は試しの版で、既定は `json-schema` のまま（「実装の到達点」）。

## 何が困っていたか

- 書き手は塊 21 種と節の札 14 種（`REPORT_SHAPE_TAGS`）を選ぶ。`json-schema` 版の定義は schema 22699 字（`node scripts/runtime/definition-size.ts`）で、毎ターンの文脈に載る。
- 差し戻しの条は 48 あり、reject が 35、数えるだけの count が 13（`src/server/report/core/rejection-mode.ts` の `REPORT_REJECTION_MODES`）。体裁の条が多く、書き手は条を避けるために文面を曲げる。
- 札は「機械が正しさを確かめられない」申告で、許さない塊を使った節を数えるだけ（`docs/architecture/display/block-criteria.md`「形の札の照合」）に留まった。
- 調査と先例は `docs/research/report-rethink-2026-10-26/index.html` の 5・7・8 節が持つ。

## 決めたこと

- **形は申告から決定表が決める。** 書き手は図の問い（`question`）、データの列の型（`N`・`O`・`T`・`Q`）と値、関係（`relation`）を申告する。形は `src/shared/report/figure-decision.ts` の `FIGURE_DECISION_ROWS` が決め、書き手の上書きは数えるだけにする（正典は `docs/architecture/display/block-criteria.md`「図の決定表」）。
- **本文は `body`（Markdown）で受け、図・表・コードなど構造が要るものだけ型つきフェンスにする。** フェンスの種類は `READER_FENCE_KINDS`（`graph`・`mermaid`・`table`・`code`・`callout`・`claims`・`image`）と `figure`。読めないフェンスは素のコードブロックに落とし、差し戻さず `brokenFenceCount` で数える。`body` 版は節を1つに畳み、節の札を持たない。
- **差し戻しの重心を、文法（読めない形・範囲外）と数の整合（図の値と本文の数、`graph` の辺）へ移す。** 体裁の条は `count` に置き、`reject` へ上げるのは数を見てからという 0028 の線は変えない。
- **帳簿は書き手に書かせない方向にする。** 色・座標・触ったファイルの一覧は描く側が持つ（`files` を外した前例が 0028 の追記にある）。

## 実装の到達点

- 申告と決定表は実装済みで、`plot` の塊と `figure` の双方に置ける。
- `body` は試しの版で、`TSUKUMO_REPORT_SCHEMA=body-fence` のときだけ受ける（`docs/readme/configuration.md`）。**既定は `json-schema` のままで、塊 21 種と節の札は既定の経路で動いている。**
- 既定を `body` に切り替えるかは、この ADR では決めない。版2つの対と判定（`docs/architecture/display/reading-time.md`「変種の対と判定」）の結果を見て、別に決める。

## 採らなかった案

| 案                                    | 採らなかった理由                                                         |
| ------------------------------------- | ------------------------------------------------------------------------ |
| 札 14 種を残して第一候補の表だけ直す  | 札の正しさを機械が確かめられない。関係の語はデータの形と突き合わせられる |
| 21 種を減らすだけで JSON のままにする | 定義は縮むが、判断の入力が札のままで、書き手の選び間違いは残る           |
| 体裁の条を先に全部 `reject` へ上げる  | 数を見る前に差し戻しが増える。0028 の「まず数える」の線に反する          |
| この ADR で既定を `body` に切り替える | 対の判定がまだ無い。決める根拠が揃ってから別に決める                     |

## 0028・0031・0034 との関係

0028 は梯子と札の部分をこの ADR が置き換えるので、状態を置き換え済みにする。0031・0034 は小見出しごとに読んで覆さないと判断した。

| ADR  | 小見出し                                      | この ADR が覆すか | 理由                                                                                                                                                             |
| ---- | --------------------------------------------- | ----------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 0028 | 梯子（論点1）・「描ける」の判定（論点2）      | 覆す              | 書き手が段を上から試す仕組みは、申告と決定表に替わる                                                                                                             |
| 0028 | 追記: 条8を形の札の表に替えた                 | 覆す              | 札を書き手が選ぶ仕組みは、`body` 版では持たない                                                                                                                  |
| 0028 | SVG・画像・機械で見る点と測り方               | 覆さない          | `svg` の塊の扱い、画像を必須にしない線、「まず数えてから差し戻す」はそのまま残る                                                                                 |
| 0031 | 構造のまま運ぶ範囲（論点1）                   | 覆さない          | `body` は読んだあと節の並びになり、欄ごとに描く                                                                                                                  |
| 0031 | 演出と目次が区切りとして受け取るもの（論点2） | 覆さない          | 見出し空の節は目次の節の行を持たず、中の `h4` を拾う規則と、欄が節1つの本文は全体で1トピックの規則が `body` を受ける。演出の区切りは粗くなるが、決めた規則の内側 |
| 0031 | 復元と保存済みの記録との互換（論点3）         | 覆さない          | 記録の形は変えない                                                                                                                                               |
| 0034 | 描く段は tsukumo が持つ・記述の口・配置と配色 | 覆さない          | 書き手が構造を記述し描く側が決める分担は、申告と決定表と同じ向き                                                                                                 |

残る決めは、0028 の「SVG（論点3）」「画像（論点4）」「機械で見る点と測り方（論点5）」と、追記の「差し戻しの条を全部、数えてから上げる」「`files` を書き手の口から外した」。
