**レポートの字の段を 12・14・15・17・20px にし、大きい字は結論の1か所に絞る。結論は task の有無によらず 17px・700・`ink-bright`、節の見出し（`h4`）は 15px・700、数のカードの数は 20px、お願いの選択肢の名前は 14px・600、「したこと」「確かめたこと」の見出しと中身は 14px にする。** 見本は `docs/history/mockup/report-type-2026-11-23/compare.html` の案B（画は `*-b.png`）。言葉と見本が食い違ったら見本が勝つ。

## 何が困っていたか

- 結論の1文目が 21px で画面でいちばん大きく、task の無い結論（17px・500）とも食い違っていた
- 節の見出し（17px）・お願いの選択肢の名前（地の字を継いで 17px）・数のカードの数（24px）の大きさが役と合っていなかった
- 「したこと」「確かめたこと」の行は 12px で、本文（14px）より小さかった

## 決めたこと

- `--report-heading-2` は `--font-size-lg`（広い画面 17px、触る画面 19px）、`--report-heading-3` は `--font-size-base` に 1px 足した値（広い画面 15px、触る画面 17px）。15px は Astryx の段に無く、固定の rem にすると触る画面で本文（16px）より小さくなるので、Astryx の段に従うつまみにした
- 役の決まり: 列の頭（表の頭など）は 12px。行の頭（左に置いて右の中身を名指すもの）は中身と同じ大きさにし、色だけ控えめにする。見本では「したこと」の見出しを 12px で撮ってあるが、利用者の注文で 14px にした
- 題・本文・ラベルは今のまま

- 節と節の間のあき
