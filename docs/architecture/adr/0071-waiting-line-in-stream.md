# 待ちの一言を流れの行に戻す（2026-11-18）

ステータス: 採用

**待ちの一言（`idle` の反応）は、声の定位置に出さず、流れの行のまま記録の位置に出す。声の定位置に出すのは迎える反応（迎えの挨拶・おかえり）だけにする。この ADR は、ADR 0063 の論点 1 の「迎えると待ちの2つを定位置に出す」のうち待ちの側を上書きする（本文は書き換えない）。**

## 何が困っていたか

待ちの一言は、ターンが閉じて2分たつと定位置に出る。定位置は入力欄のすぐ上の下端に貼り付き、いまの一言として明るくするので、次の依頼を送るまで締めのセリフや紙から離れた所に浮いて残る。利用者から、浮いたままではなく普通に出してほしいと頼まれた。

## 決めたこと

**採る: 待ちの一言は、ほかのセリフと同じく流れの行として、記録の位置（締めのセリフの後ろ）に出す。**

| 案                         | 種類   | 物差し                                                                             | 判定     |
| -------------------------- | ------ | ---------------------------------------------------------------------------------- | -------- |
| 流れの行のまま出す         | 仕組み | 言った順に並び、締めのセリフの続きとして読める。定位置から流れへ戻る移動が無くなる | 採る     |
| 定位置に出し、明るさを消す | 仕組み | 浮いた位置は変わらず、紙が短いと締めのセリフとのあいだに大きな空きが残る           | 採らない |

- 流れの行の待ちの一言は、ほかのセリフの行と同じ見た目で、完了した局面では明るさを付けない。尾は従っているセリフ（流れのいちばん新しいセリフ）に付くので、待ちの一言が出ればそこへ移る。
- 迎えの挨拶とおかえりは今のまま定位置に出す。
- 狭い画面の顔の吹き出しは変えない。
