# ホスト依存の操作は1つのポートにまとめる

Orca に全面的に依存してよいが、**ホスト（ターミナル環境）に依存する操作は1つのポートの裏に
置く**。ポートは `src/server/host/core/host.ts`、アダプタは `src/server/host/adapter/orca-host.ts`。今あるのは次の2つ:

- **ビューを見せる**（`showView`）— URL のビューが無ければ開き、あればその内容を最新にする
- **ファイルを開く**（`openFile`）— レポートに書かれた git 管理下のパスを Orca のエディタで開く
  （2026-09-24 追加。行番号を渡す引数は無いので、渡すのは裸のパスだけ）

**「開く」と「更新する」を1つの操作にしてある（`showView`）。** 分けると呼び出し側が
「今どちらの状態か」を覚えることになり、その状態はホスト側の都合（タブが閉じられた等）で
いつでも古くなる。同じ URL で何度呼んでもビューが1つになる形にして、判断をアダプタの中に閉じた。

**2026-09-11 の方針転換で、`openPane`（TUI 用のペインを開く操作）は要らなくなった**
（ターミナルへの文字送信・キー送信も同じく消えた。TUI を開かなくなったため）。

**増やすのは、仮説上の将来のためではなく、実際の要件がホストの操作を求めたときだけ。**
`openFile` は2026-09-24 に足した2件目で、動機は「VS Code にも載せ替えられるように」ではなく
**レポートに書かれたパスを開くという要件そのもの**（`docs/architecture/display.md` 4.2「各表示物」）。
**ポートに乗る操作の数と、アダプタの数（下）は別の軸**——`openFile` を足したことは2つ目の
アダプタを書く理由にはならない。

アダプタは**いま Orca の1つだけ**で、VS Code 用の実装も Electron 用の実装も**まだ書かない**。
ただし**書けるままにしておくことは条件**である（2026-09-16 の方針: Orca で進めつつ、核が特定の
技術に依存しないようにする）。**2つ目のアダプタを書くまで、実装は `orca-host.ts` 1つに保つ。**
仮説のためにアダプタを増やさないことが、その日のコストを小さく保つ唯一の手段だから。

**どのアダプタを使うかの選択は `src/main.ts` の1行**（`createOrcaHost()` を渡すところ。タブだけを
開き直す `scripts/open-views.ts` も同じく直接呼ぶ）。選ぶ口（環境変数・引数・ファクトリ）は
**置いていない** — アダプタが1つのうちは配線層の1行で足りるので、2つ目のアダプタを書くときに
改めて考える（2026-09-21 決定）。

**これは `.claude/skills/codebase-design` の「アダプタが1つならそれは仮説上のシーム。
アダプタが2つなら本物のシーム」に反する。** 意図的に外している。理由は、**箱を包むかどうかを
先送りにしているから**で、2026-09-21 に「当面やらない」と決めたあとも**載せ替えられる形を保つ**
ことは条件として残った（`docs/requirements.md` 2.2）。ポートが無いと、包むと決めた日に
`showView` を呼ぶ側まで含めて作り直すことになる。あの戒めが防ごうとしているのは「誰も求めて
いない差し替えのために間接化を積むこと」だが、ここで守っているのは**1つの関数の境界**だけで、
積んだ間接化はその1段しかない。

ただし戒めの趣旨は守る。**ポートは「ホストに何をしてほしいか」だけを表し、Orca の語彙
（`terminal split` のフラグ名、タブの概念）をインターフェースに漏らさない。** 漏らすと、
2つ目のアダプタを書くときに結局インターフェースごと直すことになり、ポートを置いた意味が消える。

具体的には、ポートに現れるのは**ペイン・配置（横／下）・ビュー・URL**だけで、`tab` も
`--direction horizontal|vertical` も出てこない。`horizontal` が左右で `vertical` が上下、
という Orca 固有の対応はアダプタの中だけで解決する
（ポート側は `beside` / `below` という、見た目の位置そのものを言う語にした）。

**失敗を例外にしない**のもポートの形の一部。`orca` が入っていない環境ではその操作を諦めて
動作を続けるのが要件（`docs/architecture/display.md` 4.2）なので、成否を戻り値で返す。

**ポートを置く範囲を広げない。** transcript の読み取り・吹き出しの組み立て・立ち絵の描画は
ホストに依存しないので、ポートの外に置く。
