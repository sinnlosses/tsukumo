# 表情の役割の名をシステムが持ち、パックの語を添える（2026-11-23）

ステータス: 採用

**表情9つの役割の名（通常・考え中・得意・慌て・真剣・驚き・落胆・高揚・退屈）と、それぞれを選ぶ場面の1文を `src/shared/character-pack/` が持つ。画面と、エージェントへの表情の説明は役割の名を主にし、パックの `expressions` のラベルはキャラクターの言い方として添える。** 役割の名は全パックで同じで、パックから消せない。ラベルは任意のままで、無くても役割の名が出る。

## 何が困っていたか

- 選ばれた表情に付く動き・吹き出しの出方・エフェクトは表情名ごとに固定（`SPEECH_ARRIVALS`）で、意味はすでに全パック共通
- 一方、表情の説明はパックのラベルだけで、パックごとに意味が食い違う。唐傘は thinking を「困り」、serious を「怒り」と呼ぶので、困った顔に考え泡が、怒った顔に「真剣な確認」の閃光が付く
- エージェントは `thinking（困り）` の説明を読んで表情を選ぶので、絵と演出と選び方が三つ巴でずれる。利用者も、画面でどの表情か分かりにくい

## 決めたこと

### 1. 役割の名と選ぶ場面

名前（表の1列目）は今の `EXPRESSIONS` のまま。役割の名は `SPEECH_ARRIVALS` がすでに持つ意味を日本語にしたもの。

| 表情名      | 役割の名 | 選ぶ場面の1文                                  | 演出（既存）             |
| ----------- | -------- | ---------------------------------------------- | ------------------------ |
| `default`   | 通常     | 特に感情を乗せない、ふだんの話し方のとき       | うなずき・エフェクトなし |
| `thinking`  | 考え中   | 調べている・迷っている・考えをまとめているとき | 傾き・考えの泡           |
| `proud`     | 得意     | うまくいった・やり遂げた・自信があるとき       | 成功の動き・きらめき     |
| `flustered` | 慌て     | 失敗した・想定外で焦った・照れて取り乱したとき | 失敗の動き・汗           |
| `serious`   | 真剣     | 大事な確認・警告・気を引き締めて伝えるとき     | 静止・閃光               |
| `curious`   | 驚き     | 意外な発見・気になること・不思議に思ったとき   | 首をかしげる・波紋       |
| `sad`       | 落胆     | 残念な結果・うまくいかなかった・申し訳ないとき | 沈む動き・雨             |
| `excited`   | 高揚     | わくわくする・うれしい・勢いづいているとき     | 成功の動き・花びら       |
| `bored`     | 退屈     | 待ちくたびれた・変化がない・気が抜けているとき | 沈む動き・泡             |

この表の語は演出（`SPEECH_ARRIVALS`）と同じ場所に並べて持つ。役割の名を足す・変える側は、演出と同時に直す。

### 2. 出す場所ごとの形

主は役割の名。パックのラベルは「あるときだけ」括弧で添える。ラベルが無い・役割の名と同じ字のときは添えない。英語の表情名をラベル代わりに出す代替は廃止する（役割の名が必ずあるので要らない）。

| 場所                                                                                        | 形                                                                                        |
| ------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| `speak`・`report`（`closing`・`waitingLine`）の表情の説明                                   | `thinking: 考え中（ふむ）。調べている・迷っているとき` を `/` でつなぐ（場面の1文つき）   |
| 迎える場面・書いた反応の指示（`src/server/welcome-greeting/core/`）                         | `- thinking: 考え中（ふむ）。<場面の1文>` の箇条書き                                      |
| 日記の表情の説明（`src/server/diary/adapter/sdk-diary.ts`）                                 | `speak` の説明と同じ形                                                                    |
| キャラクター画面の立ち絵の札（`portrait-card.ts`）と差し戻しの文（`use-character-edit.ts`） | 札の題は役割の名。ラベルがあれば小さく添える。aria-label・差し戻しの文は `考え中（ふむ）` |
| 日記の画の alt（`diary-writer.ts`）・`portrait-appearance.ts`                               | `<名前>（考え中）`。ラベルは入れない（alt は役割が分かれば足りる）                        |

形を組む関数は shared に1つ置き、各所はそれを呼ぶ。`ExpressionChoice` は `{ name, role, label? }`（`role` は役割の名、`label` はパックの語で任意）にし、`resolveExpressionLabel` は役割の名を返す `expressionRoleName` と、添える語を足した文字列を返す1つに分ける。選べる表情の絞り込み（立ち絵かラベルがある表情だけ）は今のまま。

### 3. 役割とラベルの意味が食い違うパック

**ラベルを役割に合わせて直す。絵が役割と合わないときだけ、立ち絵の割り当てを入れ替える。** 絵とラベルが合っているのに役割の名と合わないとき（唐傘の thinking の絵は口を開けて慌てた顔）は、絵を役割の側へ移す。パックのラベルは、その役割の絵を指す言い方に直す。

唐傘（実物の画を見て決めた）:

| 表情名      | いまの絵の内容       | 絵の割り当て           | ラベル（前 → 後）   |
| ----------- | -------------------- | ---------------------- | ------------------- |
| `thinking`  | 口を開けて慌てた顔   | `flustered.png` を置く | 困り → うつむき     |
| `flustered` | 目をそらして照れた顔 | `thinking.png` を置く  | 照れ → 困り         |
| `serious`   | むすっとした真顔     | そのまま               | 怒り → むすっ       |
| `bored`     | 眠った顔             | そのまま               | すやすや → すやすや |

`thinking` と `flustered` は絵ファイルを入れ替える（`thinking.png` ↔ `flustered.png`。`character.json` の `portraits` の綴りは変えず、ファイルの中身を替える）。ほかの表情（`excited` のにっこり・`curious` の驚き・`sad` の悲しみ・`proud` のくすっ）は役割と合うのでそのまま。同梱の他のパック（つくも・精霊・帳・暮羽・白鈴・行灯）は役割と食い違わないので触らない。

ホームのパック（`~/.tsukumo/characters/`）は同梱を覆うので、手元のパックは利用者が写す。

### 4. `characters/README.md` の書き換え

`expressions` の説明を次の趣旨に替える。

- 表情の役割の名はシステムが持ち、全パックで同じ。名前と役割の名の対応表は本 ADR の「1.」の表を引く
- `expressions` は「その役割を、このキャラクターならどう言うか」を書く任意の欄。画面と説明には役割の名に添えて出る。書かなくてよい
- ラベルは役割と意味を合わせる（絵が役割と合わないなら絵のほうを入れ替える）

「表情の呼び名はキャラクターの言葉なのでコード側に持たない」の記述は消す。`src/shared/character-pack/expression.ts` の冒頭の注「表情の日本語ラベルはここに持たない」も、「役割の名は持つ。パックのラベルは持たない」に替える。

## 「キャラクターの中身をコードに書かない」との線引き

コードに書くのは、表情名ごとに演出が固定で持っている意味の日本語（役割の名と場面）で、キャラクターの性格・口調・呼び方ではない。キャラクターの言い方（ラベル）・立ち絵・素材との対応は今までどおりパックの定義ファイルが持つ。

## 範囲の外

- 表情の数を増やす・名前を変える
- 演出（動き・エフェクト）の割り当て
- 同梱パック以外のパックのラベルの自動修正

## 実装の順

1. shared に役割の名を持たせ、`speak` ほか各指示の説明を替える
2. キャラクター画面の札・差し戻しの文・日記の alt を替える
3. README と唐傘のパックを直す
