# 図派の既定では、図を置かずに材料を表・手順・長い文へ逃がした report を差し戻す（2026-11-26）

ステータス: 採用

**利用者の図の既定が図派（`figurePreference: "chart"`）のセッションでは、`Report.figure` が無く、セクションに図にできる材料（3行以上の `Table`・3項目以上の番号つきの `ItemList`・流れや前後を描く部品・1つのセクションで 400 字以上の文）がある `report` を、差し戻しの条 `figure-escape` で差し戻す。差し戻し文は材料の位置と、当たった材料ごとの図への直し方（どの部品にするか）を言う。文派（`text`）では効かない。この ADR は、ADR 0036 の「`figure` を省ける欄にする」を図派について改める（ADR 0036 の本文は書き換えない）。**

## 何が困っていたか

- ADR 0036 で `figure` は省ける欄になり、図を置かない理由（`figureNone`）も書ける。理由と本文の食い違いを見る `figure-contradiction` は、`no-shape` なのにセクションに流れの部品がある回と、`short-answer` なのにセクションが2つ以上ある回しか見ず、しかも 2026-10-27 に `count` へ下げてあり差し戻さない。
- そのため、名前が3つ以上つながる材料や3行以上の表があっても、`Table` と `no-shape` を書けば通り、図派の利用者に文と表が中心のレポートが届いていた。ADR 0036 の「見直す条件」の2つ目（省いた回で、構造のある節の図が抜ける）に当たる。
- 利用者は 2026-11-26 に「レポートを図中心にしたい。文章に逃げているものを塞ぐプロンプトと検査を入れ、差し戻しの文で直し方をガイドする」と決めた。

## 決めたこと

- 条の名前は `figure-escape`（図の検査の家族 `src/server/report/core/rules/figure.ts`。検出と文は `figure/escape.ts`）。新しい条は `count` で入れる決まり（ADR 0028 の追記）の例外として、利用者の決定で初めから `reject` で入れる。根拠の行は `docs/history/decision.md` の「adr/0028 追記 差し戻しの条ごとの根拠」に置く。
- 検査は図の既定を見る。`ReportDraft` に `figurePreference` を持たせ、`report` の道具を起こした値（`reportTool` の引数）をそのまま渡す。
- 材料の境（表 3 行・手順 3 項目・文 400 字）は目安で、実証した閾値ではない。表は 2 列目より右にどの行も数（単位 3 字まで）の列があれば「数の列がある表」として `Chart`・`Plot` を勧め、それ以外は `Graph`・`Matrix`・`Compare` を勧める。
- `figureNone` を書いても、材料が残るかぎり通らない。図にした中身は表や文に重ねて書かない（記法の条3）と差し戻し文でも言う。
- `figure` の欄の説明（`reportFigureDescription`）の図派の文に、材料を表・手順・長い文へ逃がすと差し戻すことを足す。常設の記法（`REPORT_NOTATION_PROMPT`）は上限に近いので足さない。

## 採らなかった案

| 案                                        | 採らなかった理由                                                                                        |
| ----------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| 描く側で表や数の並びを自動で図にする      | どの列を図にするかを機械が決めるので外れた図が出うる。書き手が材料の形を決める（記法の条9）のと食い違う |
| 常設の記法の条を書き足して促す            | 常設の規約は上限まで数字しか残っておらず、文の促しは今も効いていない                                    |
| `figure-contradiction` を `reject` へ戻す | 理由を書かない（`figure` を省く）呼び出しには働かず、表や長い文を材料として見ない                       |
| 文派でも差し戻す                          | ADR 0036 が文派に約束した「図は構造・前後・数がある節に限る」を破る                                     |

## 見直す条件

- `figure-escape` の差し戻しのあと、同じターンで2回以上差し戻される回が続く（直し方の文が効いていない）。
- 材料の境のせいで、図にしようのない表や文まで差し戻している回が記録で見える。
