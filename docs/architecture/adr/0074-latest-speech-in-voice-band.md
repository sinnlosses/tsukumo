# 直近のセリフを入力欄の上の声の帯に置く（2026-11-18）

ステータス: 採用

**広い画面の仕事の画面で、いちばん新しいやり取りの直近のセリフ1件を、流れから外して入力欄のすぐ上の声の帯に出す。帯はメインビューのスクロール容器の外に吹き出し1件ぶんの高さを取る区画で、迎える反応（迎えの挨拶・おかえり）も同じ帯に出す。この ADR は、ADR 0071 の「待ちの一言は流れの行のまま出す」と、ADR 0069 の「締めのセリフは紙の下に置く」のうち直近の1件の置き場を上書きする（どちらも本文は書き換えない）。**

## 何が困っていたか

キャラクターの直近の一言は流れの末尾にあり、レポートを読み進めると画面の外へ流れた。以前の声の定位置（ADR 0063）は `position: sticky` でスクロールの末尾に貼り付いたので、転がした本文の上に吹き出しが重なった。利用者から、直近のセリフ1件だけは高さを取って固定し、レポートとかぶらないようにしてほしいと頼まれた。

## 決めたこと

**採る: 中央の列のメインビューと入力欄のあいだに声の帯の行を置き、直近のセリフ1件を帯へ移す。同じ文は流れと帯の2か所に出さない。**

| 案                                         | 種類   | 物差し                                                                       | 判定     |
| ------------------------------------------ | ------ | ---------------------------------------------------------------------------- | -------- |
| スクロール容器の外に帯の行を置き、移す     | 仕組み | 帯はメインビューの高さを削るだけで本文に重ならない。同じ文は1か所            | 採る     |
| 帯に写し、流れにも残す                     | 仕組み | 流れを遡ると全部読めるが、直近の文が2か所に出る                              | 採らない |
| 流れの中で `position: sticky` に貼り付ける | 仕組み | 実装は小さいが、転がした本文の上に吹き出しが重なる（以前の声の定位置と同じ） | 採らない |

- 帯に出すのは、いちばん新しいやり取りの流れの最上位にあるセリフ（反応を含む）のうち最後の1件。次のセリフが届くと、帯にあった1件は流れの記録の位置へ戻る。「作業の経過」に畳んだセリフは移さない。
- 尾・いまの一言の明るさ・出方は、流れの中の位置で決めてから帯へ移す（押して留める・最新へ戻るの決まりも同じ）。
- 帯は仕事の画面で常に吹き出し1件ぶんの高さを取り、セリフの有無・入れ替わり・局面の入れ替わりでメインビューの位置と大きさを動かさない。帯を置かないのは雑談だけ。
- 帯のぶんメインビューが縮むので、答え待ちの札へ連れてくるスクロールは、中身の入れ替わりで先頭へ戻すスクロールより後に走らせ、札を見えるところへ寄せる。
- 帯の幅は入力欄と同じ読む幅の組（ADR 0072）で、吹き出しの左端は流れのセリフとそろえる。
- 帯が伸びてメインビューが縮んだとき、下端を読んでいれば流れを下端へ寄せ直す。
- 狭い画面は帯を出さず、顔の吹き出しのまま。
