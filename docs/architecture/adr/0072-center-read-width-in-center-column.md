# 読む幅の組を中央の列の中央に置く（2026-11-18）

ステータス: 採用

**広い画面で、読む幅の上限を置いた組（進行の帯・会話の流れ・お伺い・声の定位置・始め方の一覧・雑談のログ・入力欄）を、中央の列の中で左右の中央に置く。この ADR は、ADR 0062 の論点 13 の「上限は中央の列の中で左に寄せる」を上書きする（本文は書き換えない）。読む幅の上限の値（流れの内容は 960px、帯と入力欄は縁を含めて 976px）は変えない。**

## 何が困っていたか

中央の列が読む幅の上限より広い画面（2400×1200 では中央の列が約 1571px）では、組が列の左に寄り、右に約 560px の空きが残った。利用者から、中央に寄せてほしいと頼まれた。

## 決めたこと

**採る: 組の外寸を `--center-read-width`（帯と入力欄の上限と同じ 976px）として中央の列に1つ置き、メインビューの札・始め方の一覧・雑談のログ・入力欄がこの幅の組を列の中央に置く。**

| 案                         | 種類   | 物差し                                                                       | 判定     |
| -------------------------- | ------ | ---------------------------------------------------------------------------- | -------- |
| 組を列の中央に置く         | 仕組み | 左右の空きが同じになる。立ち絵と流れの距離は幅で変わる                       | 採る     |
| 左に寄せたまま（今の形）   | 仕組み | 立ち絵と流れの距離は変わらないが、広い画面で右に大きな空きが残る             | 採らない |
| 中央の列そのものを狭くする | 仕組み | 転がる器とサイドシートの置き場まで狭まり、サイドシートがサイドバーから離れる | 採らない |

- 帯・入力欄・始め方の一覧・雑談のログは、左右の端が同じ位置にそろう。流れは組の中で左右に `--gutter-stream` の余白を取るので、中央の列が 976px を超える画面では流れの内容の幅が 960px から 928px に縮む（中央に置く組の外寸を入力欄とそろえるため）。
- 転がる器（メインビュー・雑談のログ）の幅は変えず、余白の上で転がしても効く。
- 中央の列が組より狭い幅（1400×900 など）では余白が 0 になり、見た目は変わらない。761〜1100px の柱の形と 760px 以下も変わらない。
