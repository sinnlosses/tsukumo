# 雑談モードを2ペインに戻し、立ち絵と席をメインへ移す（2026-11-19）

ステータス: 採用

**広い画面（761px 以上）の雑談モードでは、左の列と左の仕切りを出さず、メインビューとサイドバーの2ペインにする。メインビューは枠と角丸を外して背景の上に直接立ち、その中で立ち絵（つつくと話しかける）と席のアイテムを左に、会話のログを右に並べる。この ADR は、ADR 0058 の「雑談モードも同じ3列の形にそろえる」と、その手順4を上書きする（ADR 0058 の本文は書き換えない）。仕事モードの3列は変えない。**

## 何が困っていたか

ADR 0058 の手順4で雑談も仕事と同じ3列にそろえ、立ち絵は左の列、ログは中央の列に分かれた。立ち絵とセリフのあいだに仕切りと列の境目が入り、キャラクターの隣で話している感じが薄れた。利用者から、雑談では以前の仕様（3列にそろえる前）のように2ペインで話す形に戻してほしいと頼まれた。

## 決めたこと

**採る: 雑談のあいだだけ左の列を畳み、立ち絵・席・ログをメインビューの1枚に並べる。**

| 案                                                        | 種類   | 物差し                                                                                      | 判定     |
| --------------------------------------------------------- | ------ | ------------------------------------------------------------------------------------------- | -------- |
| 左の列を畳み、立ち絵と席をログと同じメインビューに並べる  | 仕組み | 立ち絵とセリフのあいだに境目が無い。仕事の3列は変わらない                                   | 採る     |
| 3列のまま、左の列とメインビューの境目（枠・仕切り）を消す | 見た目 | 仕切りで幅を変えられる口は残るが、器の列が2つに分かれたままで、ログの読む幅と立ち絵が離れる | 採らない |
| 2ペインにし、席のアイテムは雑談では出さない               | 仕組み | 3列にそろえる前と同じ見た目で手数は少ないが、いま雑談で見えている席が消える                 | 採らない |

```
┌──────────────────────────────────────────┬──────────────┐
│ メインビュー（枠なし・背景の上）             │ サイドバー     │
│                                          │ （雑談の4段）   │
│   ◯        ╭────────────╮                │              │
│  立ち絵      │ セリフ      │                │              │
│ （つつける）  ╰────────────╯                │              │
│               ╭────────────╮             │              │
│               │ 利用者の発言 │             │              │
│  席・席       ╰────────────╯（下端から積む） │              │
├──────────────────────────────────────────┤              │
│ 入力欄                                     │              │
└──────────────────────────────────────────┴──────────────┘
```

- 器（`ConversationLayout`）には、左の列を出さない旗を1つ持たせる。器は「なぜ畳むのか」を知らず、旗を立てるのは会話の画面（`presentational-conversation.tsx`）。広い幅（1101px 以上）と中くらいの幅（761〜1100px）の両方で、左の列と左の仕切りの列を出さない。サイドバーの仕切りと柱は今のまま。
- 左の列の幅（`--layout-left-width`）は仕事モードのために覚えたままにし、雑談では読まない。雑談から仕事へ戻すと、覚えた幅の3列に戻る。
- 雑談のメインビューは枠と角丸と地を外し、器の全面に敷いた背景の上に直接立つ（立ち絵は枠と地を持たない、の原則のまま）。背景の素材・敷き方・覆いの下限は変えない。
- 立ち絵と席は1つの舞台の箱にまとめ、メインビューの左に置く。席の置き方（左上は頭上、左下と右下は足元の手前）は今の `ItemSeats` のまま、舞台の箱を基準にする。左の列用の `ChatStage` は外す。
- 立ち絵の大きさは、3列にそろえる前に 1400×900 で決めた値（メインビューの高さの 80%・幅の上限 32%）を起点にし、実装の段で目視して詰める。立ち絵の素材が無いときは、舞台の箱を出さずログだけで成立させる。
- ログは立ち絵の右に置き、下端から積む。読む幅の組（ADR 0072）は、立ち絵とログを並べた組に効かせ、広い画面で立ち絵とログが左右に離れすぎないようにする。
- 入力欄はメインビューの下端の行のまま、メインビューと同じ幅に置く。声の帯・やり取りの列・答え待ちの札は、今と同じく雑談では出さない。
- 狭い画面（760px 以下）は変えない（左の列を出さず、顔を入力欄の上に出し、背景を敷く）。

## 結果

- 雑談の画面は、メインビュー（立ち絵・席・ログ・入力欄）とサイドバーの2ペインになる。仕事の画面は3列のまま。
- 画面の正典 `docs/architecture/screen-design/chat-mode-screen.md` と `docs/architecture/screen-design/background.md` は、実装と同じコミットで2ペインの記述に直す。
- 吹き出しの尾を立ち絵の顔へ向ける仕組みは仕事の流れだけに効いていて、雑談のログには付いていない。雑談に広げるかはこの ADR では決めない。
