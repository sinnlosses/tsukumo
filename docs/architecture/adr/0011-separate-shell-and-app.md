# ホスト（Orca か既定のブラウザ）と中身（Web アプリ）を分ける

画面を出す入れ物を「ホスト」と呼ぶ。**いまのホストは Orca のブラウザタブと macOS の既定のブラウザが並ぶ**
（開くのに `orca tab create --url` / `open` を使う。どちらを使うかは `docs/architecture/adr/0015-single-host-port.md`）。ページそのものは**どのホストでも動く Web アプリ**として作り、
ホストに依存する操作はホストのポート（`src/server/host/core/host.ts`）の裏に置く（下の「ホスト依存の操作は
1つのポートにまとめる」）。

TUI を捨てたことで、**ホストに頼む仕事は `showView`（ページをホストの中に開く）と `openFile`（レポートのパスを開く）だけ**になった。
ペイン分割も、ターミナルへの文字送信・キー送信も要らない。**ホスト固有の機能への依存が最小に
なったので、ホストの差し替えは現実的な選択肢**で、実際に Orca と既定のブラウザの2つを持つ。

**スタンドアロンのアプリに包むのは当面やらない**（2026-09-21 決定。`docs/requirements.md` 2.2。
それ以前は「使い勝手が上がるなら最終形は Electron」の未決だった）。**載せ替えられる形は保つ**
ので、`showView` を差し替えれば移れる状態は維持する。Node で動くことも移りやすさに効く
（Electron はもともと Node を積んでいるので、Electron に移るときにランタイムの入れ替えが要らない）。
