# 締めのセリフを紙の下に置く（2026-11-18）

ステータス: 採用

**`report` の締めのセリフ（`closing`）を、記録の順のまま紙の下に置き、紙と1組にする。書いているあいだに紙の上へ空けていた1行ぶんの押さえはやめる。この ADR は、ADR 0062 の論点 2 の「締めのセリフは紙の上に置く」と「場所を空けて押さえる」を上書きする（本文は書き換えない）。**

## 何が困っていたか

締めのセリフは記録の上では紙のすぐ後ろに届くが、流れでは紙の上へ移して描いていた（`streamItemsOf`）。締めのセリフは書き終えたレポートへの一言で、紙を渡したあとに言う（`persona.md`「締めのセリフの言い方」）。紙の上にあると、まだ読んでいない紙への前置きに見える。利用者からも、締めのセリフと最終レポートの位置を逆にしてほしいと頼まれた。

## 決めたこと

**採る: 締めのセリフは記録の順のまま紙の下に置く。並べ替えは無くなり、ADR 0062 の論点 1 の「並べ替えない」に例外は残らない。**

| 案                                       | 種類   | 物差し                                                                                                                        | 判定     |
| ---------------------------------------- | ------ | ----------------------------------------------------------------------------------------------------------------------------- | -------- |
| 紙の下に置く（記録の順のまま）           | 仕組み | 読む順が「紙 → 紙への一言」になり、言った順とも合う。並べ替えと押さえが要らなくなる。紙が長いと、締めは紙の長さぶん下に離れる | 採る     |
| 紙の上に置き、書いているあいだは押さえる | 仕組み | 締めの一言を先に読めるが、読んでいない紙への前置きに見える。並べ替えの例外と押さえの高さの決まりが要る                        | 採らない |

- 紙は、後ろの締めのセリフと1組にする（物は後ろのセリフと先に組む、ADR 0062 の論点 1 の決まりのまま）。締めのセリフがあとから加わっても、組の頭は紙なので紙を作り直さない。
- 書いているあいだは紙の上に何も押さえない。締めのセリフは紙の下に加わるので、書き終えても紙は動かない。
- 最終レポートと締めのセリフは「作業の経過」の外、畳みのすぐ下に置く。中間レポートの締めは、紙の後ろのまま畳みの中に入る。
- 最終レポートより後ろに届いた質問の記録（お願い）は、締めのセリフより後ろ、流れの最下部に残す。
