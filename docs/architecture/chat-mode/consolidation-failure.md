# 雑談モード: 定着が落ちたとき

戻り: `docs/architecture/chat-mode.md`「窓から溢れた会話は定着で畳む」

定着の結果が検査に落ちたときの逃がし口、続けて落ちたパックの契機の間引きと止め方、落ちた理由の残し方。

責務: 定着が書けなかったあとの扱い（縮みの逃がし口・間引き・止め方・診断ログの足跡）を持つ。いつ走るか・渡すもの・受け取る形は `docs/architecture/chat-mode.md`。
読む時: 定着の失敗の扱いか、その足跡に触るとき。
直す時: 縮みの逃がし口・間引きの規則・足跡の語を変えたとき。

## 縮みの検査の逃がし口

- **縮みの検査には逃がし口がある**。前に書けてから縮みの検査に落ちた回が 3 回目
  （`synopsisShrinkWaiveAt`）に届いたら、その回は縮んだあらすじのまま書く（モデルが毎回半分未満に
  畳むと、同じ行が契機ごとに落ち続けて定着が止まるため）。回数はパックごとにプロセスのメモリで数え、
  書けたら 0 に戻す。起こし直すと 0 から数え直す
- **閾値の半分（`synopsisKeepRatio`）は根拠の弱い判断の定数**。本物の `query()` を起こさない単体
  テストでは haiku の縮み方を測れず、合成の入力では境目（半分ちょうどは通り、それ未満は落ちる）だけを
  固定した。誤って拒んだときの代価は、上の逃がし口が契機 3 回までに抑える

## 続けて落ちたら契機を間引く

落ちた行は未定着のまま残り、次のターンの終わりに同じ先頭から読み直される。1回に畳む量の上限
（`consolidateEveryBytes` の2倍）に届いたあとは、行が増えても渡す行も前のあらすじも変わらないので、
同じ入力で落ち続けうる。その繰り返しで `query()` を毎ターン起こさないよう、契機を間引く。

- **数えるのは同じ入力で落ち続けうる失敗**: `threw`・`query-result`（SDK の result が成功でない）・
  `unreadable-result`（検査に落ちた。縮みを除く）
- **数えないもの**: `aborted`（時間切れと、プロセスを終えるときの設計どおりの中断を含む）・縮み
  （上の逃がし口が別に止める）・`locked`・あらすじや索引の書き込みの失敗。数えないものは 0 にも戻さない
- **0 に戻すのは、書けたときと、契機に届かず起こさなかったとき**（`not-due`）
- **続けて落ちた回数が 3 回（`failuresBeforeBackoff`）に届いたら、そのあとの契機を 2 回飛ばす。**
  また落ちるたびに倍にし、32 回（`maxSkips`）で頭打ちにする。飛ばした契機は錠も取らず行も読まない
- **勘定はパックごとに、プロセスのメモリで持つ**（縮みの回数と同じ置き方）。起こし直すと 0 から数え直し、
  錠を取り合う複数のプロセスはそれぞれ別に数える
- **飛ばしているあいだも行は溜まるが、失うものは無い。** 1回に畳むのは上限までで、飛ばさなくても入力は
  変わらない。ただし止める数（下の「続けて落ちたら止める」）が間引きの始まる数と同じなので、間引きの
  飛ばしと試し直しが実際に効くのは、止める側の全体の数が別のパックの結果で戻ったときなど、パックごとの
  勘定だけが 3 回に届いている場面に限る。そのときの落ち続ける範囲は、およそ 33 ターンに1回は試し直す
- 落ちる原因（構造化出力の長さ・ターン数の上限）はここでは直さない

## 続けて落ちたら止める

続けて落ちた回数が間引きと同じ 3 回に届いたら、**このプロセスの間は契機を起こさなくする**。

- **数え方は間引きと同じ**（`chatConsolidationBackoffEffect`）。続けて落ちた回数が 3 回
  （`failuresBeforeBackoff`）に届いたら止める。定数は間引きと1つを共有する
- **勘定はパックを区別せず、プロセスのメモリだけで持つ。** 起こし直しても止めたままで、プロセスを
  替えれば 0 から試す。永続の印は置かない
- **止めたあとは契機で何も起こさない**（間引きの試し直しも走らない）。1つのパックで落ち続けると、間引きの
  飛ばしが始まる前に止まる
- **止めた1回だけ**、診断ログへ足跡 `consolidation-halted` を書き、`chat-consolidation-halted` を流す。
  画面は雑談のサイドバー「最近の話題」の下に1行を出す

## 落ちた理由の足跡

- **落ちた理由は診断ログに種類で残る**（`swallowed-failure` の場所の語。形の崩れ・あらすじが空・長さ
  超過・予約タグ・縮みと、縮みの検査を外して書いたこと、間引いて飛ばした契機）。残すのは語だけで、あらすじの本文も
  パックの名前も入らない
