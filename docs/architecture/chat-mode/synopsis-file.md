# 雑談モード: あらすじの写しのファイル

戻り: `docs/architecture/chat-mode.md`「記憶の圧縮と忘却」

あらすじの写しのファイルの形、旧い形の読み方と移し方、定着が書く順と途中で落ちたときの直し方。

責務: あらすじの写し（`~/.tsukumo/chat-summary/<パック名>.summary.json`）の形と書き方を持つ。何を載せるか・いつ書き直すかは `docs/architecture/chat-mode.md`。
読む時: あらすじの写しの読み書きか、定着の書く順に触るとき。
直す時: 写しの形・旧い形の扱い・書く順を変えたとき。

## 形

- **中身は1つの JSON**（`v`・`delivered`・`synopsis`・`topics`・`fold`）。`delivered` は「次に起こす
  セッションへ渡す必要があるか」の1ビット（`docs/architecture/chat-mode.md` の「載せる条件」が使う）、
  `topics` は最近の話題の見出し、`fold` はあらすじがアーカイブのどの行まで取り込んだか（下の「書く順と、途中で落ちたとき」）
- **同じファイルに持ち、一時ファイルからの rename で丸ごと置き換える**のは、あらすじ・話題・印が1回の
  書き込みで揃い、書きかけの状態を読ませないから（別ファイルにすると片方だけ残った状態が生まれる）。
  ファイルを消せば印も一緒に消える。読めない JSON は無いものとして扱う（印は「未渡し」）
- 名前を `<パック名>.json` にしないのは、パック名がドットを含められるので、別のパックの旧い
  `<パック名>.topics.json` と重なるから

## 旧い形

- **旧い形**（`<パック名>.md` の1行目が印・2行目から本文、話題は `<パック名>.topics.json`）は、
  新しい形が無い・読めないときだけ読み、次に書いたとき（定着でも印の書き換えでも）新しい形へ移して
  旧いファイルを消す。**両方あるときは新しい形が正**（旧いファイルを消し損ねた・古い版の tsukumo が
  書き足した場合で、書かれた時刻は比べない）
- 旧い形の話題は `<パック名>.topics.json` を読み、**そのファイルが無い・読めない・文字列の配列でない
  写しは、見出しを本文に埋め込んでいたさらに古い形として読む**（読みだけで、書くときは埋め込まない）。
  古い形は**最後の `<topics>` から次の `</topics>` まで**を読み、箇条の印を落とし、空行を飛ばす。
  印が無い・閉じが無いときは空（推し量って出さない）。古い形の本文は、組を除いた地の文を
  あらすじとして渡す

## 書く順と、途中で落ちたとき

定着が書くのは**あらすじの写しだけ**で、`fold` を畳んだ最後の行の時刻にする。**どこまで畳んだかは `fold` が決め**、
次の定着はアーカイブの `fold` より後の行から読む。写しは1回の rename で丸ごと置き換わるので、書く途中で落ちても
前の写しのまま残り、次の契機で同じ行を畳み直す。

- **`fold` を持たない写し**（無い・旧い形）は、アーカイブの最初から畳む。前のあらすじは渡すので、行は落ちない
- 別の版の tsukumo や印の書き換えが写しを古い中身で上書きして `fold` が戻ったときは、戻った `fold` の後から畳み直す
