# アイテム

ステータス: **正典**。

責務: キャラビューの席に置くアイテムの一覧と席の選択の置き場と形、画面から足すときの受け取り方と
書き込みの境界、素材を配る URL を持つ。席の位置・大きさ・重なりは `docs/architecture/screen-design.md` 13.4、
キャラクター画面の口は同じ 13.6 が持つ。
読む時: アイテム・席・`~/.tsukumo/items/` に触るとき。
直す時: 一覧や席の持ち方・受け取りの規則・配る URL を変えたとき。

## アイテム

**アイテムは、キャラビュー（立ち絵の舞台）の席に置く飾り**（利用者決定）。例は提灯（吊るすので
左上）とカバン（置くので足元）。押す口は持たず、置いても会話には何も渡らない。

- **一覧（持ち物）**: 利用者が足したアイテムの並び。**どのキャラクターにも共通**で、パックの中には持たない
  （利用者決定）
- **席**: キャラビューの「左上」「キャラの左下」「キャラの右下」の3つ。**席ごとに一覧から1つを選んで置き、
  あとから差し替えられる**（利用者決定。アイテムごとに席を決める形ではないので、席の取り合いは
  起きず、差し替えるだけになる）。**席は空にでき、既定は空**
- **一覧は席の操作では消えない。** 席から外しても、差し替えても、起こし直しても一覧に残る。一覧から
  消えるのは、利用者がキャラクター画面で消すと確かめたときだけ

### 置き場と形

**一覧も席の選択も、ホームの `~/.tsukumo/items/items.json` 1つに持つ**（素材の画像も同じディレクトリ）。
`TSUKUMO_HOME` を渡すとホームごと移る。

```json
{
  "items": [
    { "id": "1", "name": "提灯", "image": "1.png" },
    { "id": "2", "name": "カバン", "image": "2.svg" }
  ],
  "seats": {
    "tsukumo-spirit": { "topLeft": "1", "belowRight": "2" }
  }
}
```

| キー    | 中身                                                                                              |
| ------- | ------------------------------------------------------------------------------------------------- |
| `items` | 一覧。**並びは足した順**で、新しいものが末尾。1件は `id`・`name`（表示名）・`image`（ファイル名） |
| `seats` | パックの名前 → 席ごとのアイテムの `id`。**キーの無い席は空**                                      |

- **席はキャラクターごとに持つ。** 背景がパックの持ち物で、キャラクターを切り替えると世界が丸ごと
  入れ替わる（13.8）のに揃える。同じアイテムを全員に置きたければ、それぞれの席で同じものを選べばよい
- **席の選択もパックの中（`character.json`）には書かない。** そのため、変えられないパック（`editable: false`。
  同梱だけのパック・起動先の `characters/local`）にも置ける
- **探索先はホームの1箇所だけ。** 同梱のアイテムは持たず（素材は同梱しない。`docs/requirements.md` 2.2）、
  起動先の `<cwd>` の置き場も持たない。パックの3箇所の探索（`docs/architecture/character-pack.md`）と違い、
  同名が後ろの置き場に覆われることは起きない
- **読む側は境界で検証する。** パックの名前は `parseCharacterPackName` を通したものだけを読み、一覧に無い `id` を
  指す席・ファイルの無いアイテムは空として配る（ファイルの行はそのまま残す）
- **`items.json` が読めない・形が違うときは、一覧を空として配り、書き込みの口はすべて理由を分けない定型文の
  `REFUSED` で断る。** 壊れたファイルを読めた分で上書きすると、一覧が黙って消える。ファイルが無いのは
  「まだ何も足していない」で、最初に足したときに作る
- 書き出しは一時ファイルからの置き換えで行い、途中で落ちても半端な `items.json` を残さない
- **パックを消しても `seats` の行は消さない。** 同じ名前で作り直すと席が引き継がれるが、飾りなので害が無い

採らなかった案: **席を全キャラ共通にする**（切り替えで背景だけ入れ替わり、森の精霊の舞台に前のキャラクターの
小物が残る）。**席を `character.json` に書く**（同梱・`characters/local` のパックはホームへ写さないと書けず、
写すと同梱の更新がホームの版に隠れる。パックの外の `id` をパックが指すことにもなる）。**`localStorage` に持つ**
（ビューのポートは起動ごとに既定の帯の中でずれ、origin が変わると読めなくなるので「消えない」を守れない）。
**同梱や `<cwd>` の置き場を探索に足す**（素材を同梱しない 2.2 に当たり、同名が覆う癖も持ち込む）。

### 画面から足すときの受け取り方

**足す口はキャラクター画面の「アイテム」の区画だけ**（画面の形は `docs/architecture/screen-design.md` 13.6）。
受け取り方はパックの編集と同じで、**画像は data URL を JSON に載せ、いまの WebSocket のコマンドで受け取る**
（新しい書き込みの経路を作らない。理由と採らない案は `docs/architecture/character-pack.md`「画面から作るときの置き場と受け取り方」）。

| 何         | 上限・規則                                                                                       |
| ---------- | ------------------------------------------------------------------------------------------------ |
| 画像1枚    | 立ち絵と同じ形式（`.svg`・`.png`・`.gif`）と上限（デコード後 2 MiB）。立ち絵の受け取りと同じ検査 |
| 名前       | 必須。前後の空白を除いて 1〜20 字。読み上げの名前と一覧の札に使う                                |
| 一覧の件数 | 30 件まで。超える「足す」はサーバでも断る                                                        |

- **受け取った文字列をパスにしない。** `id` はサーバが振り（いまある `id` の最大＋1 の10進）、ファイル名は
  `<id>.<svg|png|gif>` で組む。名前は `items.json` の値にすぎず、ファイル名にもディレクトリ名にもならない
- **書き込み先は `~/.tsukumo/items/` の1箇所だけ。** 同梱の `characters/*` と起動先の `characters/local` には
  どの経路でも書かない
- **コマンドは4つ**: 足す（名前と画像）・消す（`id`）・席に置く（パックの名前・席・`id`）・席を空ける
  （パックの名前・席）。席の口のパックの名前は shared のスキーマで検証し、一覧に無いパックへは書かない。
  **書いたら一覧と全パックの席を丸ごと配り直す**（口ごとに部分の差分を配らない）
- **消すときは、画像を消し、そのアイテムを置いていたすべてのパックの席を空ける**（1回の書き出しで行う）
- **名前の変更と並べ替えの口は持たない。** 変えたいときは消して足し直す
- **要件の対象外には当たらない。** 素材は利用者が自分で用意してホームに置くだけで、リポジトリに入らず配布もしない
  （`docs/requirements.md` 2.2 の素材の同梱・配布の項）。入力欄がファイルの中身を受け取る話でもない
  （同じ 2.2 のファイルの貼り付けの項）

採らなかった案: **名前から `id` やファイル名を作る**（受け取った文字列をパスにしない原則に反し、同じ名前が
ぶつかる）。**multipart や生バイトの POST で受け取る**（パックと同じ理由）。**並べ替えと名前の変更の口を持つ**
（30 件なら足した順で探せ、名前を変えたいことは消して足し直せば済む。口が増えるぶん区画が重くなる）。
**形式を背景と同じ写真向け（`.jpg`・`.webp`）にする**（小物は輪郭を抜いた絵が主で、立ち絵と同じ検査を
そのまま使える）。

### 配る URL

**素材の URL は `/item/<file>?v=<版>`**（`<file>` は `encodeURIComponent` した1区間）。

- **配ってよいのは `items.json` の `items` に載ったファイル名だけ**（allowlist）。区切りの `/` を含む経路・
  デコードできない経路・一覧に無いファイル名は 404
- 版（`?v=`）・キャッシュの持たせ方・`sandbox` 付きの CSP・トークン無しで配ることは、素材の URL と同じ規則
  （`docs/architecture/character-pack.md`「パックの一覧と素材の URL」）。版は `items.json` と画像の更新時刻の最大
