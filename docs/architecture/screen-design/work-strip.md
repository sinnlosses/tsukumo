## 13. 画面のデザイン

### 13.13 会話の画面の局面

#### 進み具合の帯

**働くあいだとレポートを読むあいだ、メインビューの札の右の側（やり取りの列の右）の上端に、段と走っている手順を
その場で書き換える横の帯を固定する**（`WorkStrip`。2026-10-02 ユーザー決定。見本は
`docs/history/mockup/work-strip-2026-10-02.html`。作業の地図と浮かぶ札とレポートの「進み具合」を置き換えた。
旧い形は `docs/history/decision.md`「screen-design.md 13.13 作業の地図・会話の画面の浮かぶ札・レポートの進み具合
（2026-10-02 に覆した記録）」）。本文ではなく、ワークプランと依頼の手順と状態から導くだけのもの。
帯は札の頭として転がっても上に残る（`position: sticky`。札の中の並びは `docs/architecture/display.md` 4.2「各表示物」のメインビュー）
（2026-10-08 に上の題の行を無くし、帯が札の右の側の上端に来た）。

```
 ┌ 進み具合の帯（札の頭） ─────────────────────────────────────────────┐
 │ ●作業中 ✓─✓─✓─(4◜) 集計の関数…  (5)─(6)─(7)  経過 6分12秒 [手順 12 ▾]   │
 │            Bash  pnpm exec vitest run …  · 12秒  · 再試行中 2/10           │
 └─────────────────────────────────────────────────────────────────────┘
```

- **状態のチップ**（2026-10-08 ユーザー決定）: 1行目の左端に、いまの状態を色の点と字で出す
  （2026-10-08 に、状態の色の枠の丸い札から変えた。見本は `docs/history/mockup/report-verdict-quiet-2026-10-08.html` の「案A 静か」）。
  状態は6つ: 作業中・背景で作業中・答え待ち・完了・止めた・失敗。枠・地・太字は無く、直径 8px の状態の色の丸い点と、
  字（13px・`--ink-soft`・普通の太さ）を 7px 空けて並べる。作業中も点だけで、回さない（回るのは今の段の丸の外周の弧。2026-10-14 ユーザー決定）。
  **背景で作業中は帯のチップだけの状態**（やり取りの列の印には無い）で、ターンが動いておらず、答え待ちも無く、
  バックグラウンドタスクが残っているときに出す（モデルはもう手を止めていて、背景のコマンドだけが生きている。2026-10-10）。
  背景で作業中の点は `--accent`。答え待ちが来ていれば答え待ちが先。
  **字と導き方はやり取りの列の結果の印と同じ表**（`docs/architecture/display.md` 4.2。列の印は変えない。背景で作業中を除く）で、
  導き方も同じ（`turnResultsOf`）。点の色は作業中 `--accent`・背景で作業中 `--accent`・答え待ち `--state-warn`・完了 `--state-ok`・
  止めた `--ink-quiet`・失敗 `--state-ng`。チップは縮めない（縮むのは今の段の名前だけ）。
  失敗の理由と次の手は失敗の塊が持ち、帯は状態の名前だけを言う
- **1行目**: 段の丸を1本の線でつなぐ。済んだ段は「✓」の印の丸だけ（飛ばした段は同じ位置に、地なし・`--rule` の破線の枠・`--ink-quiet` の「/」の丸。数え方は済んだ段と同じ。`docs/architecture/display.md`「ワークプラン」）、残りの段は番号の丸だけで、
  **名前を出すのは今の段だけ**（7段でも1行に収める。今の段の名前は末尾を「…」にする）。
  どの丸も名前を `title` と読み上げに持ち、押せる（`button`。Tab で届く）。押すと丸の下に吹き出しが出る（下の「段の吹き出し」）。
  範囲があれば、群（前・本・後）の先頭の丸の前に群の名を小さく置き、前の群の丸とは線でつながず間を空ける（今いる群の名は差し色）。
  右端に今の位置「後 1/3」（等幅・太字。範囲が無ければ「2/4」）と「経過 6分12秒」（等幅）と「手順 n ▾」の口。
  位置は群の中の番号で言うので、丸の並びの言い直しにならない（2026-10-15 ユーザー決定。2026-10-14 の「位置の 4/7 は出さない」を置き換えた。
  通し番号の「4/7」は丸の並びの言い直しだったが、群ごとの番号は受け入れ以降のどこにいるかを数で言う）。
  **760px 以下では帯を出さず、同じもの（状態・段の丸・今の段の名前・経過・「手順 n」）を頭の2行が持つ**
  （2026-10-09 ユーザー決定。13.9「狭い画面（760px 以下）」。2026-10-08 の「760px 以下では帯を2行にする」を置き換えた）
- **「いま: <節>」**（2026-10-18 決定。見本は `docs/history/mockup/report-reading-tool-2026-10-18/after-norail-w1400.png`）:
  読んでいる `##` の字を、1行目の状態のチップの右に出す。出すのはやり取りの列を畳んだときだけで（開いていれば列の
  見出しの強調が同じことを言う）、新しい行は足さない。字は `--ink-quiet`・普通の太さで、縮むのはこの字（末尾を「…」にする）。
  節は読む面の上端を通り過ぎた最後の `##` で、`###` の途中にいても親の `##` を出す。転がし切ったときは最後の `##`
  （最後の見出しが上端に届かないため）。見出しの無いレポートと、最初の見出しより前では出さない。
  **760px 以下は頭の1行目の状態の語・経過の右に同じ字を出す**（列も帯も無いので畳みは見ない。読む面の上端は本文の転がる器の上端）
- **見出しの一覧の「新」**: 中間レポートを見ていたやり取りの最終レポートで足された `##` の行の右端に、`--accent` の小さな字「新」
  （`--font-action`。行の字は `…` で縮み、印は縮まない）。`###` の行・初めて開いた閉じたやり取りには出さない。行を押すと消える
  （出す条件は `docs/architecture/display.md` 4.2。見本は場面 `report-new-section`）
- **並列の段**（`docs/architecture/display.md`「ワークプラン」の「同時に走る段は、並列の段で受ける」）: 中の段の丸を1つの囲みの中に横に並べ、
  囲みを前後の段と線でつなぐ（囲みの中の丸どうしは線でつながない）。済んだ・今・残りは丸ごとに付け、どの順で済んでも済んだ丸は戻らない。
  今の段が2つ以上なら、頭の字は今の段の名前を「・」でつなぎ（末尾を「…」で縮めるのは同じ）。今の段の丸はどれも弧が回る。お伺いが届いたら今の段の丸をどれも「?」にする。済んだ姿の「7段のうち3段済み」は並びを平らにした段で数える

```
 │ ●作業中 ✓─[(2◜) (3◜)]─(4)  B・C…  経過 2分05秒 [手順 9 ▾]          │
```

- **段の吹き出し**（2026-10-14 ユーザー決定。見本は `docs/history/mockup/work-strip-phase-popover-2026-10-14.html`。
  名前が `title` のホバーにしか無く、タッチやキーボードでは他の段の名前に届かなかった）: 段の丸を押すと、丸の下に小さな吹き出しを出す。
  中身は丸の状態で変える。

  | 丸の状態     | 名前の行        | 状態の行（等幅）              | 段のまとめ | 「この段の手順へ」 |
  | ------------ | --------------- | ----------------------------- | ---------- | ------------------ |
  | 済んだ段     | 「✓ 段の名前」  | 「済み · 所要 1分40秒」       | あれば出す | 出す               |
  | 飛ばした段   | 「/ 段の名前」  | 「飛ばした · 所要 0秒」       | あれば出す | 出さない           |
  | 今の段       | 「4. 段の名前」 | 「いま · この段 1分56秒」     | 出さない   | 出さない           |
  | 答え待ちの段 | 「4. 段の名前」 | 「答え待ち · この段 1分56秒」 | 出さない   | 出さない           |
  | まだの段     | 「5. 段の名前」 | 「これから」                  | 出さない   | 出さない           |
  - 名前の行の番号は段の丸と同じ数え方で、範囲の外の段は名前だけ。走っている手順（Bash …）は吹き出しに入れず、帯の2行目のまま
  - 所要と経過の求め方は `docs/architecture/display.md`「ワークプラン」の段ごとの所要時間と同じ（今の段は、その段が今の段に入った記録の時刻から数える）。
    測れない段（記録が途中から始まった・復元された依頼など）は「所要 不明」（今の段は「この段 不明」）
  - 「この段の手順へ」は依頼の手順の一覧を開き（開いていれば開いたまま）、一覧の中だけを転がしてその段の区切りを一覧の上端に置き、吹き出しを閉じる。
    その段の手順が1つも無ければ一覧を開くだけ
  - 閉じるのは Esc（押した丸へフォーカスを戻す）・同じ丸をもう一度押す・丸の並びの外を押す、のどれか。開くのは同時に1つで、
    別の丸を押すと開き替わる。やり取りが替わる・帯が消えると閉じる
  - 丸の押す的は 24px 四方で、見える丸の寸法・丸の並びの幅・帯の高さは押せなかったころのまま（はみ出すぶんは負の margin で打ち消す）
  - 答え待ちの今の段の丸も、並列の段の中の丸も同じに押せる。並列の段の囲みそのものは押せない。
    760px 以下の頭の2行の丸は押せない
  - 見た目: 幅 300px、地 `--surface`・枠 `--rule`・角丸 8px、丸を指す矢印つき。名前は太字の `--ink`、状態の行は `--ink-quiet`、
    段のまとめは `--ink-soft`、「この段の手順へ」は `--accent` の下線つきの字。開いている丸は `--accent` を薄めた影、
    丸の hover は枠を `--accent` に（答え待ちの丸は `--state-warn` の枠のまま）。吹き出しは丸の中心から左へ 40px ずらして置き、
    帯の左右の端から 8px 内にはみ出さないよう寄せる（矢印は丸の中心のまま）。帯の2行目には重なってよい。`aria-live` は付けない

- **2行目**: 今の段でいま走っている手順の要約（等幅。`summarizeToolInput`）と、その手順が始まってからの秒。
  メインが `report` の引数を書いている途中は「レポートを書いています」、ターンが終わってバックグラウンドタスクだけが
  動いていれば「背景で <説明>」、何も走っていなければ「考えている」。いちばん新しいバックグラウンドタスクが
  サブエージェントで、その依頼でサブエージェントの中の手順が1つでもあれば、説明の代わりに
  「背景で · 直前 <最後の手順の要約>」（等幅）を出す（説明は起こしたときのままで、同じサブエージェントに
  続きを頼むと段と食い違う）。API の再試行中なら
  「再試行中 2/10」を `--state-warn` で添える（理由と待ち時間は `title`）。行の高さは字が無くても保ち、
  **常に1行**（要約の改行は空白に畳み、長ければ末尾を「…」にする。2026-10-08 利用者決定。複数行のコマンドで帯が伸びていた）
- **お伺い**: 答え待ちが届いたら（`pending` が空でない）、今の段の丸を `--state-warn` の系統と「?」にし、
  2行目を何を待っているか（「お伺いが届いた · 許可: Bash rm -rf … · 答え待ち 8秒」、質問なら
  「質問: <1問目の header>（ほか n問）」）に替える。待った秒は、答え待ちが届いた時刻（状態の `pending` の
  `askedAt`）から数える。答える札そのものは帯の下の本文に出る
- **手順の口**: 「手順 n」を押すと、依頼の手順の一覧（13.9「いまの作業」の一覧の手順の行。失敗の行は
  引数と出力を開いて読める）を帯の真下に本文を押し下げて開き、段ごとに区切る。もう一度押すと閉じる
  （外を押しても閉じない）。高さは窓の 40% を超えたら内側で転がす。やり取りが替わると閉じる。
  済んだ段の吹き出しの「この段の手順へ」からも開く（上の「段の吹き出し」）
- **レポートに入れ替わったら**、帯は1行（2行目を外す）に縮み、「7段すべて済み · 所要 21分49秒」の
  済んだ姿で残る（途中で止めたなら「7段のうち3段済み」）。手順の口も残る。閉じたあとの続きのターンでも
  1行のまま（読んでいるあいだに伸ばさない）。続きのターンが走っているあいだは、1行目の字を済み具合でなく今の段の名前にする（2026-10-14 ユーザー決定）
- **帯は送った直後から必ず出す**（2026-10-03 ユーザー決定。ワークプランが届くまで帯が無く、動いているのか分からなかった）。
  ワークプランが届く前（答えるだけのときも）は段の丸を出さず、1行目をチップと「経過 12秒」だけにし（チップが「作業中」を言うので、
  見出しの字に「作業中」を重ねない。2026-10-08 利用者決定）、2行目は上と同じ
- **作業中の輪は今の段の丸の外周を回る弧**（2026-10-14 ユーザー決定。チップの回る輪をやめ、チップは点だけにした。
  見本は `docs/history/mockup/work-strip-phase-popover-2026-10-14.html`）。`--accent` の弧（右の辺は薄い差し色）を丸の外側に重ね、
  0.9 秒で1周する。番号は回さず、丸の幅と帯の高さは動かさない。`prefers-reduced-motion: reduce` では止まる。
  回すのは作業中と背景で作業中（ターンが終わってバックグラウンドタスクだけ残るあいだ。止まると動いていないように見える、と
  2026-10-14 ユーザー決定で回すことにした）の帯の今の段の丸（`data-phase-state="current"`）だけで、並列の段で今の段が複数ならその丸すべてが回る。
  答え待ち（印は「?」）・済んだ段・まだの段・レポートに入れ替わったあと・
  ワークプランが届く前（段の丸が無い。点が作業中を言う）は回さない
- **ワークプランの無いまま閉じたターンも、帯を残して状態と所要だけの1行にする**（2026-10-08。段の丸は無く、1行目はチップと
  「所要 …」〔失敗でも「所要」。チップが状態を言うので語を重ねない〕。失敗が帯に出ず、送った直後から出ていた帯が閉じると消えて終わり方が読めなかった）。
  閉じたのに本文が1つも無いやり取り（`no-report`）は5つのどれでもないので、ワークプランがあれば段の進みから
  決め（途中で閉じていれば止めた、全部済んでいれば完了）、ワークプランも無ければ帯ごと出さない
- **過去のやり取りを見ているあいだは出さない**。帯は最新のやり取りの上端に固定するもので、過去のやり取りの
  結果はやり取りの列の同じ印が持つので、2か所に出さない
- **経過と所要の置き場は帯の1か所**で、仕事のときは入力欄の行に経過も再試行も出さない
  （雑談モードは帯が無いので、入力欄の行に残す。`docs/architecture/display.md` 4.2「各表示物」の入力欄）
- **会話の画面には、いまの作業の札を置かない。** 帯が札の役（今の段・手順の一覧を開く口・お伺いの知らせ）を
  持つので、並べると同じことが2か所に出る（`docs/requirements.md` 4.7）。ほかの画面の帯の札と一覧（13.9）は変えない
- 色は 13.2 のトークン（済んだ段と今の段は `--accent`、残りは `--rule` と `--ink-quiet`、お伺いは `--state-warn`、状態のチップは上の「状態のチップ」の色、
  地は `--ground`、段の吹き出しは上の「段の吹き出し」の色）で、新しい色は足さない。`aria-live` は付けない（読み上げは下の「読み上げとフォーカス」）
- 帯の外寸は `--turn-card-head-height` に測って書き、見出しへ飛んだときの余白・やり取りの列が読んでいる見出しを決める基準・
  質問の札へ転がしたときの余白・お伺いの札の高さの上限がその真下を指す（帯の下に潜らせない）。帯は1行と
  手順の一覧を開いた姿で高さが変わるので、題の行を無くしたあとも実測を残す（2026-10-08）。帯を出さない過去のやり取りでは 0
