# 画面のデザイン: キャラクター画面

ステータス: **正典**。入口は `docs/architecture/screen-design.md`（画面のデザインの全体）。

責務: 13.6 設定の置き場所の中ほど。キャラクター画面と会話の画面の入れ替わり、キャラクター画面の中身（一覧・名乗り・表情・差し色・ミニ立ち絵・背景・消す帯）。
読む時: キャラクター画面の配置・口・確かめのダイアログに触るとき。
直す時: キャラクター画面の形や振る舞いを変えたとき。

## 13. 画面のデザイン

### 13.6 設定の置き場所

**キャラクター画面は会話の画面と入れ替わる**（重ねない。2026-09-17 決定。ユーザー「SPA のような
ものを想定していたよ」）:

- **切り替えは `location.hash`**（`#character`。無ければ会話の画面。キャラクター画面で選んでいる
  パックも `#character?pack=<名前>` として同じ hash に乗る。下の「キャラクター画面の中身」）。
  `stores/screen.tsx` の `useScreen()` が `hashchange` を読む（`useSyncExternalStore`）。
  リロードしても同じ画面に戻り、ブラウザの「戻る」が効き、`pnpm run dev` の再読み込み
  （HMR が当てられずにページごと読み込み直したとき・`domain/refresh.ts`）でもキャラクター画面に留まれる。サーバの経路は増えない（`?token` はそのまま）。
  **ルーターのライブラリは入れない**（画面は4つで、分岐は hook 1つで足りる）
- **会話の画面は外さず `hidden` で隠す**。
  サーバとの接続はその上の `<Root>` が持つので会話は進み続け、入力欄の下書き・選んでいるターン・
  スクロール位置も残る。戻ったときにセリフとレポートが追いついているかは目視で確かめる
  （吹き出しの追従は領域の高さに依存するため）
- **答え待ちが来たら帯の「いまの作業」が「答え待ち」に変わる**（`state.pending` が空でないとき、
  字を `state-warn` で。色だけにしない。2026-09-22 に戻る口の横から帯の右端の印へ移し、
  2026-09-23 に「いまの作業」へまとめた。13.9）。タブのタイトルの印は隠れていても効いている
- **入る口はヘッダーの帯**（13.9。2026-09-22 に置き換えた。それまではサイドバーのキャラクターの
  行の「整える」で、「ページ最上部のナビは置かない（画面が3枚以上になったら検討し直す）」と
  書いてあった。4枚目が入ったので検討し直した）。**サイドバーの「整える」は外す**
- **戻る口も帯が兼ねる**（帯の「会話」。2026-09-24 に「作る画面だけは左上の
  「← キャラクターへ戻る」を残す」を外した——作る口が独立した画面からダイアログに変わり、
  帯に出ない画面が無くなったため。下の「作るダイアログ」）
- **右下は「領域の比率を既定に戻す」だけのまま**（引き出しを作る前の形）。増える常設の要素は
  帯の1つで、サイドバーのリンクは1つ減る
- **読んでいる間に見えている必要がないものは会話の画面に置かない。** 主な仕事は長く読み続ける
  ことなので（13章のブリーフ）、整える口は別の画面に出す。**帯はこの原則の唯一の例外**
  （13.9。どの画面からも他の画面へ行けることを、面積と引き換えに採った）

**キャラクター画面の中身**（2026-09-17 決定。2026-09-24 に見本
`docs/history/mockup/character-screen-2026-09-23.html` / `.png`（2026-09-23 にユーザーが決めた形）へ
作り直した）。**左に一覧、右に選んでいるパックの詳しい設定の2段組。** 色は 13.2 の4つから増やさず
（見本の灰の段は `surface` / `ground` / `rule` / `rule-quiet` / `ink-quiet`、仕事の差し色は `accent`、
消す口の赤は `state-ng` に当てた。**16進は1つも足していない**）、書体も 13.3 の2本のまま（見本の
名前の明朝は使わない。トークン消費の画面と同じ扱い）:

```
（ここまでがヘッダーの帯。13.9）

キャラクター          2   ┌──────────────────────────────────────────────────────┐
┌──────────────────┐      │ ◯  つくもの精霊  id: tsukumo-spirit [使用中]            │
│◯ つくもの精霊     │      │    ターミナルという道具に宿った小さな精霊               │
│  表情 4 / 9 · 使用中│      │                          [⇄ このキャラクターに切り替える]│ ← 使用中以外だけ
└──────────────────┘      │ 顔  ◯ いまの顔 [↑ 差し替える] [消す]                    │
 ◯ tsukumo               │ ミニ立ち絵  ▯ いまのミニ立ち絵 [↑ 差し替える] [消す]    │
   表情 9                 │ 表情                                                    │
                          │ ┌いつもの顔┐ ┌────┐ ┌────┐ ┌────┐ ┌ ─ ─ ┐            │
                          │ │  絵    │ │ 絵 │ │ 絵 │ │ 絵 │   ＋     ← 名前つきの空欄 │
┌ ─ ─ ─ ─ ─ ─ ─ ─ ┐      │ │ 通常   │ │思案│ │どや│ │あわ│   真顔                  │
  ＋ 新しく作る           │ （5列。乗せる／フォーカスで右上に [↑] [消]）             │
└ ─ ─ ─ ─ ─ ─ ─ ─ ┘      │ 画面の差し色   雑談も仕事と同じにする                    │
   ↑ 幅 260px             │ [■ 仕事 #..] [■ 雑談 #..]                                │
                          │ 背景  ▭ いまの背景 [↑ 差し替える] [消す]             │
                          └──────────────────────────────────────────────────────┘
```

- **一覧（左・幅 260px）**: 見出し「キャラクター」と件数、パックごとの行（丸い顔・名前・
  「表情 <立ち絵のある数>」、9つそろっていなければ「表情 4 / 9」、使用中なら「· 使用中」）、
  点線の「新しく作る」（押すと作るダイアログを開く。下の「作るダイアログ」）。行はただのリンクで、
  選んでいる行は `aria-current="page"`（差し色で薄く染めた地と太字。色だけにしない）。顔を持たない
  パックは点線の丸（13.9「顔」と同じく、立ち絵や `mini` から切り抜いて代わりにしない）
- **選んでいるパックは hash に持つ**（`#character?pack=<名前>`。2026-09-24 決定）。再読み込み
  しても同じパックが開き、「戻る」で前に選んでいたパックへ戻れる。**`#character/<名前>` にしない**
  のは、`turn` と同じく画面の上に乗る付随情報だから（`stores/location-hash.ts`）。`pack` が無い・
  使用中の名前・一覧に無い名前（消した・古い URL）はどれも使用中のパックを出す（行き止まりに
  しない）。帯の「キャラ」から入り直すと `pack` は落ち、使用中のパックから始まる
  （`stores/location-hash.ts` / `stores/screen.tsx`、引き当ては `hooks/use-selected-pack.ts`）
- **使用中以外のパックも右側でそのまま直せる**（書き込む先はコマンドの `pack`。`docs/architecture/character-pack.md`「画面から作るときの置き場と受け取り方」）。使用中以外の
  名乗りの右端には**「このキャラクターに切り替える」**（`session.switchCharacter`。ターン進行中か、委譲先が動いている間は押せない
  ——サイドバーの `<select>` と同じ理由・同じ文言）。切り替えたあとも hash の `pack` はそのままなので、
  同じパックが今度は使用中として開く
- **名乗り（右の最上段）**: 大きな丸い顔（`accent` の輪）・名前・`id: <パックの名前>`（等幅。
  13.1 原則3）・「使用中」の札・自己紹介文。右端には**変えられるパックにだけ**、見本の
  鉛筆のボタンを2つ並べる。「名前と自己紹介文を設定する」（`components/character-profile-edit.tsx`）を押すと
  開くダイアログ（`character-profile-edit-dialog.tsx`）は**作るダイアログ（`character-create.tsx`）
  と同じ枠・同じ欄の書き方**で、欄は「名前」と「自己紹介文」の2つだけ（id は作ったあと
  変えないので欄を出さない。決まっていること・蒸し返さない）。**自己紹介文は雑談のサイドバーの
  プロフィールの札（13.7）にも出ることを欄の説明に添える**。「保存する」を押すと `characterPack.setProfile`
  を1回送って閉じ、詳しい設定の名乗りと一覧の名前がその場で替わる。もう1つの「プロフィールを設定する」
  （`components/character-persona-edit.tsx`）は人格の本文（`persona.md` の `## 覚えたこと` より前）を直す
  ダイアログ（`character-persona-edit-dialog.tsx`）を開き、「保存する」で `characterPack.setPersona` を送る
- **変えられないパック（`editable: false`）は、名乗りのひとことの下に理由の一言を出し**、口を
  すべて無効にする（押せない見た目のまま残す。`docs/architecture/character-pack.md`「画面から作るときの置き場と受け取り方」）。一覧の行には印を付けない（開けば分かる）
- **表情は5列の格子**（詳しい設定の幅が 52rem を切ったら入るだけの列で折り返す。`@container`）。
  カードは 立ち絵（`<Portrait>`。動きは無し。カードの地の上に直接置き、立ち絵
  自体は枠も地も持たない。13.1 原則2）と表情のラベル（パックの `expressions` から。原則4）。
  `default` のカードには「いつもの顔」の札を添える。見出しには添え書きを付けない（枚数は空欄の
  カードで分かり、口の出し方は乗せれば分かる。2026-09-24 決定）
- **「差し替える」「消す」はカードの右上のアイコン**で、**乗せたとき（`:hover`）とカードの中に
  フォーカスがあるとき（`:focus-within`）だけ出す**（2026-09-24 決定）。消さずに透明にしてある
  ので、キーボードでは Tab で口に入った時点で出る（`display: none` だと入れない）。乗せる操作の
  無い端末（`@media (hover: none)`）では最初から出す。アイコンだけの口なので、どの表情のことかは
  読み上げの名前（`<表情>を差し替える` / `<表情>を消す`）と `title` に持たせる。「消す」は
  `default` には出さない
- **立ち絵がまだ無い表情は、その表情の名前を書いた点線の空欄**（2026-09-23 ユーザー決定）。
  枠そのものが選ぶ口で、9つそろえば空欄は出ない。汎用の「表情を足す」カードは置かない
- **表情を消す前の確かめ**: 「消す」は押しただけでは送らない。押すとカードに添う幅 300px の吹き出し
  （`components/portrait-clear-confirm.tsx`。見本
  `docs/history/mockup/character-delete-expression-2026-09-23.html` / `.png`）が開き、
  見出し「「<表情>」を消しますか？」・本文「この表情を使う場面では「<`default` のラベル>」が
  出ます。」（どちらもパックのラベル。原則4）・「やめる」「消す」を出す。**画面全体は覆わない**
  ——`<dialog>` の `showModal()` で top layer には出すが、UA既定の中央寄せは外して押した位置から
  自前で置き、`::backdrop` も透明にする。「やめる」・Esc・外側のクリックはどれも何も送らずに閉じる
- **どのカードにも画像を落とせる**（落とすと差し替え・足す。受け付ける種類の検証はサーバ側）
- **差し色は画面の差し色（仕事・雑談）の2つ**。`chatAccent` を持つときだけ
  見出しの右に「雑談も仕事と同じにする」、無ければ同じ場所に「雑談も仕事と同じ」の字。
  色見本は札全体が `<label>` で、左の四角が `<input type="color">` そのもの、
  右端に今の値の16進（色だけにしない）。広い画面で間延びしないよう、幅は 24rem までに絞る
- **ミニ立ち絵は、顔の区画の下の「ミニ立ち絵」の区画**。口は顔と同じ「差し替える」「消す」の2つで、
  受け付ける形式・大きさの上限は立ち絵と同じ（`.svg` / `.png` / `.gif`。書き込む先は `mini.<形式>`）。
  **縮図（84×112。全身が収まる contain）を出すのは、定義に `mini` を持つときだけ**（`CharacterInfo.hasOwnMini`）。
  持たないときは、`portraits.default` の縮小に落ちて見えていても縮図にせず、点線の枠と「いつもの立ち絵を
  縮めて使う」の一言を出す（フォールバックの絵を「設定済み」に見せない）。縮図を押すと拡大する
  （`ImageZoom`、`size="modest"`。顔・背景と同じ）。「消す」は定義の `mini` を外し、外したあとは今までどおり
  `portraits.default` の縮小に落ちる。ミニ立ち絵の呼び名（`miniCall`）は画面から直さない
- **背景は縮図（220×124。敷いたときと同じ cover・下端合わせ）と「差し替える」「消す」の2つだけ**。
  **覆いの濃さは画面から変えない**（定義ファイルを手で直す。13.8）
- **アイテムは背景の区画の下・消す帯の上の「アイテム」の区画**（2026-10-20 利用者決定。受け取りの規則は
  `docs/architecture/stage-item.md`）。頭に「一覧はどのキャラクターにも共通・席はこのキャラクターのもの」と一言添える。
  上段は席3つの札（「左上」「キャラの左下」「キャラの右下」。縮図と、先頭が「置かない」の選び口）、下段は一覧の格子
  （縮図と名前。右上の消すアイコンは表情のカードと同じ出し方）と点線の「＋ アイテムを足す」。足すダイアログは
  作るダイアログと同じ枠で、画像（選ぶ・落とす）と名前の2欄。検査の失敗はダイアログの中に出す。消す前の確かめは
  `components/portrait-clear-confirm.tsx` と同じ形で、本文は置いている席が空になること。30 件あれば「足す」は押せず
  理由を `title` に出す。`editable: false` のパックでも席は選べる（席はパックの中に書かない）
- **760px 以下では一覧を詳しい設定の上に積む**（格子と差し色の列数は詳しい設定の幅を見る
  `@container` が決めるので、狭い画面用に別の規則は足していない）
- **`<Portrait>` は `components/domain/portrait.tsx`**（2つ目の読み手。`docs/architecture.md`「全体構成」）。並びでの大きさは
  `portrait-card.module.css` が決め、`className` で渡す（キャラビュー側の割合指定は
  `.character-region` の変数が無いので効かない。`docs/architecture/browser.md`「CSS」）
- **「このキャラクターを消す」帯は、詳しい設定の最下部・背景の節の下**（見本
  `character-screen-2026-09-23.png` の最下部）。`removal`（`docs/architecture/character-pack.md`「消すときの細部」の
  `characterPackRemoval`）が `"none"` のパック（同梱だけ・`characters/local`・一覧の外）では
  出さない。**`"delete"` と `"revert-to-bundled"` で見出し・本文・ボタンの動詞を出し分ける**
  （消せるパックは「このキャラクターを消す」/「<名前> を消す」、同梱を直したパックは
  「同梱に戻す」/「<名前> を同梱に戻す」。`docs/requirements.md` 4.4 の文言をそのまま画面の字にする）。**使用中は
  帯のボタンを押せなくする**（`inUse`。理由は帯の本文にすでに書いてあるので `title` は
  短い言い換えにとどめる）
- **帯のボタンは即座に送らず、確かめのダイアログ（`components/character-delete-confirm.tsx`。
  見本 `character-delete-2026-09-23.png`）を開く。** 作るダイアログと同じ UA 既定の中央寄せで
  画面全体を覆い、押した位置には寄らない（表情の確かめ〔`portrait-clear-confirm.tsx`〕は
  カードの位置に添うが、こちらは帯のどこから開いても同じ場所でよい）。中身は顔（無ければ
  点線の丸）・見出し「<名前> を消しますか？」／「<名前> を同梱に戻しますか？」・本文
  （消す: 表情の枚数と「元に戻せません」。同梱に戻す: 「覚えたことが消え、会話の記録は残る」）・
  id の確かめの入力欄・「やめる」「消す」／「同梱に戻す」
- **打った id がパックの id と完全に一致するまで実行ボタンは押せない**（決まっていること。
  一致の判定は表示のたびに引き直す軽い比較で、`components/character-delete-confirm.tsx` が
  自分で持つ）。実行すると `characterPack.delete` を1回送り、ダイアログを閉じる。**消えた（または
  同梱に戻った）あとの一覧の選び直しは、`hooks/use-selected-pack.ts` の「一覧に無い名前は
  使用中の姿に落ちる」という既存のフォールバックがそのまま担う**——消したパックの hash は
  残るが、一覧から消えたその名前はもう見つからないので、次の描画で使用中のパックが自動的に
  選ばれた状態になる（新しく作るときの `selectPack` のような明示の呼び出しは要らない）
