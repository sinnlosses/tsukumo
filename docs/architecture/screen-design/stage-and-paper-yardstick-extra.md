# 画面のデザイン: 「舞台と紙」の物差し（紙・進み具合・舞台・書き手）

ステータス: **正典**。入口は `docs/architecture/screen-design.md`（画面のデザインの全体）。6場面ごとの物差しは `docs/architecture/screen-design/stage-and-paper-yardstick.md`。

責務: レポートとプログレスと舞台の作り直しを数で比べるための、紙・進み具合・舞台・書き手の物差しと測り方・目標と、作り直す前の値。
読む時: レポート・進み具合・舞台を作り直したあと、良くなったかを確かめるとき。
直す時: 物差し・測り方・目標を変えたとき、値を測り直したとき。

## 紙・進み具合・舞台・書き手の物差し

合格の画は見本 `docs/history/mockup/report-progress-*/index.html`（`report-progress-` で始まるディレクトリは1つだけ）の場面で、**言葉と見本が食い違ったら見本が勝つ**。
見本の値は、見本をその URL 引数と `bar=0` で開き、`scripts/capture/capture-view.ts --measure` で測った。測る幅は 720×900・1400×900・1920×1080 の3つ。
「機械で測れるか」が「画」のものは数にせず、見本と同じ場面を同じ幅で撮った画を並べて比べる。

測る題材は次のとおり。

- 紙: 短い=`report`・中くらい=`report-tool`・長い=`report-blocks`（`fixture/fake-session/` の場面。図だけで大きい `report-svg-tone` は外す）。
- 進み具合と舞台: `work-strip-running`（作業中は `--until-step 4`）・答え待ち `question-multi`・迎え `welcome-recommendation`。

### 紙

- 合格の画: `?group=paper&moment=deliver`（渡す）と `?group=paper&moment=quick`（短い答え）
- 画で比べる点: 判定の行・結論・あなたの番が紙の頭にまとまり、スクロールせずに読める。

| 物差し                     | 測り方                                                                                                                                                                            | 目標       | 機械で測れるか | 今の値（720 / 1400 / 1920）                                                                               |
| -------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------- | -------------- | --------------------------------------------------------------------------------------------------------- |
| 一目が1画面に収まる割合    | 判定の行・結論・あなたの番（無い紙は結論まで、結論も無い紙は紙の全体）の下端が窓の高さ以下にある数を、3幅×3題材の9通りで数える（`--paper-metric` の結論の頭の高さと `--measure`） | 9/9        | 測れる         | 3/9（収まるのは `report` の3幅だけ）                                                                      |
| 次の手の紙の先頭からの距離 | 「あなたの番」（無い紙は続けて頼めること）の上端 − 紙の上端（`--measure`）                                                                                                        | 250px 以下 | 測れる         | `report-tool` 1483px / 1538px / 1538px、`report-blocks` 2125px / 2495px / 2056px、`report` は次の手が無い |
| 本文の1行の字数            | 本文の段落の幅 ÷ 計算済みの字の大きさ（`--measure` の幅）                                                                                                                         | 42 字以下  | 測れる         | 48 字 / 52 字 / 63 字                                                                                     |

見本の値は次のとおり。

- 一目: 渡すの紙は「あなたの番」の下端が 502px / 352px / 352px、短い答えの紙は結論の下端が 143px / 161px / 161px で、どれも窓に収まる。
- 次の手: 渡すの紙で 238px / 207px / 207px（720 は紙の上端 10px、ほかは 22px）。
- 本文: 16px・行送り 1.8 で、段落の幅は 660px / 656px / 656px（41 字ぶん）。

今の値は、3題材を `--paper-metric --viewport 720x900 --viewport 1400x900 --viewport 1920x1080` と `--measure` で測って次のように出した。

- 結論の頭の高さ（`--paper-metric`）は `report-tool` で 85px / 139px / 139px、`report-blocks` で 53px / 107px / 107px。`report` は結論の部品を持たず「-」。
- 一目: 判定の行は検証結果 `[aria-label="検証結果"]`、あなたの番はお願いの欄 `[data-report-region="favor"]`。`report-tool` のお願いの下端は 1662px / 1685px / 1685px、`report-blocks` は 2304px / 2642px / 2203px で、どれも窓の外。`report` は紙の全体の下端が 754px / 568px / 685px で窓に収まる。
- 次の手: お願いの欄の上端 − 紙 `[data-main-view-content]` の上端（113px / 81px / 81px）。
- 本文: 3題材の段落の幅の最大（676px / 739.44px / 882px）を、計算済みの 14px で割った。

### 進み具合

- 合格の画: `?group=flow&moment=work`（働く）と `?group=flow&moment=wait`（止まる・待つ）
- 画で比べる点: 働くあいだ、紙に済んだ段と今の段の行が出ていて、何もしていないように見える間が無い。

| 物差し                   | 測り方                                                                                                                          | 目標                                                              | 機械で測れるか | 今の値                        |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------- | -------------- | ----------------------------- |
| 働くあいだ紙が空の手の数 | 疑似セッションは実時間を持たないので、時間の代わりに `--until-step` の手ごとに撮り、紙（メインビューの本文）の行が0の手を数える | 0 手                                                              | 測れる         | 働く11手のうち4手（1〜4手目） |
| 無言の最長時間           | 診断ログ（`scripts/runtime/diagnostic.ts`）の時刻つきの行の間隔の最大                                                           | 60 秒以下（見本の手元の行は「12秒前」と最後の動きからの秒を出す） | 測れない       | 測れない（下に理由）          |

無言の最長時間は、今の記録からは出せない。
診断ログには `speech` の行が時刻つきで残る（測った日の分で 370 行）が、置き場は日付だけで分けた `~/.tsukumo/diagnostic/<YYYY-MM-DD>.jsonl` の1つで、作業ツリーごとの tsukumo が同じファイルへ書く。
行が持つのは時刻・駆動の代・イベントの種類だけ（`SessionEventFootprint`）で、どのセッションの行かを持たないので、1つの依頼の中の `speech` の間隔を切り出せない。
測るには、足跡の行にセッションを見分ける欄を足す必要がある。

### 舞台

- 合格の画: `?group=flow&moment=work` と `?group=paper&moment=deliver` の左の舞台
- 画で比べる点: 立ち絵が舞台の主役に見え、いまの吹き出しが立ち絵のすぐ上に付いている。

| 物差し                   | 測り方                                                                                                   | 目標                   | 機械で測れるか | 今の値（720 / 1400 / 1920）                        |
| ------------------------ | -------------------------------------------------------------------------------------------------------- | ---------------------- | -------------- | -------------------------------------------------- |
| 吹き出しと立ち絵のすきま | 描かれている吹き出しと立ち絵の矩形が縦横に離れている px（重なれば 0）と、吹き出しが付く側（`--measure`） | 0px で立ち絵の上に付く | 測れる         | 顔の右に 8px / 0px で右横に付く / 0px で右横に付く |
| 舞台の上側の何も無い高さ | 立ち絵・吹き出しの上端の小さいほう − 舞台の上端（上に頭・やり取りの中身があればその下端）                | 40px 以下              | 測れる         | 12px / 78px / 86px                                 |
| 立ち絵が主役に見えるか   | 見本と同じ場面を同じ幅で撮った画を並べる                                                                 | 見本と同じに見える     | 画             | 下の画で比べる点                                   |

見本の値は、1400 / 1920 で吹き出しが立ち絵の上に重なって付き（働くで 98px、渡すで 157px 重なる）、すきまは 0px。舞台の上から頭（153px）・やり取りの流れ・吹き出しが続くので、上側の何も無い高さは 0px。720 は舞台を描かない。

今の値は `welcome-recommendation` と `work-strip-running --until-step 4` で測り、2場面で同じ値だった。
舞台はキャラビュー `[data-region="character"]`（上端 768.02px / 606.7px / 723.7px）、立ち絵は `[class*="portrait"]` の描かれた件、吹き出しは `[class*="balloon"]` の描かれた件のうち枠の矩形。
1400 では立ち絵（左 28px・幅 242.55px・上端 684.97px）の右端に吹き出しの左端（260.55px）が 10px 重なり、1920 も同じく 10px 重なる。720 は立ち絵の代わりに顔（34×34px）を出す。

画で比べた点（見本の `?group=flow&moment=work` と今の `work-strip-running --until-step 4` を 1400×900 で並べた）は次のとおり。

- 見本は舞台が左の全高の列で、立ち絵が列の下半分を占め、吹き出しがその上に乗る。今は立ち絵が画面の左下の帯に 242×222px で収まり、帯の残りは背景の画で、立ち絵は主役に見えない。
- 見本は働くあいだ紙に段ごとの結果の行が並ぶ。今の4手目は紙に依頼の1行しかなく、作業は頭の帯の番号の丸と道具の1行だけに出る。
- 紙は、見本が判定の行・結論・あなたの番を最初の画面に置くのに対し、今の `report-tool` は結論の下に検証結果の行が並び、お願いの欄は上端 1619.41px で2画面目にある。
