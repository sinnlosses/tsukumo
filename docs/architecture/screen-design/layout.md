# 画面のデザイン: レイアウトと差せるもの

ステータス: **正典**。入口は `docs/architecture/screen-design.md`（画面のデザインの全体）。

責務: 「舞台と紙」の器（舞台・紙・欄外・浮く入力欄・重ねる紙の並びと、姿勢ごとの形）、揃え・図の高さ・欄外注の列・部品の横並びと、パック・使う人が差すものの受け渡し。
読む時: 器の配置・姿勢・重ねる紙・レポートの部品の並びに触るとき、差せる値の経路を知りたいとき。
直す時: レイアウトの決まりか、差せるものの受け渡しを変えたとき。

## 13. 画面のデザイン

### 13.4 Layout

構想を1文で。**背景を全面に敷いて立ち絵を左に立たせ（舞台）、レポートは中央の1枚の紙で読む。ほかの画面は舞台を残したまま、右から紙を重ねる。**
決めた理由と採らなかった案の正典は `docs/architecture/adr/0057-stage-and-paper-layout.md`、見本は `docs/history/mockup/ui-rebuild-2026-11-12/whole.html`（言葉と見本が食い違ったら見本が勝つ）。

```
┌ 背景（全面。上下と右へ向けて地の色で覆う）────────────────────────────────────────────┐
│ 部屋の頭      │   ┌ 紙（最大 880px）───────────────┐   欄外（190〜260px） [右上の群] │
│ 今日の灯り    │   │ 判定の行・結論・本文             │   この部屋のやり取り            │
│ 吹き出し      │   │                                  │                                 │
│ 「手元」の行  │   │                                  │                                 │
│   立ち絵      │   │ ╭ 浮く入力欄 ──────────────────╮ │                                 │
│ 舞台          │   │ ╰──────────────────────────────╯ │                                 │
└───────────────┴───┴──────────────────────────────────┴─────────────────────────────────┘
```

- **器は舞台（`Stage`）と、舞台の右の場所（`PaperDesk`）の2列**（`components/page/conversation/components/stage/`・`paper-desk/`）。器は画面の全面を覆い（`position: fixed; inset: 0`）、body の縁の余白を受けない。場所は `data-region`（`stage`・`paper`・`dock`・`margin`・`home`）でも名乗る
- **背景は舞台の全面に敷く**（`--character-background-image`）。上・下・右へ向けて `--ground` で覆い、右ほど濃くして紙の後ろで背景が字の邪魔をしないようにする。舞台そのものは枠も地も持たない（原則2）
- **器の姿勢は4局面のうち3つの形**（ADR 0057 論点 2。姿勢は `MainViewContent` の `kind` から引き、送ったときと閉じたときにだけ変わる）:

| 姿勢   | 舞台の幅                    | 舞台の右                                                                                                            |
| ------ | --------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| 迎える | `clamp(340px, 42vw, 900px)` | 紙と欄外を出さない。右の地に迎えの一言・始め方・入力欄を下寄せで積み（幅 680px まで）、入力欄は働くと同じ下端に置く |
| 働く   | `clamp(300px, 26vw, 600px)` | 中央の紙（最大 880px）・紙の下端に浮く入力欄・右の欄外（190〜260px）                                                |
| 渡す   | 働くと同じ                  | 働くと同じ配置で、紙にレポートを出す                                                                                |

- **尋ねるは働くの姿勢のまま、入力欄の場所にお伺いを出し、紙の中身を引く**（不透明度 0.32）。お伺いは答え待ちの色の輪で囲み、舞台の幅も紙の位置も動かさない
- **雑談は舞台を画面の 40% に広げる**。紙には雑談の画面、欄外には「覚えていること」「最近の話題」を出す（`chat-mode-screen.md`）
- **紙**は `--surface` の地・上の角だけ丸め・浮く影。内側は上 18px・左右 44px、下は浮く入力欄に本文の終わりが隠れないだけ空ける（200px）。紙の下端の 110px で本文を紙の地へ溶かす。紙は `container-type: size` で、図の高さの上限などは紙の内寸から引く
- **浮く入力欄**は紙の左右 30px 内・下端から 16px に浮かせ、`--surface-float` の地と浮く影を持つ
- **欄外**は働くと渡すで「この部屋のやり取り」（`TurnList`。古い順に1行ずつ、押すとそのやり取りへ移る）を出す。上端は右上の群のぶん空ける
- **重ねる紙**は、タスク・成果・使用量・キャラクター・設定の5枚を右から重ねる（`ui/sheet/sheet.tsx` の `Sheet`。Astryx の `Drawer` を覆いなしで開く）。幅は `min(100% - 64px, 1000px)`、上を 16px あけ、左上だけ丸める。開閉は `location.hash` で表す（ADR 0057 論点 3）
  - 紙を開いているあいだ、舞台の右の場所は `inert` にして覆い（`rgb(12 10 16 / 0.52)`）を敷く。舞台と部屋の頭は操作できるまま残す
  - 閉じるのは Esc・覆いの押下・閉じるボタン・ブラウザの「戻る」で、hash を会話の画面へ戻し、フォーカスを開いた入口へ戻す
  - 見本帳（`#design`）は紙にせず全面で出す
- 入口（部屋の頭・探す）は `room-head-and-search.md`、760px 以下は `narrow-screen.md`

- **文字の揃えは全面左揃え。** 日本語の読み物なので、中央揃えも両端揃えも使わない。**レポートの表と図
  （題つきの部品）は、外枠をレポートの本文の列の左端から置く**（中央には置かない。13.3「Type」）。**表の題（「表 1 …」）と凡例は左に揃える。
  図の題（「図 1 …」）だけは、図の下で図の幅の中で中央に置く**。題を持たない表も、表の幅まで縮めて左に置く。内幅いっぱいの部品（見比べ・前後・列が 7 以上の表）と、欄外注の列を持つ部品（本文の列に収まる）は動かない。
  mermaid の箱は文字 12px を守る最小の段で描き、63em と読む面の段は本文の列の左端に揃える（`display/figure-caption.md`）。
  図の題が折り返すときは行の長さを揃えて（`text-wrap: balance`）、「図 1」の番号ごと題の全体を図の幅の中心に寄せる。
  実装の CSS はこの揃えへ部品ごとに合わせていく途中で、外枠を中央に置く規則が残っている部品がある
- **図の高さは読む面の高さの 70% まで**（縦に長い図は箱の中でスクロールする）:
  `graph`・`mermaid`・`svg`・`image` の高さ（`svg` と `image` は外枠の高さ）は `--report-figure-max`（`70cqh`。紙〔`.paper`〕の
  `container-type: size` の内寸）を超えない。図は縦横比を保って縮むが、`svg` と `image` は原寸の幅の
  `--report-figure-min-scale`（0.75。いまの図が縮む範囲の外で、主ラベルは約 10.5px）倍より小さくしない。
  縦に長くてなお上限を超える図は、外枠の中で縦にスクロールして読む（上限に収まる図は変わらない。前後の部品の画像と
  `mermaid` は対象外）。全体は押して開く拡大（`ImageZoom`、`size="width"`）でも見る。拡大の操作は `image` に加えて `graph`・`mermaid`・`svg` にも付ける（図そのものを
  押す。キーは Enter・Space。描き終える前の mermaid は開かない）。拡大の面は図を実寸（`viewBox` の幅と高さ）の
  画像にして出し、縦に流れるときの「閉じる」は下端に貼り付く。`chart` の高さは横棒だけ項目数で決まり（`max(320px, 項目数 × 28px + 48px)`）、ほかは 320px のまま。
- **中間レポートの箱（`.main-step.is-interim`）の中は入れ子を1段にする**: 箱の中の
  `card`・`stats`・`compare`・畳み（`details`）は枠の色を透明にして（太さは残し、寸法を変えない）、
  地の段（`surface-raised`。`stats` は `surface` から上げる）と余白で分ける。`options` の行の罫も外す。
  枠の色と `stats` の地は `--report-chunk-rule`・`--report-chunk-ground` で、箱が置き、部品の側が
  `var()` の第2引数に元の値を持つので、最終レポート（箱なし）の部品は枠つきのまま変わらない
- **欄外注の列**: レポートの本文の右の余白に、本文の流れの外の言葉を置く列。載るのは
  `memo` の `note` と、部品の `aside`（出典・どこを見るかの1行）の2つだけで、字は 12px（`--font-label`）・
  行間 18px・`--ink-quiet`、`memo` には「メモ」のラベルを `--ink-soft` で添える。欄外注は直前の部品の
  上端に揃える。**本文の列（63em）の右に 160px 以上空くときだけ欄外注の列に出し**、列のあきは 28px、
  欄外注の列の左に `--rule-soft` の 1px の線を引く。空かないときは、欄外注を部品の直後に 12px の1行ずつで畳む。
  1920 幅でも欄外注の列は本文の列のすぐ右に置き、本文ごと左揃えのまま。**欄外注の列を持つ部品は、表と図でも
  本文の列（63em）に収まる**
- **レポートの部品の横並びは、ビューポート幅でなく本文の器（`.detail-block`。コンテナ名 `report-body`）の幅で畳む**
  : `dl`・名前付きの `list`・`compare`・`image` の説明の並び・`files` の横並びは、
  器の幅が 2 列の下限（1 列 20em を2つとすき間 0.75rem。`.detail-block` の字は 15px なので約 612px）に
  満たないとき 1 列に積む。やり取りの列を開いて本文が狭くなっても、お伺いのカード・質問の記録の preview でも、
  同じ幅で畳む。760px の `@media` は画面全体の組み替え（`narrow-screen.md`）にだけ使い、レポートの部品には使わない。
  **`stats`・`cols` の列数は全部か約数か 1 列**にし、3＋1 のような半端な段を作らない（項目数は
  `NotationBlock` が `stats-of-<n>`・`cols-of-<n>` の class にする）。列の最小幅は `stats` が 10rem（折れ線・値・
  分母 `36 / 48` が1行に収まる幅）、`cols` が 14rem で、4つは 4→2→1（本文 676px 以上で4列）、3つは 3→1
  （504px 以上で3列）、`cols` は2つ・3つ・4つのとき同様、それ以外は 1 列
- **舞台のアイテムの席**（一覧と席の持ち方は `docs/architecture/stage-item.md`）:
  席は舞台（`.character-region`）の中に絶対位置で置き、重なりは背景 → 左上 → 立ち絵 → 左下・右下 → 吹き出しの並びと「ログ」のボタン。
  どの席も縦横比を保って高さ `24cqh`・幅 `14cqw` まで。**左上**は上端に付けて左端から 16px（吊るす。頭に掛かる分は立ち絵の後ろ）。
  **左下・右下**は下端を床（領域の下端）に付け、立ち絵を anchor で引いて、左下は立ち絵の左端から 8px、右下は右端を
  立ち絵の右端から `--balloon-overlap` 内側（吹き出しの列が始まる線）に揃え、幅は立ち絵の幅の 35% まで。
  吹き出しの列と横に重ならず、足元の高さなので顔に掛からない。飾りなので `alt=""`・押せない（`pointer-events: none`）。
  立ち絵が無いパックでは左下・右下を出さない。760px 以下は出さない。セリフのログの床と雑談の紙にも置かない。
  実装で足した規則（利用者未承認・蒸し返してよい）: 領域の幅が約 21.5rem 以下で吹き出しの列が立ち絵の下へ回り込む幅では、左下・右下も出さない（列に隠れるため）。
  採らなかった案: 立ち絵を寄せて席を空ける（立ち絵と吹き出しの位置は動かさない）・吹き出しより手前に置く
  （字に絵が被る。13.8）・px の固定の大きさ（舞台の高さが変わると立ち絵だけが縮む）・ログと雑談にも出す（要るときに足す）
- **押せるものは 24x24 以上、字は 12px 以上、本文の字は 4.5:1 以上**（WCAG 2.2 の
  最小の的。的は押す箱で測り、ラベルが的の入力・`<select>` の中のボタン・文中リンクは除く。無効のものと
  飾りの記号はコントラストの対象にしない）。13.2 の「コントラストの下限」は色を受け取る側の検算で、
  こちらは画面が守る側の約束。守っているのは E2E の `readability-scan.ts`（`scanReadability`）
- **依頼のあいだ、舞台と紙の位置と幅は動かさない。** 姿勢が変わるのは送ったときと閉じたときだけ（13.13）
- **前後のやり取りへは `[` `]` のキーで移る**。欄外の「この部屋のやり取り」の行を押しても移る
- **入力欄の道具の行の「＋ 新規」**: 道具のアイコンと右の経過時間・送信⇄中断のあいだに、縦の区切り線（`--rule`）を置き、その右に経過時間、経過時間と送信⇄中断のあいだに `outline-accent` のボタンを置く。
  道具の列は「書く操作」、このボタンは「会話そのものの操作」で、押すと確認なしで新しいセッションを始める（`/clear` と同じ）。
  ターンの最中やバックグラウンドタスクが動いている間（`restartRefused`）は押せず、`title` にサーバが断るときと同じ理由（`FRAME_ERROR_REASON.sessionSwitchDuringTurn`）を出す。
  ビューポートが 1000px 以下では字「新規」を隠して絵だけにする。760px 以下はボタンも区切りも出さない（探すの「セッションを切り替える」の一覧に「＋ 新しく始める」がある）

### 13.5 差せるものの受け渡し

- **パック**: `character.json` に `accent` を1つ足す。無ければ既定値に落ちる
- **パック（背景）**: `character.json` の `background`（素材のファイル名と覆いの不透明度）。
  **舞台の全面に敷く**（紙と重ねる紙の地には敷かない）。無ければ背景画像は出ない（13.8）
- **使う人（アイテム）**: 一覧は全キャラ共通・席はキャラクターごと。キャラクター画面（13.6）から足して席に置き、
  `~/.tsukumo/items/` に持つ（`docs/architecture/stage-item.md`）
- **使う人**: `ground` / `surface` / `ink` の3つ。**キャラクター画面から変え、
  `localStorage` に持つ**（13.6）
- どちらも、届いた値は**境界で検証してから CSS 変数に流す**（外部由来の値の扱いは
  `docs/coding-standards.md`）
