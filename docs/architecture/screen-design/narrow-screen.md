## 13. 画面のデザイン

### 13.9 狭い画面（760px 以下）

**スマホでやることは「様子を見る」「聞かれたら答える」「止める」の3つで、この3つを親指の届く下半分に集める。**
舞台・サイドバー・部屋の頭の左の群は出さず、上から「頭・紙・顔と吹き出し・入力欄」の縦の1列にする。迎えるでは顔と吹き出しを紙（始め方）の上に置く。

```
┌──────────────────────────────┐
│ ◯ ● 作業中                 ≡ │ ← 頭（1行。顔・状態・やり取りの題・≡）
│   ID の変換を新旧どちらでも…  │
├──────────────────────────────┤
│ 紙（残りの高さ。転がるのはここだけ）│
│                              │
├──────────────────────────────┤
│ ◯ ╭ 最新の1件の吹き出し ─╮   │ ← 顔と吹き出し
│   ╰──────────────────────╯   │
│ ［答え待ちのカード］           │ ← 答え待ちのあいだだけ
│ ［入力欄                   ↑］ │
└──────────────────────────────┘
```

- **器は全面の縦の並び**（`stage.module.css`・`paper-desk.module.css` の `@media (max-width: 760px)`）。紙と入力欄は入れ物の箱を作らず（`display: contents`）、外枠の縦の並びへ直に加わり、`order` で並べる。転がるのは紙だけで、高さの上限は外枠が決める
- **紙**は角を丸めず影も付けない。内側は上 14px・左右は `--gutter-page`。浮く入力欄を使わないので、紙の下端の空きと溶かしは無い
- **入力欄**は紙の下に積み（浮かせない）、地と影を持たない
- **背景は出さない**（`.stage-scene` を `display: none`）。舞台の立ち絵とアイテムの席も出さない

#### 頭

**画面のいちばん上に1行の頭を置く**（`RoomNarrowHead`。広い幅では出さない）。見本の `.N-head` のとおり、左から顔（38px の丸）・状態と題の2段・「≡」のボタン（押せる的の 44px 四方）。上下の余白は持たず、頭の高さを「≡」の的と罫線の 45px に抑える（720 の戻るの物差しは `stage-and-paper-yardstick.md`「作り直した後の値」）。下に `--rule` の罫線を引く。

- 上の段は状態の点と語（部屋の頭の状態の行と同じ語と色。`room-head-and-search.md`「状態の行」）
- 下の段の題は、迎えるでは部屋の頭の主の字（作業ディレクトリの名前か部屋の名前）、ほかでは最新のやり取りの題（依頼の1行目。欄外のやり取りの並びと同じ `turnTitle`）。1行に収まらないぶんは末尾を省く
- 顔はパックの `face`（`CharacterFace`）で、無いパックでは出さない
- **「≡」は探す（⌘K）の一覧を開く**（`aria-label` は「メニューと探す」、押す的は 40px 以上）。広い幅の探すと同じ一覧で、「移る」の群にタスク・成果・使用量・キャラクター・設定の5枚と、仕事と雑談の切り替え・「セッションを切り替える」が載る（ADR 0057 論点 5）
- 「文脈 n%」の札は頭に出さない。探すの「使用量」から使用量の紙を開く

#### 重ねる紙とセッションの一覧

- **重ねる紙は全面に出す**（`ui/sheet/sheet.module.css`。上をあけず、角を丸めない）。閉じたら探すの一覧ではなく会話の画面へ戻る
- セッションの一覧は、探すの「セッションを切り替える」から開く。広い幅と同じ一覧（`RoomSessionMenu`）で、幅は画面の幅から 28px を引いた分まで

#### 顔と吹き出し

**紙の下に、顔と最新の1件の吹き出しを出す**（`components/page/conversation/components/character-view/phone-balloon.tsx` の `PhoneBalloon`）。広い幅の舞台の代わりで、どちらを出すかは CSS の `@media` が決める。

- 左に顔、右に吹き出し。**作業中も答え待ちも待ちも、最新の1件を常に出す**（セリフか、いま出す反応）。セリフも反応も無いときは顔だけを出す
- **吹き出しは3行で切って末尾を「…」**（`line-clamp: 3`。高さが変わって紙が揺れないように）。押すとセリフのログが開き、
  そこで全文と過去のセリフを読む
- 立ち絵の表情の切り替えは顔の絵には映さない（顔はパックの `face` の1枚）
- 吹き出しの下に「手元」「待ち」の行（`PhoneActivity`）を出す（`scene-behavior.md`「舞台の「手元」の行」）

#### 答え待ちのカード

**答え待ちのあいだは、広い幅と同じく入力欄の場所の上にお伺いを出す**（`InquiryCard` の `placement="dock"`）。紙の中身は引かせ、紙の中にお伺いのカードは出さない（同じものを2箇所に出さない）。中身と答え方は `inquiry.md`。

#### ソフトウェアキーボードが出たとき

高さは `100dvh` のまま、ページの `<meta name="viewport">` に `interactive-widget=resizes-content` を
足して、キーボードのぶん `dvh` が縮むようにする（効かないブラウザでは、フォーカスした欄をブラウザが見える所へ送るのに任せる）。
縮んだぶんは紙が受ける。頭は畳まない。

#### 見本に無い場面

| 場面                       | 見え方                                                                  |
| -------------------------- | ----------------------------------------------------------------------- |
| 雑談モード                 | 頭の状態は「雑談している」。紙は雑談の画面                              |
| ほかの画面の紙を開いている | 紙が全面に重なり、頭も隠れる。紙の閉じるボタンか Esc で会話の画面へ戻る |
| 見本帳（`#design`）        | 紙にせず全面で出す。頭は出さない                                        |

中身を持つ部品（やり取りの並び・レポート・お伺いの選択肢・設定の中身）は広い画面のものを
使い、どこに出すかは各機能の CSS の `@media` で決める（`docs/architecture/browser.md`「CSS」）。
