## 13. 画面のデザイン

### 13.6 設定の置き場所

**今回のことは帯とサイドバーに、それ以外はキャラクター画面に**（「今回のこと」は帯とサイドバーに割る）。画面から変えられるものを**セッション限りかどうか**で割り、
セッション限りのものは読んでいる間も見える場所に、それ以外（利用者の設定もパックの持ち物も）は
会話の画面から出た**キャラクター画面**に置く。**キャラクターの切り替えだけは第3の扱い**
（下の注記）。

**セッション限りのものは、さらに「動き方」と「相手と場所」に割る**（ユーザーが
ヘッダーのモック `docs/history/mockup/header-2026-09-23.png` を示した）。**動き方**のうち仕事か雑談かは、どの画面からでも触れる帯に置く。
モデル・effort・許可モードは次のターンの結果を変える入力欄の設定なので、依頼を書く入力欄の下の行に置く
（761px 以上。760px 以下は引き出しの名乗りの行の下）。**相手と場所**
（どのキャラクターと・どのセッションを続けるか）は選び直す頻度が低く、選ぶと画面ごと
入れ替わるので、サイドバーに残す（帯の資格の規則は 13.9「帯に何を置くか」）。

**歯車の見た目と演出の5つは `state.json` に持つ**（`docs/architecture/adr/0076-gear-preferences-in-state-json.md`。型と畳み方は `src/shared/session/gear-preference.ts`）。
地・領域・字の色、背景の暗さ・パネルのぼかし・パネルの濃さ、書き上げる演出の速さ、動きを減らす、起動するスキルの5つ。

- **ポートに左右されない。** 以前の `localStorage` はポートごとに分かれ、同じブラウザで 7391 と 7392 の2つを起こすと、7391 で書いた5つは 7392 に無かった（実測の表は ADR）。いまはどのポートで開いても同じ `state.json` の値が出る
- **持ち方**: 5つとも、ほかの歯車の設定と同じ `state.json` の最上位に欄ごとに持つ（`appearanceColor`・`appearanceAdjust`・`revealSpeed`・`motionPreference`・`launchSkill`）。欠けた・壊れた欄はその欄だけ既定に畳む。歯車の外の `localStorage`（領域の比率・下書きなど）は寄せない
- **書き方と届け方**: 歯車は1欄ずつ `setGearPreference` で書き、サーバは書いたあと読み直した5欄を `gear-preferences-changed` で全部のページへ流す
- **一瞬の既定色の避け方**: ページの HTML を返すときにサーバが値を `<script type="application/json">` の塊として焼き、ブラウザの入口が描き始める前に同期で読む。整えた3色は `<html>` の `style` にも焼く（ブラウザのスクリプトが動く前にも1回描かれ、そこで地が既定の色になるため）
- **移し方**: `state.json` に値が無い欄は、最初に開いたページが古い `localStorage` の鍵の値で描き始め、最初の `hello` のあとサーバへ1回写し、書けたら鍵を消す（書けなければ鍵を残し、次に開いたときにまた写す）。`state.json` に値がある欄は `state.json` が勝ち、古い鍵を送らずに消す。壊れた古い鍵も送らずに消す
- **「設定をファイルで開く」の口は置かない**。動いている tsukumo が書き戻すファイルで、手で書いた値が上書きされうるため。開く手段は今のホストで足り、`ALLOWED_COMMANDS` には当たらない

**色は「利用者が決める部分」と「キャラクターが決める部分」に割る**（ユーザーが
設定のポップオーバーのモック `docs/history/mockup/settings-2026-09-23.png` を示した。設定はいまダイアログで、
見本は `docs/history/mockup/settings-dialog-look-2026-10-14.png` ほか。ラベルは「地の色」「領域の色」「字の色」）。
**地・領域・字の色は歯車へ移し、差し色（パックの持ち物）はキャラクター画面に残す。** 同じ
`<input type="color">` が並んでいても、**一方は「どの端末でも自分が読みやすい画面」、もう一方は
「このキャラクターの見た目」** で、変えたくなる時機も持ち先（`~/.tsukumo/state.json` と
`~/.tsukumo/characters/<name>/`）も違う。色の検証は `src/shared/session/gear-preference.ts`、
`:root` への差し方は `src/browser/domain/appearance-color.ts` に置く。
**揃った3色の組は、テーマの見本4枚（夜・墨・宵・行灯）として見た目の面の頭に並べ**、16進は畳まない「カスタムの色」に入れる（組は `APPEARANCE_THEMES`。差し色は組に入れない）。

**背景の暗さ・パネルのぼかし・パネルの濃さは、色の下に並ぶ標準の範囲入力**（`src/browser/domain/appearance-adjust.ts`。`state.json` の欄は色と別の1つ）。
背景の暗さは動かすまで値を持たず、その間はパックの `veil`（省略時 0.75）に従う。動かすと利用者の値が `veil` の前の項に入り、70% と地と字の色で決まる下限は割らない。
「既定に戻す」は色と3つの調整の両方を戻し、背景の暗さは利用者の値を消してパックの値へ戻る（ぼかしと濃さは既定の 12px・45%）。

**歯車に置くのは上の3群と、ワークフローのサーフェスだけ**（モックのうち 送信キー・通知・吹き出しで話しかける・発話を
読み上げる・文字の大きさ は置かない。通知は Orca の機能に任せる）。**領域の比率を戻すボタンも
歯車に入れない**——狭い画面では仕切りごと `display: none` になるので、ボタンだけが歯車に残ると
行き先の無い操作になる。

**リポジトリごとの設定は持たない**（`docs/architecture/adr/0025-no-project-settings.md`）。
設定の置き場は環境変数と歯車の2つで、歯車の3群は「この利用者がどこで開いても同じ好み」。
タスクの節を出すかは起動先の `.beads` が読めるかで決まり、画面から変えるボタンは無い。
**ワークフローのスキルの並びはリポジトリに属するが、tsukumo は値を持たない**（
ADR 0025 の改訂の節）。値は `.tw/config.toml` にワークフローが持ち、歯車の「ワークフロー」の面は
ワークフローの設定コマンド（`docs/architecture/workflow-contract.md`「設定コマンド」）の `--schema` で欄の形をもらって描き、`set` で書くだけ。
ほかの3群と違って「どのリポジトリの値か」があるので、面の見出しの下に作業ツリー名と `.tw/config.toml` の絶対パスを出す
（下の「設定の歯車」）。

**新しいセッションの既定（モデル・effort・許可モード・図の既定）は `~/.tsukumo/state.json` に覚える**
（覚えたキャラクターと同じファイル・同じ扱い。`src/server/session/adapter/remembered-default.ts` の冒頭）。**`localStorage` には
置けない** — セッションはブラウザが繋がる前にサーバ側で起こすので、起こすときに読める場所に無いと
意味がない。効き方は5つ:

- **起こすたびに効く**（起動も起こし直しも、切り替え画面からの再開でも新規でも同じ）。読むのは `session-launch` の
  1回だけで、同じ値が `query()` のモデル・effort・許可モードにも、画面へ流す
  `session-default-changed` にも渡る（画面に出る既定と、実際に起こした既定がずれない）。**effort は
  対応しないモデル（`haiku` など）でも渡す**——渡すかどうかをモデルごとに出し分けない
- **帯で変えた値は既定を書き換えない**（帯はセッション限り）。逆に、歯車で既定を変えても
  **いま動いているセッションは変わらない**（効くのは次に起こすときから）
- **既定に「全部許す」（`bypassPermissions`）は選べない。** `<select>` に出さないだけでなく、
  コマンドの検証でも落とす（`SESSION_DEFAULT_PERMISSION_MODES`。`src/shared/session/session-default.ts`）。
  全部許すのは起こしたあと帯からその都度選ぶもので、次に起こすたびに黙って全部許す状態から
  始まる形にはしない
- **読めない・欠けている・知らない値は同梱の既定**（Opus・`medium`・`auto`）。壊れた
  `state.json` で起動が止まらない（キャラクターの覚え方と同じ扱い）。**effort だけ、欄が
  無い古い `state.json` でも他の2つ（モデル・許可モード）は読んだ値のまま**——effort を足す前に
  覚えたファイルを持ち込んでも、それまで覚えていたモデル・許可モードを捨てない
  （`src/server/session/adapter/remembered-default.ts`）
- **図の既定（`figurePreference`。図を置く `chart`／文を主にする `text`、同梱の既定は `chart`）は4つ目で、効き方は同じ。**
  起こすときの値が `report` の `figure` の欄の説明の文を変える（`docs/architecture/adr/0036-optional-figure-and-preference.md`）。
  欄が無い古い `state.json` は、effort と同じく他の3つを読んだ値のまま図の既定だけ同梱の既定に畳み、知らない値は4つとも同梱の既定に倒れる
- **`TSUKUMO_HOME` を分ければ既定も分かれる**（ホームごと差し替わるため。`TSUKUMO_HOME` の doc コメント）

**裏方のモデルは同じ `state.json` に別の欄（`backgroundModels`）として覚える**（`src/shared/session/background-model.ts`）。
会話とは別に起こす使い捨ての問い合わせ4つ（おすすめ・迎えの一言と反応・雑談の記憶の整理・キャラクターの生成）が使うモデルで、
役ごとに別々に選ぶ。新しいセッションの既定には混ぜない（あちらは会話を起こすときの4つで1組）。
問い合わせを起こすたびに読むので、変えると次に起こす問い合わせから効き、いま走っている問い合わせは変わらない。
欄が無い・壊れている・知らない値の役は、その役だけ同梱の既定（haiku・sonnet・haiku・opus）に畳み、ほかの役と覚えたキャラクター・新しいセッションの既定は読んだ値のまま。
歯車では「新しいセッション」の面の下に「裏方のモデル」の群として並べ、画面へは `background-models-changed` で流す。日記と使い方の見直しは呼び出し側が会話のいまのモデルを渡すので対象外

**話しかける間合いも同じ `state.json` に別の欄（`speakingPace`）として覚える**（`src/shared/session/speaking-pace.ts`）。
待ちの一言の間（1分・2分・5分・出さない。既定2分）と、進み具合の催促の黙りの間（3分・5分・10分・しない。既定5分）の2つを、別々に選ぶ。
欄が無い・壊れている・知らない値の欄は、その欄だけ同梱の既定に畳み、ほかの欄と覚えた値は読んだ値のまま。
効くのは次に起こすセッションから。起こすときに読んだ値を状態（待ちの一言）と駆動（催促）に渡すので、歯車で覚え直しても、いま動いているセッションの時刻は変わらない。
「しない」で止めるのは黙りで決める差し込みだけで、フェーズの切れ目の差し込みは止めない。雑談では待ちの一言を出さないまま。
`docs/architecture/adr/0071-waiting-line-in-stream.md` の「2分」は既定の値。
歯車では「演出」の面の下に「話しかける間合い」の群として並べ、画面へは `speaking-pace-changed` で流す

**書き上げる演出の速さは色と同じ `state.json` に持つ**（欄は `revealSpeed`。選択肢の名前と節の間隔は
`src/browser/domain/reveal-speed.ts` に集める——歯車（`components/frame/screen-nav/`）とレポートの演出
（`domain/reveal/use-report-reveal.ts`）の両方が読むので、機能どうしの import を増やさず
`browser/domain/` へ置く。`docs/architecture.md`「全体構成」）。選択肢は3つ（既定は**標準**）。
値は、草稿の無い確定版の節を1つポンと出してから次の節を出すまでの間隔:

| 選択肢 | 節の間隔       |
| ------ | -------------- |
| 標準   | 240ms          |
| 速い   | 120ms          |
| 切る   | （演出しない） |

- **速いは標準の半分**。どちらも演出の全体は3秒に収める（節が多いときは間隔を詰める。`domain/reveal/start-pop.ts` の `startPop`）
- **切ると演出そのものを走らせない**。`domain/reveal/use-report-reveal.ts` の `useReportReveal` が
  `revealSpeed === "off"` を見て `startPop` を呼ばずに済ませるので、本文はマウントした時点で
  すぐ全部出て、筆先に付くミニ立ち絵（`docs/requirements/portrait-motion.md` 4.3）も出ない。
  書いている途中のレポート（草稿）も、「切る」では届いた部品にポンを掛けず、骨組みを明滅させない（止めた薄い帯にする）
- **選び直しても、書いている最中の演出には効かない。** `useReportReveal` は速さも `reveal`
  （書き上げる相手かどうか）と同じく**マウントした時点の値だけ**を読む（`useState` の初期値
  として1回読むだけで、あとから歯車を触っても読み直さない）。次に書き始めたレポートから
  新しい速さになる

**動き方は、読む場所と変える場所が同じ1つ**。以前は「帯は
名乗り、サイドバーは触らせる」として、モデルと許可モードの**読みだけ**を帯に置き、`<select>` は
サイドバーに残していた。帯の操作子がその読みを兼ねるので、**読みだけの字とサイドバーの
`<select>` は両方外す**（13.9「何を外すか」）。サイドバーは会話の画面にしか無いので、
キャラクター画面とトークン消費の画面からも変えられるようになる。

**キャラクターの切り替えは「セッション限り」から「ずっと」へ移したわけではない。** 選ぶ操作自体は
今回どおりセッション限り（起こし直すと戻る）だが、**次に起こしたときの初期値としては覚える**
（ユーザーの指摘「終了直前のキャラクターで起動時にもそうであってほしい」）。
持ち先は `localStorage` ではなく `~/.tsukumo/state.json`（`adapter/remembered-default.ts`）。
**cwd には依存させない**（キャラクターの好みはプロジェクトごとではないため）。置き場所は帯の顔から
開く選択メニュー（13.9「キャラクターの選択メニュー」）。

**覚えるのは「画面から名前が選ばれた」ときだけ**（前項の決定は覆していない
— 覚える範囲を、当初からそのつもりだった「画面から選んだとき」に絞っただけ）。**起こし方は
3つあり、どれで来たかで覚えるかが決まる**:

| 起こし方                  | これから起こすパック                 | 覚えるか   |
| ------------------------- | ------------------------------------ | ---------- |
| 起動                      | 初期パック（指定 > 覚えた値 > 既定） | 覚えない   |
| `session.switchCharacter` | 画面から選ばれた名前                 | **覚える** |
| `session.setChatMode`     | いま出しているパックのまま           | 覚えない   |

**`session.setChatMode` は覚えない**。以前は「起こし直しに使うパック」を
「画面から選ばれた名前」と同じ欄で渡していたので、**モードを切り替えただけで
`~/.tsukumo/state.json` の覚えたキャラクターが書き換わっていた**（`TSUKUMO_CHARACTER` の使い捨ての
パックも、同梱の既定も、雑談へ入った瞬間に「前回のキャラクター」になっていた）。`core` の
コメントは当時から「覚えるのは画面から選んだときだけ」と書いてあり、**実装と食い違っていた。**
直し方は**2つの意味を型で分ける**こと（`CharacterSelection`。初期パック／画面から選ばれた名前／
いま出しているパックのまま の3つ。`src/server/character-pack/core/character-selection.ts`）。「いま出しているまま」は
名前を運ばないので、画面から選ばれたのと取り違えようがない。

- **同じパックを画面から選び直したときは覚える**（変えない）。画面から選ぶのは明示の操作なので、
  値が同じかどうかで扱いを分けない
- **`TSUKUMO_CHARACTER` を指定していても、画面から選べば覚える**（変えない）。環境変数が
  勝つのは**起動時にどのパックで起こすかを読むとき**だけで（指定 > 覚えた値）、画面からの明示の
  選択に負ける理由にはしない。その回だけ試したいなら、切り替えずに起こしたまま使う

**割るのは保存先ではなく「読んでいる最中に触るか（セッション限り）／腰を据えて整えるか
（それ以外）」**（**歯車はこの割りの外**——どの画面からでも触れる場所に、腰を据えて整えるものの
うち**キャラクターに紐づかない**ものだけを集めた）（そうした理由は `docs/history/decision.md`「design.md 13.6 設定の置き場所
（保存先ではなく寿命で割る理由）」）。キャラクター画面に並ぶのはパックの持ち物
（立ち絵・差し色・背景）だけになった。添え書き（「この端末だけ」のような）は出さない。
