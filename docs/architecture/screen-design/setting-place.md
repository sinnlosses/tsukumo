責務: 13.6 設定の置き場所の前半。部屋の頭・設定の紙・キャラクターの紙への割り振り、新しいセッションの既定、演出の速さ、キャラクターの切り替えの覚え方。

## 13. 画面のデザイン

### 13.6 設定の置き場所

**今回のことは部屋の頭に、それ以外は重ねる紙（設定の紙・キャラクターの紙）に**。画面から変えられるものを**セッション限りかどうか**で割り、
セッション限りのものは読んでいる間も見える部屋の頭に、それ以外（利用者の設定もパックの持ち物も）は
サイドバーの入口の行から開く重ねる紙に置く（ADR 0057 論点 3）。**キャラクターの切り替えだけは第3の扱い**
（下の注記）。部屋の頭と紙の入口の形は `room-head-and-search.md`。

**いま動いているセッションのモデル・effort・許可モードは画面から変えない。** 入力欄の札（`RunSettingChip`）は
いまの値を見せるだけで、変えるのは設定の紙の「セッションの既定」（次に起こすときから効く）。

| 変えられるもの                                                 | 寿命                                                                                                                         | 置き場所                                           |
| -------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------- |
| 仕事 / 雑談                                                    | セッション限り（起こし直す）                                                                                                 | 部屋の頭の「仕事」「雑談」の門                     |
| キャラクターの切り替え                                         | **選択はセッション限り（起こし直す）、次回の初期値は覚える**                                                                 | キャラクターの紙の「このキャラクターに切り替える」 |
| セッションの切り替え                                           | セッション限り（起こし直す）                                                                                                 | 部屋の名前から開くセッションの一覧                 |
| 地・領域・字の色（`ground` / `surface` / `ink`）               | 利用者の設定（`localStorage`）                                                                                               | **設定の紙**の「見た目」                           |
| 新しいセッションの既定（モデル・effort・許可モード・図の既定） | 利用者の設定（`~/.tsukumo/state.json`）                                                                                      | **設定の紙**の「動き方」                           |
| 書き上げる演出の速さ                                           | 利用者の設定                                                                                                                 | **設定の紙**の「見た目」                           |
| ワークフローのスキルの並び                                     | **リポジトリ**（`.tw/config.toml`。値はワークフローが持ち、tsukumo は設定コマンドで見せて書くだけ）                          | **設定の紙**の「このプロジェクト」                 |
| キャラクターの立ち絵・差し色                                   | **ずっと**（`~/.tsukumo/characters/<name>/`。`docs/architecture/character-pack.md`「画面から作るときの置き場と受け取り方」） | キャラクターの紙                                   |
| キャラクターの背景                                             | **ずっと**（同上）                                                                                                           | キャラクターの紙                                   |
| キャラクターのミニ立ち絵                                       | **ずっと**（同上）                                                                                                           | キャラクターの紙                                   |
| 新しいパックを作る                                             | **ずっと**（同上）                                                                                                           | 作るダイアログ（キャラクターの紙から開く）         |

**色は「利用者が決める部分」と「キャラクターが決める部分」に割る**（ユーザーが
設定のポップオーバーのモック `docs/history/mockup/settings-2026-09-23.png` を示した。設定はいまダイアログで、
見本は `docs/history/mockup/settings-dialog-look-2026-10-14.png` ほか。ラベルは「地の色」「領域の色」「字の色」）。
**地・領域・字の色は設定の紙に置き、差し色（パックの持ち物）はキャラクターの紙に置く。** 同じ
`<input type="color">` が並んでいても、**一方は「どの端末でも自分が読みやすい画面」、もう一方は
「このキャラクターの見た目」** で、変えたくなる時機も持ち先（`localStorage` と
`~/.tsukumo/characters/<name>/`）も違う。**保存の仕方は変えていない**（`localStorage` の鍵も
検証も `src/browser/domain/appearance-color.ts` のまま。機能をまたいで読まれるようになったので
`browser/domain/` へ上げただけ。`docs/architecture.md`「全体構成」）。

**設定の紙の群は「動き方」「見た目」「知らせ」「このプロジェクト」の4つ**（`room-head-and-search.md`「設定の紙の面の並び」。
モックのうち 送信キー・吹き出しで話しかける・発話を読み上げる・文字の大きさ は置かない）。

**リポジトリごとの設定は持たない**（`docs/architecture/adr/0025-no-project-settings.md`）。
設定の置き場は環境変数と設定の紙の2つで、「このプロジェクト」のほかの群は「この利用者がどこで開いても同じ好み」。
タスクの紙の入口を出すかは起動先の `.beads` が読めるかで決まり、画面から変えるボタンは無い。
**ワークフローのスキルの並びはリポジトリに属するが、tsukumo は値を持たない**（
ADR 0025 の改訂の節）。値は `.tw/config.toml` にワークフローが持ち、設定の紙の「ワークフロー」の面は
ワークフローの設定コマンド（`docs/architecture/workflow-contract/config-and-beads.md`「設定コマンド」）の `--schema` で欄の形をもらって描き、`set` で書くだけ。
ほかの群と違って「どのリポジトリの値か」があるので、面の見出しの下に作業ツリー名と `.tw/config.toml` の絶対パスを出す
（`room-head-and-search.md`「設定の紙の面の並び」）。

**新しいセッションの既定（モデル・effort・許可モード・図の既定）は `~/.tsukumo/state.json` に覚える**
（覚えたキャラクターと同じファイル・同じ扱い。`src/server/session/adapter/remembered-default.ts` の冒頭）。**`localStorage` には
置けない** — セッションはブラウザが繋がる前にサーバ側で起こすので、起こすときに読める場所に無いと
意味がない。効き方は5つ:

- **起こすたびに効く**（起動も起こし直しも、セッションの一覧からの再開でも新規でも同じ）。読むのは `session-launch` の
  1回だけで、同じ値が `query()` のモデル・effort・許可モードにも、画面へ流す
  `session-default-changed` にも渡る（画面に出る既定と、実際に起こした既定がずれない）。**effort は
  対応しないモデル（`haiku` など）でも渡す**——渡すかどうかをモデルごとに出し分けない
- 設定の紙で既定を変えても**いま動いているセッションは変わらない**（効くのは次に起こすときから）
- **既定に「全部許す」（`bypassPermissions`）は選べない。** `<select>` に出さないだけでなく、
  コマンドの検証でも落とす（`SESSION_DEFAULT_PERMISSION_MODES`。`src/shared/session/session-default.ts`）。
  次に起こすたびに黙って全部許す状態から始まる形にはしない
- **読めない・欠けている・知らない値は同梱の既定**（Opus・`medium`・`auto`）。壊れた
  `state.json` で起動が止まらない（キャラクターの覚え方と同じ扱い）。**effort だけ、欄が
  無い古い `state.json` でも他の2つ（モデル・許可モード）は読んだ値のまま**——effort を足す前に
  覚えたファイルを持ち込んでも、それまで覚えていたモデル・許可モードを捨てない
  （`src/server/session/adapter/remembered-default.ts`）
- **図の既定（`figurePreference`。図を置く `chart`／文を主にする `text`、同梱の既定は `chart`）は4つ目で、効き方は同じ。**
  起こすときの値が `report` の `figure` の欄の説明の文を変える（`docs/architecture/adr/0036-optional-figure-and-preference.md`）。
  欄が無い古い `state.json` は、effort と同じく他の3つを読んだ値のまま図の既定だけ同梱の既定に畳み、知らない値は4つとも同梱の既定に倒れる
- **`TSUKUMO_HOME` を分ければ既定も分かれる**（ホームごと差し替わるため。`TSUKUMO_HOME` の doc コメント）

**書き上げる演出の速さは `localStorage` に持つ**（色と同じ並び。保存と読み取りは
`src/browser/domain/reveal-speed.ts` に集める——設定の紙（`components/frame/screen-nav/`）とレポートの演出
（`domain/reveal/use-report-reveal.ts`）の両方が読むので、機能どうしの import を増やさず
`browser/domain/` へ置く。`docs/architecture.md`「全体構成」）。選択肢は3つ（既定は**標準**）。
値は、草稿の無い確定版の節を1つポンと出してから次の節を出すまでの間隔:

| 選択肢 | 節の間隔       |
| ------ | -------------- |
| 標準   | 240ms          |
| 速い   | 120ms          |
| 切る   | （演出しない） |

- **速いは標準の半分**。どちらも演出の全体は3秒に収める（節が多いときは間隔を詰める。`domain/reveal/start-pop.ts` の `startPop`）
- **切ると演出そのものを走らせない**。`domain/reveal/use-report-reveal.ts` の `useReportReveal` が
  `revealSpeed === "off"` を見て `startPop` を呼ばずに済ませるので、本文はマウントした時点で
  すぐ全部出て、筆先に付くミニ立ち絵（`docs/requirements/portrait-motion.md` 4.3）も出ない。
  書いている途中のレポート（草稿）も、「切る」ではポンも待ちの罫線も出さない
- **選び直しても、書いている最中の演出には効かない。** `useReportReveal` は速さも `reveal`
  （書き上げる相手かどうか）と同じく**マウントした時点の値だけ**を読む（`useState` の初期値
  として1回読むだけで、あとから設定の紙を触っても読み直さない）。次に書き始めたレポートから
  新しい速さになる

**キャラクターの切り替えは「セッション限り」から「ずっと」へ移したわけではない。** 選ぶ操作自体は
今回どおりセッション限り（起こし直すと戻る）だが、**次に起こしたときの初期値としては覚える**
（ユーザーの指摘「終了直前のキャラクターで起動時にもそうであってほしい」）。
持ち先は `localStorage` ではなく `~/.tsukumo/state.json`（`adapter/remembered-default.ts`）。
**cwd には依存させない**（キャラクターの好みはプロジェクトごとではないため）。置き場所はキャラクターの紙
（`room-head-and-search.md`「顔」）。

**覚えるのは「画面から名前が選ばれた」ときだけ**（前項の決定は覆していない
— 覚える範囲を、当初からそのつもりだった「画面から選んだとき」に絞っただけ）。**起こし方は
3つあり、どれで来たかで覚えるかが決まる**:

| 起こし方                  | これから起こすパック                 | 覚えるか   |
| ------------------------- | ------------------------------------ | ---------- |
| 起動                      | 初期パック（指定 > 覚えた値 > 既定） | 覚えない   |
| `session.switchCharacter` | 画面から選ばれた名前                 | **覚える** |
| `session.setChatMode`     | いま出しているパックのまま           | 覚えない   |

**`session.setChatMode` は覚えない**。以前は「起こし直しに使うパック」を
「画面から選ばれた名前」と同じ欄で渡していたので、**モードを切り替えただけで
`~/.tsukumo/state.json` の覚えたキャラクターが書き換わっていた**（`TSUKUMO_CHARACTER` の使い捨ての
パックも、同梱の既定も、雑談へ入った瞬間に「前回のキャラクター」になっていた）。`core` の
コメントは当時から「覚えるのは画面から選んだときだけ」と書いてあり、**実装と食い違っていた。**
直し方は**2つの意味を型で分ける**こと（`CharacterSelection`。初期パック／画面から選ばれた名前／
いま出しているパックのまま の3つ。`src/server/character-pack/core/character-selection.ts`）。「いま出しているまま」は
名前を運ばないので、画面から選ばれたのと取り違えようがない。

- **同じパックを画面から選び直したときは覚える**（変えない）。画面から選ぶのは明示の操作なので、
  値が同じかどうかで扱いを分けない
- **`TSUKUMO_CHARACTER` を指定していても、画面から選べば覚える**（変えない）。環境変数が
  勝つのは**起動時にどのパックで起こすかを読むとき**だけで（指定 > 覚えた値）、画面からの明示の
  選択に負ける理由にはしない。その回だけ試したいなら、切り替えずに起こしたまま使う

**割るのは保存先ではなく「読んでいる最中に触るか（セッション限り）／腰を据えて整えるか
（それ以外）」**（**設定の紙はこの割りの外**——どの画面からでも触れる場所に、腰を据えて整えるものの
うち**キャラクターに紐づかない**ものだけを集めた）（そうした理由は `docs/history/decision.md`「design.md 13.6 設定の置き場所
（保存先ではなく寿命で割る理由）」）。キャラクターの紙に並ぶのはパックの持ち物
（立ち絵・差し色・背景）だけになった。添え書き（「この端末だけ」のような）は出さない。
