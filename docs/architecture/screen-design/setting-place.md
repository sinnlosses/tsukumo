## 13. 画面のデザイン

### 13.6 設定の置き場所

**今回のことは帯とサイドバーに、それ以外はキャラクター画面に**（2026-09-17 決定。2026-09-23 に
「今回のこと」を帯とサイドバーに割った）。画面から変えられるものを**セッション限りかどうか**で割り、
セッション限りのものは読んでいる間も見える場所に、それ以外（利用者の設定もパックの持ち物も）は
会話の画面から出た**キャラクター画面**に置く。**キャラクターの切り替えだけは第3の扱い**
（2026-09-14 決定。下の注記）。

**セッション限りのものは、さらに「動き方」と「相手と場所」に割る**（2026-09-23 決定。ユーザーが
ヘッダーのモック `docs/history/mockup/header-2026-09-23.png` を示した）。**動き方**（仕事か雑談か・
モデル・許可モード）は次のターンの結果を変えるので、どの画面からでも触れる帯に置く。**相手と場所**
（どのキャラクターと・どのセッションを続けるか）は選び直す頻度が低く、選ぶと画面ごと
入れ替わるので、サイドバーに残す（帯の資格の規則は 13.9「帯に何を置くか」）。

| 変えられるもの                                       | 寿命                                                                                                                         | 置き場所                                               |
| ---------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------ |
| 仕事 / 雑談                                          | セッション限り（起こし直す）                                                                                                 | 帯の「仕事」「雑談」の門（13.9）                       |
| モデル                                               | セッション限り                                                                                                               | 帯のドロップダウン（13.9）                             |
| effort                                               | セッション限り                                                                                                               | 帯のドロップダウン（13.9、モデルと許可モードのあいだ） |
| 許可モード                                           | セッション限り                                                                                                               | 帯のドロップダウン（13.9）                             |
| キャラクターの切り替え                               | **選択はセッション限り（起こし直す）、次回の初期値は覚える**                                                                 | 帯の顔から開く選び口（13.9）                           |
| セッションの切り替え                                 | セッション限り（起こし直す）                                                                                                 | 帯の札から開く切り替え画面（13.9）                     |
| 地・領域・字の色（`ground` / `surface` / `ink`）     | 利用者の設定（`localStorage`）                                                                                               | **帯の右端の歯車**（13.9）                             |
| 新しいセッションの既定（モデル・effort・許可モード） | 利用者の設定（`~/.tsukumo/state.json`）                                                                                      | **帯の右端の歯車**（13.9）                             |
| 書き上げる演出の速さ                                 | 利用者の設定                                                                                                                 | **帯の右端の歯車**（13.9）                             |
| ワークフローのスキルの並び                           | **リポジトリ**（`.tw/config.toml`。値はワークフローが持ち、tsukumo は設定コマンドで見せて書くだけ）                          | **帯の右端の歯車**の「ワークフロー」（13.9）           |
| 領域の比率を既定に戻す                               | 利用者の設定（`localStorage`）                                                                                               | 上下の仕切りの右端（比率を動かしたときだけ出るピル）   |
| キャラクターの立ち絵・差し色                         | **ずっと**（`~/.tsukumo/characters/<name>/`。`docs/architecture/character-pack.md`「画面から作るときの置き場と受け取り方」） | キャラクター画面                                       |
| キャラクターの背景                                   | **ずっと**（同上）                                                                                                           | キャラクター画面                                       |
| キャラクターのミニ立ち絵                             | **ずっと**（同上）                                                                                                           | キャラクター画面                                       |
| 新しいパックを作る                                   | **ずっと**（同上）                                                                                                           | 作るダイアログ（キャラクター画面から開く）             |

**色は「利用者が決める部分」と「キャラクターが決める部分」に割る**（2026-09-23 決定。ユーザーが
設定のポップオーバーのモック `docs/history/mockup/settings-2026-09-23.png` を示した。2026-10-14 に設定はダイアログになり、
見本は `docs/history/mockup/settings-dialog-look-2026-10-14.png` ほか。ラベルは「地の色」「領域の色」「字の色」）。
**地・領域・字の色は歯車へ移し、差し色（パックの持ち物）はキャラクター画面に残す。** 同じ
`<input type="color">` が並んでいても、**一方は「どの端末でも自分が読みやすい画面」、もう一方は
「このキャラクターの見た目」**で、変えたくなる時機も持ち先（`localStorage` と
`~/.tsukumo/characters/<name>/`）も違う。**保存の仕方は変えていない**（`localStorage` の鍵も
検証も `src/browser/domain/appearance-color.ts` のまま。機能をまたいで読まれるようになったので
`browser/domain/` へ上げただけ。`docs/architecture.md`「全体構成」）。

**歯車に置くのは上の3群と、ワークフローの面だけ**（モックのうち 送信キー・通知・吹き出しで話しかける・発話を
読み上げる・文字の大きさ は置かない。通知は Orca の機能に任せる）。**領域の比率を戻すボタンも
歯車に入れない**——狭い画面では仕切りごと `display: none` になるので、ボタンだけが歯車に残ると
行き先の無い操作になる。

**リポジトリごとの設定は持たない**（2026-10-08 決定。`docs/architecture/adr/0025-no-project-settings.md`）。
設定の置き場は環境変数と歯車の2つで、歯車の3群は「この利用者がどこで開いても同じ好み」。
タスクの節を出すかは起動先の `.beads` が読めるかで決まり、画面から変える口は無い。
**ワークフローのスキルの並びはリポジトリに属するが、tsukumo は値を持たない**（2026-10-14 決定。
ADR 0025 の「2026-10-14 の改訂」）。値は `.tw/config.toml` にワークフローが持ち、歯車の「ワークフロー」の面は
ワークフローの設定コマンド（`docs/architecture/workflow-contract.md`「設定コマンド」）の `--schema` で欄の形をもらって描き、`set` で書くだけ。
ほかの3群と違って「どのリポジトリの値か」があるので、面の見出しの下に作業ツリー名と `.tw/config.toml` の絶対パスを出す
（下の「設定の歯車」）。

**新しいセッションの既定（モデル・effort・許可モード）は `~/.tsukumo/state.json` に覚える**
（覚えたキャラクターと同じファイル・同じ扱い。`src/server/session/adapter/remembered-default.ts` の冒頭）。**`localStorage` には
置けない** — セッションはブラウザが繋がる前にサーバ側で起こすので、起こすときに読める場所に無いと
意味がない。効き方は5つ:

- **起こすたびに効く**（起動も起こし直しも、切り替え画面からの再開でも新規でも同じ）。読むのは `session-launch` の
  1回だけで、同じ値が `query()` のモデル・effort・許可モードにも、画面へ流す
  `session-default-changed` にも渡る（画面に出る既定と、実際に起こした既定がずれない）。**effort は
  対応しないモデル（`haiku` など）でも渡す**——渡すかどうかをモデルごとに出し分けない
- **帯で変えた値は既定を書き換えない**（帯はセッション限り）。逆に、歯車で既定を変えても
  **いま動いているセッションは変わらない**（効くのは次に起こすときから）
- **既定に「全部許す」（`bypassPermissions`）は選べない。** `<select>` に出さないだけでなく、
  コマンドの検証でも落とす（`SESSION_DEFAULT_PERMISSION_MODES`。`src/shared/session/session-default.ts`）。
  全部許すのは起こしたあと帯からその都度選ぶもので、次に起こすたびに黙って全部許す状態から
  始まる形にはしない
- **読めない・欠けている・知らない値は同梱の既定**（Opus・`medium`・`auto`）。壊れた
  `state.json` で起動が止まらない（キャラクターの覚え方と同じ扱い）。**effort だけ、欄が
  無い古い `state.json` でも他の2つ（モデル・許可モード）は読んだ値のまま**——effort を足す前に
  覚えたファイルを持ち込んでも、それまで覚えていたモデル・許可モードを捨てない
  （`src/server/session/adapter/remembered-default.ts`）
- **`TSUKUMO_HOME` を分ければ既定も分かれる**（ホームごと差し替わるため。`TSUKUMO_HOME` の doc コメント）

**書き上げる演出の速さは `localStorage` に持つ**（色と同じ並び。保存と読み取りは
`src/browser/domain/reveal-speed.ts` に集める——歯車（`components/domain/screen-nav/`）とレポートの演出
（`domain/reveal/use-report-reveal.ts`）の両方が読むので、機能どうしの import を増やさず
`browser/domain/` へ置く。`docs/architecture.md`「全体構成」）。選択肢は3つ（既定は**標準**）:

| 選択肢 | 文字1つあたり  | 塊の下限 | 塊の上限 |
| ------ | -------------- | -------- | -------- |
| 標準   | 40ms           | 2400ms   | 8000ms   |
| 速い   | 20ms           | 1200ms   | 4000ms   |
| 切る   | （演出しない） | —        | —        |

- **速いは3つとも標準の半分**。下限・上限を一緒に半分にしないと、短い塊が下限に張り付いた
  まま「速い」を選んでも速さが変わって見えない（`domain/reveal/plan.ts` の `topicDurationMs` が
  塊の大きさをこの3値で時間に直す）
- **切ると演出そのものを走らせない**。`domain/reveal/use-report-reveal.ts` の `useReportReveal` が
  `revealSpeed === "off"` を見て `startReveal` を呼ばずに済ませるので、本文はマウントした時点で
  すぐ全部出て、筆先に付くミニ立ち絵（13.6 冒頭の表・`docs/requirements.md` 4.3）も出ない
- **選び直しても、書いている最中の演出には効かない。** `useReportReveal` は速さも `reveal`
  （書き上げる相手かどうか）と同じく**マウントした時点の値だけ**を読む（`useState` の初期値
  として1回読むだけで、あとから歯車を触っても読み直さない）。次に書き始めたレポートから
  新しい速さになる

**動き方は、読む場所と変える場所が同じ1つ**（2026-09-23 に改めた）。2026-09-22 には「帯は
名乗り、サイドバーは触らせる」として、モデルと許可モードの**読みだけ**を帯に置き、`<select>` は
サイドバーに残していた。帯の操作子がその読みを兼ねるので、**読みだけの字とサイドバーの
`<select>` は両方外す**（13.9「何を外すか」）。サイドバーは会話の画面にしか無いので、
キャラクター画面とトークン消費の画面からも変えられるようになる。

**キャラクターの切り替えは「セッション限り」から「ずっと」へ移したわけではない。** 選ぶ操作自体は
今回どおりセッション限り（起こし直すと戻る）だが、**次に起こしたときの初期値としては覚える**
（2026-09-14 決定。ユーザーの指摘「終了直前のキャラクターで起動時にもそうであってほしい」）。
持ち先は `localStorage` ではなく `~/.tsukumo/state.json`（`adapter/remembered-default.ts`）。
**cwd には依存させない**（キャラクターの好みはプロジェクトごとではないため）。置き場所は帯の顔から
開く選び口（13.9「キャラクターの選び口」）。

**覚えるのは「画面から名前が選ばれた」ときだけ**（2026-09-21 決定。2026-09-14 の決定は覆していない
— 覚える範囲を、当時からそのつもりだった「画面から選んだとき」に絞り直しただけ）。**起こし方は
3つあり、どれで来たかで覚えるかが決まる**:

| 起こし方                  | これから起こすパック                 | 覚えるか   |
| ------------------------- | ------------------------------------ | ---------- |
| 起動                      | 初期パック（指定 > 覚えた値 > 既定） | 覚えない   |
| `session.switchCharacter` | 画面から選ばれた名前                 | **覚える** |
| `session.setChatMode`     | いま出しているパックのまま           | 覚えない   |

**`session.setChatMode` は覚えない**（2026-09-21 に直した）。それまでは「起こし直しに使うパック」を
「画面から選ばれた名前」と同じ欄で渡していたので、**モードを切り替えただけで
`~/.tsukumo/state.json` の覚えたキャラクターが書き換わっていた**（`TSUKUMO_CHARACTER` の使い捨ての
パックも、同梱の既定も、雑談へ入った瞬間に「前回のキャラクター」になっていた）。`core` の
コメントは当時から「覚えるのは画面から選んだときだけ」と書いてあり、**実装と食い違っていた。**
直し方は**2つの意味を型で分ける**こと（`CharacterSelection`。初期パック／画面から選ばれた名前／
いま出しているパックのまま の3つ。`src/server/character-pack/core/character-selection.ts`）。「いま出しているまま」は
名前を運ばないので、画面から選ばれたのと取り違えようがない。

- **同じパックを画面から選び直したときは覚える**（変えない）。画面から選ぶのは明示の操作なので、
  値が同じかどうかで扱いを分けない
- **`TSUKUMO_CHARACTER` を指定していても、画面から選べば覚える**（変えない）。環境変数が
  勝つのは**起動時にどのパックで起こすかを読むとき**だけで（指定 > 覚えた値）、画面からの明示の
  選択に負ける理由にはしない。その回だけ試したいなら、切り替えずに起こしたまま使う

**割るのは保存先ではなく「読んでいる最中に触るか（セッション限り）／腰を据えて整えるか
（それ以外）」**（**歯車はこの割りの外**——どの画面からでも触れる場所に、腰を据えて整えるものの
うち**キャラクターに紐づかない**ものだけを集めた）（そうした理由は `docs/history/decision.md`「design.md 13.6 設定の置き場所
（保存先ではなく寿命で割る理由）」）。キャラクター画面に並ぶのはパックの持ち物
（立ち絵・差し色・背景）だけになった。添え書き（「この端末だけ」のような）は出さない。
