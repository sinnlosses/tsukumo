## 13. 画面のデザイン

### 13.14 デザイントークン（余白・角丸・影・動き）

**色は `color.md`、字の大きさは `principle-and-type.md`「13.3 Type」が持つ。ここは残りの 4 つ。** 値は `src/browser/styles/theme.css` が持ち、CSS からは `var()` で読む。決めた理由・今の直書きの分布・採らなかった案・置き換えの順は `docs/architecture/adr/0041-design-system-tokens-and-gallery.md`。この文書で「デザイントークン」と書くのは CSS のカスタムプロパティのことで、LLM のトークン消費とは別。

#### 余白

名前は大きさの語で、`ui/stack` の `gap` の語と同じ。**同じ値を 2 つの名前で持たない。**

| トークン      | 値       | 使う場面                                    |
| ------------- | -------- | ------------------------------------------- |
| `--space-2xs` | 0.125rem | 罫と字のあいだ・印の上下の細い余白          |
| `--space-xs`  | 0.25rem  | 字と字・小さな部品の内側                    |
| `--space-sm`  | 0.5rem   | 部品の内側の標準・同じ群の部品のあいだ      |
| `--space-md`  | 0.75rem  | 箱（`Surface`）の内側の標準・群と群のあいだ |
| `--space-lg`  | 1rem     | 区画のあいだ・ダイアログの内側              |
| `--space-xl`  | 1.25rem  | 大きな区画のあいだ                          |
| `--space-2xl` | 1.5rem   | 領域と領域のあいだ                          |

- 寄せ方は「近い段へ。同点は大きい段へ」（6px は `sm`・10px は `md`）。
- 28px 以上は余白ではなく領域の寸法で、直書きのまま書く。負の余白は `calc(-1 * var(--space-xs))`。
- 段は端に足す（`3xl`）。`md` の意味を動かさない。

#### 角丸

| トークン         | 値      | 使う場面                           |
| ---------------- | ------- | ---------------------------------- |
| `--radius-sm`    | 0.25rem | 印・コードの欄・小さな枠           |
| `--radius-md`    | 0.5rem  | ボタン・入力欄・札の標準           |
| `--radius-lg`    | 0.75rem | 箱（`Surface`）・区画              |
| `--radius-xl`    | 1rem    | ダイアログ・重なる面               |
| `--radius-pill`  | 999px   | 丸い札・状態のチップ               |
| `--radius-round` | 50%     | 丸（点・アイコンの枠・立ち絵の枠） |

#### 影

| トークン           | 値                                                               | 使う場面                 |
| ------------------ | ---------------------------------------------------------------- | ------------------------ |
| `--shadow-raised`  | `0 8px 24px rgb(0 0 0 / 0.3)`                                    | メニュー・浮かぶ札       |
| `--shadow-overlay` | `0 20px 50px color-mix(in srgb, var(--ground) 80%, transparent)` | ダイアログ・引き出し・板 |
| `--shadow-ring`    | `0 0 0 2px var(--accent)`                                        | 選んでいる・目印の輪     |

- ぼかしのある影（ぼかし 1px 以上で `inset` でないもの）はトークンを使う。向きのある影と、色・幅が部品ごとに違う輪・内側の線（`inset`）は直書きのまま許す。

#### 動き

| トークン        | 値    | 使う場面            |
| --------------- | ----- | ------------------- |
| `--motion-fast` | 0.12s | hover・色の切り替え |
| `--motion-base` | 0.2s  | 開閉・寄り・出入り  |

- `transition` の時間だけをトークンにする。緩急は `ease-out` を基本にし、キーワードのまま書く。
- `animation`（吹き出し・立ち絵・読み込みの回転）は部品ごとの局所のつまみ（`--portrait-*-duration` など）が持つ。
- `prefers-reduced-motion: reduce` のときは、`theme.css` の全要素への規則が時間を `0.01ms` にするので、トークンの側では何もしない。

### 13.15 直書きを止める検査

`test/architecture/` の検査が、`src/browser/` の `theme.css` 以外の `*.css` で、上の 4 つの値がトークンかそれに従う値（`0`・`auto`・`em`・`%`・局所の `var(--*)`・28px 以上の余白・向きのある影・輪と `inset`）だけであることを確かめる。字の大きさの検査（`test/architecture/font-size.test.ts`）と同じ形で、**置き換えが済むまでの違反は、ファイルごとの件数の除外の一覧に載せて通す**。件数が増えたら落ち、減ったら一覧を減らすよう促す。除外の一覧は減る向きにだけ動く。

### 13.16 `ui/` の箱の部品

`ui/` の部品は、持つのは顔（地・枠・字の色・振る舞い）で、置き方（margin・flex・align-self）は呼び出し側が `className` で渡す。箱の語彙を持つ 3 つを足す。props は全部必須で、型で縛る（`ui/stack` と同じ）。

| 部品      | 持つもの                                                                                                                                                                                                              |
| --------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Surface` | 地（`tone`: `--surface`・`--surface-raised`・`--surface-accent`）・枠（`--rule-soft` の 1px で固定）・角丸（`radius`: `--radius-*`）・内側の余白（`space`: `--space-*`）・影（`shadow`: `none`・`raised`・`overlay`） |
| `Badge`   | 小さな印。`tone`（`neutral`・`ok`・`warn`・`ng`・`accent`）・字は `--font-label`・角丸は `--radius-pill` か `--radius-sm`                                                                                             |
| `Divider` | 罫。`--rule`・`--rule-soft`・`--rule-quiet` の 3 段                                                                                                                                                                   |

カタログの部品（`report` の a2ui の面）は、枠を `Surface`・見出しを `Heading`・並べる入れ物を `Stack` 系・印を `Badge` で組む。

### 13.17 見本帳

**見本帳は専用の画面 `#design`。** 帯に出さず、hash を打って開く。初期読み込みの束には入れず、`import()` で外して読む。デザイントークン（値と使われ方）・`ui/` の部品（状態ごと）・カタログの全部品を 1 ページに並べる。カタログの部品の例は `report_part_card` が返す例をそのまま使い、a2ui の面で描く。撮影（`scripts/capture/capture-catalog.ts`）と E2E からは hash で開いて撮る。Storybook は入れない（理由は ADR 0041）。
