# 画面のデザイン: 振り返りと日記帳の見開き

ステータス: **正典**。入口は `docs/architecture/screen-design.md`（画面のデザインの全体）。

責務: 成果の画面の振り返りのボタンの扱い、書き終わりの知らせ、日記帳の見開き、見本、仮に決めたこと。
読む時: 振り返りのボタン・知らせ・日記帳の見開きに触るとき。
直す時: それらの形や振る舞い、仮の決めを変えたとき。成果の画面の並びと灯りの暦は `docs/architecture/screen-design/diary.md`。

## 13. 画面のデザイン

### 13.10 成果の画面

#### ボタンを押せないとき・押したあと

- **日記を書いているあいだは押せない**（「ターンが進んでいるあいだ」ではない。
  振り返りは会話とは別の問い合わせで書くので、**会話のターン中・答え待ちでも押せる**。
  `docs/requirements.md` 4.11「振り返りの依頼」）。**`disabled` にせず `aria-disabled="true"`**
  にし、理由をボタンの下に文で出す（書いている日のボタンは「振り返り中…」に変わる。ほかの日は
  「いま<日付>の日記を書いているので送れない」。13.9「動き方の操作子」と同じ扱い）。空の日は
  「振り返る成果が無い」を出す。両方成り立つときは空の日の理由だけ（書き終えても押せないため）
- **雑談のときも押せる。** 日記は会話のモードに関わらず同じ形で書く。成果を一緒に喜ぶのは
  「一緒にいる感じ」の側の用事なので、雑談で頼めないと目的に反する（トークン消費の
  「減らし方を見てもらう」が雑談で押せないのは、要るツールが雑談では載らないため）
- **押したら振り返りのコマンドを1回送り、画面は移らずに留まる**（下の
  「押したら会話へ移る形をやめた理由」）。見ている日の (b) 振り返り中になる:
  - ボタンが「振り返り中…」（回る印つき。`aria-disabled`）に変わる。**会話の画面へ移る口は
    置かない**（「会話の画面で様子を見る ›」は置かない。振り返りは会話の画面に何も
    出さないので、見に行っても何も無い）
  - 吹き出しの下に**3段の進み**: 「この日のタスクを読む」「日記を書く」「いちばんを選ぶ」。
    済んだ段は ✓、いまの段は回る印、まだの段は中抜きの輪（見直しの段と同じ作り。13.1 原則5 の
    とおり、印の形でも区別する）。段の決まり方は `docs/requirements.md` 4.11「日記」
  - 頭の行の時刻の代わりに「いま書いています…」（回る印つき）。吹き出しは点線の枠で空のまま
    （**書いている途中の本文は流さない**。ユーザーの決定の代わりの案1）。
    その日に既に日記があれば、前の段落を出したまま点線の枠にする
  - しおりの区画は点線の枠にし、「日記を書き終えたら、<名前>がいちばんの1件を選びます」の1行
  - 帯の「いまの作業」は、会話のターンが動いていなければ「振り返り中」と「<日付>の日記を
    書いています」（13.9「いまの作業」）
  - **会話の画面（メインビュー・キャラビュー）には何も出ない**。依頼文もレポートもセリフも
    増えない（書いている最中の吹き出しも、書き上がったときのセリフも、この画面の区画と下の
    知らせだけが持つ）
  - **振り返り中に別の日へ切り替えても、進みは書いている日の (a) にだけ出す**（ほかの日の
    ボタンは「いま<日付>の日記を書いているので送れない」で押せない）
- **書き上がったら**、吹き出しに新しい段落を**書き上げの演出**（レポートの筆が走る演出。
  `browser/domain/reveal/`）で頭から見せ、しおり・暦の鈴を差し替える。演出が掛かるのは
  **書き上がったその場だけ**で、あとから日を開き直したときは演出なしで出す。
  `prefers-reduced-motion: reduce` では演出しない
- **書けなかったら**（問い合わせが `diary` を受け付けられずに終わった。時間切れ・失敗も同じ）、
  進みを消してボタンを戻し、吹き出しの場所に「日記を書けなかった。もう一度押すと書き直す。」の
  1行を出す（その日に前の日記があれば、前の段落の下に添える）。次に振り返りを押すか、プロセスを
  起こし直すまで残る
- 送ったあとは、書き終わるまでボタンが押せないことで二重送りを防ぐ（別の印は足さない）

**押したら会話へ移る形をやめた理由**（当時の記述は `docs/history/decision.md`
「screen-design.md 13.10 成果の画面（押したら会話へ移る・吹き出しの写しを置かない・見本を
置かない）」）: 感想を `speak` で受け取っていたころは、返事が見える場所（キャラクターの吹き出し）
へ連れて行くしかなかった。**日記はセリフの写しではなく、その日のページとして残る別の成果物**に
なったので、書き上がる場所はこの画面になり、進みもこの画面の区画が描く（トークン消費の
画面の「減らし方を見てもらう」が留まるのと同じ理由）。同じ理由で「この画面に吹き出しの写しを
置かない」もやめた——ここの吹き出しに出るのは日記で、キャラビューのセリフとは別のもの。

#### 書き終わりの知らせ

(c)。日記が書き上がったら、**画面の下の中央に浮く札**で「<日付>のページができました」を知らせる。
札は鈴の印・文言・「日記帳で開く」（塗りのボタン。押すとその日の見開き (d) が開き、知らせは
消える）・「×」（消すだけ）の並び。日付は「9月23日」の形（今日でも「今日」と言い換えない。
ページの名前として読むため）。

- **成果の画面でだけ出す**（「どの画面にいても出す」ではない。会話の画面では
  キャラビューの吹き出しに重なり、作業の邪魔になるため）。振り返りのあいだにほかの画面へ
  移っていたら、成果の画面へ戻ったときに出る。成果の画面でその日を見ていても出す（見本 c）
- **消えるのは「×」・「日記帳で開く」・次の振り返りを押したとき・プロセスを起こし直したとき**
  （仮）。時間では消さない（離れているあいだに消えると知らせた意味が無い）
- 消したかどうかはタブのメモリにだけ持つ（仮。再読み込みすると、同じ知らせがもう一度出る）
- `role="status"`（読み上げは1回だけ）。フォーカスは奪わない

#### 日記帳の見開き

(d)(e)。**「日記帳で読む」・知らせの「日記帳で開く」から開くモーダル**
（`use-modal-dialog.ts`。Esc・枠の外・「閉じる」で閉じ、閉じたら開いた口へフォーカスを戻す）。
画面の上に見開き1つを重ね、後ろの成果の画面は暗くする。

- **頭の行**: 「つくもの日記帳」は**画面の題なので固定の語**（パックの名前は入れない。付喪神の
  「つくも」で、tsukumo の名の由来。キャラクターの中身ではない）と、添え書き（「この日の日記から
  開きました」など、どの口から開いたか）。右に「‹ 9月15日」「9月23日 ›」「目次」「閉じる」
- **前後の送り**（仮）: 「‹」「›」は**前後の日記のある日**へ飛ぶ（日記の無い日は飛ばす。見本 d の
  9月16日 → 9月15日 / 9月23日）。白紙の日（e）から送ったときも、その日の前後の日記のある日へ。
  向こうに日記が無ければその向きは `aria-disabled`。ボタンの字は行き先の日付
- **目次**（仮）: 押すと見開きの上に、**日記のある日を新しい順に並べた一覧**を月ごとの見出しで
  出す（1行に日付・曜日・しおりのタスク ID）。押すとその日へ。範囲は暦の5週に限らず、保存して
  あるすべて
- **左ページ**: しおり（「しおり ── この日のいちばん」と ID・`summary`・理由。ページの上端から
  金色のしおりの帯を垂らす）、「この日に終えたこと」（ID と `summary` を4件まで。超えたら「ほか
  N 件」の1行）、左下に**卒業・節目の丸い印**
  （卒業は「卒業 T-xxx」、節目は数を漢数字にした「五百」「件目のタスク」の形。複数あれば並べる）
- **右ページ**: **縦書き**（`writing-mode: vertical-rl`）。右端の1列に上から、漢数字の日付
  （「九月十六日」）・曜日（「水曜日」）・灯りの印と段階の語（「灯り　明るい」）を積み、その左に
  本文、左下に署名（書いたパックの顔と名前）。**本文はすべての段落を書いた順に並べ、段落のあいだは1行空け、2つ目からの
  段落の頭に書いた時刻を小さく添える**（仮。「〔22:10〕」の形）。ページは縦の罫線の地で、
  **罫の間隔は本文の行送りと同じ**にし、本文の1列が罫と罫のあいだに収まるようにする
- **白紙の日（e）**: 左ページのしおりの場所は点線の帯と「振り返りのあとに、<名前>が挟みます。」、
  終えたことと印はふだんどおり。右ページは日付と灯りのあとに「このページは、まだ白紙。」と、
  主ボタン「**この日を振り返る**」（地が `--accent`・字が `--ground`）、その下に「<名前>がこの
  ページに日記を書きます」。押すと**その日付で (b) と同じ振り返りを送り**、見開きを閉じて、その日の
  (a) を見せる。押せない条件は (a) のボタンと同じ（理由もボタンの下に出す）。署名の場所には
  いまのパックの顔
- **今日より後の日・空の日**も白紙の日と同じ形で、空の日はボタンの代わりに「振り返る成果が
  無い」
- 見開きの中は横スクロールさせない。狭い画面（760px 以下）では左右のページを縦に積む
  （右ページが上）。**縦書きの本文がページに収まらなければ、収まるまで字と罫をいっしょに
  縮める**（描いた本文がはみ出しているかを測って決める。字数からは見積もらない）。6割まで
  縮めても収まらないときだけ、本文を左へ送らせる

#### 見本

**見本は `docs/history/mockup/achievement-diary-2026-09-25/` の5枚**（SEIKA-4 の a〜e。
`python3 -m http.server` で開いて `*.dc.html` を見る）。色・寸法の値はインラインの style にある。
**見本のサンプル文（キャラクターの口調の日記・理由）は使わない**（原則4）。

**見本どおりにしない4点**（ユーザーの決定「代わりの案」）: 書いている途中の本文は
流さない（見本 b は流している）・卒業は新形式で登録したタスクだけ・暦は5週ぶんを1回の
`bd list` の結果から数える（`git log` でコミットを数える形にはしない）・**明朝体は外から取らず端末の明朝体に既定で寄せる**
（キャラクターパックが書体を同梱すればそれに従う。13.3）。

**見本を置く形に改めた理由**（以前は「見本を置かない」だった）: 以前のこの画面は
既にある部品の組み合わせだけで、新しい見た目の判断が無かった。日記帳は縦書きの見開き・灯りの
暦・吹き出しの日記と、新しい見た目の判断が多く、ユーザーが見本で形を決めたので、それを正典の
隣に置く。

#### 仮に決めたこと

見本で決まっていないことは、**プロトタイプとして仮に決めて作り、使いながら直す**（ユーザーの
決定）。上の本文で「（仮）」と書いたものの一覧:

| 卒業とみなす日数・節目の刻み | 登録から7日以上 / タスク 250 件ごと                                             | `docs/requirements/achievement.md`「卒業と節目」                        |
| 吹き出しに出す段落           | いちばん新しい段落だけ                                                          | この節「並べるもの」                                                    |
| 書き足したときの段落の区切り | 見開きで1行空け、2つ目からの段落の頭に時刻                                      | この節「日記帳の見開き」                                                |
| 目次に並べるもの             | 日記のある日のすべてを新しい順に、月の見出しつき                                | この節「日記帳の見開き」                                                |
