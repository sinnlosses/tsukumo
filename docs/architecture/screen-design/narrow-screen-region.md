# 画面のデザイン: 狭い画面の区画

ステータス: **正典**。入口は `docs/architecture/screen-design.md`（画面のデザインの全体）。

責務: 760px 以下の窓の本文・板・顔と吹き出し・答え待ちの札・入力欄・引き出し、キーボード、見本に無い場面、画面が増えたときの畳み方。
読む時: 狭い画面の区画の1つに触るとき。
直す時: それらの寸法・振る舞いを変えたとき。全体の形・部品の行き先・頭は `docs/architecture/screen-design/narrow-screen.md`。

## 13. 画面のデザイン

### 13.9 画面のナビゲーション

#### 狭い画面（760px 以下）

**本文**（余白 上下 14・左右 16、塊の間 16。下端に高さ 40 の、透明から `--ground` へのぼかしを重ねる）:

- 依頼は “ と1行だけ（列 18px と残り・間 8。“ は明朝 22px で `--accent` を `--ground` へ6割混ぜた色、字は 13.5px・行の高さ 1.7。
  長い依頼は2行で切って「…」、押すと全文を板で読む）
- 「済んだ段 · 中間レポート」の見出し（11px・字間 0.1em・`--ink-quiet`）の下に、**1段1行の一覧**（行の高さ 40、上に `--rule` の罫線。
  列は 16 / 16 / 残り / 中身なり / 14 で間 8: `--state-ok` の ✓〔11px 太字〕・番号〔等幅 11px〕・段の題〔13px・1行で「…」〕・
  所要〔等幅 11px〕・›）。働くあいだと最終レポートの無いまま閉じたやり取りで出す。そこでは中間レポートを点線の箱に本文ごと積む形は出さない
- 一覧の下に「いまの段 · n 題」（見出しと同じ字）と、いま走っている手順の1行（等幅 11.5px・`--ink-quiet`・1行で「…」。
  再試行中・答え待ちもここに出す）。長いコマンドの行は頭に置かない
- **行を押すと下から板が上がり、その段の中間レポートを読む**（下の「板」）
- **最終レポートのある閉じたやり取りは、広い画面と同じ 依頼 → 最終レポート → 経過の畳み に並べる**（2026-10-19 利用者決定。
  一覧は出さず、畳みの中の中間レポートは広い画面と同じ描き方で、押して開く。最終レポートを最初の1画面に入れ、
  中間レポートの置き場を一覧と畳みの2か所に割らないため）。最終レポートは板に入れない。
  失敗で終わったターンは失敗の塊を最終レポートの頭に付ける（13.13「失敗の塊」）
- 迎える局面は本文に始め方の一覧（13.13「始め方の一覧」）をそのまま出す。過去のやり取りを見ているあいだは本文の上端に知らせの行を出す

**板**（下から上がる面。中間レポートと「手順 n」と、答え待ちの札の「ほか n」・添え書きの読み口が共有する）:

- 後ろに `rgba(8,8,12,0.55)` の覆い。面は下端に付け、高さは `min(600px, 100dvh - 頭の高さ)`、上の角丸 22、地 `--surface`、
  上に `--rule` の罫線と上向きの深い影。上端につまみ（40x4・角丸 2・`--rule`。上下の余白 8 / 4）
- 頭（余白 6 16 12・下に罫線・間 8）: ✓・「n/N · 所要」（等幅 11px）・段の題（14px 太字）
- 中（余白 14 16・間 12・14px・行の高さ 1.85）: 中間レポートの本文を広い画面と同じ部品で描き、検証の表もそのまま。中だけが転がる
- 下端（余白 12 16 30・上に罫線・間 8）: 「‹ n/N」「n/N ›」の2つのボタン（それぞれ幅半分・高さ 44・角丸 12・`--rule` の枠）。
  端の段では押せないほうを `aria-disabled` にする
- **閉じ方は、覆いを押す・つまみを下へ払う・Esc の3つ**。閉じたら押した行へフォーカスを戻す

**顔と吹き出し**（入力欄の上。余白 上 10・左右 12、答え待ちの札との間 10）:

- 左に顔（34px の丸）、右に吹き出し（余白 9 12・角丸 14 14 14 4〔顔の側の下だけ尖らせる〕・地 `--surface-accent`・
  枠 `--surface-accent` を `--accent` へ寄せた色・13px・行の高さ 1.65）。下端を揃える
- **作業中も答え待ちも待ちも、最新の1件を常に出す**（セリフか、いま出す反応）。セリフも反応も無いときは顔だけを出す
- **吹き出しは3行で切って末尾を「…」**（`line-clamp: 3`。高さが変わって本文が揺れないように）。押すとセリフのログが全面で開き、
  そこで全文と過去のセリフを読む
- 立ち絵の表情の切り替えは顔の絵には映さない（顔はパックの `face` の1枚）

**答え待ちの札**（答え待ちのあいだだけ、吹き出しの下・入力欄のすぐ上に固定。本文を転がしても動かない）:

- 形: 角丸 16、地は `--state-warn` の 10% から 4% への縦の濃淡、枠は `--state-warn` の 45%、余白 14 14 12
- 頭（11.5px 太字 `--state-warn`）: **「？ 答え待ち」を必ず字で出す**（色だけで伝えない。13.1 原則1）。続けて「· 」と、質問なら `header`、
  許可ならツール名（字は `--ink-quiet` の細字）。質問が2問以上なら右端に「n / N」
- 問い（上 6・14.5px 太字・行の高さ 1.7）: 質問は問いの文、許可は「<ツール名> を実行してよい？」
- 等幅の札の並び（上 8・間 5・折り返す。1つは等幅 11.5px・地 `--surface-raised`・角丸 6・余白 2 7）: **質問なら添え書きの
  図の塊のうち最初の `list` の項目、許可なら `toolInputText` から取った対象（ファイルのパスかコマンドの1行）**。6つを超えたら
  6つまで出して「ほか n」（11.5px `--ink-quiet`）を添え、押すと板で全部を読む。どちらも無ければ並びを出さない
- 答え（上 12）: すべて高さ 44・角丸 12。**押した瞬間に答える**（狭い画面には「これで答える」を置かない。2問以上の質問は1問ずつ
  次へ進み、最後の問いで送る）。塗るのはおすすめの印のある選択肢（地 `--state-warn`・字 `--ground`・太字）、ほかは `--rule` の
  枠だけ。おすすめが無ければどれも塗らない
  - 2択: 2列（間 8）
  - 3〜4択: 1列に縦に積み（間 8）、頭に番号（等幅）を添える
  - 「その他」（自由記述）: ボタンにしない。入力欄が受け、置き文字を「答えを書くか、上で選ぶ」に変える
  - 複数選択: 1列の行を押すたびに印（✓）が付け外しされ、最後に塗った「これで答える」を置く（複数選択だけは押した瞬間に送らない）
  - 許可: 「拒否」「許可」の2列で、「許可」を塗る
- 添え書きのある質問は、頭の右に「詳しく」の文字ボタン（高さ 26）を置き、押すと板で添え書き（背景・判断の軸・選択肢ごとの良い点と
  悪い点・図）を読む。**板の中は 13.13「お伺い」の札の1列の形**（詳細を選択肢の下へ回した形）で、選んで答えることもできる
- 札の高さの上限は `50dvh`。超えたら札の中の問いと等幅の札の並びが転がり、答えのボタンは札の下端に残す
- 本文の中のお伺いの札（13.13「お伺い」）は狭い画面では出さない（同じものを2箇所に出さない）。入力欄の上の「お伺いへ」の帯も出さない

**入力欄**（余白 8 10 と下に `env(safe-area-inset-bottom)` を足した分、上に `--rule` の罫線、地 `--ground` を `--surface` へ半分寄せた色。
並びの間 8・下端揃え）:

- 左に ＋（40px の丸・`--rule` の枠・地は透明・20px の字 `--ink-quiet`。`aria-label` は「添える」）。押すと欄の上に3行の面が開き、
  **「画像を添える」（画像の添付〔`docs/requirements.md` 4.10〕のファイル選び）・「/ コマンド」（欄に `/` を入れて補完を開く）・
  「@ ファイル」（欄に `@` を入れて補完を開く）** を選ぶ。各行の高さは 44
- まん中に丸い欄（最小の高さ 40・余白 9 14・角丸 20・地 `--surface`・`--rule` の枠・14px）。打つと縦に伸び、上限は画面の高さの 30%
  で内側が転がる。置き文字はふだん「<キャラクターの名前>への依頼を書く」、質問の答え待ちは「答えを書くか、上で選ぶ」
- 右は1つの丸ボタン（40px）: **ターン進行中は止める ■**（`--ink` の 12px 角・角丸 3。`--rule` の枠）、**それ以外は送る ↑**
  （地 `--accent`・字 `--ground`。打った字が無いあいだは枠だけの無効の見た目）。進行中に打った字は送らず欄に残す（広い画面で送るボタンの席が「中断」になるのと
  同じ）。背景で作業中はターンが進んでいないので ↑ を出し、送った言葉は脇の話になる（`docs/architecture/display.md` 4.2「脇の話」）
- **■ を押すと、入力欄の上に「止める」「続ける」の2つのボタン（高さ 44・2列）の札を重ねて確かめ、「止める」で中断のコマンド
  （`session.interrupt`）を送る**。「続ける」・Esc・札の外を押すと閉じて何もしない。広い画面の「中断」は確かめずに止めるまま
- 押せる大きさはすべて 40〜44

**引き出し**（頭の右上の ≡ から右に出る面）:

- 後ろに `rgba(8,8,12,0.6)` の覆い。面は右端に付けて幅 330（画面がそれより狭ければ画面の幅から 60 引いた幅）、上から下まで、
  地 `--surface`・左に `--rule` の罫線と左向きの深い影。上の余白は 6 と `env(safe-area-inset-top)`、塊の間 12
- 名乗りの行（余白 左右 16・間 10）: 顔（28px）・部屋の名前（明朝 16px 太字・字間 0.08em）・短縮ID（等幅 12px `--accent`）。
  **顔を押すとキャラクターの選び口、短縮IDを押すと切り替え画面**（13.9「キャラクターの選び口」「切り替え画面」。どちらも
  引き出しの上に重なって開く）
- その下の1段（余白 左右 16・間 8）: 仕事・雑談の2つの門（広い画面の帯と同じ文字のタブ。押したときの扱い・ターン進行中の扱いも同じ）と、
  モデル・effort・許可モードの口。口の形は会話の画面のサイドバーの
  下端の帯と同じ絵だけの口（13.9「会話の画面の帯とサイドバーの下端の帯」）で、送るコマンドとターン進行中の扱いは広い画面のまま
- 切り替え（`role="tablist"`。左右 14・余白 3・間 4・角丸 12・地 `--ground`・`--rule` の枠）: 「やり取り / タスク / 使用量」の3つ
  （高さ 34・角丸 9・13px）。選んでいるタブは地 `--surface-raised`・字 `--ink`・太さ 600、ほかは地なし・`--ink-quiet`。
  雑談中は「タスク」が「話題」になる。開いたときは前に選んだタブ（ページを開いているあいだだけ覚える）
- **「やり取り」はこのセッションのやり取りの並び**（やり取りの列のやり取りの行と同じ材料。新しいものが下）。1行は列 16 と残り
  （間 10・余白 12 14・角丸 12）: 済みは `--state-ok` の ✓、いまの回は回る輪で地 `--surface-accent`。依頼の1行目
  （14px・行の高さ 1.55。済みは `--ink-soft`、いまの回は `--ink` の 600）と、下に「開始の時刻　所要」（等幅 11px。いまの回は
  「作業中 <経過>」）。**押すと引き出しを閉じ、本文をそのやり取りへ移す**（やり取りの列の行を押したのと同じ）
- 「タスク」はサイドバーのタスク一覧の区画、「話題」は雑談のときのサイドバーの4段、「使用量」は使用量の行とプラン使用量の札。
  どれも中身はサイドバーの部品のままで、引き出しの幅に合わせて縦に積む
- 下端（上に `--rule` の罫線・余白 14 16 と下に `env(safe-area-inset-bottom)`・間 8）: 「＋ 新しいやり取り」（残りの幅・高さ 44・
  角丸 12・`--rule` の枠・13.5px）と設定の歯車（44px 角）。**「＋ 新しいやり取り」は切り替え画面の「＋ 新しいセッション」と同じ
  `session.startNewSession`**（キャラクターもモードもいまのまま、続きを探さずに新規で起こす。ターン進行中か、委譲先が動いている間は押せず、理由は `title`）
- **歯車を押すと、引き出しの中身（切り替えとタブの中身）が設定の面に入れ替わる**。面の頭に「‹ 戻る」、先頭にキャラ・トークン・
  成果の3つの口（高さ 44 の行。押すと引き出しを閉じてその画面へ移る）、その下に設定の中身（設定のダイアログと同じ面のうち `FACES` の `inDrawer` の4つ〔見た目・セッションの既定・演出・タスクの実行〕を面の名前の見出し付きで縦に並べたもの。13.9「設定の歯車」）
- 閉じ方は、覆いを押す・Esc・≡ をもう一度押す。閉じたら ≡ へフォーカスを戻す
- 画面の字は「やり取り」のまま使う（やり取りの列と同じ語）。識別子は今のもの（やり取りの並びは `ReportOutline` の材料、新しく
  起こすのは `session.startNewSession`）

**ソフトウェアキーボードが出たとき**: 高さは `100dvh` のまま、ページの `<meta name="viewport">` に `interactive-widget=resizes-content` を
足して、キーボードのぶん `dvh` が縮むようにする（効かないブラウザでは、フォーカスした欄をブラウザが見える所へ送るのに任せる）。
縮んだぶんは本文が受ける。**入力欄にフォーカスがあるあいだは吹き出しを畳んで顔だけにする**（`:focus-within` で CSS だけで切り替える）。
答え待ちの札は問いと答えのボタンを残し、等幅の札の並びは1行に畳む。頭は畳まない。

**見本に無い場面**:

| 場面                         | 見え方                                                                                                                                                                                                |
| ---------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 待ち（依頼待ち）             | 頭の1行目は「依頼待ち」と、題の代わりに直前のやり取りの依頼の1行目（無ければ部屋の名前）。2行目は出さない。本文は直前のやり取り（無ければ始め方の一覧）                                               |
| バックグラウンドタスク       | 頭の状態の語が「背景で作業中」で、経過は数え続ける（13.9「バックグラウンドタスク」）                                                                                                                  |
| ターンの失敗                 | 頭の状態の語は 13.9「いまの作業」の表の判定のまま（ターンが失敗で終わっただけなら「依頼待ち」、セッションが終わったときだけ「止まっている」）。本文は最終レポートの頭に失敗の塊。吹き出しは失敗の反応 |
| 雑談モード                   | 頭の2行目を出さず、1行目の題の代わりに「雑談」。本文は雑談のログ（13.7。立ち絵は出さない）。最新のセリフはログの末尾にあるので、入力欄の上は顔だけで吹き出しを出さない                                |
| キャラ・トークン・成果の画面 | 頭の1行目の左を「‹ 会話へ」の口（高さ 36）と画面の名前にし、右の ≡ は残す。2行目は出さない。答え待ちが来たら状態の語が頭に出る                                                                        |
| 接続が切れた・会話が終わった | 入力欄の上の帯（13.13「お伺い」の切断・終了の帯）をそのまま答え待ちの札の位置に出す                                                                                                                   |

中身を持つ部品（サイドバーの区画・やり取りの並び・レポート・お伺いの選択肢・設定の中身）は広い画面のものを
使い、どこに出すかは各機能の CSS の `@media` で決める（`docs/architecture/browser.md`「CSS」）。狭い画面のために増えるのは、
頭・引き出し・板・答え待ちの札の器と、入力欄の ＋ の面と ■ の確かめの札。

#### 画面が5枚以上になったら

広い画面は横に並べるだけで伸びる。**狭い画面は引き出しの歯車の面の口が縦に伸びるだけ**なので、枚数が
増えても畳み方を変えずに済む（帯を2段にする・横スクロールさせる、のどちらも要らない）。
