## 13. 画面のデザイン

### 13.9 画面のナビゲーション

#### 設定の歯車

**帯のいちばん右端の歯車を押すと、左にナビ・右に面を置く 880×600 のダイアログが開く**
（2026-10-14 決定。ポップオーバーから替えた。ユーザーが見本の画を作って確定した:
`docs/history/mockup/settings-dialog-look-2026-10-14.png`（見た目）・
`docs/history/mockup/settings-dialog-session-2026-10-14.png`（セッションの既定）・
`docs/history/mockup/settings-dialog-reveal-2026-10-14.png`（演出）。旧ポップオーバーのモックは
`docs/history/mockup/settings-2026-09-23.png`）。置くのは 13.6 の表の3群とワークフローの値を、**5つの面**（`FACES` の行）に割る:
**見た目（地・領域・字の色）／セッションの既定（モデル・effort・許可モード）／演出（書き上げる速さ）／
タスクの実行（起動するスキル）／ワークフロー（スキルの並び。2026-10-14 に足した）**。

```
┌──────────────────────────────────────────────────────────────┐
│ ⚙ 設定                                                     × │  ← 頭（高さ 54）
├────────────────┬─────────────────────────────────────────────┤
│ あなたの好み    │ 見た目                                       │
│ ▌🎨 見た目     │ ┌ 領域の中の字  地の上の字 あ Aa        ○ ┐ │  ← 見本の帯
│   ≡ セッション │ 地の色        ■ #16151c                      │
│     の既定     │ 領域の色      ■ #1c1b24                      │
│   ✦ 演出       │ 字の色        ■ #e4e2ea                      │
│                │                              [既定に戻す]    │
└────────────────┴─────────────────────────────────────────────┘
```

- **歯車は枠も地も無い 36px の四角に、線画の歯車（18px の SVG・`currentColor`）だけを置く**
  （2026-09-23 決定。見本の `<header>` の形。字の「⚙」はフォントで大きさも太さも揃わないので
  使わない）。字は `--ink-quiet`、押すと `<dialog>` が開く
- **箱は幅 880・高さ 600（画面の 86% まで）・角丸 16・枠 1px の `--rule`、背景は暗く沈める**（`ui/dialog` の
  `backdrop="dim"`）。**頭は高さ 54**で、左に歯車の線画と「設定」、右に閉じる ×（`aria-label` は「閉じる（Esc）」）、
  下に罫線
- **左ナビは幅 232**。見出し「あなたの好み」の1群に、「見た目」「セッションの既定」「演出」「タスクの実行」「ワークフロー」の5項目（高さ 36・角丸 9・13.5px）。
  「ワークフロー」だけはリポジトリに属する値だが、「このリポジトリ」の群は作らず同じ群に置く（どのリポジトリかは面の見出しの下で言う。2026-10-14 利用者決定）。
  **選んだ項目は、左端の差し色の縦線（幅 3）・薄い差し色の地・太字・差し色のアイコン**で示し、別の項目を選ぶと
  選んだ項目へ移る（色だけで伝えない）。差し色は `accent`（パックの持ち物）で、16 進は書かない。
  **ダイアログを開くたび「見た目」から始まる**。面は `FACES` の配列に1行ずつ宣言するので、足すときは1行書けばナビと面が出る（引き出しに出すかも行の `inDrawer` で宣言する）
- **右の面は内側 22/28。面の名前は 18px の太字で、書体はアプリの既定**。行は「名前 132 ＋ 操作 1fr」の2列・
  列の間 20・行の上下 12・行の間に細い罫線。字の下限は 12px。**下の帯は右端の「既定に戻す」だけ**で、
  ワークフローの面には出さず、ワークフローの面は自分の下の帯（やめる・保存）を持つ（色を戻す押し口が色と関わらない面に残ると、押した結果が面に現れない。面ごとに `FACES` の `foot` で宣言する）
- **ワークフローの面**は利用者の見本（`docs/history/mockup/workflow-setting-2026-10-17.png`）の形。面の名前の下に「<作業ツリー名> のリポジトリ」の太字と `.tw/config.toml` の絶対パス（どこでも折り返す）を置き、
  罫線で区切って欄を並べる。欄は `tw config --schema` が返した順で、並びの欄だけ（`schema: 2`）。欄の頭は `label`（14px 太字）と、右に `description`（12px の薄い字）。
  欄の `steps`（スキルの並び）は上から次の順に置く:
  - **流れの帯**（角丸 12・内側 10/12 の枠）に、並びの順で「<番号> <`title`>」の札（高さ 28・角丸 14）を「→」でつなぐ。並びを変えるとその場で変わる。「着手」「完了」の語は出さない
  - **行の札**（細い線・角丸 12・間 10）。左からつかむ点（6つの点 2×3、各 3px・間 3px）・番号の丸（24）・名前（`title`、14px 太字）と識別子（`label`、等幅 12px）・その下に説明（`description` を1行で切り、全文は `title` 属性）・右端に「…」。番号の丸どうしを細い縦線でつなぐ。
    候補に無い今の値は行に残し、名前の位置に値を出して「候補に無い」の印を付ける。保存前の並びと位置が違う行（足した行を含む）は、枠を `--state-warn` にして「● 並びを変えた」の字を添える
  - **つかんで並べ替える**: つかむ点（押し口 24×40、名前は「<`title`> を動かす（↑↓ キーでも）」）をポインタで押したまま動かすか、
    フォーカスして Space でつかみ ↑↓ で動かし Space で置く。Esc はつかむ前の位置へ戻し、ダイアログは閉じない。つかんでいるあいだは、つかんだ札を差し色の枠と浅い影で少しずらして浮かせ、
    置き場所を行の間の差し色の線で示す（行そのものは動かさない）。置いた結果は下書きに入り、読み上げに「<`title`> を <n> 番目へ置いた」などの1文を渡す（`aria-live`）。
    並びが1つだけのときと書いているあいだは、つかむ点を押せない。つかむ操作が使えないときの手段として「…」の並べ替えを残す
  - **「…」**は いちばん上へ／ひとつ上へ／ひとつ下へ／いちばん下へ／並びから外す（区切りの下、失敗の色）。先頭の上へ2つ・末尾の下へ2つ・最後の1つの外すは押せない。開くと最初の押せる行にフォーカスし、↑↓ で巡り、Esc でメニューだけ閉じる
  - **並びに入っていないスキル**: 候補（`values`）のうち並びに無いものを、小見出し「並びに入っていないスキル 押すと最後に足す」の下に点線の札「＋ <`title`> <`label`>」で並べ、押すと並びの最後に足す。
    無いときは点線の行「足せるスキルはない（<数>つとも並んでいる）」を押せない字で出す
- **ワークフローの面の操作は下書きだけを変え、保存するまで書かない**。下の帯は変更中だけ左に「● 並びを変えた」（1つ外しただけなら「● <`title`>を外した」）を出し、右に「やめる」「保存」（変更が無いときと書いているあいだは押せない）。
  保存で、並び全体を1回の `tw config set` で書いて返った値で描き直す（押した側へ先に倒さない）。ワークフローが値を断ったら、その欄の下に理由を1行出し、下書きは残す。やめるで今の値に戻す。
  **下書きがあるまま面を切り替える・ダイアログを閉じると、下書きは黙って捨てる**（確かめない。面を開くたびに読み直す）。
  `tw` が無い・設定コマンドを持たない・`.tw/config.toml` が無い・読めないときは
  欄を出さず、リポジトリの行の下に何が無いかを1文で言い、ナビの項目は残す（`docs/architecture/workflow-contract.md`「設定コマンド」）
- **見た目の面は、先頭に3色の見本の帯**（高さ 54・角丸 10。「領域の中の字」を領域の色の地で、「地の上の字 あ Aa」を字の色で、
  右端に差し色の輪）。輪は `title` で「差し色はキャラクターが決める」と伝える（差し色はここでは選べない）。
  色の操作は 30×30 の色見本の四角（`<input type="color">`）と16進の読み出し
- **閉じ方は Esc・×・背景の押下**。閉じたら歯車へフォーカスを戻す（`<dialog>` の `close` が届く1箇所）。外側の `pointerdown` の
  購読（`use-dismiss-signal.ts`）は使わない。狭い画面（760px 以下）は歯車が帯から消え、引き出しの設定の面が
  `FACES` の `inDrawer` の4つの面（見た目・セッションの既定・演出・タスクの実行）を、面の名前の見出し付きで縦に並べ、末尾に「既定に戻す」を1つ置く
  （面の中身はダイアログと同じ部品で、色の面にも見本の帯が出る。演出の行名もダイアログと同じ「書き上げる速さ」。ワークフローの面は引き出しには置かない）
- **色の操作子は `<input type="color">` のまま**（キャラクター画面にあったものをそのまま移した。
  13.6）。**検証も保存も `src/browser/domain/appearance-color.ts` のまま**で、`ground` と `ink` の
  コントラストが下限を割る色は受け取らない（13.2）。**受け取らなかったときは、色の行の下に
  理由を1行出す**（どちらの色との差が足りないか。黙って元の色へ戻すと、選んだ色が効かない
  不具合に見えるため）。次に受け取られたとき・既定に戻したとき・面を閉じたときに消える
- **「既定に戻す」は群ごとに1つ**（色ごとには置かない）。3色を一度に既定へ戻すほうが、
  「1色だけ戻す」より欲しくなる場面が多い（読みにくい組み合わせから抜けたいとき）。
  **上書きが1つも無ければ押せない**（戻す先が無いことを、押せるかどうかで表す）

#### 顔

**帯の左端、部屋の名前の左に、いまのパックのキャラクターの顔を丸く切り抜いて出す**
（2026-09-23 決定）。キャラクターを替えると変わる。

- **素材は `character.json` の新しい欄 `face`**（ファイル名1つ。立ち絵と同じ種類のファイルを
  受け付ける。正方形を勧める）。検証は `src/shared/character-pack/character-definition.ts`、画面へは
  `CharacterInfo` に `/character/<pack>/<file>` の URL として載せる（`mini` と同じ経路・同じ取り直しの印）
- **表情では変わらない1枚**（`mini` と同じ）。表情はキャラビューの立ち絵が持つ
- **丸く切り抜く**（`border-radius: 50%` と `object-fit: cover`）。透過の絵の縁が帯に溶けない
  ように、丸の地を `--surface-accent` で塗る。**大きさは 36px の固定値**で、外側に差し色の 1px の輪
  （`box-shadow: 0 0 0 1px var(--accent)`。2026-09-23 に 2px から細くした）を掛ける。帯の高さから
  の式にしないのは、高さが 52px に決まって式で追う理由が無くなり、式のままだと狭い画面の顔
  （頭の 30px・引き出しの 28px・吹き出しの 34px）まで帯の高さに引きずられるため
- **定義に `face` が無いパックでは何も出さない**（部屋の名前だけの、いまの見え方）。空の丸も
  頭文字の丸も出さない。**`mini` や立ち絵から切り抜いて代わりにしない**（下の「採らなかった案」）
- `alt` はキャラクターの名前（パックの `name`）。部屋の名前と並ぶので、読み上げは
  「<キャラクターの名前> <部屋の名前>」になる
- **同梱パックには足す。** `tsukumo` は `default.png` から顔を切り出した1枚、`tsukumo-spirit` は
  `default.svg` の `viewBox` を顔に寄せた1枚
- **キャラクター画面から差し替える／外せる**（2026-09-25 決定。それまでは定義を手で直す
  だけだった）。詳しい設定に「顔」の区画を足し、口は背景と同じ「差し替える」「消す」の2つ
  （`docs/architecture/character-pack.md`「画面から作るときの置き場と受け取り方」）。受け付ける形式・大きさの上限は立ち絵と同じ（`.svg` / `.png` /
  `.gif`）——写真が主な素材の背景よりも、立ち絵と同じ「キャラクターの絵」という素材の性質に
  近いため
- **部品は `browser/components/domain/character-face.tsx` へ上げて共有する**（帯とサイドバー〔雑談の
  プロフィールの札〕・キャラクター画面は互いに import しない領域どうしなので、機能をまたいで読む部品は
  `components/` に置く。`docs/architecture.md`「機能の中を分ける」）。大きさと丸の地は置く側の `className` が決め、
  部品自体は領域の見た目を持たない
- **帯の顔は押せる**（下の「キャラクターの選び口」）

#### キャラクターの選び口

**帯の顔の右下に小さな「⌄」を添え、顔を押すとキャラクターの一覧が顔の真下に重なる**（2026-09-27
ユーザー決定。見本 `docs/history/mockup/session-switch-2026-09-27/HD-4-IdTag.png`）。選ぶと
`session.switchCharacter` を送る（起こし直し。キャラクターの編集の「このキャラクターに切り替える」と同じコマンド）。

- **「⌄」は 16px の丸に 10px の下向きの矢印**（地 `--surface`・枠 `--rule`。ホバー・開いている間は
  枠を `--accent`）。顔そのものの大きさと輪は上の「顔」のまま
- **一覧は「いまの作業」の一覧と同じ形のポップオーバー**（`--surface` の地・`--rule` の枠・角丸）。行は顔の
  縮図（24px）と名前で、**いまのキャラクターの行は枠と地と「使用中」の字**で示す（色だけで伝えない）。
  いまのキャラクターを押しても送らず閉じるだけ
- **ターン進行中か、委譲先が動いている間はほかのキャラクターの行を押せない**（起こし直しなので。理由は `title` に定型文）
- 閉じるのは、もう一度顔を押す・外側を押す・Esc（Esc のときはフォーカスを顔へ戻す）。**プルダウン
  （`<select>`）にしない**——ブラウザの選択肢の一覧には顔を出せず、帯の顔から開くのに一覧が名前の
  文字だけになるため
- 狭い画面では引き出しの名乗りの行の顔から同じ一覧が開く（名乗りの行の下に、引き出しの幅いっぱいで重なる）
