# 画面のデザイン: 成果の画面

ステータス: **正典**。入口は `docs/architecture/screen-design.md`（画面のデザインの全体）。

責務: 成果の画面（つくもの日記帳）の並び、日記の区画、しおり、小さな驚き、色、灯りの暦、空の日の見え方。
読む時: 成果の画面に触るとき。
直す時: 並べるもの・灯りの暦・空の日の見え方を変えたとき。見開き（日記帳）は 13.10 の続きで、`docs/architecture/screen-design.md` の同じ見出しが指す子。

## 13. 画面のデザイン

### 13.10 成果の画面

**終えたタスク（Beads の閉じた課題）を1日ぶんずつ見て、キャラクターがその日の日記を書く画面**（数を見る画面として決めたのを、
「つくもの日記帳」へ作り替えた）。目的は
「**キャラクターが自分の仕事をちゃんと見ていてくれて、それが後から読み返せる形で積もっていく**」
楽しさ。
数え方・卒業と節目・灯りの段階・依頼の文面は `docs/requirements.md` 4.11、データの受け取り方は
`docs/architecture/shared-contract.md`「成果は `SessionState` に入れない」、日記の保存の形は `src/server/diary/adapter/diary.ts` の冒頭、語は
`docs/glossary.md`「日記」「日記帳」「しおり」「灯りの暦」「卒業」「節目」。
帯の4つ目の口「成果」から開き、hash は `#achievement`（`Screen` の `achievement`）。
**開いただけでは日記を書かせない。**

場面は見本の5つ（下の「見本」）で、上から順に (a) ふだん・(b) 振り返り中・(c) 書き終わり・
(d) 暦の日を押す・(e) まだ振り返っていない日を押す。

```

 │ │ 月 火 水 木 金 土 日 × 5段                │                        │
```

#### 並べるもの

(a) ふだん。上から5つ。**読む面の色は受け取らない**（13.1 原則1）ので、キャラクターの色
（`--accent`）は日記の区画の枠と吹き出し・ボタン・灯りにだけ載せる。**前日比と連続日数は
置かない**（数を競わせる画面にしない。ユーザーの決定）。

1. **日の切り替え**: 画面の題「成果」の右に「‹」「›」の2つの `<button>` と、あいだの日付。
   日付は「9月24日（木）」の形（年は今年でなければ添える）。「今日」「昨日」は添えない
   （日によって有る無しが変わり、行の高さが動くため）。**今日を見ているときは「›」を `aria-disabled` にし、「今日へ」は出さない**。今日以外
   を見ているときは「›」の右に「今日へ」を出す。「‹」は制限しない（リポジトリより前の日は空の日
   として出る）。**見ている日は hash の `?date=YYYY-MM-DD` に持つ**（13.6 の `pack` と同じく、
   画面の上に乗る付随情報。リロードで同じ日に戻り、ブラウザの「戻る」で前に見た日へ戻れる）。
   `date` が無い・読めないときは今日
2. **灯りの暦**: 下の「灯りの暦」
3. **日記の区画**: 左に立ち絵、右に頭の行・吹き出し・数の札・振り返りのボタン。
   - **頭の行**: 「<名前>の日記」・「振り返り [21:40]」（いちばん新しい段落を書いた時刻）・右端に
     「日記帳で読む」（押すと見ている日の見開き (d) が開く。日記が無い日は押せない）。名前と立ち絵は**書いたときのパック**
     （日記に残した名前と顔。下の「書いたパックが無いとき」）
   - **吹き出し**: いちばん新しい段落だけを出す（書き足した日の前の段落は見開きで読む。仮）。
     書体は**端末の明朝体**（13.3 の例外）。本文は切らない
   - **立ち絵**: 書いたパックの立ち絵を、日記に残した表情で出す。日記が無い日はいまのパックの
     立ち絵を `default` で出す
   - **日記がまだ無い日**: 吹き出しの代わりに、枠を点線にした空の吹き出しに「まだこの日の日記は
     無い。」の1行。頭の行の時刻は出さず、「日記帳で読む」は押せない（`aria-disabled`）
   - **数の札は1枚**: 「終えたタスク」。大きい数字（等幅。寸法はトークン消費の
     画面の札の数と同じ）と項目名だけ。幅は区画の右の列の半分（コミットの札は無く、
     2枚だったときの1枚ぶんの幅のまま）
   - **振り返りのボタン**: 文言は「**<パックの名前>と振り返る**」（いまのパックの `name`。
     キャラクターの名前をコードに書かない。原則4）。枠と字が `--accent` の、地を塗らない形
     （見本の形。主ボタンの塗りは見開きの「この日を振り返る」に使う）。**その日の日記が既に
     あっても押せる**——押すと書き足す（`docs/requirements.md` 4.11「日記」）
4. **しおり**（この日のいちばん）: 「<名前>が選んだ この日のいちばん」の見出しと、タスクの ID
   （等幅）・`summary`・「」で括った理由の3行。**日記が無い日・しおりの無い日記（終えたタスクが
   0の日）は区画ごと出さない**
5. **小さな驚き**: 見出し「小さな驚き」と添え書き「この日に起きた特別なこと」、その下に札を
   横に並べる（3枚で折り返す）。札は2種類で、**どちらも無い日は見出しごと出さない**:
   - **先輩タスクの卒業**: ID と `summary`、下の行に「登録から N 日」と「M月D日から、
     おつかれさまでした」
   - **節目**: 「通算 500 件目のタスク」（数は3桁ごとに区切る）と、
     下の行に「T-xxx が 500 件目になりました。」
     **画面全体の幅は 60rem**（40rem から広げた。`.achievement` の `max-width`）。
     40rem のままだと日記の吹き出しの本文幅が狭く、全角250字ほどの日記が9行に折り返していた
     （同日のフィードバック）。**広げるのは日記の区画だけでなく画面全体**——しおり・小さな驚き・
     灯りの暦も同じ列に縦に並ぶので、区画だけをはみ出させると下のカード列と幅が揃わなくなる。
     60rem はトークン消費の画面（`src/browser/components/page/token-usage/token-usage.module.css` の
     `.token-usage`）と同じ値で、新しい数値を作らず「1枚で縦に流す画面」どうしで幅を揃えた。
     本文の字の大きさ・書体（13.3）は変えない。

**終えたタスクの
一覧はこの画面に置かず、見開きの左ページ（d）へ移した**（区画が5つに増え、一覧まで並べると
日記より長くなる。一覧を読むのは日記を読み返すときなので、日記の隣に置く）。
**`develop/progress.md` の小節も並べない**（`docs/requirements.md` 4.11「何を数えるか」）。

**書いたパックが無いとき**（日記を書いたあとでパックを消した・名前を変えた）: 名前は日記に残した
ものを出し、立ち絵と顔は出さない（フォールバック。いまのパックの絵で代えない——別の誰かが
書いたように見えるため）。

**色**: しおり・小さな驚き・日記ありの鈴に使う金色は、`--state-warn`（答え待ち・注意の意味の色）を
流用しない。トークン消費の画面の `--usage-*` と同じく、**この画面の中でだけ使う固定の色**として
`theme.css` に足した（値は見本 `docs/history/mockup/achievement-diary-2026-09-25/
SEIKA-4a-Base.dc.html` から取った。しおり・小さな驚きの卒業の札・節目の札で見本が微妙に違う
色相を使っているところは、どれも「小さな驚き」1つの概念の下なので1系統に簡略化してある）:

| トークン                 | 使う場所                                                             |
| ------------------------ | -------------------------------------------------------------------- |
| `--diary-gold`           | アイコンの地・節目のアイコンの地・灯りの暦の「日記あり」の鈴         |
| `--diary-gold-strong`    | いちばん明るい字（しおりの要約・節目の数）                           |
| `--diary-gold-ink`       | 見出し・ラベルの字（しおりの見出しと理由・「通算」「件目のタスク」） |
| `--diary-gold-ink-quiet` | 控えめな字（タスク ID・卒業の日数のラベル・添え書き）                |
| `--diary-gold-surface`   | しおり・節目・卒業の札の地                                           |
| `--diary-gold-border`    | しおり・節目・卒業の札の枠                                           |

金色の要素にはどれも文字のラベル（「この日のいちばん」「先輩タスクの卒業」「節目」「日記あり」）
が必ず添う（13.1 原則5）。日記の区画・吹き出しはキャラクターの色（`--accent`／導出の
`--surface-accent`）をそのまま使い、新しいトークンは足さない。

#### 灯りの暦

**直近5週の日ごとの成果を、狐火の灯りで並べる**（見本 a）。見出し「灯りの暦」と添え書き
「成果のあった日に狐火がともります · 押すとその日を選びます」、右に凡例（灯りなし・ほのか・ともる・
明るい・日記あり）。

- **並び**: 月曜はじまりの7列 × 5段。最後の段は今日を含む週で、その週の今日より後の日は日付を
  薄く出すだけ（灯りも鈴も出さず、押せない）。範囲は最初の段の月曜〜最後の段の日曜で、暦の下に
  「8月24日〜9月27日」の形で添える。日付は月の初日と最初のマスだけ「9/1」の形、ほかは日だけ
- **1マス**: 左上に日付、まん中に灯り（段階ごとの狐火の形。灯りなしは中抜きの輪郭だけ）、右上に
  **日記ありの鈴**（その日に日記があるときだけ）。**今日のマスは下に「今日」を添え、見ている日の
  マスは枠を `--accent` にする**
- **灯りの段階**は4つ（灯りなし／ほのか／ともる／明るい）で、区切りは `docs/requirements.md`
  4.11「灯りの段階」
- **押すと**、画面の見ている日が変わるだけで、見開きは開かない（日記帳は日記の区画の「日記帳で
  読む」か書き終わりの知らせから開く）。マスは `<button>` で、読み上げは
  「9月16日、灯り ともる、日記あり」の形
- **届くまで**は「…」を出さず、届いたあとと同じ大きさの空のマス35個と範囲ラベルの空行を置く
  （届いても下の区画が動かない）
- **暦は見ている日によって動かない**（いつも今日を含む5週）。見ている日が5週より前なら、どの
  マスにも見ている日の枠が付かない
- 読めないときの暦の出し方は `docs/requirements.md` 4.11「数えられない・読めないとき」

#### 空の日・数えられないとき

読めない・数えられない場面の出し方は `docs/requirements.md` 4.11「数えられない・読めないとき」。ここは読める日の見え方だけ。

| 場面                      | 見え方                                                                                                                                                 |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 空の日（終えたタスクが0） | 札は **0 のまま出す**（消すと日によって画面の形が変わる）。吹き出しの場所に「この日に終えたタスクは無い。」の1行。ボタンは押せない。暦のマスは灯りなし |
| 取りに行っている間        | 前に出していた日の中身を薄くして残す（新しい日の数が届いたら差し替える）。初めて開いたときは札の数を「…」にし、吹き出しは空の枠                        |
