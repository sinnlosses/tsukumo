## 13. 画面のデザイン

### 13.6 設定の置き場所

**画面の差し色を編集する口の形**（2026-09-23 決定）:

- **コマンドは `characterPack.setAccent`（`target: "work" | "chat"` で1つの色を差す）と、雑談の差し色を消す
  `characterPack.clearChatAccent` の2つ**。`target` を引数で分けた（型を割らない。採らなかった案は `docs/history/decision.md`「screen-design.md 13.6 設定の置き場所（差し色を編集する口の形で採らなかった案）」）
- **`accent`（仕事）を消す口は無い。** `accent` は画面全体の色の元なので、消すと戻り先が無い。
  戻す口を持つのは「決まっていること」どおり `chatAccent` だけ
- **`character-definition.ts` に最上位の欄を書く関数を足した**（`definitionWithAccent` /
  `definitionWithoutChatAccent`）。既存の `editedDefinitionJson` は `portraits` /
  `background` という**入れ子**の1件を差し替える形なので、そのまま `group` を
  省略可能にはせず、入れ子を重ねない `editedTopLevelDefinitionJson` を別に置いた（採らなかった案は同じ節）
- **雑談の差し色が無いときの色見本は、いまの仕事の差し色（引きずり中の値も含む）をそのまま出す。**
  仕事の色をドラッグしている最中も雑談側が一緒に動く。**「仕事と同じ」であることは色だけで
  伝えず**、戻す口の場所に同じ字を添える（13.1 原則1）
- **送信の debounce は仕事・雑談の差し色で同じ定数（`ACCENT_DEBOUNCE_MS`）を使う。** どちらも「ドラッグ中の色を
  離れてから1回にまとめる」という同じ操作なので、間隔を2つに分ける理由が無い

**作るダイアログ**（キャラクター画面の一覧の下の「新しく作る」から開く。独立した画面ではなく
キャラクター画面の上に重なるダイアログ。2026-09-24 に見本
`docs/history/mockup/character-create-2026-09-23.html` / `.png` へ作り直した。それまでは
`#character/new` という独立の画面で、左上に「← キャラクターへ戻る」を持っていた
〔2026-09-17 決定〕）:

```
（キャラクター画面の上に、覆いごと重なる）

           新しいキャラクター

┌────────────────┐  名前 [__________________]
│                │   画面や吹き出しに出る名前
│  いつもの顔の   │
│   立ち絵        │  id  [__________________]
│  画像をドロップ、│   半角の英数字と . _ - …。保存するフォルダの名前になります
│  または押して選ぶ│
│ ほかの表情はあと │  画面の差し色
│  から足せます    │  [■ 仕事 #..] [■ 雑談 #..]
└────────────────┘
[ 立ち絵から生成   ]
 置いた立ち絵から名前・id・差し色・人格を書きます…

 人格
┌──────────────────────────────────────────────┐
│                                              │
└──────────────────────────────────────────────┘
 口調や性格を書く。空なら人格なしで作る

 背景は、作ったあとに設定できます          [やめる] [作る]
```

- **「立ち絵から生成」は立ち絵を置くまで押せない。** 押すと「生成中…」に変わり、そのあいだは
  「作る」も押せない。生成できたら id・名前・差し色2つ・人格の5つの欄を上書きし、利用者が直してから
  「作る」を押す。生成できなかったときはボタンの下の一言が「生成できなかった。…」に変わるだけで、
  欄と立ち絵には触らない（`docs/architecture/character-pack.md`「画面から作るときの置き場と受け取り方」）
- 人格の欄は「プロフィールを設定する」のダイアログと同じ見た目の入力欄（上限も同じ 8000 文字）。高さ 900px の
  窓でも「やめる」「作る」が見えるよう、**操作ボタンの帯はダイアログの下に固定し、その上の
  中身（見出し・格子・人格）だけがスクロールする**

- **開閉は呼び出し側（`hooks/use-character.ts`）の state**（`<dialog>` は常にマウントし、`open` に
  開閉だけを追随させる。既存の `<dialog>` と同じ形〔`task-board/hooks/use-task-board.ts`〕）。
  **表示上の状態なので URL には持たせない**——`#character/new` という独立の hash は無くなった
  （`stores/location-hash.ts`）
- 中身は `docs/requirements/character-pack.md` 4.4「新しく作る」のまま（名前・id・`default` の立ち絵・画面の差し色2つ・人格）。
  **名前と id を別の欄に分ける**（見本に合わせる。`docs/requirements/character-pack.md` 4.4「id と表示名を分けて受け取る」）。
  id の欄の下には、空・形が合う間は静かな案内、崩れたら理由（形が合わない／もう使われている）が
  出る（見本の「英数字とハイフン」は規則より狭いので、id の案内文はいまの規則
  〔`isCharacterPackName`〕に合わせて書き直した）
- **作れたら自動で閉じ、一覧で作ったパックを選んだ状態にする。** 「このキャラクターに切り替える」
  は出さない——**切り替えない**のは `docs/requirements.md` 4.4 のままだが、**切り替える口も作るダイアログには置かない**
  ように改めた（2026-09-24 決定。それまでは作るダイアログの中に切り替える口があった
  〔2026-09-17 決定〕）。切り替えは一覧で選んだあと、`<CharacterEdit>` の詳しい設定にある
  「このキャラクターに切り替える」（13.6 冒頭「使用中以外のパックも右側でそのまま直せる」）で行う
- **「やめる」・Esc・backdrop のクリックはどれも閉じる。** 閉じるたびに呼び出し側が下書きを
  空へ戻す（`key` で作り直す。`docs/coding-standards.md`「useEffect の代わりに使うもの」の
  「props が変わったら state を捨てる」）ので、次に開いたときは常に空の状態から始まる
- 表情を足すのは、選んだあとのキャラクター画面（作る口には持ち込まない）
- **画面の分け方・入る口・並べ方で採らなかった案**は `docs/history/decision.md`
  「design.md 13.6 設定の置き場所（採らなかった案）」

- 色は**境界で検証してから** CSS 変数に流す（13.5）。読めない組み合わせが来たら受け取らずに既定へ落とす
- サイドバーは**タスク一覧の区画と下端の帯**（`docs/architecture/display.md`「各表示物」）。
  「いま何をしているか」の区画は 2026-09-23 に帯の「いまの作業」へ移した（13.9）。
  **下端の帯は区画ではなく**（`.sidebar-footer`。見出しを名乗らず、左右いっぱいに広がり、上端の罫線と
  一段沈んだ地で区画と切り分ける）、中はモデル・effort・許可モードの口とコンテキスト・プラン使用量の目盛り
  （13.9「会話の画面の帯とサイドバーの下端の帯」）。
  キャラクターとセッションの切り替えは 2026-09-27 に帯の左上へ移した（13.9「キャラクターの選び口」・
  「切り替え画面」）
