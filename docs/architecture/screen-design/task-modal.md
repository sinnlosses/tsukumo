ステータス: **正典**。入口は `docs/architecture/screen-design.md`（画面のデザインの全体）。

## 13. 画面のデザイン

### 13.12 タスクのモーダル

サイドバーの「一覧を見る」で開くモーダルの見た目（2026-09-28 決定）。**左に一覧、右に選んだタスクの
Markdown の詳細**で、見本は `docs/history/mockup/task-board-2026-09-28/` の `TASK-1-List.dc.html`
（一覧と詳細）と `TASK-2-Jump.dc.html`（待ちの ID から前のタスクへ飛ぶ）、1440 幅で撮った同名の `.png`。
**値は見本のインラインの style と画面下の「説明」の節が正**で、ここにはその要点と、見本の色を
トークンへ写した対応だけを置く。中身とふるまい（本文の出どころ・絞り込み・検索・ID のつながり）は
`docs/architecture/display.md`「タスクのモーダル」。

- **箱**: 1320×780（窓より大きくしない）・角丸 18・帯の下に少し空けて横の中央（見本は上から 84）。
  地 `--surface`・枠 `--rule`、背景は `<Dialog backdrop="dim">`。見出しの帯は上下 14・左右 20
- **最新化の ↻**（2026-10-12）: 見出しの帯の件数の右・キーの案内の左に、閉じるボタンと同じ 34px・角丸 9 の枠（`--rule`）で置く。
  サイドバーの見出しでは枠なしの 24px（1.5rem）で「一覧を見る」の左。読んでいるあいだは `--accent` で 1 秒に1回転する
- **字の大きさは見本のまま**（20px のタイトル・16px の本文の見出しなど、13.3 の段に無い値も寄せない。
  切り替え画面〔13.9「切り替え画面」〕の 30px の ID と同じく、このモーダルの中だけの値）
- **左の一覧**: 幅は既定 470 で、詳細との境の仕切り（`LayoutResizer`）をドラッグして 300〜760 の間で
  変えられる（詳細には 360 を残す。幅は `localStorage` に保ち、再読み込み後も同じ）。詳細が残りの幅。検索欄は高さ 36、絞り込みの札は高さ 30・角丸 15・
  間 6。行は上下 10・左 16・右 14 で、1段目は ID 12px 等幅・状態 12px、2段目は要約
  13px・行間 1.55・2行で省略。**選んでいる行は `--surface-accent` の地と左端 3px の `--accent`**
  （色だけで伝えないため、左端の帯の形も添える）。選んでいる絞り込みの札は一段明るい地と字
  （`--surface-raised`・`--ink`）
- **状態の印**: 着手できる → `--accent` の点＋「着手できる」、待ち → `--state-warn` の輪＋「待ち <ID>」、
  保留 → `--ink-quiet` の字＋一時停止の印＋相手の ID、
  ドラフト（2026-10-11）→ `--ink-quiet` の字＋「ドラフト」。サイドバーの行とのぞき窓の印は `--ink-quiet` の破線の丸
  （空の丸の未着手と同じ 12px で、枠だけ破線）
- **属性の札**（2026-10-11）: タスクの `difficulty`・`loopable` は、ラベル（枠付きの札）とは別の欄で出す。
  サイドバーの行は幅が狭いので属性を出さない（題の幅を取るため）。モーダルの左の一覧の行は1段目の右端に、字を使わずアイコンだけで置く
  （2026-10-17）。`difficulty` は点3つ（5px・間 2px）のうち haiku 1・sonnet 2・opus 3 を `--ink` の 80% で塗り、残りは `--rule`。
  `loopable` が `Y` のものだけ点の左に lucide の `Repeat`（12px・`--ink-quiet`）を添え、`N` は何も出さない。
  どちらも名前は `role="img"` の `aria-label` に持つ。詳細の情報の表の「難しさ」「ループ」の2行は字の札
  （等幅・`--font-label`・`--ink-quiet` で枠なし。`loopable` が `N` のものだけ `--state-warn` の枠と字）
- **右の詳細**: 上下 22・左右 28。ID 13px 等幅＋status の札、タイトル 20px 太字、情報の表 12px
  （行の間 8・角丸 10）。本文は 14px・行間 1.85、見出しは 16px 太字＋下線、コードは 12px 等幅、
  チェックは 14px。詳細は内側で縦に転がし、見出しの帯と下の操作の帯は動かない
- **下の操作の帯**: 高さ 64。ボタンは高さ 36（「tsukumo に頼む」だけ 40）。「tsukumo に頼む」は
  `--accent` の地で、押せない間は薄くして横に理由の字を添える。ドラフトでは代わりに
  「却下する」（枠。高さ 36）と「計画する」（`--accent` の地。高さ 40）を右寄せで並べる
- **ドラフトの仕分け**（絞り込み「ドラフト」のとき。見本 `docs/history/mockup/task-board-draft-batch-2026-10-24.html`）:
  行の右端に3択（計画・却下・保留）を枠 `--rule-soft`・角丸 8 の1つの組で出す。札は `--font-label`・高さ 28 以上で、
  選んだ札は左の「●」と字の色でも言う（計画は `--state-ok`、却下は `--state-ng` の字と同じ色の 18% の地、保留は `--ink` の字と `--surface-raised` の地）。
  却下の行は要約の下に「却下の理由:」と1行の入力欄を出す。下端の帯は箱の全幅で、高さ 64・左に「仕分けを戻す」（枠。高さ 36）と
  `--ink-quiet` の「保留の n 件は触らない」、右に「計画 n・却下 m を頼む」（`--accent` の地。高さ 40）。
  帯が出ているあいだは詳細の下の操作の帯を出さない
- **つながりの札**（見本2）: 高さ 38・角丸 9・間 6、地 `--ground`・枠 `--rule`。ID 12px 等幅＋状態＋
  要約 13px（1行で省略）＋右端に ›。札の見出しは 12px で、「先に終わっていてほしいもの」は
  `--state-warn` の字、「これを待っているもの」は `--ink-quiet` の字
- **パンくず**（見本2）: 12px・高さ 20。「‹ <ID> に戻る」はリンクの色、区切りの › は `--ink-quiet`、
  いまの ID は等幅。「絞り込みの外」の添え書きは 12px の `--ink-quiet`
- **読み込み中**: 起こしてから最初の一覧が届くまで、サイドバーのタスクの節とこのモーダルの中身は、
  行の形をした帯3本（高さ 14・角丸 4・幅は 88%・72%・80%、色は `--ink` を 10% 重ねた色）で描く。
  文字の「不明」「読めない」は出さない。帯は 1.6 秒周期でゆっくり明滅し、`prefers-reduced-motion: reduce` では止める
- **狭い画面（760px 以下）は2列を縦に積む**（`docs/requirements.md` 4.7）。箱は画面の内側いっぱい
  （`100dvh` から余白を引いた高さ）で、一覧が上で高さは箱の 40% まで（内側で転がす）、詳細が残りの
  高さ（内側で転がす）、下の操作の帯は箱の下端に残す。見出しの帯のキーの案内は畳む

#### サイドバーのタスクののぞき窓

サイドバーのタスクの行と、そこから開くのぞき窓の見た目（2026-10-04 決定）。見本は
`docs/history/mockup/sidebar-task-peek-2026-10-04.html`（場面1の行のホバーと場面3。画は同じ名前の
`.png`）。**値は見本のインラインの style が正**で、ここには要点と、見本の色をトークンへ写した対応だけを
置く（見本の #1f1e28 は `--surface`、#3a3946 は `--rule`、#2a2933 は `--rule-quiet`、#1f2e2e は
`--surface-accent`、浅葱 #66d1be は `--accent`、ボタンの字 #0d201c は `--ground`）。中身とふるまいは
`docs/architecture/display.md`「サイドバー」の「のぞき窓」。

- **字は 12px を割らない**（13.3。見本で 12px 未満の箇所は `--font-label` へ上げて写した: 窓の状態の語と
  ID・関わるタスクの行〔見本 11.5px〕、行の ID〔見本 11px〕。本文の中のコードの札〔見本 0.9em〕は 12px）
- **行**: 行全体が1つのボタン。4列の grid（印 14px・ID 50px・題 `minmax(0,1fr)`・`›` 16px）、列の間 10px、
  高さ 40px、内側の余白 0 8px 0 10px、角丸 9px、行どうしは 1px 空ける（罫線は引かない）。題は1行で末尾を
  「…」。**ホバーで地が `rgb(255 255 255 / 0.035)` になり、右端の `›`（14px）が `--accent` で出る**
  （ホバーしていない行では透明）。**窓を開いている行は `--surface-accent` の面と、`--rule` と `--accent` を
  混ぜた色の `inset 0 0 0 1px` の枠**（色だけで伝えない）。済んだ行は打ち消し線と弱い字のまま。
  進行中のカードもカード全体が1つのボタンで、1行目の右端に `›` を置き、ホバーと開いている間は枠を
  `--accent` にする
- **窓**: 幅 400px（画面が狭ければ `100vw - 16px`）・内側の余白 16px 18px 14px・角丸 16px・地 `--surface`・
  枠 `--rule`・影 `0 24px 60px rgb(0 0 0 / 0.55)`・塊の間 12px。上から、状態の印（12px）と語・ID（`--accent`・
  等幅）・右端に閉じるボタン（26px 角の「×」） → 題（15px `--font-body`・太字・行の高さ 1.6） → 関わる
  タスク（12px・`--ink-quiet`、ID は等幅） → `--rule-quiet` の罫線の下に本文の頭 → 下端の行に左「全文を開く ↗」
  （12px の入口）・右「これを始める →」（高さ 32px・角丸 9px・`--accent` を上は明るく下は暗く混ぜた
  グラデーションの地・字 `--ground`・13px・太字）。**ドラフトの窓は右が2つになる**（2026-10-11）: 「これを始める →」の代わりに、
  左に「却下する」（「全文を開く ↗」と同じ 12px の入口。高さ 24px 以上）、右に「計画する」（上の主ボタンと同じ作り）を、
  間 8px で並べる。新しい寸法・色は足さない
- **本文の頭**: 字 13px（`--font-secondary`）・行の高さ 1.8・字は `--ink-soft`。本文の見出しは 12px 太字の
  `--ink-quiet` の小さなラベルに組む。高さの上限 170px で切り、下 40px を `--surface` へ溶かす
- **置き方**: モーダルでない `<dialog>` を `position: fixed` で置く（top layer に積まないので、確認と
  タスクのモーダルは必ず上に出る）。**窓の右端を押した行の左 52px**（サイドバーの枠から約 20px 外）に、
  **縦は窓の中央を行の中央に合わせてから画面の上下 8px の内へ寄せる**（下の方の行を押したときは上へ
  寄る）。**尾**（12px の正方形を 45 度回した右向きの三角。右と上の辺だけ `--rule` の枠）は押した行の中央の
  高さに置き、窓を寄せたぶんだけ窓の中で動かす（角から 20px の内）。窓の大きさ・画面の大きさ・
  スクロールが変わるたびに置き直す。1024 幅（柱から開いたサイドバー）でも 1440 幅でも窓はサイドバーの
  左に収まる。**左に窓が入りきらない幅（760px 以下で、タスク一覧が引き出しの中にあるとき）は左端 8px に寄せて行に
  重ね、尾を出さない**
