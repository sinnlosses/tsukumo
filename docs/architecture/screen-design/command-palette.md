# 画面のデザイン: コマンドパレットとショートカット

ステータス: **正典**。入口は `docs/architecture/screen-design.md`（画面のデザインの全体）。

責務: コマンドパレット（⌘K）と、画面全体で効くショートカットの割り当て・効く条件・キーの字の見せ方。
読む時: パレットの行やショートカットを足す・変えるとき。
直す時: パレットの形や、ショートカットの割り当て・効く条件を変えたとき。

## 割り当て

macOS を前提にし、画面全体のショートカットは **⌘ と英字** で割り当てる（設定だけ macOS の慣例の ⌘,）。
Ctrl・Option を伴う押し方は読まない。入力欄の中の macOS のカーソル移動（Ctrl+A・Ctrl+E・Ctrl+K など）と
ブラウザに譲るためで、Ctrl+K を押してもパレットは開かない。⌘ に Shift を足した押し方も読まない。

| キー | 操作                                                       |
| ---- | ---------------------------------------------------------- |
| ⌘K   | コマンドパレットを開く・閉じる                             |
| /    | 入力欄へ移る（どの画面からでも会話の画面へ移ってから移る） |
| ⌘J   | セッションの切り替え画面を開く                             |
| ⌘E   | タスクのモーダルを開く（会話の画面へ移ってから開く）       |
| ⌘,   | 設定のモーダルを開く                                       |

- **`/` は打っていないときだけ効く**。入力欄・入力要素・`contenteditable` の中では字として入る。始め方の一覧に限らず、どの場面でも効く
- **⌘ のショートカットは入力欄で打っている最中でも効く**。IME の変換中は読まない
- **ほかの重なる面（設定・切り替え画面・タスクのモーダルなど）が開いているあいだは読まない**。パレットが開いているときだけは、パレットを閉じてから操作を走らせる
- 受けるのは `CommandPalette` の `document` の `keydown` 1つで、読み取りは `shortcutOf` に閉じる
- Orca のタブの中で開くので、Orca 自身が先に取るキーとはぶつかりうる。割り当ては ⌘T・⌘W・⌘N・⌘Q・⌘R など、ウィンドウやタブを操るキーを避けて選んだ

## パレット

- **探す欄と、「操作」「画面へ移る」「設定の項目」の3群の行**。探す欄で行の名前を部分一致で絞り、↑↓（Ctrl+P / Ctrl+N でも）で選び、Enter で走らせる。開くと最初の行を選んだ状態で始まり、絞り込むたびに選びは絞った最初の行へ戻る。Esc と外側のクリックで閉じる
- 「操作」は入力欄へ移る・セッションを切り替える・新しいセッションを始める・タスクの一覧モードを開く・設定を開く・比率を既定に戻す（会話の画面にいるときだけ）。「画面へ移る」は仕事・雑談・キャラクター・トークンの使用量・成果で、いま出している画面の行は出さない。「設定の項目」は数が多いので、何か打つまで並べない
- ターン進行中で起こし直せないあいだ、新しいセッションと、いまと違うモードの会話の行は行ごと出さない（進行が終わると戻る）
- **箱の上端は帯の下に留め、絞り込んで行が減ったら下から縮む**（中央に置くと箱が上下に跳ねる）
- 開き直すと探す欄と選びが初めに戻る
- 描くのは `ui/` の `CommandPalette` の包みで、中身は Astryx の `CommandPalette`（箱・探す欄・群・行の見た目は Astryx のまま）

### キーの字の見せ方

キーを読むのは探す人だけなので、行の主役にしない。

- キーは `ui/` の `Kbd`（キーごとの枠）で描き、行の右端に置く。選んでいる行でも見た目を変えない
- キーの案内の帯（下端の「↑↓ 選ぶ ⏎ 走らせる」の行）は置かない
