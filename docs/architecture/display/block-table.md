# 出力の分離（セリフと詳細）: 表・対応表・見比べ・前後

戻り: `docs/architecture/display.md`「出力の分離（セリフと詳細）」

- **表の描き方は型から決め、書き手は何も選ばない**（`docs/research/report-block-richness.md`
  2章）。列の全セルが数なら右揃えで `tabular-nums`（桁が縦に揃う）。列の全セルが `status` なら、セルの中に
  `Badge`（`shape: square`・記号＋文）を置く（地は状態の色の13%。セル全体のタイルにはしない。`--state-*` から導出し、16進は書かない）。
  記号には状態の語（OK / 要注意 / NG）を `aria-label` で添え、色だけに頼らない。
  状態のセルがある列の、状態の無いセルは地を塗らず `ink-soft`（見出し行と同じ補助の字）の
  ままにし、行の左に色の線は引かない。表に出た状態だけを、題（「表 n」）の下・表の上に左揃えの凡例
  （色見本＋記号＋語）で添える。列に `align` は持たせず、Markdown の組み立て時に1箇所で判定する。
  長い表を切った残りは `rest`（省略可。「ほか 12 件（0.5% 未満）」）で言い、あれば表の直後に
  1行で添える（`ink-quiet`・罫なし）。強調行 `{ cells, emphasis: true }` の地は `--surface-raised`（3行まで。超えれば `many-emphasis-rows`）。
  案を列に並べた表で採った案の列は、任意の `emphasisColumn`（0 始まりの位置1つ。色は書かせない）で強調する。
  その列の見出しとセルに `--accent` の薄い地を敷き、行の強調と重なるセルは行の地に `--accent` を重ねて両方を残す。
  列の数以上の位置は `emphasis-column-range` で差し戻す。
  数の格子（曜日×時間帯の件数など）は、任意の `heat`（`{ from, to }`。0 始まり・両端を含む列の範囲）で範囲のセルを6段の濃淡で塗る。
  段は範囲の全行の最大値を6等分した帯で決め（並べ替え・絞り込みで変わらない）、薄い段は `ink` の 4%、ほかは `--chart-series-1` の濃さで、濃い2段は字を `ground` に沈める。
  最大のセルに白い枠（`ink-bright`）を内側に引き、表の下に「少 … 多（最大 n に枠）」の凡例を添える。範囲の列には数の棒を出さない。
  任意の `totals: true` で、範囲の行の合計を右の列「計」に、列の合計と総計を `tfoot` の行「計」に描く側が足す（書き手は合計を書かない）。
  合計の行・列は `rows` に入らないので並べ替え・絞り込みの対象にならず、合計の行は表の最後に残る。合計は見えている行だけを足す。
  範囲が列の外か逆順、範囲に 0 以上の素の数でないセルがある、`heat` の無い `totals`、範囲に `%` のセルがある `totals` は `heat-range` で差し戻す。
  質問の添え書きの Markdown（`report-table-markdown.ts`）には濃淡と合計を書き出さず、範囲の列は棒の無い数の列になる。見本の場面は `report-table-heat`。
  セルに入らない行ごとの詳しい中身は、行の形 `{ cells, emphasis?, detail?, depth?, best? }` の任意の `detail`（インライン）で持つ。
  `detail` のある行だけ、1列目の先頭に開け閉めの押しボタン（`aria-expanded`）を出し、初めは閉じている。
  開くと行の直下に全列を通した1行で中身を出す。開け閉めは行の部品の状態で、並べ替え・絞り込み・10 行の畳みを通っても元の行に付く。
  Markdown への書き出しは、表の下に「1列目の字: 中身」の箇条で出す。
  階層（ディレクトリの木など）は、行の任意の `depth`（1〜3 の整数。書かない行と配列の行が 0）で1列目を字下げして1つの表に並べる。
  子は親の行の直下に1段深く置く。描く側は1列目の `td` に段の印（`table-depth-1`〜`table-depth-3`）を付け、`padding-inline-start` を1段 1.5em ずつ寄せる（開け閉めの押しボタンと強調の印ごと寄る）。数の列と棒は段に依らず今の描き方のまま。
  並べ替えは同じ親の子どうしの中だけで行い、子は部分木ごと親の直下に付いて動く。絞り込みは合う行の祖先（前にある、段が1つずつ浅い行）も残す。
  操作できる表（`sortable`・`filterable`）の操作の置き場は、並べ替えが列の見出しのボタン、絞り込みが題（「表 n」）の行の右端のバッジ。表の上に別の行は置かない。
  並べ替えの見出しの `th` には `aria-sort`（`ascending`・`descending`・`none`）を付け、並べ替えている列にだけ ▲・▼ を添える。並べ替えられない表の見出しには付けない。
  `ChoicePicker` に結んだ表は、バッジを出さない。
  最初の行の段が 0 でない・前の行より2段以上深い行がある・`depth` のある表に `totals` を付けた（親の行に子の数が含まれ合計が二重になる）ものは `row-depth` で差し戻し、3 を超える値は schema が受けない。
  質問の添え書きの Markdown には、1列目の字の前に段の数だけ全角の空白（U+3000）を置く。見本の場面は `report-table-tree`。
  行ごとの最良のセルは、行の任意の `best`（0 始まりの列番号）で書き手が名指し、そのセルの前に ◆（`cell-best-mark`、色は状態の ok）を描く。
  tsukumo は値から最良を計算しない（良い向きが行ごとに違う。値段は小さいほど良く、メモリは大きいほど良い）。セルの字の色と太さは変えない。
  `columns` の列の数以上の位置（`totals` が足す「計」の列を含む）は `best-column-range` で差し戻す。`heat` と `emphasisColumn` はそのまま併用できる。
  `table` の説明には、行は大きさか重要度の順（1列目のあいうえお順にしない）・単位は見出しに1回だけでセルに書かない・
  セルは語句・数・状態にする、の3条を置く。
  セルの条は、ある列のセルの平均が全角35字以上の表を `sentence-table` で数える（差し戻しはしない）。
  2行以下の表は差し戻さず、記録の「2行以下の表のあるレポート」で数える
  （「部品を足す・外す基準」の版10）
- **行と列の交点が状態の印の対応表は `matrix` の部品で見せる**（`columns`・`rows`〔`name` と
  `cells`＝`ok` / `warn` / `ng` / `na`、または `{ status, note }`〕を受ける）。交点は印（✓ ！ ✕ －）で描き、
  状態は記号・色・`aria-label`（状態の語。行と列の名前は表の見出しが読み上げる）で言う。
  **交点の補足は `note` の 12 字まで**（「7日まで」「別料金」のような短い語。印の下に小さい字で出し、
  `aria-label` は「要注意（7日まで）」のように補足を括弧で添える）。超えると schema が受けない。
  文や長い数を添えたい・列の型が混じるなら `table` の状態のセル。
  **採った列は `emphasisColumn`**（0 始まりで `columns` の位置。行の名前の列は数えない）。
  その列の見出し・セル・末尾の行に `table` の強調の列と同じ差し色の薄い地を敷き、見出しに描く側が「推奨」の札を付ける。
  **末尾の値の行は `footer`**（`name` と `cells` の行を 3 行まで。書き手が書き、描く側は数えない。印の数「○ / △ / ×」も月額も書き手の値）。
  格子の下に区切り線を挟んで並べ、本体の 10 行の切りには入らない。凡例は格子に出た状態だけを1つ添える。
  取り違えは差し戻さず、使われ方の記録の「塊の種類 × レポート数」で `table` と `matrix` の比を見る。
  行と `footer` の行のセルの数が `columns` と揃わなければ `table` と同じ `ragged-table` で、
  列の数以上の `emphasisColumn` は `table` と同じ `emphasis-column-range` で差し戻す。
  列が多い格子は表と同じ横スクロールの器に収まる。見本の場面は `report-matrix`
- **2つを見比べるときは `compare` の部品で見せる**（`title`・`sides`〔ちょうど2つ。各 `heading` と
  `points`＝短い1行の並び〕を受ける）。2枚のカードを横に並べ、器が狭いときは縦に積む。見分けは見出しの
  文字だけで、判定の色は持たない。**カードの中はインラインの文字の箇条だけ**（コードは `code` の `diff`、図は
  `mermaid`、値を揃えるなら `table`）。使い分けは、判定（採る・検討・採らない）を付けるなら `options`、項目ごとに
  両側の値を揃えるなら `table`（セルの `from` / `to` は1つの値の前後）、3つ以上は `table`、**向きのある変化（前 → 後）は
  `compare` の `relation: before-after`**（`relation` が `versus`〔既定〕なら向きの無い2つ〔案A と案B〕で、側の見出しは書き手が付けるまま）。
  取り違えは差し戻さず、同じ記録で見る
- **変更の前と後は `compare` の `relation: before-after` で左右に並べる**（`title`・`sides`〔左が前・右が後〕を受ける。旧い `beforeAfter`〔`before`・`after`〕は受け口で `compare` に書き換えて読む。`docs/architecture/adr/0047-compare-relation.md`。
  側はちょうど2つ。3つ以上の並びは `table`）。側は `kind` で判別する合併型で、`image`〔`path`と任意の `region`〕/ `code`〔`language`・
  `source`。`diff` にせずその側の中身をそのまま書く〕/ `points`〔短い1行の並び〕/ `mermaid`〔`source` だけ。
  `sequenceDiagram`・`stateDiagram-v2` で、時間の順の前後に使う。種類の外なら差し戻し、位置は `mermaid` のソースの出現順で言う〕/
  `svg`〔`svg` の部品と同じ欄〕のどれか。**左右で種類が違ってよい**（設定の文言 → 画面のような前後を書ける）。
  左に前・右に後のカードを同じ幅で並べ、間に `aria-hidden` の「→」を置く。カードの頭の見出しは tsukumo が「前」「後」の文字で付け
  （書き手は書かない。前は `ink-quiet`・後は `ink` で、色は補助）、器が狭いときは前を上・後を下に積んで矢印を下向きに回す。
  画像の側は `image` の部品と同じ置き場から引き、読めなければ同じ「画像を出せない」のカードになる。`alt` は「前の画面」
  「後の画面」に題を添えたもの。**画像の側に `notes` は持たせない**（半分の幅に番号を足すと画像がさらに縮み、
  前後で番号が重なる。見る場所を言うなら `image` の `notes`）。題は図として
  数え、外枠は縮めない。
  - **`relation: before-after` で両側が `code` のときは、描く側が行の差を取って行に印を付ける**（書き手の欄は増やさない。
    どちらかの側が 200 行を超えたら差を取らず、印の無い描き方に戻す）。行の差は行単位の LCS で、共通の行の間の隙間では
    前の n 行と後の m 行を頭から min(n, m) 行ずつ変えた行の対にし、余りを消した行（前だけ）・足した行（後だけ）にする。
    前の側の変えた行・消した行は ng、後の側の変えた行・足した行は ok の地と左の線で塗り、足した行には字の後ろに「新設」の札を付ける。
    変えた行の中の語の差には印を付けない。片側にだけある行の向かいには空の行を入れて左右の行の高さを揃え
    （前を上・後を下に積む狭い器では揃える相手が無いので空の行を描かない）、図の下に色の凡例（「変えた行（前）」
    「変えた・足した行（後）」のように、その側に出た種別だけ）を出す。印の行が1つも無ければ凡例は出さない。
    `relation: versus`（対等な2つで行の対応が無い）と、片側だけが `code` の前後には付けない
  - **両側が `image` のときだけ、題の行の右に「並べる」「切り替え」「重ねる」の押しボタンの組（`role="group"`・`aria-label="見せ方"`）を出す**
    （2枚の差は同じ位置で入れかえるほうが速く見つかる。`docs/research/report-block-craft.md` 5章・9.1）。
    並べるは前・後を画像の左上のバッジつきで並べ、間に「→」を置く。切り替えは大きな1枚と前・後の見本（120px 幅）で、
    見本を押すか、大きな1枚にフォーカスがあるときの Space で、同じ位置で前と後が入れかわる
    （空白も `transition` も挟まない。変化盲を避ける）。見本は `aria-pressed` で見えている側を示す。
    重ねるは前の上に後を重ね、`<input type="range">`（初めは中央・左が前・右が後）の位置から右だけ後を見せて、境に縦線を引く。
    両側の画像の自然な寸法の縦横比の差が1%以内のときだけ選べる（違うときは押しボタンを出さず、保存値が重ねるでも並べるで描く）。
    選んだ見せ方は `localStorage` に覚え、次もそこから始める（読めない・壊れた値は並べる）。
    ボタンは24px以上の押せる面を持つ。どちらかの画像が「画像を出せない」のカードになったら、押しボタンも見本も出さず並べる形にする
  - **前後の部品の中の画像を押すと、前後を入れかえて見られる面（`CompareZoom`）で、押した側から開く**。
    左上に前／後の2つ組（`aria-pressed`。選んだ側は `accent` の枠と薄い地）、右に案内「← → で前と後 · Esc で閉じる」と ×、
    下に部品の題（「図 N」は等幅。数え方は部品の題と同じ）を中央・13px で置く。← で前、→ で後に替わる（選ぶ動作で、
    2つ組のボタンを押しても同じ）。幅は 960px を上限に画面へ収めて中央に出す。縦に長い画像は面の中で流れ、上の行は残る。
    Esc・背景・×で閉じ、閉じたら押した画像へフォーカスを戻す。面は `document.body` の直下へ描く（部品の中に置くと、
    本文の `p` の測り・図の画像の枠と角丸・側の箱の margin が面に当たる）。部品の外の `image` と、画像がカードになった部品の読めた側は、画像ごとの拡大（`ImageZoom`）のまま
  - **前後の画像の「変わった場所」の枠は、書き手が `image` の側ごとの任意の `region` で渡す**（
    出どころは書き手の指定に決め、差分からの検出は採らない。撮影の揺れ〔時計・アニメ〕で誤検出し、画像処理の依存が増えるため）。
    `region` は画像に対する % の `left`・`top`・`width`・`height`。無ければ枠を出さず、欠陥にしない。
    `report` は範囲外（0 未満・100 超・`left + width` か `top + height` が 100 超）と幅・高さ 0 以下を差し戻す
    （位置の誤りは静かに出るので機械で拾う）。使用の記録（`report-usage`）は、枠が付いた回を部品の欄 `beforeAfterRegion`（版15）、版25から `compareRegion` で数える。
    枠の見た目は見本どおり（前は `surface` と `ink` の混色の不透明な灰、後は `accent`。2px・角丸 6px・外に 4px の薄い輪）で、大きく見る面でも出す。
    `region` は Markdown の `<img data-change-region="left,top,width,height">` で運び、サニタイザは `img` にだけ許す
    （4領域が名乗る `data-region` とは別の名前にし、`[data-region]` が当たるのは4領域だけという前提を守る）。
    枠は `aria-hidden` の飾りで押せる要素を足さず、`region` の無い側・切り替えの見本・画像がカードになった側には出さない
  - 使い分けは、向きの無い2つは `compare`、1つの値の前後は表のセルの `from` / `to` か
    `stats` の `before`、行ごとの差分は `code` の `diff`、構造の前後は `graph` の印。
    書き手への規約（記法の「図の有無は利用者の既定に従う」の原則と「確かめたことは断定し…」の条）は、図の問いと関係の申告を言い、画面を変えた作業は撮った画像を `image` で載せ、
    同じ場面の前後の2枚は `compare` の `relation: before-after` で並べる（見た目に出ない・撮れないときは `checks` の `unobserved` に理由）。
    1行の変更に使わせない旨は `compare` の `describe` が持つ。
  - 箇条の側が6つ以上なら `options`・`compare` と同じ違反で差し戻す。取り違えは差し戻さず、
    使われ方の記録の「塊の種類 × レポート数」で見る
- **問い・データ・関係を申告する図は `plot` の部品で受け、形ごとの描き方が入るまでは表として描く**（`question`・`data` の列・`relation` と任意の `form`。
  詳細は `docs/architecture/display/section-and-block.md`）。`data` の列を表の列、`values` を行に起こして `table` と同じ描き方に通し、題は `question`。
  列の型〔`N`・`O`・`T`・`Q`〕は決定表で形を選ぶのに使うが、どの形も描き方は表のまま。`table` と同じ「表 n」の題を付ける
