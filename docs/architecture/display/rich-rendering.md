# 各表示物: レポートの見せ方・パスとコード・色・外部ライブラリ・帯のいまの作業

戻り: `docs/architecture/display.md`「各表示物」

- **レポートの見せ方**: **リッチのまま保つ**（2026-09-11 のユーザーの決定）。**レポートには
  HTML を直接書ける**。Markdown も従来どおり使える。HTML は**行頭がタグの行から、対応する閉じタグの行まで**の1ブロックとしても、
  **段落・表のセル・箇条書きの項目の途中に埋め込む形（インライン）** としても書ける
  （2026-09-12 決定）。
  **ブロックの中に空行を入れてよい**（2026-09-16 決定）。**HTML の中で Markdown を解釈させるには
  CommonMark の規則で空行が要る**ので、「空行を入れない」と規約で縛ると `<details>` の中で表や
  箇条書きが使えなくなる。縛る代わりに、塊に割る側が閉じタグまで割らない。
  どちらの経路も**通すのは許可リストに載った要素・属性だけ**で、
  `script` / `style` / `iframe` は中身ごと、`on*` と `javascript:` は属性ごと落とす
  （許可リストは `src/browser/components/page/conversation/components/markdown/renderer/sanitize-schema.ts` の1箇所に集約）。ただし**コードスパン
  （`` `code` ``）の中に書いた HTML はタグにせず、文字のまま出す**。
  `style` 属性は、**tsukumo が棒・目盛・点に付ける形（`width` / `margin-left` の割合と `flex` の数値3つ）だけを通し、
  それ以外は属性ごと落とす**。
  段組みは、レンダラー側が**ステップをカードにして縦に1本で積み**（横に並べてZ字に読ませない。
  **番号も振らない**）、**1つのステップの中**を読みやすく組む。レポートの中身の段組みは
  tsukumo が塊から組む（モデルに HTML で段組みを書かせない。`display:grid` などの `style` は落ちる）。**色だけで意味を伝えない**（文字でも読めるようにする）
- **レポートに書かれたパスは押すとホストで開く**（Orca はエディタ、ブラウザは OS の既定のアプリ）（2026-09-24 決定）。**押せるのは
  git 管理下の一覧にあるパスだけ**（誤検出を避ける。一覧に無い文字列は押せる部品にならない）。
  対象は3か所: inline code（`` `src/foo.ts:12` ``・`` `src/foo.ts:10-14` `` の形。**行番号は Orca へ運ばない**——Orca に口が無いので、
  表示の `:12` はそのまま残るが、開くのは裸のパスだけ）、フェンスの info 文字列に書いたファイル名
  （` ```diff src/foo.ts ` のブロック左上のラベル）、Markdown の相対リンク
  （`[x](src/foo.ts)`。スキームの無い相対リンクでページ自身が遷移しないよう、
  **ファイルを指すときだけ `<a>` を離れて押せる部品にし、指さないときは押しても何も
  起きない素のテキストにする**。押せる部品は文の中で折り返せるよう `role="button"` と `tabIndex` を付けた
  `<span>` で、Enter・Space でも開く）。開く依頼とサーバ側の検証は `src/shared/contract/host.ts` の `hostContract.openFile`
- **行番号のある押せるパスに重ねるかフォーカスして 500ms 経つと、その行の前後の抜き書きを浮かせて出す**
  （2026-10-18 決定）。押す動き（Orca で開く）は変えない。1行を指したら前後3行、`path:a-b` の範囲なら
  範囲の前後1行（どちらも 15 行まで）を等幅で出し、指した行だけ地を濃くして行末に「← 12 行」と添える。
  頭の行はパスと出した行の範囲。行番号の無いパスには出さない。待ちを始めるのはマウスで重ねたときとキーボードでフォーカスが入ったときだけで、
  touch の操作（重なり・叩いて入るフォーカス）と、押して入るフォーカスでは始めない。外へ出る・
  フォーカスが外れる・Esc・外での押下・スクロールで閉じ、浮きは押せる要素を持たない。
  **抜き書きは照らし合わせ用で、レポートの主張は本文に書く**（ホバーに事実を置かない）。
  読むのは git 管理下の一覧にあるファイルだけ（ホストへ開く依頼と同じ門番）で、
  1 MiB を超える・NUL を含む・シンボリックリンクのファイルは読まない。1行は 200 字で省く。
  レポートを書いたあとにファイルが縮んで指した行が無いときは「… 行目はいまのファイルに無い」と出す。
  手続きは `src/shared/contract/repository.ts` の `repositoryContract.fileExcerpt`
- **フェンス付きコードブロックの頭の帯に、クリックでクリップボードへ写すボタンを常に置く**（全文。shell の塊の例外は下）
  （2026-09-28 決定。ドラッグで選ばずに写せるように）。**塊の種類を分けず、フェンス付きコードブロックすべてに付ける**
  （mermaid・chart は除く）。書き手が「写してよい文章か」を選び分ける負担を無くし、画面に出る形も
  1通りに保つため。写す中身はフェンスの中身そのまま（行番号・ファイル名のラベル・ボタンの文字を
  含まない、書き上げる演出が終わった後の全文。印や畳みがあっても全文）。**例外は shell の塊**
  （言語が `bash`・`sh`・`zsh`・`console`・`shell` で、`$ ` で始まる行が1つ以上ある塊）で、コマンドの行
  （`$ ` で始まる行と、行末が `\` のコマンドの続き）だけを頭の `$ ` を外して写す（2026-10-17）。
  写すとボタンの文字が短いあいだ「コピーした」に変わる
- **`code` の塊は、強調する行 `marks`（`{ lines: "4-8" | "12", label }`）を持てる**（2026-10-17）。印の行は
  地を `--surface-raised`、左に 2px の `--accent` を沈めた罫にし、ラベルは印の最初の行の右端に 12px・
  `--ink-quiet` で置く。**`marks` のある塊だけ**、印の行から3行より離れた無印の範囲が20行を超えたら、
  その範囲を「n 行を畳んだ」の1行にして、押すと開く（`marks` の無い塊は畳まない）。`lines` が読めない形か
  ソースの行数の外なら差し戻す。shell の塊は、`$ ` で始まる行をコマンド、それ以外を
  出力として分け、出力の行は色付けを外して `--ink-soft` の字にする。折り返しは切らず、行番号の列は持たない。
  `marks` はフェンスの info の末尾の1語で描画側へ運ぶ。`path` 付きの塊は `source` を変えない
  （実物との一致の検査が掛かる）
- **`code` の `diff` は、変わった行の中の違う語まで地を濃くする**（2026-10-17）。`-` の行の連続の直後に
  同じ数の `+` の行が続くとき、同じ順の行どうしを対にして語の LCS を取り、違う語に `--state-ng`（`-` の行）・
  `--state-ok`（`+` の行）を 45% 混ぜた地を重ねる。語は英数字と `_` の連なり・空白の連なり・記号1字ずつで切る。
  数の違う塊・対にならない行・`---`/`+++` で始まる行・どちらかの行の語が 200 を超える行は、行単位のまま。
  対の行がある塊は `marks` が無くても行ごとに描き、書き手が書くものは増えない
- **色を指す inline code は、その色を地にして出す。** 中身の文字全体が1つのカラーコード
  （`#bca0ec` など。3・4・6・8桁）か、ページの色のトークン名（`ink-quiet` / `--ink-quiet` /
  `var(--ink-quiet)`）のときだけで、文中に色が混ざったものとフェンスの中は変えない。字は地の
  明るさで `ink` と `ground` を持ち替える。「`ink-quiet`（灰）」のように言葉で色を言い添えなくても、
  読み手が色を見て分かるようにするため。トークンの判定は、ページで実際にその名前の色が解決できるか
  で決める（色の一覧をコードに持たない）。解決した色は、ルート要素の style が変わる
  （画面の色の上書き・差し色）まで覚え、描くたびにスタイルの再計算を起こさない
- **使う外部ライブラリ**: コードの色付け（highlight.js）・図（mermaid のコードブロック）・
  グラフ（Chart.js のコードブロック）に使う。**どれも残す**（2026-09-11）。
  **どれも `package.json` の依存**で（2026-09-20 決定）、**CDN からは読まず `node_modules` の
  実ファイルを `127.0.0.1` から配る**（会話の内容が載るページに外部スクリプトを持ち込まない。
  `docs/architecture/adr/0012-bundle-vendor-library.md`）。**mermaid と Chart.js は、その図が
  窓の少し手前に見えたときだけ描く**（5.3MB を束ねに入れない。mermaid は図が現れたら読み込みだけ手すきに先に済ませる）
