# 脇の話

戻り: `docs/architecture/display.md`「脇の話」

**委譲中（バックグラウンドタスクが残っているあいだ）に入力欄から送った言葉は、新しい依頼にせず「脇の話」として親のやり取りに
吊るす**（2026-10-07 利用者決定。用語は `docs/glossary.md`「脇の話」。見本は `docs/history/mockup/aside-thread-2026-10-07.html`）。
それまでは送った言葉がいつも `request` になり、「いまどう？」の一言でも札が割れて、帯がワークプランの無い新しい札に切り替わり、
帯・経過・中間レポートが消えた。委譲中のやり取りは状況の確認や一言の頼みに近い。

- **脇の話かどうかは、サーバが `prompt` を受けた瞬間に機械的に決める**。条件は、仕事のとき（雑談では決めない）・
  サーバの姿の `backgroundTasks` が1件以上・送り方（`PromptRouting`）が `aside-when-background` の3つ。本文は読まない。
  ブラウザが渡すのは送り方だけで、バックグラウンドタスクの有無は見ない（駆動が動くのはサーバの姿の上なので、判定もそこで1回だけ行う）。
  入力欄の ⌘⏎ は `aside-when-background`、⌘⇧⏎ は `new-request` で、バックグラウンドタスクがあっても新しい依頼として札を割る。
  始め方の一覧・タスクの実行から送る依頼は送り方を省き、`new-request` になる
- **脇の話は `request` ではない別の出来事と記録 `aside` にする**（`text`・`images`・時刻。ターンの通し番号は持たない）。
  `request` でないので、札の割り方（`splitIntoTurns`）・記録の窓・同じ依頼の範囲を読むもの（ワークプラン・依頼の手順・
  `WorkPlanReview`）は、脇の話を親のやり取りの中として読む。札も「n / N」も増えず、帯は親のワークプラン・今の段・経過を出し続ける。
  経過は親の依頼を送った時刻から数え続け（続きのターンと同じ）、吹き出しと表情は脇の話のターンの頭でも持ち越し、答えのセリフを後ろに足す（空に戻すのは書きかけだけ）
- **claude へ送る文面は `<tsukumo-aside>` の包みに入れる**。claude は包みで脇の話と分かり、組み直し
  （`src/server/session-driver/core/session-restore.ts`）は transcript の `user` の包みを見て `aside` に戻す。
  判定を transcript に残る形にしたのは、組み直すときにはバックグラウンドタスクの顔ぶれが分からないため。組み直しでは、
  バックグラウンドタスクの知らせ（`origin.kind` が `task-notification`）の `user` メッセージで続きのターンを区切り、委譲の続きのセリフを脇の話の答えに混ぜない
- **答えは `speak` で受け、`report` は求めない**。脇の話のターン（`aside` から、次の依頼・続きのターン・ターンの終わりまで）の
  セリフには `answersAside` の印を付け、メインビューは脇の話とその後ろの印の付いたセリフを対にする。答えは吹き出しと、
  親の札の脇の話の欄（上の「各表示物」のメインビュー。届いた位置の、いちばん下に足す）に出る。条は `WORK_PLAN_PROMPT` の「脇の話」の項で、包まれた言葉には
  `speak` の1〜2文で答え、親の作業が進んだ（委譲の返却が届いた）ときだけ、いつもどおり親のワークプランへ `work_plan` と `report` を
  渡す、と頼む。「レポートの記法」には足さない（脇の話では本文を書かない。`Stop` の関所もそのまま）
- **脇の話のターンの `report` には段の閉じ方・背景のシェル・画像の無い `report` の差し戻しを掛けない**（`ReportReview`。`src/server/report/core/report-review.ts`）。
  脇の話のターンでも同じ依頼のワークプランは残っているので、掛けると答えるだけの `report` まで `workPlanClosing` を求めて差し戻すため。
  ほかの差し戻し（送り直し・新しい事実の無い呼び出し・応えていない `work_plan`・`ng` のある `finished`・規約違反）はそのまま掛かり、`aside` は新しい事実に数える。
  ターンの頭の `session-info` は脇の話のターンの頭にも届くので、脇の話の印はそこでは戻さない
- **「止めて」「方針を変えて」も、親のワークプランを引き継いだまま受ける**。脇の話のターンの `work_plan` はそのまま親の帯を
  進める・組み替える（委譲の返却が脇の話のターンの最中に届いたときも同じ）。止めるなら `stopped` の `report` で親の帯を
  止めた姿にする。委譲先を止める操作は claude 自身が行い、tsukumo は持たない
- **バックグラウンドタスクが終わって親のやり取りが閉じても、欄は親の札に残す**。開いているあいだは開いて出し、閉じたら畳んで
  「脇の話 n件」の行だけにする
- **やり取りの列では、親のやり取りの行の2行目に「脇 n」を出して畳む**（上の「各表示物」のメインビュー）
- **防げないこと**: バックグラウンドタスクの顔ぶれは SDK の知らせが届いた時点のものなので、終わった直後で知らせがまだ届いていない
  一瞬に送った言葉は脇の話になる。そのときは ⌘⇧⏎ で送り直せる
