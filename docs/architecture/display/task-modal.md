# タスクのモーダル

戻り: `docs/architecture/display.md`「タスクのモーダル」

サイドバーの「一覧を見る」で開くモーダル（一覧モード）。**左に一覧の表、右に選んだタスクの詳細**（本文を Markdown で
描く）の2列で、**箱・頭・表・仕切りの形は ADR 0061 の参考情報が名指す見本の `index.html?design=b2&view=list`
が正**（つまみで詳細を広げた形は `view=list&split=wide`、数値は同じ置き場の `refine.html`「一覧モード」）。
詳細とつながりのたどり方は見本2枚（`docs/history/mockup/task-board-2026-09-28/` の
`TASK-1-List.dc.html`・`TASK-2-Jump.dc.html` と同名の `.png`。見本の中のタスクの文言はダミー）。
中身とふるまいは次の箇条書き、寸法・色・狭い画面の並びは下の「13.12 タスクのモーダル」に置く。

- **本文の出どころ**: タスクの本文は**一覧の要約と一緒に届ける**（選んだときに取りに行く手続きは作らない）。
  見回りが読んだものから作るので、一覧と本文の新しさがずれず、検索が本文まで引ける。
  課題の `description`・`acceptance_criteria`・`notes` を Beads の欄の順に、tsukumo が決めた見出しで並べたもの
  （節を並べ替えない。`docs/architecture/adr/0024-no-skill-dependency.md`）。Beads の comment は `bd list` に載らないので出さない。
  本文を載せても1回の読みの時間は変わらないので、見回りの間隔は変えない
- **並び**: 一覧に載る範囲はサイドバーと同じ（閉じた課題は新しいほうから10件。11件目以降を落としたときは、
  一覧の末尾に「一部のみ（閉じたタスクは新しいものだけで、ほか N 件は載っていません）」の一言を添える）で、
  並びは**サイドバーと同じ段**（いま・つぎ・待ち・ドラフト・済み。分け方は `stageTasks`）で、段の中は一覧の順、
  済みの段だけ番号の降順。段の見出しに件数を添え、済みの段も開いて出す。↑↓ はこの順で段をまたいで動く。
  **一覧は1行1件の表**で、列は左から番号・題・難しさ・ループ可。状態の印は番号の前、待ちの相手は題の後ろに
  「待ち <相手>」（待ちの残る保留は「保留 · <相手>」）で添える。題は1行に収め、入りきらない分は末尾を省く。
  読み上げは `role="listbox"` のまま、段は中の `role="group"`（名前は段の名前と件数）、列の見出しの行は `aria-hidden`。
  行の名前は番号・題・状態（待ちの相手が無い行は読み上げだけ）・難しさ・ループ可の順に読める
- **状態の言い方**は一覧の行・詳細の情報の表・つながりのカードで同じにする。`todo` は依存から計算して
  「着手可」か「待ち」（まだ済んでいない依存の ID を必ず字で添える。閉じていない課題に無い依存
  〔閉じた課題・一覧に無い ID〕は止めない）、`hold` は「保留」
  （済んでいない依存があれば ID を添える）、`draft` は「ドラフト」、`doing` は「進行中」、`done` は「完了」、想定外の値は注意色〔`--state-warn`〕の「!」と
  値のまま。**色だけで伝えない**（印の形と字が言う）
- **課題のラベルは詳細の情報の表に「ラベル」の行として字のままバッジで並べる**（Beads の `labels` をそのまま出し、
  意味は解釈せず並べ替え・絞り込み・色分けに使わない。無い課題では行ごと出さない。担当は出さない。
  `docs/architecture/adr/0024-no-skill-dependency.md`）
- **頭の1行**: 題「タスク」と一覧に載っている件数・検索欄・最新化の口・閉じる口。
  キーの案内（`↑↓` 選ぶ・`⏎` 頼む・`Esc` 閉じる）は箱の下端の操作の帯の左に置く
- **最新化の口**（見本 `docs/history/mockup/task-refresh-2026-10-12.html`）: サイドバーの見出しの
  「一覧を見る」の左と、この帯に同じ部品を置く。字は出さず、`title` と `aria-label` に「最新化」を持たせる。
  押すと見張りが見回りの次の周期を待たず1回読む（実行中なら今の読みに乗る）。
  応答は読み終えてから返り、そのあいだは2か所とも `--accent` で回って押せない（使用量の行の ↻ と同じ回り方）。
  一覧そのものはいつもの一覧の知らせで届く
- **件数の帯（絞り込み）**: 頭の下に1行で、すべて・進行中・着手可・待ち・保留・ドラフト・完了の7つ。
  「すべて」のほかは状態の印を添え、それぞれに件数を添える（数え方はサイドバーの段とは別）。
  1つだけ選べ、既定は「すべて」。「着手可」と「待ち」は `todo` を
  着手できるかで2つに割ったもの、「保留」は `hold`、「ドラフト」は `draft`、「進行中」は `doing`、「完了」は `done` だけ
  **想定外の値はどの札にも属さず、「すべて」でだけ出る**
- **検索**: 引くのは **ID・要約・本文**（大文字小文字を区別しない部分一致。件数の帯の絞り込みと組み合わさる）。
  ファイル名はタスクの ID をそのまま名前にしているので別には引かない（案内の文言は「ID・言葉で探す」）。
  ID の形を決め打ちしない（Beads の ID のまま、部分一致で当たる）。絞った結果が0件なら一覧に
  「当てはまるタスクが無い」と出し、詳細は空にする
- **開いたときの選択**: 開くたびに絞り込みは「すべて」に戻り、検索欄には**サイドバーの探す欄の語を引き継ぐ**
  （サイドバーの「一覧を見る」とサイドシートの「一覧モードで開く」。語は `useTaskBoardRequest` の頼みに載る。
  一覧モードで変えた語はサイドバーへ戻さない。レポートのタスク ID と始め方の一覧から開いたときは空）。
  選択は、名指しがあればそのタスク、無ければ進行中の先頭、無ければ着手可の先頭、どちらも無ければ表の先頭の行。
  **サイドシートの「一覧モードで開く」・狭い幅でサイドバーの行を押したとき・レポートのタスク ID から開いたときは、そのタスクを
  選んだ状態で開く**（絞り込み・検索の外でも「絞り込みの外」の一時の行で出す）。**開いている間に一覧が届き直しても**
  選んでいるタスクが一覧に残っていれば選択を保ち、消えていれば名指しが無いときと同じ行へ移る
- **キー操作**: ↑↓ で行を移ると詳細がすぐ切り替わる。検索欄にフォーカスがある間の Enter は、選んでいる行の頼む口の確認を開く
  （頼む口を押せる行だけ。変換確定の Enter・修飾キーつき・ドラフト〔口が2つ〕・押せない行では何もしない。
  器でなく検索欄で受けるのは、閉じるボタンや件数の帯のボタンの Enter を拾わないため）。Esc・閉じるボタン・モーダルの外側のクリックで
  閉じる（`<dialog>` の `showModal()` に任せ、フォーカスは開いたボタンへ戻る）。行を押すと選ぶだけで、
  頼まない
- **詳細**: 押すと番号を写す ID（写す絵を添える。status の生の値は出さない）・タイトル（要約）・情報の表（状態・難しさ・ループ・ラベル・置き場所）・
  本文。**置き場所の行**は「Issue」に課題の `external_ref`（`https://` で始まる URL の
  ときだけ。無ければ行ごと出さない）。依存を1つでも持つタスクは**本文の上に「先に終わっていてほしいもの」
  のカード**を依存ごとに並べる（ID・状態・要約。一覧に無い依存は ID に「一覧に無い」を添え、押せない）
- **本文中の ID の自動リンク**: 本文の地の文と、中身がまるごと1つの ID の inline code のうち、
  **いまの一覧に載っている ID と字面が一致するもの**だけを押せる字にする（語の途中は当てない。
  フェンスの中は当てない）。ID の形の正規表現は持たない——一覧が知っている ID だけを当てるので、
  ID の形が変わってもそのまま当たり、一覧に無い ID
  （閉じて一覧から落ちたタスク）は押せない字にならない
- **本文の描き方**: レポートの描画は流用せず、タスクのモーダルが専用に持つ。
  使うのは `react-markdown` と `remark-gfm`・`remark-cjk-friendly` だけで、**生の HTML は解釈しない**
  （字のまま出す）。描くのは見出し・段落・箇条書き・番号・チェック（静的な印。押せない）・
  inline code・フェンス（色付けしない）・表（横に溢れたら表だけスクロールする）・リンク（`http(s)` だけ
  新しいタブで開き、それ以外は字のまま）。レポートの記法（`note` などの class）・mermaid・Chart.js・
  パスを押すとエディタで開く部品は持たない。流用しないのは、置かれる機能（`features/`）が
  会話の画面の部品を import できず（`docs/architecture.md`「領域の機能と、置かれる機能」）、
  本文の読み物としての字の段（14px・行間 1.85）もレポートと違うため
- **下の操作の帯**: 箱の下端に全幅で置き、左からキーの案内・置き場所を開くリンク
  （「Issue を開く」で、`external_ref` を新しいタブで開く。`external_ref` が無ければ出さない）・「<キャラクター名> に頼む」
  （上向きの矢印つき。名前が無いときは「頼む」。ID を写す口は詳細の頭の番号で、帯には置かない。サイドシートの同じ口と同じ確認を開き、OK で文面（固定の文面か、歯車のプルダウンで入口のスキルを選んでいれば「/スキル名 {id}」。選択肢は `tw config --entries` が返すスキルと「未設定」）の `{id}` を ID にして送る）。**頼む口を押せるのは
  「着手可」タスクと、依存がすべて済んだ保留のタスク**（保留なら送る文面の末尾に「このタスクは保留なので、着手の前に判断を聞いて。」を添え、確認にもその文面がそのまま出る）で、それ以外は薄くして押せず、横に理由を添える（待ちと、
  依存が残る保留 → 「待ちが終わると頼めます」、進行中 → 「着手済みです」、完了 →
  「終わったタスクです」）。**ドラフトでは頼む口の代わりに「却下する」「計画する」を並べ**、
  サイドシートの同じ名前のボタンと同じ確認を開く。ターンが動いている間の断り方は区画の確認と同じ。
  **ドラフトをまとめて分類する場面はここに置かない**（絞り込み「ドラフト」でも行ごとの3択と下端の仕分けの帯は出ない。
  サイドバーの「仕分ける」から開くサイドシートの場面は `sidebar.md`）
- **つながりをたどる**（見本2）: 「先に終わっていてほしいもの」のカード・本文中の ID を押すと、
  **モーダルの中で詳細だけが切り替わり、一覧の選択も追いかける**。詳細の上にパンくず
  （「‹ <前の ID> に戻る › <いまの ID>」）を出し、**直前の1つだけ**を持つ（履歴を積まない）。
  戻るは `Alt+←` でも同じ。一覧で別の行を選ぶとパンくずは消える。飛んだ先には逆向きの
  **「これを待っているもの」**（いまの一覧のうち、このタスクを依存に持つもの）のカードも出す。
  飛んだ先が絞り込みや検索で一覧から隠れているときは、**その行だけを一時的に一覧に出し
  「絞り込みの外」と小さく添える**（一覧で別の行を選ぶと引っ込む）
- 検索・絞り込み・選択・パンくずは表示上の状態なので**保存しない**（閉じると捨てる）

## 13. 画面のデザイン

### 13.12 タスクのモーダル

サイドバーの「一覧を見る」で開くモーダルの見た目。**左に一覧、右に選んだタスクの
Markdown の詳細**で、見本は `docs/history/mockup/task-board-2026-09-28/` の `TASK-1-List.dc.html`
（一覧と詳細）と `TASK-2-Jump.dc.html`（待ちの ID から前のタスクへ飛ぶ）、1440 幅で撮った同名の `.png`。
**値は見本のインラインの style と画面下の「説明」の節が正**で、ここにはその要点と、見本の色を
トークンへ写した対応だけを置く。中身とふるまい（本文の出どころ・絞り込み・検索・ID のつながり）は
この文書の上の節。

- **箱**: 幅は 1240 まで（ビューポートから 80 を引いた幅を超えない）・高さはビューポートから上下 48 ずつ引いた残り
  （`Dialog` の既定の高さの上限は外す）・角丸 18・画面の中央。1400×900 で 15 件がスクロールなしで収まる。
  地 `--surface`・枠 `--rule`、背景は `<Dialog backdrop="dim">`。頭の1行は高さ 48 で、題 14px 太字と件数 12px 等幅・
  検索欄（高さ 32・幅 420 まで）・右端に口。件数の帯は高さ 28 の札を1行に並べ、入りきらない幅では横に転がす
- **閉じると最新化の口**: 枠なしで、サイドシート・モーダルの帯では 28px。サイドバーの見出しの最新化だけは、
  ラベルの段（12px）の見出しに合わせて 24px（絵は 14px）にし、「一覧を見る」の字も 12px にそろえる。
  最新化は頭の1行の右端で閉じる口の左、サイドバーの見出しでは「一覧を見る」の左。読んでいるあいだは `--accent` で 1 秒に1回転する
- **字の大きさは見本のまま**（20px のタイトル・16px の本文の見出しなど、13.3 の段に無い値も寄せない。
  切り替え画面〔13.9「切り替え画面」〕の 30px の ID と同じく、このモーダルの中だけの値）
- **左の一覧（表）**: 幅の既定は箱の幅の 64% で、詳細との境の仕切り（`LayoutResizer`）をドラッグか、
  仕切りにフォーカスを置いて ←→（1回 24）で変えられる。表は 480 より、詳細は 360 より詰めない
  （両方は収まらない幅では表の 480 を守る）。仕切りにはつまみ（`ResizeHandle` の縦長の印）が見える。
  幅は `localStorage` の `tsukumo-task-board-list-width:v2` に px で保ち、再読み込み後も同じ（前の鍵 `:v1` は読まず消さない）。詳細が残りの幅。
  表は CSS の grid と `subgrid` で列をそろえ、列の見出しの行（高さ 32・転がしても上に残る）、段の見出し（12px・件数は等幅）、
  行（高さ 30・題 12px・番号 12px 等幅）の順。**選んでいる行は `--surface-accent` の地と `--accent` を 46% に薄めた細い枠**
  （色だけで伝えないため、枠の形も添える）。選んでいる件数の札は一段明るい地と字
  （`--surface-raised`・`--ink`）
- **状態の印**: サイドバー・サイドシート・モーダルの行・詳細・つながりのカードで、`TaskState`（印は `ui/icon` の絵）が同じものを出す。
  進行中 → `--accent` の中を塗った円（`CircleDotIcon`）＋「進行中」、着手可 → `--accent` の輪（`CircleIcon`）＋「着手可」、
  待ち → `--ink-quiet` の砂時計（`HourglassIcon`）＋「待ち <ID>」、
  保留 → `--state-warn` の円に二本線（`CirclePauseIcon`）＋「保留」（済んでいない依存があれば ID を添える）、
  ドラフト → `--ink-quiet` の破線の輪（`CircleDashedIcon`）＋「ドラフト」、
  完了 → `--ink-quiet` の円にチェック（`CircleCheckIcon`）＋「完了」、
  想定外の値 → `--state-warn` の円に感嘆符（`CircleAlertIcon`）＋値のまま。
  サイドバーの行は印だけで、語は `title` に持つ
- **属性**: タスクの `difficulty`・`loopable` は、ラベル（枠付きのバッジ）とは別の欄で出す。
  `loopable` が `Y` のものは ∞（`ui/icon` の `InfinityIcon`）の印で出し、`N` は印を出さない。
  色はサイドバーの行が `--state-ok`（待ちのあるとき 38% に薄める）、モーダルの行・詳細は `--ink-quiet`。
  サイドバーの行は2段目に難しさの目盛り（決まっているときだけ）と ∞（`todo`・`hold` の行に限る）を出す。
  モーダルの表は「難しさ」の列に3段の目盛り（6×3px・間 2px。haiku 1・sonnet 2・opus 3 を `--ink-soft` で塗り、残りは `--ink` の 22%）だけを置き、
  モデル名の語は出さない（名前は `role="img"` の `aria-label` と title の「難しさ <モデル名>」に持つ）。「ループ可」の列に ∞ を置く。
  詳細の情報の表の「難しさ」は目盛りと語、「ループ」は ∞ と「ループ可」（`N` は「手で進める」）。
  ∞ の名前は `role="img"` の `aria-label` に持つ。「Y」「N」の字は出さない
- **右の詳細**: 上下 22・左右 28。ID 13px 等幅（押すと写す口）、タイトル 20px 太字、情報の表 12px
  （行の間 8・角丸 10）。本文は 14px・行間 1.85、見出しは 16px 太字＋下線、コードは 12px 等幅、
  チェックは 14px。詳細は内側で縦にスクロールし、頭の1行・件数の帯・下の操作の帯は動かない
- **下の操作の帯**: 高さ 64。左端にキーの案内（12px・`--ink-quiet`、キーは等幅の枠）。ボタンは高さ 36（頼む口だけ 40）。「<キャラクター名> に頼む」は
  `--accent` の地で、押せない間は薄くして横に理由の字を添える。ドラフトでは代わりに
  「却下する」（枠。高さ 36）と「計画する」（`--accent` の地。高さ 40）を右寄せで並べる
- **つながりのカード**（見本2）: 高さ 38・角丸 9・間 6、地 `--ground`・枠 `--rule`。ID 12px 等幅＋状態＋
  要約 13px（1行で省略）＋右端に ›。カードの見出しは 12px で、「先に終わっていてほしいもの」は
  `--state-warn` の字、「これを待っているもの」は `--ink-quiet` の字
- **パンくず**（見本2）: 12px・高さ 20。「‹ <ID> に戻る」はリンクの色、区切りの › は `--ink-quiet`、
  いまの ID は等幅。「絞り込みの外」の添え書きは 12px の `--ink-quiet`
- **読み込み中**: 起こしてから最初の一覧が届くまで、サイドバーのタスクの節とこのモーダルの中身は、
  行の形をした帯3本（高さ 14・角丸 4・幅は 88%・72%・80%、色は `--ink` を 10% 重ねた色）で描く。
  文字の「不明」「読めない」は出さない。帯は 1.6 秒周期でゆっくり明滅し、`prefers-reduced-motion: reduce` では止める
- **狭い画面（760px 以下）は2列を縦に積む**（`docs/requirements.md` 4.7）。箱は画面の内側いっぱい
  （`100dvh` から余白を引いた高さ）で、一覧が上で高さは箱の 40% まで（内側でスクロールする）、詳細が残りの
  高さ（内側でスクロールする）、下の操作の帯は箱の下端に残す。仕切りは出さない。下の操作の帯のキーの案内は畳む

#### サイドバーのタスクの行とサイドシート

サイドバーのタスクの行と、そこから開くサイドシートの見た目。行の見本は
