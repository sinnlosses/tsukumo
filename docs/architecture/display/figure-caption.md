# 出力の分離（セリフと詳細）: 画像・図と表の題・書き上げる演出・入口の検査

戻り: `docs/architecture/display.md`「出力の分離（セリフと詳細）」

- **寸法は専用の部品を持たない**（`dimension`〔寸法図〕の部品は直近 28 日で使われた記録が 0 回で外した。寸法は `table` か、
  位置・重なりなら `svg` で書く。旧い記録の `dimension` は読み戻しで知らない種類の部品として落とす）
- **手で確かめた画面は `image` の部品で画像として見せる**（`path`〔撮ったファイル。絶対か cwd からの
  相対〕・`caption`〔何が見えるかの1行〕を受け、1つの部品に1枚）。**前後は `compare` の `relation: before-after` で左右に並べる**（旧い `beforeAfter` は受け口で書き換えて読む。`docs/architecture/adr/0047-compare-relation.md`）。
  **`checks` の行とは結ばない**（何を確かめた画像かは `caption` に書く）。
  画像は描いた `report` を受けた時点でサーバが1回読んでメモリの置き場に置き（復元のあとの読み直しは「画像を描く条件」）、
  鍵は `report` の呼び出しの id と部品に書かれたままのパスの組。ブラウザは `/report-image/<toolUseId>/<path>`（起動トークン付き）で
  置き場を引き、許可リストは `img` の `src` を `/report-image/` で始まる値だけに絞る（外部の URL・`data:`・ほかのパスは属性ごと落ちる）。
  置き場に置くときにファイルの頭から読めた幅と高さは、`report` の引数ではなくサーバが `report` のイベントと記録に載せ（`imageSizes`）、
  `img` の `width`・`height` になる（読めない画像には付けない）。`img` は `loading="lazy"`・`decoding="async"` で、配る画像は `private, max-age=3600`。
  読めない・置き場に無い・`src` が落ちた画像は「画像を出せない」のカードになる（枠ごと斜めの縞の面にし、中央に画像に斜線を引いた印、
  その下に「画像を出せない」とその理由の2行を置く。縞・印・2行は `aria-hidden` の飾りで、意味は役割 `img` の `aria-label` が言う）。
  逃げ道に書いた画像（`![]()` / `<img>`）は `image` の部品へ差し戻す。画像は押すと幅に合わせて拡大して見られる（読めないカードには入口が無い。前後の部品の中の画像は、前と後を入れかえて見られる別の面で開く。`block-table.md` の前後の部品）。
  置き場・消し方は「画像を描く条件」。題の扱いは次の「図と表の題」と同じ
- **画像のどこを見るかは `image` の `notes` に番号つきで添える**（`notes`〔1項目1文の説明の並び。
  既定は空〕を受ける。画像1枚と題という形が同じなので、新しい部品にしない）。**画像の上に番号の印は置かない**
  （座標はモデルが外しやすく、外れたかを機械で確かめられない）。並びに1始まりの番号を振り、場所は説明の文で言う
  （「左上の帯」のように場所から書き始める）。広い幅では画像の右に並びを置き、器が狭いときは画像の下に積む（`compare` と同じ境目）。
  並びは親の幅を取るので外枠を縮めない（`notes` が空なら本体の幅に縮める）。画像が読めないときも、並びは
  「画像を出せない」のカードの横に残る。6つ以上は `options`・`compare` と同じ違反で差し戻す
- **図と表には番号つきの題を付ける**。図（`image`・
  `compare`・`mermaid`・`graph`・`chart`・`timeline`・`svg`・`stats`）は題を本体の**下**に「図 n」、表（`table`・`matrix`・表として描く間の `plot`）は
  題を本体の**上**に「表 n」。番号は図と表を別々に、セクションをまたいで部品の並びの順に1から数える。
  `options` は候補の採否のカードなので数えない。**題が空でも番号は出し**（題の有無で番号の振り方が変わらない）、
  **`fold` で畳んだ中も数える**（畳んでも番号が飛ばない）。引数は `title`（`image` だけ `caption`）で、`mermaid`・`graph`・`chart`・`timeline`・`svg` は
  `title` を省いてよい。`stats` は `title` を持たないので、番号だけの題の行になる。
  **題は本体の幅を超えない**: `image`・`table`・`matrix`・`svg` は外枠が本体の幅に縮み（20rem を下限にして、
  短い表の題が何行にも折れないようにする）、題の行は外枠の幅で折り返す。親の幅を取る `chart`・`timeline`・`stats`・`compare` と、
  `pre` に描く `mermaid`・`graph` は、題と凡例の幅を図の幅の段にそろえる（段の選び方は次の項）。題の文字は inline code だけを解く（太字・リンクは効かない）
- **`mermaid`・`graph` の図は、文字 12px（CSS px。svg の自然な文字 16px × 縮尺）を守る幅の段で描く**。
  図を差したあと、描画後の svg の縮尺を 42em（`body`）→ 63em（`wide`）→ 読む面（`full`）の順に当てて測り、12px 以上になる最初の段にする。
  縮尺は svg の箱の幅と高さを `viewBox` の幅と高さで割った小さいほう（高さの上限 70cqh で縮むぶんも含む）。
  どの段でも下回る `flowchart LR`・`graph LR` は、描画側が先頭行を `TD` に置き換えて描き直す（書き手の `direction` は変えず、差し替えたことは図に出さない）。
  それでも下回る図は高さの上限を外して描き、自然幅が 42em の内幅に収まれば 42em のまま自然寸法で（`natural`）、超えれば読む面の幅にする（`scroll`）。
  `scroll` で自然幅が読む面の内幅を超えるとき、内幅まで縮めて文字が 12px 以上なら内幅に縮め、下回るなら自然寸法のまま `pre` の中で横にスクロールする（`Row` のセルの中では読む面がセルになる）。
  拡大のボタンは変えない。全部の段の外枠を本文の列の左端から始める（`body`・`natural` も中央には置かない。題は図の下・図の幅の中で中央。`screen-design/layout.md`「文字の揃え」）。
  段は描いた時点の幅で決め、ビューポートの幅が変わっても測り直さない。前後の部品の側の図は側の幅に収めるので段を当てない。
  確かめる場面は `report-graph-wide`（LR・12 ノード）・`report-graph-scroll`（横にスクロールする TD）、数は `capture-view.ts --paper-metric` の「svg の文字の最小 px」と「11px 未満の図」（差し戻しにはしない）
- **主経路の長い `graph` は、tsukumo が行を折り返して座標を決める**（`docs/architecture/adr/0034-figure-description-drawn-by-tsukumo.md`）。
  主経路は戻り道でないエッジで辿る最長の一本道で、**6 ノード以上**の図を `src/browser/components/page/conversation/domain/graph-fold.ts` が蛇行の行（偶数行は左から右、奇数行は右から左）に並べ、
  `svg` の部品と同じ外枠（拡大・縮み方も同じ）で描く。1行の数は 3〜6 個から、図を器（1440x900 のレポートの幅と図の高さの上限）に縦横比を保って収めたとき
  字がいちばん大きく見えるものを採る。主経路に無いノードはつながる主経路のノードの上の段に置き、隣り合わないエッジと戻り道は行のあいだの通り道と図の左の外側を回す。
  群は行ごとに属する箱だけを囲み、題は最初の囲みにだけ付ける。主経路に無いノードどうしのエッジ・同じノードの上の取り合い・戻り道でないエッジの輪がある図と、
  5 ノード以下の図は今の mermaid の経路で描く（カードの連鎖が先に当たる）。書き手の `direction` は折り返した図には効かない。確かめる場面は `report-graph-fold`
- **戻り道は `A <- B: 語`**（B から A へ戻るエッジ）。配色は書き手が書かず、印から tsukumo が決める: 色の目印の無い群は地の色を3色
  （`--graph-ground-1`〜`3`）で巡らせ、` @a`〜` @e` のノードは枠に加えて地を薄く塗り（`--graph-tone-fill-*`）、戻り道は `--graph-return` の破線にして凡例に「戻り道」を出す。
  変更の印（`+ `・`- `・`~ `）は戻り道と色の目印より先に効く。mermaid の経路と折り返し配置の両方に同じ規則を当てる
- **セクションを書き上げる演出の塊（トピック）の単位にする**（`docs/research/report-block-richness.md`
  2章）。見出しのレベルはセクションの中の副見出しにも、水平線はセクションの中の軽い区切りにも使われるので、DOM のタグからは
  境目を当てない。本文は欄ごとに入れ物を作り（`docs/architecture/adr/0031-report-body-as-regions.md`）、演出はセクションの欄の入れ物
  （`data-report-section`）1つを1トピックにする。見出しの無いセクションも欄1つなので1つのトピックになる。見出しの見た目は変えない。
  頭の欄（結論・検証結果）は筆の対象にせず、振り返りとお願いの欄は最後のセクションのトピックに入る
  （セクションの欄を持たない本文は全体が対象）。セクションの見出し（`h4`・`h5`）と図表の題の行は筆の対象から外して最初から出す（
  題の行を子に持つ外枠は対象にせず中の本体だけを書く）。演出の全体は10秒で終わり、上限をまたぐ塊はそこまでに書き切り、
  後ろの塊は上限の時刻に一度に出る。演出中だけ、ステップの右上に「全部出す」のボタンを出す
- **型で守られるようになった検査は外した**（表の見出し〔`table.title` が必須〕・`#` の見出し〔見出しは
  セクションの欄〕・本文の中のお願い〔`note` の種別に無い〕）。代わりに差し戻すのは、行のセルの数が `columns` と
  揃わない表・セクションが2つ以上あるのに見出しの無いセクション・**逃げ道の外側（HTML の塊の中でないところ）に部品の種類が
  ある記法**（`#` / `##` の見出し・表・箇条書き・`note`・`stats`・フェンス・mermaid）。最後の1つが無いと、
  本文を丸ごと逃げ道に入れて型を素通りできる。HTML の塊の中を見ないのは、複数の部品を `<details>` に
  まとめて畳む・並べるのが逃げ道の役目だから。記法は逃げ道を構文木（ブラウザと同じ remark の組）にして読み、
  ブラウザが記法として描く形だけを数える（HTML の行に空行なしで続く `- 項目`・段落に続く `2. 項目`・
  区切りの行のセル数が合わない表は数えない）。容れ物の深さは HTML の中の `<details>` / `<div>` のタグを
  1つずつ数えて決める（インラインコードの中は数えない）
- 崩れた部品・知らない種類の部品は入口で落とし、部品1つの読み損ねでレポートを捨てない。切り替える前の transcript の
  文字列の `body` は同じ入口で逃げ道の部品1つのセクションに畳むので、過去のレポートの見た目は変わらない
