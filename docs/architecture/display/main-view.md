# 各表示物: メインビュー（局面・最終と中間のレポート・畳み）

戻り: `docs/architecture/display.md`「各表示物」

- **メインビュー**: **ターンの局面ごとに、始め方の一覧 / 働くあいだの札 / レポートを出し分ける**（2026-10-02 決定。
  局面の判定・入れ替える瞬間は `docs/architecture/screen-design.md` 13.13）。
  **狭い画面（760px 以下）では見せ方だけが替わる**（2026-10-09 ユーザー決定。広い画面の見せ方は変えない）: 依頼は “ と1行、
  中間レポートは1段1行の一覧（✓・番号・題・所要・›）で、押すと下から上がる板でその段の中間レポートを読み、‹ › で前後の段へ移る。
  一覧の下に今の段と走っている手順の1行、渡したあとは一覧の下に最終レポートを広い画面と同じ描き方で流す。進み具合の帯は札の上端に
  置かず、同じものを画面の頭が持つ。寸法は `docs/architecture/screen-design.md` 13.9「狭い画面（760px 以下）」。
  **本文として出すのは確定したレポートだけ**で、札の上端の進み具合の帯は本文ではない（作業の**進行**——いま何をしているか、
  その依頼で実行中／終わった手順の一覧、失敗したツールの引数・出力——を、メインビューで見せる帯。
  2026-09-11 からは「レポートだけを出し、進行は帯の「いまの作業」が持つ」だった）。
  **ツールの実行は種類を問わずレポートに出ない。** ツールの記録から描くのは質問の記録と、進み具合の帯だけ。
  **レポートは `report` ツールで受け取る**（2026-09-24 決定）。`report` が1つでも呼ばれたターンは、
  最後の呼び出しを最終レポート、それより前を中間レポートにし、`report` の外に書いた本文は出さない。
  **段を進めた `work_plan` の段のまとめも中間レポートになる**（上の
  「ワークプラン」の「段が移ったときの中間レポート」）。
  **最終レポートの札（ラベル・箱を外すこと）は、いちばん新しいやり取りではそのやり取りが閉じている
  （ターンが動いておらず、バックグラウンドタスクも残っていない）ときだけ立つ**（2026-09-26 決定）。ターンが
  終わって本文が確定扱いになっても、バックグラウンドタスクを待つあいだや、通知で claude が続きのターンを
  自分で始めたあいだは、次の `report` でいま最後の本文が中間レポートへ回るかもしれない——確定して
  いないものに札を立てない。閉じるまでは中間レポートの枠にもせず、素の本文のまま出す。
  **ラベル（「中間レポート」「最終レポート」）は結論部の目録の1行の頭に置く**（2026-09-30。上の
  「タスクの作業のレポートは、結論部を「目録の1行・見出し・一文」の3段にする」）。最終レポートの
  ラベルは、中間レポートのあるやり取りか、本文に `task` があるときだけ出す。畳んだ中間レポートは
  `<summary>` がラベルと先頭行（段のまとめなら終えた段、`task` があれば結論。結論が空なら作業の名前）を持つので、目録の1行にはラベルを置かない。
  **`task` のある中間レポートの先頭行に作業の名前を使わない**（2026-10-01 決定）。同じ作業の中間レポートが
  全部同じ題で並び、見分けが付かなかった。
  **`report` が呼ばれなかったターンは、最後の本文（空白だけのものは除く）をそのまま最終レポートに
  する**（2026-09-24 決定）。それより前の本文は、資料らしい形をしていても出さない——中間レポートは
  `report` と段のまとめからしか生まれない。最後の本文の中身（日本語か、実況か）は問わない。判定は
  `main-view.ts` の `selectLastText`（それまで積んでいた実況・英訳・資料の判定と、その経緯は
  `docs/history/decision.md`）。
  （**英訳の出どころは Claude Code の催促**——ターンが `speak` で終わり本文が空だと、Claude Code が
  英語の固定文を利用者の発言として差し込み、モデルがレポートを英語で書き直す。2026-09-23 決定で、
  ターンを本文で終えさせ、催促の入口そのものを塞いだ。2026-09-24 に `report` ツールへ移ってからは
  「`report` → 締めの `speak` → 「完了」の1行」の順で終えさせ、最後の1行で催促の入口を塞いだ。
  **2026-09-25 に「完了」の1行の条を外した**（ユーザー決定）——`report` を呼ばないターンでは
  その1行が最終レポートとして画面に出たため。催促は子プロセスへ渡す環境変数で塞ぐ
  （`docs/architecture/chat-mode.md` 4.9）。2026-09-27 に、通った `report` でターンを閉じ、締めのセリフを
  `report` の `closing` へ移した。締めの言い方の条は `persona.md`「締めのセリフの言い方」）
  **規約の条項は残す**（`report-notation.ts` の「前置きと締めを書かない」「レポートは必ず日本語で
  書く」など。素の TUI では tsukumo 側の判定が効かないため）。
  **中間レポートは1ターンに何件でも積む**。**1ターンの上限（`MAX_MAIN_VIEW_ENTRIES`＝40）は、画面に出るもの
  （レポート・質問の記録）だけを数える**——ツールの実行はメインビューに出ないので数えない。
  **この上限は実際には当たらない**（実測は `docs/history/decision.md`）——値を上げるのではなく、
  1つのやり取りが際限なく伸びたときの止めとして置いてある。超えた分は既存どおり古いほうから落として件数だけを残す。
  **中間レポートは見分けが付く形で出す**: 地は最終レポートと同じ `surface` のまま、枠を破線にし、「中間レポート」の
  小さなラベルを載せる（新しい色は作らない。
  `docs/architecture/screen-design.md` 13章）。**最終レポートは箱（枠・内側の余白）を持たず**、領域の `surface` を
  紙にする（2026-10-03。札は枠を持たない、の決定を本文まで広げた）。中間レポートの破線の箱と
  箱のない最終レポートは形で見分ける。
  **`memo` の `note` と塊の `aside` は、本文の列の右の余白の柱に出す**（2026-10-17 利用者決定。Distill の gutter・Tufte の傍注に倣い、
  補足を走り読みの経路から外す）。余白の柱の傍注は直前の塊の上端に揃え、本文の列は1本のまま（2段組にしない。Z 字に読ませない決定とは別の形）。
  本文の列の右に 160px 以上空かないときは、余白の柱に出すものを塊の直後の1行として本文の中に畳む。余白の柱は書き上げる演出の対象外で、
  最初から出す。寸法は `docs/architecture/screen-design.md`「余白の柱」。
  **あとに別のレポートが出た中間レポートは畳む**（2026-09-16 決定。全部開いたまま積むと、
  ターンが長いほど画面が伸びるため）。**まだ追い越されていない最後の中間レポートは
  開いたまま**にする。畳んだ `<summary>` には「中間レポート」＋本文の先頭行（見出しなら記号を
  落としてその語）を出す。畳んだ中身は DOM に残す（記録からは消さない）。
  **最終レポートのある閉じたやり取りは、中間レポートを「経過の畳み」1つにまとめて最終レポートの下に置く**（2026-10-18 利用者決定。
  中間が多いやり取りほど、最終レポートが中間の下に回って最初の1画面から落ちていたため。見本は
  `docs/history/mockup/report-reading-tool-2026-10-18/after-full-w1400.png`）。経過の畳みは閉じた `<details>` で、
  `<summary>` は「経過 n 件」（n は中間レポートの数）に、段のまとめがあれば「 · 所要 <合計>（<段> <所要> · …）」を添える
  （測れなかった段があれば合計は出さない）。開くと中間レポートを届いた順に、上の1行の畳みの形で並べる。
  働くあいだと、最終レポートの無いまま閉じたやり取り（失敗・止めた）は経過の畳みを置かず、上の畳み方のまま届いた順に並べる。
  見出しの一覧（やり取りの列の見出しの行）は閉じた畳みの中を拾わないので、最終レポートの見出しだけが並ぶ。
  **利用者がそのやり取りを働いているあいだに中間レポートを見ていたときだけ**、最終レポートの `##` のうち最後の中間レポートに
  無かった節（`sections[].heading` の字が同じなら同じ節で、記号を含んでいても字そのもので比べる。描いた字や組んだ Markdown では比べない）の行の右に、accent の小さな字「新」を出す
  （初めて開いた閉じたやり取りには出さない。会話の間だけ覚え〔セッションが替わるまで。画面を隠して戻しても残す〕、その行を押すと消える。列を畳んでいるあいだは見えない）。
