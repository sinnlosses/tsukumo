# 各表示物: 入力欄・配り方・フォールバック

戻り: `docs/architecture/display.md`「各表示物」

- **入力欄**: 右下（4.7）。v1 で持つのは (1) 複数行入力＋送信、(2) 実行中の中断、
  (3) `/` のコマンド補完（`system` の `init` の `slash_commands` から）、(4) **経過時間の表示**
  （送信ボタンと同じ行。2026-09-12 決定）、
  (5) **`@` のファイル補完**（2026-09-18 決定）の5つ。
  **レポートの字を選んで、読んだ箇所を指して聞ける**（「引いて聞く」）: メインビューのレポートの本文（`data-report-body` の中。
  質問の記録・お伺いの詳細では出さない）で字を選び終えたとき（pointerup・選択のキー操作のあと）だけ、
  選択の最後の行の下端に付けて、小さな口（見える面は高さ約14px。押せる的は見えない余白で24px以上に保つ）を出す。
  行の隙間（選択の下端から次の行の字の上端まで約8px）には収まらないので、次の行の字の上端を約5px覆う。選択が消える・Escape・口の外を押す・スクロールで消える。
  押すと、選んだ字（前後の空白は落とし、300字で切って切ったら末尾に …）の各行の頭に `> ` を付け、
  空行を1つ挟んで下書きの頭に入れる（既にある下書きはその後ろに残す）。キャレットは下書きの末尾で、入力欄にフォーカスする。
  口を出しても選択は消さず、⌘C の働きは変えない。
  **狭い画面（760px 以下）では見せ方と止め方が替わる**（2026-10-09 ユーザー決定。広い画面の入力欄は変えない）: ＋ の口から
  画像の添付・`/` の補完・`@` の補完の3つを選び、右の1つのボタンがターン進行中は止める、それ以外は送るになる。
  **止めるは「止める」「続ける」で確かめてから中断を送る**（広い画面の「中断」は確かめない）。
  経過時間の行は出さず、経過は画面の頭が持つ。行に出していた API の知らせは、「利用上限に達した」と、雑談のときの再試行中・
  失敗の理由だけを入力欄の上の1行に出す
  （形・寸法・置き文字は `docs/architecture/screen-design.md` 13.9「狭い画面（760px 以下）」）。
  **仕事のときは、(4) の経過時間と、下の API の知らせのうち再試行中・失敗の理由を入力欄の行に出さず、
  進み具合の帯（経過・所要・再試行中）とレポートの頭の失敗の塊が持つ**（2026-10-02。`docs/architecture/screen-design.md`
  13.13「進み具合の帯」と「失敗の塊」。同じことを2か所に出さない）。**この行に残すのは「利用上限に達した」だけ**（いま送っても
  通らないことは送る手の目の前に要り、狭い画面でも入力欄のすぐ上に見えている）。
  雑談モードは帯も失敗の塊も無いので、下の2段落の形のまま経過・再試行中・失敗の理由も行に出す。
  **経過時間の行には API の知らせも出す**（2026-09-24 決定。4.1）: 経過時間の左に小さな枠を1つ
  置き、**再試行中**（`再試行中 2/10`。理由と待ち時間は `title`）・**利用上限に達した**
  （`利用上限 18:00まで`。別の日なら `9/26 18:00まで`）・**失敗で終わったターンの理由**
  （`API が混んでいて受け付けなかった`。内部の綴りは `title`）の順に強く、出すのは1つだけ。**「利用上限が近い」は
  出さない**（2026-09-27 ユーザー決定。枠の残り具合はサイドバーのプラン使用量の札が出す）。
  続く・まだ使えるものは枠と字が `--state-warn`、止まった・使えないものは `--state-ng` で、
  **意味は字が言う**（色だけに頼らない）。道具の口の横に収まらなければ、経過時間の
  行ごと次の段へ送り、それでも収まらなければ末尾を省略する（全文は `title` とメインビュー）。
  **失敗で終わったターンは経過時間の字も「所要」ではなく「失敗」にする**。帯の「いまの作業」の
  語は変えない（再試行中も作業中のまま。`docs/architecture/screen-design.md` 13.9「いまの作業」）。
  **経過時間は「依頼を送ってから、バックグラウンドタスクが残っていない状態でそのターンが終わるまで」**
  （2026-09-12 決定。バックグラウンドタスクを跨ぐ扱いは 2026-09-27 決定）。委譲した先が背景で動いたままターンが
  一旦終わっても、バックグラウンドタスクが残っている間は「経過」のまま数え続け、claude が自分で始めた
  続きのターン（`turn-resumed`）でも起点は依頼を送った時刻のまま付け直さない。バックグラウンドタスクが
  残っていないターンの終わりで初めてその値で止まり（失敗なら「失敗」）、次の依頼で0から始まる。
  **(1) の割り当ては Enter で改行、Command+Enter で送信**（2026-09-12 決定）。
  IME の変換確定の Command+Enter は送信に
  しない。送信ボタンには Command+Enter を示す記号を添える
  （`docs/architecture/screen-design.md` 13.13「札を移るキーと送るキーの案内」）。
  **(3) の絞り方は Claude Code の TUI の手触りに寄せる**（2026-09-12 決定）:
  絞り方は**前方一致を先に、続けて部分一致**を出す（各グループの中はアルファベット順、
  合計最大10件。入力が `/` だけのときはアルファベット順の先頭10件）。確定キーは
  **Tab・Enter のどちらも確定だけ**（引数を続けて打てる。送信は Command+Enter に一本化した
  ので、確定と送信を同じキーで兼ねない）。
  **選択の上下移動は矢印キーに加えて `Ctrl+P`（前へ）・`Ctrl+N`（次へ）でも行える**
  （2026-09-16 決定。macOS のテキスト入力では emacs 風に `Ctrl+P` / `Ctrl+N` がキャレット移動へ
  割り当たっているため、候補が出ている間だけ奪って `preventDefault` する。`Meta`
  （Command）と組み合わせたときは反応しない。候補が出ていないときは何もしない）。
  **候補には説明を添える**（2026-09-12 決定）。説明は SDK の `supportedCommands()`（と、以降の
  変化を押してくる `system` の `commands_changed`）が名前と一緒に返すものをそのまま出し、
  **tsukumo 側に説明の表を持たない**（組み込みコマンドの分も SDK が返す）。説明が無いものは
  名前だけで出す。
  **`init` は最初の依頼を送るまで届かない**。それまでの候補は
  `supportedCommands()` が返した一覧をそのまま使い、**その間だけ端末専用コマンドの除外が効かない**
  （`init` が届いた時点で除外込みの一覧に戻る）。ブラウザ側は**0件を掴んでもキャッシュせず**、
  次に `/` を打ったときに取り直す（起動直後に `/` を打ったタブが空のまま固定されないため）。
  **(5) の候補は git 管理下のファイル**（`git ls-files`。git リポジトリでないディレクトリでは
  候補を出さない。2026-09-18 決定）。**候補に出すのはパスだけで、ファイルの中身は読まない。**
  合図は**行頭または空白の直後の `@`**で、そこからキャレットまでに空白が入ったら終わり
  （`@` は文中にも出るので、(3) の「先頭かつ空白なし」は使えない）。
  絞り方は (3) に合わせて**前方一致を先に、続けて部分一致**（各グループの中は辞書順、合計最大
  10件）で、**そこだけ大文字小文字を区別しない**（打った綴りのまま `README.md` に当てられる）。
  キー操作も (3) と同じで、確定すると**キャレットの直前の `@<打ちかけ>` が `@<リポジトリ相対パス> `
  に置き換わる**（前後に書いた文は触らない。すぐ後ろがすでに空白なら末尾の空白は足さない）。
  **(3) と (5) の候補は同時に出ない。**
  一覧は**サーバへの問い合わせ1本**（手続き `repository.listFiles`。起動トークンが要る）で1回取り、
  **絞り込みはブラウザ側**で行う（打鍵のたびに `git ls-files` を起こさない）。
  応答は `{ paths, omittedCount }` で、サーバは 20000 件を超えた分を並びの後ろから落とし、落とした件数を
  `omittedCount` に載せる。**落としたときは、候補の末尾に「一部のみ（ほか N 件は候補に出ません）」の
  一言を添える**（候補が0件でも出す。選べる候補には数えない。2026-10-16 決定）。20000 件以下では出ない
  **入力履歴と繰り返しの仕組みは次**（v1 に含めない）。ファイルの貼り付けはしない（2.2）が、
  **画像は貼り付け・ドロップ・画像のボタンで受け取る**（4.10）。**入力欄の下の `/` と `@` の
  ボタンは、キャレットの位置にその1文字を打つのと同じ**（補完が開くかは打ったときと同じ規則。
  `@` は前が空白でなければ空白を挟む。2026-09-23 決定）。
  **打ちかけは入力が1秒止まったらセッションごとに `localStorage` へ保ち（直近10セッション分。文面とキャレットだけで、画像は保たない）、再読み込み後に入力欄が空なら戻す。送信すると消す。**
  **入力欄は素の `<textarea>` と、書きながら装飾が見えるマークダウンエディタを切り替えられる**
  （2026-09-26 決定）。エディタは見出し・太字・コードなどにその場で字の大きさ・太さ・色を付け、
  **キャレット（選択範囲）の無い行の記号（`#`・`**`・`` ` ``・`>`・リンクの `(URL)` など）は隠して
  装飾だけを見せ、キャレットのある行では記号を字の色を落として出す**（2026-10-01 決定）。コードフェンスはキャレットがフェンスの中に
  あれば開きと閉じの記号を両方出す。箇条書きの印は `•`、引用は行の左の罫で見せ、隠したリンクの
  行き先は字に添える（マウスを置くと出る）。番号付きの印と表は記号のまま。**下書きは1つ**で、切り替えても書いた字・キャレットの位置・添えた
  画像はそのまま残る。**Enter で改行・Command+Enter で送信・`/` と `@` の補完・画像の貼り付けと
  ドロップはエディタでも同じ**。切り替えの口は道具の行のボタン1つ（キーは付けない）で、選んだ
  モードは利用者の端末に覚え（`localStorage`）、既定は `<textarea>`。**エディタの面にだけ、面の
  上に書式のボタン**（太字・斜体・取り消し線・コード・リンク・箇条書き・引用）**の行が出る**。
  選んだ範囲を Markdown の記号で囲み（行の書式は行頭に付ける。範囲が無いときは記号の対だけ入れて
  間にキャレットを置く）、書式のキーは付けない。**範囲を選んで `http://` か `https://` の URL を
  貼ると `[選んだ字](URL)` になる**（範囲が無いとき・URL でないとき・画像はそのまま）。
  部品の選定とつなぎ方は `docs/research/markdown-composer.md`
- **配り方**: HTML は**ファイルに書き出さず**、`127.0.0.1` にだけバインドしたローカルの HTTP
  サーバからメモリのまま配る（`docs/architecture/adr/0017-serve-from-local-http.md`）。
  **会話の内容をディスクに書く経路を作らない**。**サーバはイベントと状態を
  WebSocket 1本で押し、ブラウザ側の部品が描く**（2026-09-13 決定。`docs/architecture.md`「shared」。
  ページの URL に起動トークンが付く）
- **フォールバック**: 表示できないものがあっても**残りを表示して動作を続ける**。
  立ち絵の素材が無い環境では**セリフだけを表示する**、`orca` コマンドが無い環境では
  **タブを開かずに配信だけ続ける**。表示物が1つ欠けたことを理由に起動失敗にしない
- **VOICEVOX の口パク同期は後回しでよい**（MVP に含めない。2.2 の「検討しない」より**こちらを正典にする**）。**タイプライター表示は既に別の形で
  入っている** — 本文を塊ごとに出す「書き上げる演出」（4.3）がそれに当たるので、同じ機能を
  もう一度提案しない
