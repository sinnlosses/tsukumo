# タスク運用: 新しい /loop の流れの段階

入口は `docs/workflow.md`（このリポジトリでのタスク運用の上乗せ）。

責務: 夜間の掃除や自動の振り返りのような新しい `/loop` の流れを入れる順序と、段階を上げる条件を持つ。
読む時: 新しい `/loop` の流れを入れる、既にある流れの段階を上げ下げするとき。
直す時: 段階や上げる条件を変えたとき。

## 新しい `/loop` の流れの段階

新しい流れは4段階を順に上げる。段階を飛ばさない。上げる条件は、判定の期日（送り出しから14日）の数と、その間の成功・誤りの件数で書く。

| 段階 | 何をするか                     | 上げる条件                                                     |
| ---- | ------------------------------ | -------------------------------------------------------------- |
| 1    | 手のリハーサル（人が手で通す） | 直近3回が成功、誤り0件                                         |
| 2    | 報告だけ（書き換えない）       | 判定の期日を2回迎え、その間の報告が直近5件とも成功、誤り0件    |
| 3    | 人の承認つきの書き換え         | 判定の期日を2回迎え、その間の書き換えが直近10件で承認、誤り0件 |
| 4    | 有界な自律（回数と範囲に上限） | 上げる先は無い                                                 |

- 誤り: 人が取り消した書き換え、事実と違う報告、範囲の外への書き込み。
- どの段階でも、誤りが1件出たら1段戻す。
- 期日の判定は、流れの記録の件数を読んで行い、数えた件数を結果に書く。
