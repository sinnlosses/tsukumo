# タスク運用: 参考に示された画像・ディレクトリを残す

入口は `docs/workflow.md`（このリポジトリでのタスク運用の上乗せ）。

責務: 指示で参考に示された画像・ディレクトリを、タスクにする時点で残す手順を持つ。
読む時: 参考にするモックやスクリーンショットが示されたタスクを書くとき。
直す時: 残し方（置き場・タスク本文への書き写し）を変えたとき。

## 参考に示された画像・ディレクトリを残す（2026-09-23 決定）

**指示で参考に示されたものは、タスクにする時点でリポジトリに写すか、中身をタスク本文に
書き写す。** `~/Downloads/` やリポジトリ直下に置かれたままのファイルは、着手するまでに
消えたり動いたりする（2026-09-20・09-22 に示されたスクリーンショット3枚は、いまはもう無い）。

| 示されたもの                                  | どう残すか                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| --------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| デザインのモック（画像・HTML）                | `docs/history/mockup/<主題>-<YYYY-MM-DD>.<拡張子>` に写してコミットし、タスク本文にそのパスを書く。本文の「決まっていること」には、見本の寸法・記号・並び（字の大きさ・色の役割・行頭の記号・数を置く位置）を箇条で写す。HTML は写したあと `node scripts/capture/mockup-font-floor.ts <パス>` を打ち、字の下限（12px）を下回る値が出たら、本文には 12px に上げて書く。HTML は 1440x900 で撮った画像を同じ名前の `.png` で添える（外のフォントや画像に頼る HTML は、あとで開くと見た目が変わる）。ディレクトリで示されたら、参考にするファイルだけを写す |
| 動いている tsukumo の画面のスクリーンショット | モックと同じく `docs/history/mockup/` に写してコミットする（会話が写っているが、ユーザーが 2026-09-23 に許した。`docs/coding-standards.md`「会話内容の扱い」）。見て分かったこと（どの要素がどこでどうなっているか）もタスク本文に書く                                                                                                                                                                                                                                                                                                                  |
| よそのリポジトリ・ディレクトリ                | 写さない。タスク本文に `<パス> @ <コミットハッシュ>` の形で書き、参考にした中身（名前の付け方・構成など）を本文に書き写す                                                                                                                                                                                                                                                                                                                                                                                                                               |

- **入力欄に貼った画像は、Claude Code が一時ファイルに書き出している。** 会話に届く画像の
  見出し（`[Image: source: /private/tmp/claude-<uid>/…/images/<n>.png …]`）のパスから、消える前に
  `docs/history/mockup/` へ写す（tsukumo 側は `src/server/session-driver/core/prompt-image-shelf.ts` の
  メモリにしか持たない）。パスが消えていたら、利用者がファイルに保存してパスで示す
