# 人向けの入口

ステータス: **図解**（正典は各図の直後の表に名指す文書。規則を言い直さない）。入口は `README.md`。

責務: リポジトリの全体像を人が掴むための図解の入口と、読む順を持つ。
読む時: はじめてリポジトリを読むとき、全体の構成を図で見たいとき。
直す時: 図解の子のファイル（`docs/guide/`）を足したとき、読む順を変えるとき。

## はじめて読む人の読む順

1. `README.md`
2. `docs/guide/overview.md` の全体図（プロセス・層・画面の領域）
3. `docs/guide/domain-map.md` の用語の関係図（会話・作業・キャラクターの主な語）
4. `docs/guide/flow-conversation.md` の会話の基本の流れ（起動・依頼・許可と質問・差し戻し）
5. `docs/guide/flow-session-and-delegation.md` のセッションの起こし直しと委譲の流れ
6. `docs/guide/screen-tour.md` の画面の見て回り方（見本帳・状態のカタログ・疑似セッション）

以降の図解は、後続のタスクが1行ずつ足す。
