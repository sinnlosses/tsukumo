# コーディング規約: 外へ送る操作の承認

ステータス: **正典**。入口は `docs/coding-standards.md`（規約の理由と例外の入口と、子のファイルの一覧）。

責務: 承認が要る外部への操作の一覧と、hook が見分ける形を持つ。
読む時: `gh`・`git push` など外へ送るコマンドを打つ・委譲先に渡すとき、外へ送る操作を見る hook を足す・直すとき。
直す時: 承認が要る操作・その例外・hook が見分ける形を変えたとき。

## 承認が要る外部への操作

次の操作は、人の承認を得てから打つ。承認の範囲と例外の正典は `AGENTS.md`「承認が要ること」で、ここはその中の外部への送信を、打つコマンドの形に開いた一覧。

| 操作                           | 例                                                                                                                                                                                                                                                                                                           | 承認の例外                                                 | hook が見分けるか            |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------- | ---------------------------- |
| GitHub への書き込み            | `gh` の群 `issue`・`pr`・`label`・`release`・`repo`・`gist`・`project`・`secret`・`variable`・`workflow`・`run`・`cache`・`ssh-key`・`gpg-key` で、動詞が `list`・`view`・`status`・`diff`・`checks`・`search`・`download`・`watch`・`clone`・`checkout` 以外のもの（`gh issue create`・`gh pr merge` など） | `tw` が行う書き込み（`AGENTS.md`「承認が要ること」の括弧） | 見ない（いまは hook が無い） |
| `gh api` の書き込みの形        | `-X`/`--method` の値が GET 以外、方法の指定が無く `-f`/`-F`/`--field`/`--raw-field`/`--input` がある（gh が POST にする）、`graphql` で `mutation` を送る                                                                                                                                                    | 同上                                                       | 見ない（いまは hook が無い） |
| `git push`                     | `git push`・`git -C <dir> push origin main`（`--dry-run`/`-n` は送らないので外れる）                                                                                                                                                                                                                         | なし（`tw ship`・`pnpm run ship` は push しない）          | 見ない（いまは hook が無い） |
| パッケージ・成果物の公開       | `npm publish`・`pnpm publish` など                                                                                                                                                                                                                                                                           | なし                                                       | 見ない                       |
| そのほかの外部サービスへの送信 | `curl -X POST` など、外のサービスへ中身を送るもの                                                                                                                                                                                                                                                            | なし                                                       | 見ない                       |

`gh auth`・`gh config` のように上の群に無いものは外への送信ではない。認証情報や設定の変更は `AGENTS.md`「承認が要ること」の別の項で承認が要る。
